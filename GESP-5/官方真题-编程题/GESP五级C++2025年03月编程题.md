# 编程题1解析


你好！我是你的 GESP/NOI 竞赛培训老师。这道题目是 GESP C++ 五级考试中非常经典的一道**贪心算法**题目。它考察了学生对问题的转化能力、贪心策略的选择以及基础的数据处理能力。

下面我将按照你的要求，对这道题进行深度的解析。

---

### 1. 题意的理解

*   **背景**：小 A 有 $2n$ 件物品，要卖给小 B 和小 C。
*   **限制条件**：
    1.  每件物品只能卖给一个人（要么 B，要么 C）。
    2.  小 B 必须恰好买走 $n$ 件物品。
    3.  小 C 必须恰好买走 $n$ 件物品。
*   **目标**：对于第 $i$ 件物品，卖给 B 的价格是 $b_i$，卖给 C 的价格是 $c_i$。求小 A 卖出所有物品能获得的**最大总收入**。

**通俗理解**：
我们有 $2n$ 个“坑位”，一半归 B，一半归 C。每件物品都有两个身价，我们需要决定每件物品归谁，使得总价最高，且最终 B 和 C 手里的物品数量严格相等。

---

### 2. 题目核心要求

*   **算法策略**：贪心算法。
*   **数据处理**：数组排序。
*   **时间复杂度**：主要消耗在排序上，为 $O(N \log N)$。鉴于 $n \le 10^5$，即物品总数 $2n \le 2 \times 10^5$，这个复杂度完全可以在 1.0s 内跑完。
*   **数据类型**：由于价格最高可达 $10^9$，且有 $2 \times 10^5$ 件物品，总金额可能达到 $10^{14}$ 级别，**必须使用 `long long`** 存储结果。

---

### 3. 解题思路

这道题如果直接去想“怎么分”，容易陷入动态规划或者复杂的组合逻辑中。我们采用**“基准 + 补偿”**的思维模型（也叫差价法）：

1.  **假设基准**：假设我们非常“偏心”，先把**所有**的 $2n$ 件物品都卖给小 B。
    *   此时总收入为：$\sum_{i=1}^{2n} b_i$。
    *   此时状态为：小 B 有 $2n$ 件物品，小 C 有 $0$ 件物品。

2.  **调整平衡**：题目要求小 B 和小 C 各拿 $n$ 件。目前 B 多了 $n$ 件，C 少了 $n$ 件。
    *   我们需要从这 $2n$ 件物品中，选出 $n$ 件物品，“转卖”给小 C。

3.  **计算代价/收益**：
    *   如果我们将第 $i$ 件物品从卖给 B 改为卖给 C，收入的变化量是 $c_i - b_i$。
    *   为了让总收入最大，我们应该选择那些**“转卖给 C 后收益增加最多”**（或者**“亏损最少”**）的物品。

4.  **贪心策略**：
    *   计算每件物品的差价 $d_i = c_i - b_i$。
    *   将差价数组 $d$ 从大到小排序。
    *   选取前 $n$ 个最大的差价对应的物品转卖给 C。

5.  **最终公式**：
    *   最大收入 = (所有物品卖给 B 的总价) + (选出的 $n$ 个最大的差价之和)。

---

### 4. 样例的分析

**样例 1 分析：**

*   **输入**：
    *   $n = 3$（共 6 件物品）
    *   $b = [1, 3, 5, 6, 8, 10]$
    *   $c = [2, 4, 6, 7, 9, 11]$

*   **步骤 1：全卖给 B**
    *   基础收入 = $1+3+5+6+8+10 = 33$。
    *   此时 B 有 6 件，C 有 0 件。

*   **步骤 2：计算差价 $d_i = c_i - b_i$**
    *   $d = [2-1, 4-3, 6-5, 7-6, 9-8, 11-10]$
    *   $d = [1, 1, 1, 1, 1, 1]$

*   **步骤 3：选择转卖**
    *   我们需要选 $n=3$ 件转卖给 C。
    *   因为差价全是 1，随便选 3 个，增加的收益都是 $1+1+1=3$。

*   **步骤 4：计算结果**
    *   总收入 = $33 + 3 = 36$。
    *   **输出：36**。与样例一致。

**样例 2 分析：**

*   **输入**：
    *   $n = 2$（共 4 件物品）
    *   $b = [6, 7, 9, 9]$
    *   $c = [1, 2, 10, 12]$

*   **步骤 1：全卖给 B**
    *   基础收入 = $6+7+9+9 = 31$。

*   **步骤 2：计算差价 $d_i = c_i - b_i$**
    *   $d = [1-6, 2-7, 10-9, 12-9]$
    *   $d = [-5, -5, 1, 3]$

*   **步骤 3：排序并选择**
    *   差价从大到小排序：$[3, 1, -5, -5]$。
    *   我们需要选 $n=2$ 件转卖给 C。
    *   选最大的两个差价：$3$ 和 $1$。
    *   增加的收益 = $3 + 1 = 4$。

*   **步骤 4：计算结果**
    *   总收入 = $31 + 4 = 35$。
    *   **输出：35**。与样例一致。

### 5. 完整的代码和逻辑解析

这里提供一份标准的 C++ 题解代码，并附带详细注释。

```cpp
#include <iostream>
#include <vector>
#include <algorithm> // 用于 sort

using namespace std;

// 定义最大数组大小，题目 n <= 1e5，所以物品总数 <= 2e5
const int MAX_N = 200005;

int main() {
    // 优化输入输出速度（可选，但在竞赛中是好习惯）
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    if (!(cin >> n)) return 0;

    vector<long long> b(2 * n);
    vector<long long> c(2 * n);
    vector<long long> diff(2 * n); // 存储差价 c[i] - b[i]

    // 1. 输入 B 的价格
    for (int i = 0; i < 2 * n; i++) {
        cin >> b[i];
    }

    // 2. 输入 C 的价格，并同时计算差价
    for (int i = 0; i < 2 * n; i++) {
        cin >> c[i];
        diff[i] = c[i] - b[i];
    }

    // 3. 计算基准收入：假设全卖给 B
    long long total_income = 0;
    for (int i = 0; i < 2 * n; i++) {
        total_income += b[i];
    }

    // 4. 贪心核心：对差价进行排序
    // 默认是从小到大排序
    sort(diff.begin(), diff.end());

    // 5. 选取最大的 n 个差价加到总收入中
    // 因为 sort 是升序，最大的 n 个数在数组的最后面
    for (int i = n; i < 2 * n; i++) {
        total_income += diff[i];
    }

    // 6. 输出结果
    cout << total_income << endl;

    return 0;
}
```

### 6. 参考代码的逻辑解析和注释

针对你提供的官方参考代码进行逐行解析：

```cpp
#include <bits/stdc++.h> // 万能头文件，包含所有标准库
using namespace std;

const int N = 2e5 + 5; // 定义常量 N，略大于题目最大数据范围 2*10^5
int n;
long long b[N], c[N], d[N]; // b, c 存价格，d 存差价。必须用 long long 防止溢出
long long ans; // 答案累加器，必须 long long

int main() {
    // 输入 n
    scanf("%d", &n);
    // assert 是断言，用于调试，确保输入符合题目范围，竞赛提交时可忽略
    assert(1 <= n && n <= 1e5);

    // 输入 b 数组
    for (int i = 1; i <= 2 * n; i++) {
        scanf("%lld", &b[i]);
        assert(0 <= b[i] && b[i] <= 1e9);
    }

    // 输入 c 数组
    for (int i = 1; i <= 2 * n; i++) {
        scanf("%lld", &c[i]);
        assert(0 <= c[i] && c[i] <= 1e9);
    }

    // 核心逻辑开始
    for (int i = 1; i <= 2 * n; i++) {
        ans += b[i];          // 第一步：先把所有物品按 B 的价格加进答案 (全卖给 B)
        d[i] = c[i] - b[i];   // 第二步：计算每件物品卖给 C 相对于卖给 B 的差价
    }

    // 第三步：对差价数组排序。默认是从小到大 (升序)
    sort(d + 1, d + 2 * n + 1);

    // 第四步：贪心选取。
    // 因为数组是升序的，最大的 n 个数位于下标 [n+1, 2n] 的区间内
    for (int i = n + 1; i <= 2 * n; i++) {
        ans += d[i]; // 加上这些差价，相当于把这些物品“转卖”给了 C
    }

    printf("%lld\n", ans);
    return 0;
}
```

### 7. 易错点和注意事项

1.  **数据溢出（最重要！）**：
    *   题目中 $n$ 最大为 $10^5$，价格最大为 $10^9$。
    *   总价值最大可能达到 $10^5 \times 10^9 = 10^{14}$。
    *   `int` 的最大值约为 $2 \times 10^9$，远远存不下答案。
    *   **必须**将存储总价的变量（`ans`）以及价格数组（`b`, `c`）和差价数组（`d`）定义为 `long long` 类型。

2.  **排序方向与下标**：
    *   `std::sort` 默认是**从小到大**排序。
    *   数组总长度是 $2n$。
    *   我们需要最大的 $n$ 个差价。
    *   排序后，数组的前半部分 $[1, n]$ 是较小的差价，后半部分 $[n+1, 2n]$ 是较大的差价。
    *   所以循环累加时，是从 `i = n + 1` 开始，而不是从 `1` 开始。

3.  **逻辑转换**：
    *   初学者容易试图用双重循环或者复杂的 `if-else` 来判断每件物品给谁，这会导致逻辑混乱且超时。
    *   一定要掌握“**先全给一方，再通过差价调整给另一方**”的模型，这是解决此类“二选一且数量固定”问题的通法。

# 编程题2解析

你好！我是你的GESP、NOI竞赛培训老师。这道题目是典型的**数论（Number Theory）**应用题，涉及**原根（Primitive Root）**的判定。

虽然题目背景看起来很数学，但只要掌握了数论中的几个核心定理，这道题其实是一道标准的“模板题”。对于GESP五级及以上或NOIP选手来说，**快速幂**和**质因数分解**是必须掌握的基本功。

下面我为你详细拆解这道题：

---

### 1. 题意的理解
题目要求判断给定的整数 $a$ 是否为质数 $p$ 的原根。题目给出了原根的定义：
1.  $1 < a < p$。
2.  $a^{p-1} \pmod p = 1$（这是费马小定理，对于质数 $p$ 和 $a$ 不整除 $p$ 必然成立）。
3.  对于任意 $1 \le i < p-1$，都有 $a^i \pmod p \neq 1$。

**通俗解释：**
$a$ 的幂次模 $p$ 的结果会循环。这个循环的最小正周期如果是 $p-1$，那么 $a$ 就是原根。也就是说，$a^1, a^2, ..., a^{p-1}$ 模 $p$ 的结果互不相同，且填满了 $1$ 到 $p-1$ 的所有整数。

### 2. 题目核心要求
-   **输入规模大：** $p$ 高达 $10^9$。这意味着我们不能使用 $O(p)$ 的暴力循环来验证每一个 $i$。
-   **多组数据：** $T \le 20$，我们需要一个高效的单次判定算法。
-   **数学性质：** 必须利用数论性质将验证步骤从 $O(p)$ 优化到 $O(\sqrt{p})$ 或更低。

### 3. 解题思路
#### 第一步：数学优化（关键考点）
直接验证“对于任意 $1 \le i < p-1$ 均不为 1”太慢了。我们需要利用**阶（Order）**的性质。

-   **阶的定义：** 使得 $a^k \equiv 1 \pmod p$ 成立的最小正整数 $k$，称为 $a$ 模 $p$ 的阶，记作 $\delta_p(a)$。
-   **拉格朗日定理推论：** $a$ 模 $p$ 的阶 $\delta_p(a)$ 一定是 $\phi(p)$ 的因数（对于质数 $p$，$\phi(p) = p-1$）。

**判定原根的充要条件：**
$a$ 是模质数 $p$ 的原根，当且仅当 $a$ 的阶等于 $p-1$。
换句话说，**对于 $p-1$ 的任何真因数 $d$（即 $d < p-1$），$a^d \not\equiv 1 \pmod p$。**

**如何快速验证？**
我们不需要检查 $p-1$ 的所有因数。只需要检查 $p-1$ 的**最大真因数**即可。
设 $p-1$ 的所有**不同**质因数为 $q_1, q_2, ..., q_k$。
如果对于所有的 $q_i$，都有：
$$a^{\frac{p-1}{q_i}} \not\equiv 1 \pmod p$$
那么 $a$ 就是原根。

**逻辑：** 如果 $a$ 的阶小于 $p-1$，那它一定是 $p-1$ 除以某个质因数后的结果（或更小）。如果连这些“最大的真因数”次幂都不等于 1，那更小的因数次幂肯定也不等于 1。

#### 第二步：算法流程
1.  计算 $m = p - 1$。
2.  对 $m$ 进行**质因数分解**，找出所有的质因数 $q$。
    -   注意：$p$ 最大 $10^9$，所以 $m$ 也是 $10^9$ 级别。我们需要 $O(\sqrt{m})$ 的试除法分解质因数。
3.  对于每一个找到的质因数 $q$，利用**快速幂**计算 $a^{\frac{p-1}{q}} \pmod p$。
4.  如果计算结果等于 1，说明 $a$ 不是原根，输出 "No"。
5.  如果所有质因数检测通过，输出 "Yes"。

### 4. 样例的分析
**输入：** `3 998244353`
-   $p = 998244353$（这是一个著名的NTT模数，它是质数）。
-   $p-1 = 998244352 = 2^{23} \times 7 \times 17$。
-   $p-1$ 的质因数有：2, 7, 17。
-   我们需要验证：
    1.  $3^{(p-1)/2} \pmod p \neq 1$
    2.  $3^{(p-1)/7} \pmod p \neq 1$
    3.  $3^{(p-1)/17} \pmod p \neq 1$
-   经计算（由程序完成），这三个式子都不等于 1。
-   **输出：Yes**

**输入：** `7 998244353`
-   同样分解 $p-1$ 得到质因数 2, 7, 17。
-   验证 $7^{(p-1)/2}$, $7^{(p-1)/7}$, $7^{(p-1)/17}$。
-   实际上，$7^{(p-1)/2} \equiv 1 \pmod p$（7是模p的二次剩余）。
-   一旦有一个等于 1，就不是原根。
-   **输出：No**

### 5. 完整的代码和逻辑解析
这里我将对官方提供的代码进行逐行解析。

**官方代码逻辑解析：**

```cpp
#include <cstdio>
using namespace std;

int a, p;
int ans; // 标记变量，1表示是原根，0表示不是

// 快速幂函数：计算 (b^e) % p
int fpw(int b, int e) {
    if (e == 0) return 1;
    int r = fpw(b, e >> 1); // 分治：计算 b^(e/2)
    r = 1ll * r * r % p;    // 平方：(b^(e/2))^2 = b^e
    if (e & 1)              // 如果 e 是奇数
        r = 1ll * r * b % p; // 再乘一个 b
    return r;
}

// 检查函数：传入 p-1 的一个因数 e
void check(int e) {
    if (fpw(a, e) == 1) // 如果 a^e ≡ 1 (mod p)
        ans = 0;        // 说明 a 的阶 <= e < p-1，不是原根
}

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        scanf("%d%d", &a, &p);
        ans = 1; // 先假设是原根

        int phi = p - 1; // 欧拉函数值，对于质数 p，phi(p) = p-1
        int r = phi;     // r 用来辅助分解质因数

        // 试除法分解质因数
        for (int i = 2; i * i <= phi; i++) {
            if (phi % i == 0) { // 找到一个质因数 i
                check(phi / i); // 核心判定：检查 a^((p-1)/i) 是否等于 1
                while (r % i == 0)
                    r /= i;     // 除去所有的因子 i，保证 i 只被处理一次
            }
        }
        // 如果循环结束后 r > 1，说明还有一个大于 sqrt(phi) 的质因数
        if (r > 1)
            check(phi / r); // 检查最后一个质因数

        printf(ans ? "Yes\n" : "No\n");
    }
    return 0;
}
```

### 6. 易错点和注意事项
作为竞赛老师，我要特别强调以下几个“坑”：

1.  **数据溢出（非常重要）：**
    -   题目中 $p \le 10^9$。在快速幂中，我们需要计算 `r * r` 或者 `r * b`。
    -   两个 $10^9$ 级别的数相乘会达到 $10^{18}$，这超过了 `int` 的范围（约 $2 \times 10^9$）。
    -   **修正：** 必须使用 `long long` 进行中间乘法运算。官方代码中使用了 `1ll * r * r % p`，这是正确的写法。如果直接写 `r * r % p`，会导致溢出错误（WA）。

2.  **质因数分解的边界：**
    -   试除法循环条件是 `i * i <= phi`。
    -   循环结束后，必须检查剩下的 `r` 是否大于 1。如果大于 1，说明剩下的 `r` 本身就是一个质因数（且是大质因数），不能漏掉对它的检查。

3.  **费马小定理的陷阱：**
    -   题目虽然给了 $a^{p-1} \equiv 1$，但这只是必要条件。很多初学者会以为只要满足费马小定理就是原根，这是错误的。必须验证其“最小性”。

4.  **变量作用域：**
    -   官方代码将 `a, p` 设为全局变量，这样 `fpw` 函数就不需要每次都传参 `p` 了，这是一种常见的竞赛编程技巧，可以减少函数调用开销和代码长度。

5.  **时间复杂度分析：**
    -   分解质因数耗时 $O(\sqrt{p})$。
    -   每次 `check` 调用快速幂耗时 $O(\log p)$。
    -   质因数个数很少（对于 $10^9$ 的数，质因数最多也就不到 10 个），所以主要耗时在分解质因数上。
    -   $\sqrt{10^9} \approx 31622$，对于 1.0s 的时限完全足够。
