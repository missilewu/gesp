# 编程题1解析

这道题考察了数论基础、循环优化以及字符串格式化输出，是五级考试中非常典型的“数学+模拟”类题目。

---

### 1. 题意的理解

- **核心任务**：给定一个正整数 $N$，将其分解为质因数的乘积。
- **数学背景**：根据算术基本定理，任何一个大于 1 的整数都可以唯一地分解为有限个质数的乘积。
- **输出规范**：
    - **排序**：质因数必须从小到大排列。
    - **连接符**：乘号用 `*` 表示，注意星号左右各有一个空格。
    - **指数形式**：如果某个质因数出现多次（次数 > 1），需要合并写成 `底数^指数` 的形式（例如 $2^2$），且指数符号 `^` 左右**没有**空格。
    - **特殊情况**：如果 $N$ 本身就是质数，直接输出 $N$。

### 2. 题目核心要求

- **数据范围**：$2 \le N \le 10^{12}$。这是一个非常关键的信息。
    - $10^{12}$ 超过了 C++ 中 `int` 的范围（约 $2 \times 10^9$），因此必须使用 `long long` 类型。
    - 算法复杂度：由于 $N$ 很大，如果使用 $O(N)$ 的暴力试除法会超时。我们需要利用 $\sqrt{N}$ 的性质将复杂度降低到 $O(\sqrt{N})$。
- **格式化控制**：输出格式的拼接是本题的易错点，特别是第一个因子前不能有空格，后续因子前需要加 `*`。

### 3. 解题思路

#### 算法选择：试除法

我们要找到 $N$ 的所有质因数。最直接的方法是从最小的质数 2 开始尝试去除 $N$。

1. **枚举因子**：从 $i = 2$ 开始，一直枚举到 $\sqrt{N}$。
2. **统计次数**：对于每一个 $i$，如果 $N$ 能被 $i$ 整除，说明 $i$ 是一个质因数。我们需要用一个循环不断地除以 $i$，直到 $N$ 不能被 $i$ 整除为止，同时记录除的次数（即指数）。
3. **输出处理**：
    - 每找到一个因子，判断它是第几个因子。如果不是第一个，先输出 `*`。
    - 根据次数输出：次数为 1 输出 `i`，次数大于 1 输出 `i^次数`。
4. **处理剩余的大质数**：
    - 当循环结束（即 $i > \sqrt{N}$）后，如果 $N$ 仍然大于 1，说明剩下的这个 $N$ 本身就是一个大于 $\sqrt{原N}$ 的质数。需要将其作为最后一个因子输出。

#### 优化细节

- 循环条件可以写成 `i * i <= N`。随着 $N$ 不断被除变小，循环次数会显著减少。

### 4. 样例的分析

- **样例 1：输入 6**
    
    - $i=2$，6 能被 2 整除，次数为 1，N 变为 3。输出 `2`。
    - $i=3$，循环条件 $3*3 > 3$ 不满足，退出循环。
    - 循环结束后 $N=3 > 1$，输出 `* 3`。
    - 最终结果：`2 * 3`。
- **样例 2：输入 20**
    
    - $i=2$，20 能被 2 整除：20/2=10，10/2=5。次数为 2，N 变为 5。输出 `2^2`。
    - $i=3$，5 不能被 3 整除。
    - 循环条件 $3*3 > 5$ 不满足，退出循环。
    - 循环结束后 $N=5 > 1$，输出 `* 5`。
    - 最终结果：`2^2 * 5`。
- **样例 3：输入 23**
    
    - 23 是质数。
    - 从 $i=2$ 到 $i=4$，都不能整除 23。
    - 循环结束，$N=23 > 1$。
    - 直接输出 `23`。

### 5. 完整的代码和逻辑解析

代码如下（`cpp`）：

```cpp
#include <iostream>
#include <vector>
#include <cmath>

using namespace std;

int main() {
    // 1. 定义变量，注意使用 long long
    long long N;
    cin >> N;

    // 标记是否是第一个输出的因子，用于控制 " * " 的输出
    bool isFirst = true;

    // 2. 试除法，从 2 开始枚举
    // 注意：i 也要用 long long，防止 i*i 溢出
    for (long long i = 2; i * i <= N; i++) {
        // 如果 i 是 N 的因子
        if (N % i == 0) {
            int count = 0;
            // 循环除以 i，统计次数
            while (N % i == 0) {
                N /= i;
                count++;
            }

            // 3. 格式化输出
            if (!isFirst) {
                cout << " * ";
            }

            if (count == 1) {
                cout << i;
            } else {
                cout << i << "^" << count;
            }

            isFirst = false; // 后续不再是第一个因子
        }
    }

    // 4. 处理剩余的大质数
    // 如果 N 最后还剩下一个大于 1 的数，说明它是一个质因数
    if (N > 1) {
        if (!isFirst) {
            cout << " * ";
        }
        cout << N;
    }

    cout << endl;

    return 0;
}
```

### 6. 参考代码的逻辑解析和注释

- **`long long N;`**：这是本题最基础的陷阱。$10^{12}$ 远大于 `int` 最大值，必须用 `long long`。
- **`bool isFirst = true;`**：这是一个常用的编程技巧（Flag 标记法）。题目要求因子之间用 `*` 连接，这意味着第一个因子前面没有符号，而后续因子前面都有。通过判断 `isFirst`，我们可以避免在行首输出多余的空格或符号。
- **`for (long long i = 2; i * i <= N; i++)`**：
    - 这里利用了数学性质：如果 $N$ 有一个因子大于 $\sqrt{N}$，那么它对应的另一个因子一定小于 $\sqrt{N}$。因此我们只需要检查到 $\sqrt{N}$。
    - 随着 `N` 在 `while` 循环中不断减小，`i * i <= N` 的边界也在动态缩小，这大大提高了效率。
- **`while (N % i == 0)`**：这是试除法的核心。一旦发现因子 `i`，就将其“除尽”，这样保证了后续找到的因子一定是质数（因为合数因子早就被其包含的质因子除掉了）。
- **`if (N > 1)`**：这是处理类似输入 `10` ($2 \times 5$) 或 `23` 的情况。当循环结束时，如果 $N$ 还没变成 1，说明剩下的 $N$ 是一个无法被 $\sqrt{原N}$ 以内的数整除的大质数，必须把它输出。

### 7. 易错点和注意事项

- **数据类型错误**：使用 `int` 存储 $N$。在 GESP 五级考试中，看到 $10^9$ 以上的数据，必须条件反射使用 `long long`。
- **循环边界溢出**：在 `for` 循环中，如果写成 `i * i <= N`，而 `i` 定义为 `int`，当 $N$ 很大时，`i * i` 可能会超过 `int` 范围导致溢出变成负数，造成死循环或错误。建议将 `i` 也定义为 `long long`。
- **格式错误 (Presentation Error)**：
    - `*` 前后必须有空格。
    - `^` 前后**不能**有空格。
    - 行末不能有多余空格。
- **忘记处理最后的质数**：很多同学写完循环就结束了，导致输入 23 输出为空，或者输入 10 只输出 2。一定要记得检查循环结束后 $N$ 是否大于 1。
- **指数为 1 的情况**：题目要求仅当出现多次时才合并指数。如果因子只出现一次，直接输出数字即可，不要输出 `2^1`。

# 编程题2解析


这道题目是经典的 **“带期限的作业调度问题”**（Job Sequencing with Deadlines），在算法竞赛中属于**贪心算法**的经典应用。这道题非常适合用来考察学生对贪心策略的理解以及数据结构的简单应用。

---

### 1. 题意的理解

**通俗解释：** 想象你是一个参加游戏的选手，你有 $n$ 个时间段（比如第 1 天、第 2 天……第 $n$ 天）。同时有 $n$ 个小游戏等着你玩。

- 每个小游戏玩一次只需要花费 **1 个时间段**。
- 每个小游戏都有一个**截止时间**（期限 $T_i$），比如必须在第 3 天结束前玩完。
- 每个小游戏玩完都有一个**奖励**（价值 $R_i$）。
- 如果你在规定时间（包括截止时间当天）玩完了，就能拿到奖励；如果超时了，就没有奖励。

**你的目标：** 安排一个计划，让你拿到的总奖励最大化。

---

### 2. 题目核心要求

1. **输入数据：**
    - $n$：游戏数量和时间段数量。
    - 数组 $T$：每个游戏的截止时间。
    - 数组 $R$：每个游戏的奖励。
2. **约束条件：**
    - 每个游戏耗时均为 1。
    - 同一时间段只能玩一个游戏。
    - 必须在 $T_i$ 时刻或之前完成第 $i$ 个游戏才能得分。
3. **输出：** 能获得的最大总奖励值。

---

### 3. 解题思路（贪心策略）

这就好比去超市买东西，你手里有 $n$ 个购物袋（时间段），你想装价值最高的东西。

**核心贪心思想：** 我们要优先做**奖励（价值）最高**的游戏。因为奖励高的游戏对总分贡献大，我们应尽最大努力保住它。

**具体步骤：**

1. **排序：** 将所有游戏按照**奖励 $R_i$ 从大到小**进行排序。如果奖励相同，截止时间早的优先（虽然这步不是必须的，但是个好习惯）。
2. **遍历与安排：** 依次遍历排序后的游戏。对于当前这个奖励最高的游戏：
    - 我们尽量把它安排在**离它的截止时间最近**的空闲时间段。
    - 例如，某个游戏截止时间是第 3 天。我们优先看第 3 天有没有空？
        - 如果第 3 天空着，就安排在第 3 天。
        - 如果第 3 天被占了，看第 2 天有没有空？
        - 如果第 2 天也被占了，看第 1 天有没有空？
        - 如果前 3 天都满了，说明这个游戏无论如何都来不及做了，直接放弃。
3. **累加：** 只要成功安排了游戏，就把它的奖励加到总分里。

**为什么这样做是对的？** 因为我们总是优先考虑价值最大的任务。对于任何一个任务，如果我们把它安排在“最晚可能的时刻”（即截止时间或之前的最晚空闲时间），就能给前面截止时间的任务留出更多的空位。这是一种局部最优导致全局最优的策略。

---

### 4. 样例的分析

**输入数据：**

- $n = 7$
- 期限 $T$: `4 2 4 3 1 4 6` (对应游戏 1~7)
- 奖励 $R$: `70 60 50 40 30 20 10` (对应游戏 1~7)

**步骤演示：**

1. **排序：** 我们需要把游戏按奖励从高到低排列。这里为了方便，我们给游戏编号：
    
    - 游戏 1: 期限4, 奖励70
    - 游戏 2: 期限2, 奖励60
    - 游戏 3: 期限4, 奖励50
    - 游戏 4: 期限3, 奖励40
    - 游戏 5: 期限1, 奖励30
    - 游戏 6: 期限4, 奖励20
    - 游戏 7: 期限6, 奖励10 _(注：样例输入本身已经是按奖励降序排列好的，这简化了我们的分析)_
2. **贪心选择：**
    
    - **处理游戏 1 (奖70, 限4):** 看第 4 时间段空吗？空。占用第 4 时间段。【总奖: 70】
    - **处理游戏 2 (奖60, 限2):** 看第 2 时间段空吗？空。占用第 2 时间段。【总奖: 70+60=130】
    - **处理游戏 3 (奖50, 限4):** 看第 4 时间段空吗？不空（被游戏1占了）。看第 3 时间段空吗？空。占用第 3 时间段。【总奖: 130+50=180】
    - **处理游戏 4 (奖40, 限3):** 看第 3 时间段空吗？不空。看第 2 时间段空吗？不空。看第 1 时间段空吗？空。占用第 1 时间段。【总奖: 180+40=220】
    - **处理游戏 5 (奖30, 限1):** 看第 1 时间段空吗？不空。没位置了，放弃。
    - **处理游戏 6 (奖20, 限4):** 看第 4, 3, 2, 1 时间段都满了。放弃。
    - **处理游戏 7 (奖10, 限6):** 看第 6 时间段空吗？空。占用第 6 时间段。【总奖: 220+10=230】

**最终结果：230**。与样例输出一致。

---

### 5. 完整的代码和逻辑解析 (C++)

这里提供两种实现方式。 **方法一：暴力查找（适合 $n \le 500$）** 由于 $n$ 很小，我们可以直接用数组标记时间段是否被占用，然后向前遍历查找空位。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// 定义游戏结构体
struct Game {
    int t; // 期限
    int r; // 奖励
};

// 排序规则：按奖励从大到小排
bool compareGames(Game a, Game b) {
    return a.r > b.r;
}

int main() {
    int n;
    if (!(cin >> n)) return 0;

    vector<Game> games(n);
    for (int i = 0; i < n; i++) {
        cin >> games[i].t;
    }
    for (int i = 0; i < n; i++) {
        cin >> games[i].r;
    }

    // 1. 排序
    sort(games.begin(), games.end(), compareGames);

    // 标记时间段是否被占用，下标从1开始对应第1天，初始化为false
    // n最大500，开稍微大一点防止越界
    bool slot[505] = {false};
    int maxReward = 0;

    // 2. 贪心遍历
    for (int i = 0; i < n; i++) {
        int deadline = games[i].t;
        int reward = games[i].r;

        // 从截止时间往前找空位
        for (int j = deadline; j >= 1; j--) {
            if (!slot[j]) {
                // 找到空位
                slot[j] = true; // 标记占用
                maxReward += reward; // 累加奖励
                break; // 当前游戏安排好了，跳出内层循环处理下一个游戏
            }
        }
    }

    cout << maxReward << endl;

    return 0;
}
```

---

### 6. 参考代码的逻辑解析和注释

针对上面的代码进行逐行解析：

1. **`struct Game`**: 定义了一个结构体，把每个游戏的“期限”和“奖励”捆绑在一起。这是因为排序时，奖励变了，对应的期限也要跟着变，不能分开存两个数组排序。
2. **`compareGames`**: 这是 `std::sort` 用的比较函数。`return a.r > b.r;` 表示我们要**降序**排列（大的在前）。
3. **`bool slot[505] = {false};`**: 这是一个“桶”或者“标记数组”。`slot[i] = true` 意味着第 $i$ 个时间段已经被占用了。
4. **`for (int j = deadline; j >= 1; j--)`**: 这是贪心策略的关键实现。对于当前游戏，我们不看前面的时间，直接从它能活的最后一天（deadline）往前倒推。一旦发现某天 `slot[j]` 是 `false`，就立马占住。这样能最大程度保留前面的时间段给其他可能期限更早的游戏。

**进阶思路（并查集优化）：** 如果 $n$ 很大（比如 $10^5$），上面的 $O(n^2)$ 算法会超时。那时需要用**并查集**来优化查找空位的过程，将查找复杂度降为近似 $O(1)$。但在 GESP 5 级和本题 $n \le 500$ 的限制下，上述代码是最优解，简单且不易出错。

---

### 7. 易错点和注意事项

1. **数据关联丢失：**
    
    - **错误做法：** 分别对期限数组 $T$ 和奖励数组 $R$ 单独排序。
    - **后果：** 游戏 1 的期限是 4，奖励是 70。如果你分开排序，可能导致游戏 1 的期限变成了 1，或者奖励变成了 10。
    - **正确做法：** 使用 `struct` 结构体或者 `pair`，保证期限和奖励绑定在一起移动。
2. **排序方向错误：**
    
    - 题目求最大奖励，所以必须**按奖励从大到小**排。如果从小到大排，先安排了廉价游戏占用了时间，高价值游戏就进不来了。
3. **边界条件：**
    
    - 查找空位时，循环条件是 `j >= 1`，因为时间段是从 1 开始的。
    - 数组大小要开够，虽然 $n \le 500$，但习惯性开 `505` 或 `1000` 可以避免边界问题。
4. **理解“截止时间”：**
    
    - 截止时间 $T_i$ 意味着可以在 $1, 2, ..., T_i$ 任意时刻完成。很多同学误以为必须在第 $T_i$ 时刻完成。
