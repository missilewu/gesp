
# 2025-03-02：原根判断
## 难点1：逻辑的推导

在不知道费马小定理的情况下，如果根据题目的条件推导出下面这个通俗的解释： 
- $a$ 的幂次模 $p$ 的结果会循环。这个循环的最小正周期如果是 $p-1$，那么 $a$ 就是原根。也就是说，$a^1, a^2, ..., a^{p-1}$ 模 $p$ 的结果互不相同，且填满了 $1$ 到 $p-1$ 的所有整数。

根据题目给的条件，先用几个是小的数计算，发现一下规律。

1.  $1 < a < p$
2.  $a^{p-1} \pmod p = 1$
3.  对于任意 $1 \le i < p-1$，都有 $a^i \pmod p \neq 1$

我们取 a = 4, p = 5; 
-  $4^{1} \pmod 5 = 4 \pmod 5 = 4$
-  $4^{2} \pmod 5 = 16 \pmod 5 = 1$
-  $4^{3} \pmod 5 = 64 \pmod 5 = 4$
-  $4^{4} \pmod 5 = 256 \pmod 5 = 1$

可以看到 2 和 4 次方都是 1， 说明 4 不是 5 的原根；而且发现循环周期是 2 不是 4；

我们取 a = 3, p = 5; 
-  $3^{1} \pmod 5 = 3 \pmod 5 = 3$
-  $3^{2} \pmod 5 = 9 \pmod 5 = 4$
-  $3^{3} \pmod 5 = 27 \pmod 5 = 2$
-  $3^{4} \pmod 5 = 81 \pmod 5 = 1$
- $3^{6} \pmod 5 = 243 \pmod 5 = 3$
-  $3^{7} \pmod 5 = 729 \pmod 5 = 4$
- .$3^{8} \pmod 5 = xxx7 \pmod 5 = 2$
- $3^{9} \pmod 5 = xxx1 \pmod 5 = 1$

我们可以看到 只有在 p-1 = 4, 2p-1 = 9, 3p-1 = 14 的时候，余数是1，因此 3是5的原根。而且还能够发现一个特点，这个 3,4,2,1的循环周期就是 p-1 = 4；

## 难点二：化简，数学优化

-   **输入规模大：** $p$ 高达 $10^9$。这意味着我们不能使用 $O(p)$ 的暴力循环来验证每一个 $i$。
-   **多组数据：** $T \le 20$，我们需要一个高效的单次判定算法。
-   **数学性质：** 必须利用数论性质将验证步骤从 $O(p)$ 优化到 $O(\sqrt{p})$ 或更低。

首先，我们前面推导出来了，只有最小循环周期是 p-1 的时候，才能够判断出原根。因此，我们要找到一个比 p-1 小的周期 x。这个 x 有一个特点，一定是 p-1 的一个因数。
其次，这个因数x有什么特点呢？可以通过质因数分解得到，例如：p-1 的一个质因数是 q，那么这个因数x一定是 (p-1) / q；
最后得出，我们只需要对 p-1进行质因数分解，就可以得到 x， 判断 $a^x \equiv 1\pmod p$ 是不是成立即可。

## 算法流程
1.  计算 $m = p - 1$。
2.  对 $m$ 进行**质因数分解**，找出所有的质因数 $q$。
    -   注意：$p$ 最大 $10^9$，所以 $m$ 也是 $10^9$ 级别。我们需要 $O(\sqrt{m})$ 的试除法分解质因数。
3.  对于每一个找到的质因数 $q$，利用**快速幂**计算 $a^{\frac{p-1}{q}} \pmod p$。
4.  如果计算结果等于 1，说明 $a$ 不是原根，输出 "No"。
5.  如果所有质因数检测通过，输出 "Yes"。

### 1. 样例的分析
**输入：** `3 998244353`
-   $p = 998244353$（这是一个著名的NTT模数，它是质数）。
-   $p-1 = 998244352 = 2^{23} \times 7 \times 17$。
-   $p-1$ 的质因数有：2, 7, 17。
-   我们需要验证：
    1.  $3^{(p-1)/2} \pmod p \neq 1$
    2.  $3^{(p-1)/7} \pmod p \neq 1$
    3.  $3^{(p-1)/17} \pmod p \neq 1$
-   经计算（由程序完成），这三个式子都不等于 1。
-   **输出：Yes**

**输入：** `7 998244353`
-   同样分解 $p-1$ 得到质因数 2, 7, 17。
-   验证 $7^{(p-1)/2}$, $7^{(p-1)/7}$, $7^{(p-1)/17}$。
-   实际上，$7^{(p-1)/2} \equiv 1 \pmod p$（7是模p的二次剩余）。
-   一旦有一个等于 1，就不是原根。
-   **输出：No**

### 2. 完整的代码和逻辑解析
这里我将对官方提供的代码进行逐行解析。

**官方代码逻辑解析：**

```cpp
#include <cstdio>
using namespace std;

int a, p;
int ans; // 标记变量，1表示是原根，0表示不是

// 快速幂函数：计算 (b^e) % p
int fpw(int b, int e) {
    if (e == 0) return 1;
    int r = fpw(b, e >> 1); // 分治：计算 b^(e/2)
    r = 1ll * r * r % p;    // 平方：(b^(e/2))^2 = b^e
    if (e & 1)              // 如果 e 是奇数
        r = 1ll * r * b % p; // 再乘一个 b
    return r;
}

// 检查函数：传入 p-1 的一个因数 e
void check(int e) {
    if (fpw(a, e) == 1) // 如果 a^e ≡ 1 (mod p)
        ans = 0;        // 说明 a 的阶 <= e < p-1，不是原根
}

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        scanf("%d%d", &a, &p);
        ans = 1; // 先假设是原根

        int phi = p - 1; // 欧拉函数值，对于质数 p，phi(p) = p-1
        int r = phi;     // r 用来辅助分解质因数

        // 试除法分解质因数
        for (int i = 2; i * i <= phi; i++) {
            if (phi % i == 0) { // 找到一个质因数 i
                check(phi / i); // 核心判定：检查 a^((p-1)/i) 是否等于 1
                while (r % i == 0)
                    r /= i;     // 除去所有的因子 i，保证 i 只被处理一次
            }
        }
        // 如果循环结束后 r > 1，说明还有一个大于 sqrt(phi) 的质因数
        if (r > 1)
            check(phi / r); // 检查最后一个质因数

        printf(ans ? "Yes\n" : "No\n");
    }
    return 0;
}
```

### 6. 易错点和注意事项
作为竞赛老师，我要特别强调以下几个“坑”：

1.  **数据溢出（非常重要）：**
    -   题目中 $p \le 10^9$。在快速幂中，我们需要计算 `r * r` 或者 `r * b`。
    -   两个 $10^9$ 级别的数相乘会达到 $10^{18}$，这超过了 `int` 的范围（约 $2 \times 10^9$）。
    -   **修正：** 必须使用 `long long` 进行中间乘法运算。官方代码中使用了 `1ll * r * r % p`，这是正确的写法。如果直接写 `r * r % p`，会导致溢出错误（WA）。

2.  **质因数分解的边界：**
    -   试除法循环条件是 `i * i <= phi`。
    -   循环结束后，必须检查剩下的 `r` 是否大于 1。如果大于 1，说明剩下的 `r` 本身就是一个质因数（且是大质因数），不能漏掉对它的检查。

3.  **费马小定理的陷阱：**
    -   题目虽然给了 $a^{p-1} \equiv 1$，但这只是必要条件。很多初学者会以为只要满足费马小定理就是原根，这是错误的。必须验证其“最小性”。

4.  **变量作用域：**
    -   官方代码将 `a, p` 设为全局变量，这样 `fpw` 函数就不需要每次都传参 `p` 了，这是一种常见的竞赛编程技巧，可以减少函数调用开销和代码长度。

5.  **时间复杂度分析：**
    -   分解质因数耗时 $O(\sqrt{p})$。
    -   每次 `check` 调用快速幂耗时 $O(\log p)$。
    -   质因数个数很少（对于 $10^9$ 的数，质因数最多也就不到 10 个），所以主要耗时在分解质因数上。
    -   $\sqrt{10^9} \approx 31622$，对于 1.0s 的时限完全足够。
