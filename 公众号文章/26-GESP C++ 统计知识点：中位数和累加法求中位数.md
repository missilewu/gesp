
# GESP C++ 统计知识点：中位数和累加法求中位数

在做[GESP C++ 五级 2025年12月的编程题第二题 —— 相等序列](https://gesp.ccf.org.cn/101/attach/1727912539586592.pdf)，遇到了中位数的应用，以及通过累加法求中位数的编程机巧。在此简单的总结，用以加深印象和知识分享。

---

## 一、问题背景

我们有一组数的频率分布：  
$$
x_1, x_2, \dots, x_n
$$
每个数可以出现多次。我们希望找到一个值 \(m\)，使得总代价  
$$
f(m) = \sum_{i=1}^{n} |x_i - m|
$$
最小。  

这个问题在数学上叫做 **绝对偏差最小化问题**。  

---
### 数学结论

结论：  
> 当 `f(m)` 取最小时，`m` 是这组数的中位数。  

证明思路：  
- 把所有数排序：$x_1 \le x_2 \le \dots \le x_n$。  
- 当 $m < x_k$ 时，增加 `m` 会减少左边的差值但增加右边的差值。  
- 当 $m > x_k$ 时，减少 $m$ 会减少右边的差值但增加左边的差值。  
- 唯一平衡点就是中间位置的数，也就是`中位数`。 


## 二、中位数的基础数学定义

对于一组有序数据，中位数是处于数据中间位置的数值，是描述数据集中趋势的核心统计量，具体规则如下：

- 将一组数据**从小到大排序**后，若数据总个数为**奇数**，正中间唯一的数值即为中位数；
    
- 若数据总个数为**偶数**，中间存在两个数值，数学上可取两数的平均值；在编程竞赛中，两个中间值均可作为最优解，不会影响最终计算结果。
    

简单来说，中位数的核心特征是：**数据分布的平衡点**，左右两侧的数据数量基本均等。

在中小学教学中，我们老师常常通过一个经典的“选址问题”来具象化这个概念：
- **案例**：假设一条直线上有5个村庄，现在要在这条线上建一个邮局，使得所有村庄到邮局的**距离之和**最短。
- **直观推导**：如果邮局建在最边缘的村庄，总距离显然很长；如果建在正中间的村庄，左右两边的村庄数量尽可能接近，此时总距离最短。
通过这个例子，我就能深刻理解：中位数追求的是“绝对误差最小”（对极端值具有极强的抗干扰性，即稳健性）。注意与平均数的对比：平均数追求的是“平方误差最小”（受极端值影响大）。

中位数的应用可以结合具体的学科背景进行拓展：

1. **统计学与经济学**：在分析居民收入或房价时，平均数往往会被少数极高收入者或豪宅“拉高”。此时，中位数能更真实地反映普通大众的“中等水平”。例如，马斯克和十几个普通人同处一室，平均收入可能过千亿，但中位数依然是普通人的收入。
2. **算法与工程**：在图像处理中，为了去除图像上的噪点（如黑白斑点），常使用“中值滤波”。取像素点周围邻域的中位数作为中心像素的新值，既能有效去除极端噪点，又能很好地保留图像的边缘细节。

## 三、累加法的求中位数

求中位数，我们需要把数据集合显式排序，然后根据元素数量的奇偶性来找到“中间”的数，即中位数。而在编程实践中，往往会用`累加法`求中位数，具体步骤如下：

1. 统计每个元素的出现频次数，从而把相同元素分到一组中，聚集到一起： 
$$
\text{freq}[j] = \text{出现次数}
$$

2. 然后从最小的元素的频次开始累加： 
$$
\text{prefix}[j] = \sum_{k=0}^{j} \text{freq}[k]
$$

3. 当 $\text{prefix}[j] \ge \frac{n}{2}$ 时，说明已经覆盖了至少一半的元素。  此时的 `j` 就是中位数。  这相当于在排序后的序列中走到第 $\lceil \frac{n}{2} \rceil$ 个位置。准确的说就是$\lceil \frac{n}{2} \rceil$ 这个位置就在当前的元素分组中，因为分组中的元素是一样的，因此当前这个元素就是要找的中位数了。

### 直觉理解
- 排序法：直接找第中间个数。  
- 累加法：用频率统计模拟排序。  
  - 每次累加代表“走过了这些数”。  
  - 当走过一半时，说明到达中间位置。  
  - 累加法是排序法的数学等价形式。  
  - 它利用频率分布代替排序，效率更高。  

这就是为什么“累加次数直到达到一半以上的元素”能找到中位数。

### 例子理解

我们用例子 `[4, 3, 2, 2, 1, 0, 0]` 来完整演示“累加次数直到达到一半以上的元素”的过程，

#### 1. 排序后计算中位数

先把集合排序：  
`[ 0, 0, 1, 2, 2, 3, 4 ]`

总共有 (n = 7) 个数。  
中位数应该是第 $\lceil \frac{7}{2} \rceil = 4$ 个数 → **2**。

---

#### 2. 统计频次

统计每个指数出现的次数：

- 元素 0：出现 2 次
- 元素 1：出现 1 次
- 元素 2：出现 2 次
- 元素 3：出现 1 次
- 元素 4：出现 1 次

---

#### 3. 累加过程

我们从最小的指数开始累加：（也是一个典型的前缀和形式）

- j=0 → 累积 = 2
- j=1 → 累积 = 3
- j=2 → 累积 = 5

此时，累积次数 `5`，满足条件 $频次 \times 2 \geq n$ （即 $10 \geq 7$）。  
说明已经覆盖了超过一半的元素。  所以中位数就是当前的元素 **2**。


## 四、通用代码模版

适用于：数据值域小、求中位数、求绝对值和最小的场景，利用频率统计，效率高。排序法虽然直观，但是效率低，不适用于此类场景。

```cpp
// 1. 初始化计数数组（值域 0~MAX_VAL）
int cnt[MAX_VAL + 1] = {0};
// 2. 读入数据，统计个数
int n; cin >> n;
for(int i=1; i<=n; i++){
    int x; cin >> x;
    cnt[x]++;
}
// 3. 前缀和找中位数
int pre = 0, mid = 0;
for(int v=0; v<=MAX_VAL; v++){
    pre += cnt[v];
    if(pre * 2 >= n){
        mid = v;
        break;
    }
}
// 4. 计算所有数到中位数的绝对值总和
long long sum = 0;
for(int v=0; v<=MAX_VAL; v++){
    sum += 1LL * cnt[v] * abs(v - mid);
}
```

结合真题的代码来看，我们也需要注意这个编程技巧。元素的频次累计是从 `1` 开始，因此在统计完成后，一定要回填 `0`的频次（即：总数 `n` 减去已经统计出来的元素频次总和）

```cpp
// 统计所有 j≥1 的总个数
int total = 0;
for(int j=0; j<20; j++) total += num[p][j];
// 指数为 0 的数量 = 总数 - 含有该质因子的数
num[p][0] = n - total;
```
