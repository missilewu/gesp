 

# GESP C++ 质因数分解和试除法代码

**分解质因数 (Prime Factorization)**，就是把一个**大于1的正整数**，拆成若干个**质数**相乘的形式。根据**算术基本定理**（前面学习的唯一分解定理），这个拆分结果（不计顺序）是**唯一**的。

 **适用范围：** 只针对合数。质数（如 2, 3, 5, 7）本身已经是“最小单位”，无法再分解；数字 1 既不是质数也不是合数，也不进行分解。

## 一、常用分解方法

### 1. 短除法
**步骤**：
1. 从最小质数 **2** 开始试除
2. 能整除就记下这个质数，用商继续除
3. 不能整除就换下一个质数（3,5,7...）
4. 直到商是质数为止
5. 把所有除数和最后的商写成连乘形式

**例子：分解 72**
```
 2 | 72
 2 | 36
 2 | 18
 3 |  9
      3
```
**结果**：
- 展开式：**72 = 2 × 2 × 2 × 3 × 3**
- 标准式（指数）：**72 = 2³ × 3²**

**适用场景：** 日常作业、考试手算、求最大公因数或最小公倍数。

**注意事项**

*  **结果唯一性：** 根据算术基本定理，任何一个合数分解质因数的结果都是**唯一**的，不会因为你的拆分顺序不同而改变。
*  **书写规范：** 最终结果必须写成**乘积**的形式（例如 `72 = 2 × 2 × 2 × 3 × 3`），不能写成 `72 = 8 × 9`（因为 8 和 9 还是合数，没有分解彻底）。

**更多例子**
- **60** = 2 × 2 × 3 × 5 = **2² × 3 × 5**
- **100** = 2 × 2 × 5 × 5 = **2² × 5²**
- **45** = 3 × 3 × 5 = **3² × 5**
- **17**（质数）= **17**

### 2. 树状图法 / 塔式分解法 (Factor Tree Method)

这是一种图形化的方法，非常适合初学者理解“拆分”的过程，视觉上很直观。

- **核心逻辑：** 像树枝一样，把一个数不断“劈开”成两个因数，直到无法再分。
- **操作步骤：**
    1. 把原数写在顶端（树根）。
    2. 将其拆分为任意两个因数（例如 24 拆成 4 和 6）。
    3. 如果拆出来的数还是合数（如 4 和 6），继续拆分（4→2×2, 6→2×3）。
    4. 直到所有分支的末端都是质数。
- **适用场景：** 教学演示、帮助理解数字结构、处理较小的数字。

### 3. 试除法 (Trial Division)

这是计算机算法中最基础的方法，也是短除法的逻辑延伸。

- **核心逻辑：** 暴力枚举。从 2 开始，一直试除到 `√n`​ （根号n）。
- **操作步骤：**
    1. 从 `2` 开始，**暴力枚举**每一个数去试除 `n`。
    2. 一旦能整除，说明找到质因子，**除干净**并记录。
    3. 只需试到 `i × i > n` 就停。
    4. 最后若 `n > 1`，剩下的数就是那个**大于 √n** 的质因子。
- **适用场景：** 编程入门、解决中小规模数字的分解问题。

### 4. 高级算法 (Advanced Algorithms)

当数字非常大（例如几十位甚至上百位）时，上述方法都会失效（计算时间太长）。这时需要用到更高级的数学算法，通常用于密码学领域。

- **Pollard's Rho 算法：** 一种基于概率的算法，专门用于分解大整数，效率远高于试除法。
- **适用场景：** 密码学（如破解 RSA 加密）、信息学奥赛（处理 10121012 以上的大数）。

### 5. 方法对比总结 

为了更直观地理解不同方法的区别，我用千问做了一个对比表：

|方法名称|核心特点|推荐场景|优点|缺点|
|:--|:--|:--|:--|:--|
|短除法|竖式计算，逻辑严密|手算、考试|步骤清晰，不易出错，速度快|需要熟练背诵乘法口诀和质数|
|树状图法|图形分支，直观展示|初学者、教学|容易理解“分解”的概念|数字大了画起来很乱，占空间|
|试除法|循环试除，机械化|编程、小数据|逻辑简单，代码容易实现|面对大数时效率极低|
|高级算法|概率与数论|超大数、密码学|能处理普通方法算不动的巨数|原理复杂，难以手算|

## 二、质因数分解编程实现（试除法）

### 1. 方法步骤

思路跟我在数学教材的短除法一致，只是考虑到计算机语言实现时，有一些细节点。因此有些GESP的教材和材料，也会称该方法为短除法。

1. 从最小质数2开始，依次试除目标数n；
2. 若能整除，记录该质数（质因数），并统计其指数（除以多少次能除尽）；
3. 将n更新为除尽后的商，重复步骤1-2，直到商为质数；
4. 最后将剩余的质数（商）作为质因数，指数为1。

### 2. C++ 代码实现

豆包+千问

```cpp
#include <iostream>
#include <vector>
using namespace std;

/**
 * 函数：分解质因数
 * 参数：n - 需要分解的整数
 * 返回：包含所有质因数的 vector，例如 12 返回 [2, 2, 3]
 */
vector<int> factorize(int n) {
    vector<int> res; // 创建一个空容器，用来存放找到的质因数

    // ---------------------------------------------------------
    // 核心循环：试除法
    // 从 i=2 开始尝试，直到 i*i > n 为止。
    // 为什么是 i*i <= n？因为如果 n 有因数，必有一个因数 <= sqrt(n)。
    // 使用 i*i 可以避免使用 sqrt() 函数，防止浮点数精度问题。
    // ---------------------------------------------------------
    for (int i = 2; i * i <= n; ++i) {
        
        // 【调试专用】取消下面注释可查看每一步的变化
        // cout << "尝试除数: " << i << ", 当前n: " << n << endl;

        // 内层循环：如果 n 能被 i 整除，说明 i 是质因数
        // 使用 while 是为了把 n 中包含的因子 i 全部除干净
        while (n % i == 0) {
            res.push_back(i); // 将找到的质因数 i 存入结果列表
            n /= i;           // 更新 n，相当于把 i 从 n 中剥离出去
            
            // 【调试专用】
            // cout << "  -> 找到因数 " << i << ", n 变为 " << n << endl;
        }
    }

    // ---------------------------------------------------------
    // 关键步骤：处理剩下的那个“大”质数
    // 如果循环结束后，n 仍然大于 1，说明剩下的 n 本身就是一个质数。
    // 例如：分解 14。
    // 1. i=2 时，14 变成 7。
    // 2. i=3 时，3*3 > 7，循环结束。
    // 3. 此时 n=7，如果不加这句，7 就会丢失。
    // ---------------------------------------------------------
    if (n > 1) {
        res.push_back(n);
    }

    return res; // 返回结果列表
}

int main() {
    int n;
    // 读取输入
    if (cin >> n) {
        // 调用函数，使用 auto 关键字自动推导类型 (C++ 11 特性)
        auto f = factorize(n);
        
        // 使用范围 for 循环输出结果 (C++ 11 特性)
        // 读作：对于 f 中的每一个元素 x
        for (int x : f) {
            cout << x << " ";
        }
        cout << endl;
    }
    return 0;
}
```

- **时间复杂度**：
    - 最坏：**O(√n)**（n 是大质数）
    - 最好：**O(log n)**（n 是 2 的幂）
