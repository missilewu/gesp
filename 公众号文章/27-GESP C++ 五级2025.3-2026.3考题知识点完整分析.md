这是高频基础考点，占整体考题约22%，细分如下：
1. **链表细分**：单链表、双向链表、循环链表三大类，单链表遍历/插入/删除/尾部操作、双向链表插入/删除/空判断、循环链表初始化/遍历、链表与数组效率&场景对比、链表存储技巧；
2. **数组细分**：数组特性、数组与链表的适用场景差异、数组和链表存储差异、数组线性表复杂度分析

### 模块2：经典算法体系（排序+查找+分治+贪心+递归）

占整体考题约38%，是考察占比最高的模块：
1. **排序算法**：快速排序、归并排序、插入排序，考察稳定性、时间/空间复杂度、优化技巧、合并操作、分治思想对比
2. **查找算法**：二分查找（普通二分、下界Lower Bound、上界Upper Bound、二分答案/切木头模型、二分适用条件、中点mid的计算细节、查找出现位置细节）
3. **分治算法**：分治求最大子段和、分治与递归区别、分治思想应用
4. **贪心算法**：贪心核心特征、任务调度、钱币找零、区间调度、局限性分析
5. **递归与栈溢出**：递归执行过程、递归终止条件、递归与迭代对比、递归栈溢出、斐波那契/汉诺塔递归实现复杂度分析、尾递归特征和性能优化

### 模块3：初等数论知识

占整体考题约25%，属于稳定高频模块：
1. **最大公约数&最小公倍数**：欧几里得（辗转相除法）执行流程、适用场景、同余与模运算、LCM计算
2. **素数筛法**：埃氏筛、线性筛（欧拉筛）原理、实现细节、效率对比、素数判定性质
3. **数论基础定理**：唯一分解定理、倍数约数性质、9的倍数判定
4. **斐波那契数列**：递归实现的时间复杂度、迭代优化方案

### 模块4：高精度运算专题

占整体考题约15%，细分覆盖高精度加、减、乘、除四类运算，考察进位/借位细节、试商技巧、模拟进位逻辑、大数运算的边界处理。高精度加法（模拟进位）、高精度减法、高精度乘法（进位处理）、高精度除法（试商、大数除小数）、阶乘高精度实现（这个超纲，可以扩展了解）

## 二、每个细分知识点核心要点梳理
### （一）数据结构模块

#### 1. 数组核心考点
1. 特性：连续内存、下标随机访问 $O(1)$；插入/删除需要平移元素，复杂度 $O(n)$
2. 适用场景：数据固定、查询远多于修改；不适合频繁增删
3. 线性表复杂度判断：数组实现线性表任意位置增删平均$O(n)$

#### 2. 单链表（哑结点是高频单选考点）
1. 结构：仅存后继指针，单向遍历，无随机访问，访问指定元素$O(n)$
2. 增删复杂度：
   - 已知前驱节点：插入/删除 $O(1)$
   - 仅已知当前节点：删除需要遍历找前驱 $O(n)$（无法$O(1)$删尾节点）
3. 哑结点（头哨兵）技巧：统一空链表、头节点删除边界，简化代码逻辑（真题常考代码填空）
4. 循环单链表：尾节点指向头，遍历终止条件为回到起点；典型应用：约瑟夫问题、区块链模型
5. Floyd判圈算法（快慢指针）：判断链表是否存在环，单选常考原理

#### 3. 双向链表（双向循环链表）
1. 每个节点存前驱+后继指针，已知任意节点均可$O(1)$完成插入、删除操作
2. 空链表判断：head == nullptr / tail == nullptr；双向循环链表初始化头尾互指
3. 尾部插入操作：无需遍历，直接修改tail指针，$O(1)$复杂度

#### 4. 链表VS数组 对比必背（单选高频）
| 需求         | 选数组 | 选链表 |
| ---------- | --- | --- |
| 随机下标快速读取   | √   | ×   |
| 频繁中间插入、删除  | ×   | √   |
| 存储空间连续     | √   | ×   |
| 长度动态变化、不确定 | ×   | √   |

#### 5. 数组线性表
数组实现的线性表插入删除需要平移后续元素，平均时间复杂度$O(n)$，优势是支持下标随机快速访问，适合长度固定、查询多修改少的场景

#### 6. 真题判断易错点
1. 单链表能$O(1)$删除任意指定节点 → **错**（尾节点无法处理）
2. 双向链表删除已知节点复杂度$O(1)$ → **对**
3. 链表支持随机访问 → **错**
4. 循环链表遍历结束条件是回到起始节点 → **对**


### （二）算法设计模块
#### 1. 排序算法

- **快速排序**：基于分治，不稳定排序；最坏时间复杂度$O(n^2)$（有序序列），Partition 过程是核心，优化三数取中可规避；平均复杂度$O(n\log n)$，递归深度过大易栈溢出；
- **归并排序**：稳定排序，分治思想；最好/最坏/平均复杂度均$O(n\log n)$，需要额外$O(n)$辅助空间，核心难点是两个有序子序列的合并操作；必须会手写 `merge` 函数，常用于求“逆序对”数量。
- **排序稳定性**：相等元素排序后相对位置不变则稳定，插入、归并稳定；快排、希尔、堆排不稳定

| 算法   | 稳定性 | 时间复杂度                     | 核心考点                 |
| ---- | --- | ------------------------- | -------------------- |
| 快速排序 | 不稳定 | 平均$O(n\log n)$，最坏$O(n^2)$ | 有序数组性能最差；三数取中优化；划分操作 |
| 归并排序 | 稳定  | 最好/最坏/平均均$O(n\log n)$     | 分治思想；两个有序数组合并；可求逆序对  |

1. 排序稳定性定义：相等元素排序后相对位置不变
2. 真题判断：快速排序是稳定排序 → **错**；归并排序恒定$O(n\log n)$ → **对**
. 
#### 2. 二分查找系列
- **普通二分查找**：仅适用于**严格有序序列**，每次折半缩小范围，复杂度$O(\log n)$
- **下界Lower Bound**：找到有序序列中第一个≥目标值的位置，是二分查找的拓展
- **上界Upper Bound**：找到有序序列中第一个＞目标值的位置，是二分查找的拓展
- **二分答案（切木头模型）**：对答案范围二分判定可行性，适用于答案单调可验证的最值最大化/最小化问题，需要设计check校验函数
- **易错点**：中点mid防溢出写法、循环终止条件、查找最左/最右出现位置的边界调整

#### 3. 分治算法
- **核心思想**：分而治之，把大问题拆成若干独立子问题，子问题求解后合并结果；分治一定可以改成递归实现，但递归不一定是分治（如普通递归遍历）；
- **典型场景**：归并排序、快排、最大子段和

#### 4. 贪心算法
- **核心**：每一步做局部最优选择，期望得到全局最优；**局部最优≠全局最优**（如部分币值的钱币找零问题），因为局部最优不是最优子结构；
- **高频场景**：活动任务调度、区间覆盖、钱币找零；需要严格证明贪心策略的正确性
- **判断易错**：贪心一定能得到全局最优解 → **错**

#### 5. 递归与栈溢出
- 递归两大必要条件：**终止条件**（无终止条件会无限递归、栈溢出）+递推公式
-  栈溢出原因：递归深度过大，超出系统栈容量
-  斐波那契朴素递归：时间复杂度$O(2^n)$，迭代优化后$O(n)$
-  递归与迭代：所有递归均可改写为循环迭代，迭代无栈溢出风险
-  判断易错：缺少终止条件会栈溢出 → **对**；递归一定比迭代快 → **错**

### （三）初等数论模块
#### 1. 欧几里得算法（辗转相除法 GCD）
1. 公式：$\gcd(a,b) = \gcd(b,a \bmod b)$，余数为0时除数为最大公约数
2. 配套最小公倍数：$\text{LCM}(a,b)=\dfrac{a\times b}{\gcd(a,b)}$；计算优先 `a/gcd*b` 防止溢出
3. 配套考点：同余、模运算、9的倍数判定（各位数字和模9等于原数模9）
4. 判断易错：辗转相除法仅适用于正整数，负数无意义 → **正确**

#### 2. 素数筛法（两套筛对比，必考）
##### （1）埃氏筛（埃拉托斯特尼筛）
- 原理：找到素数，标记它所有倍数，内层循环起点常见`2*i`或`i*i`
- 时间复杂度：$O(n\log\log n)$
- 缺点：合数会被多个质因子重复标记，效率较低

##### （2）线性筛（欧拉筛，五级重点）
- 核心原理：**每个合数只被自身最小质因子标记一次**，无重复标记
- 关键代码：`if(i%primes[j]==0) break;` 一旦整除立刻跳出循环
- 复杂度：严格 $O(n)$，大数据筛素数优先使用
- 判断结论：同等规模下，线性筛效率高于埃氏筛 → **正确**

#### 3. 唯一分解定理
任意大于1的正整数，**唯一**分解为若干质数幂次乘积；质因数分解结果唯一，判断题高频考点。

#### 4. 其他数论考点
1. 完全数、因数枚举优化：枚举到 $\sqrt{n}$ 减少循环次数
2. 倍数判定：9的倍数等价于各位数字之和是9的倍数
3. 质因数分解存储、质因数拆分逻辑

### （四）高精度运算模块

用数组/字符串模拟超大整数的四则运算（超出64位整型范围）：
- **高精度加法**：从低位向高位逐位相加，处理进位
- **高精度减法**：低位逐位相减，处理借位，提前判断大小避免负数出错
- **高精度乘法**：逐位相乘累加进位，处理多轮进位
- **高精度除法（大数÷小数）**：从高位试商，逐位求商、算余数；大数÷大数需要减法配合试商，是难点
- **高精度阶乘**：迭代累乘，全程维护进位逻辑
- **核心考点**：进位、借位、试商模拟手工计算逻辑
