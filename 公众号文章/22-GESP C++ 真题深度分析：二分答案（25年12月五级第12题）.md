### 二、 check 函数的数学原理
```cpp
int cuts = (L - 1) / x;
```

**为什么是 (L-1)/x？**
- 一段长度 L，切成每段最长 x
- 段数 = **ceil(L / x)**
- 刀数 = **段数 - 1**
- 公式推导：
  ```
  刀数 = ceil(L / x) - 1
       = (L - 1) / x   （整数除法下等价）
  ```

**举例验证（题目样例 L=10，K=2）**
- x=5：(10-1)/5 = 9/5 = 1 刀 ≤ 2 → **可行**
- x=4：(10-1)/4=2 刀 ≤2 → **可行**
- x=3：(10-1)/3=3 刀 >2 → **不可行**

---

### 三、正确答案

```cpp
int l = 左边界, r = 右边界;
while (l < r) {
    int mid = l + (r - l) / 2;
    if (check(L, K, mid)) {
        r = mid;      // 可行，尝试更小
    } else {
        l = mid + 1;  // 不可行，必须更大
    }
}
return l;
```

- mid 可行 → 右边界左移，保留 mid 作为候选
- mid 不可行 → 左边界移到 mid+1

### 一、题目

#### 题干
给定⼀个 n x n 的矩阵 matrix ，矩阵的每⼀⾏和每⼀列都按升序排列。函数 countLE 返回矩阵中第k ⼩的元素，则两处横线上应分别填写（ ）

#### 代码

// 统计矩阵中 <= x 的元素个数：从左下角开始
// 统计矩阵中 <= x 的元素个数：从左下角开始
int countLE(const vector<vector<int>>& matrix, int x) {
	int n = (int)matrix.size();
	int i = n - 1, j = 0, cnt = 0;
	while (i >= 0 && j < n) {
		if (matrix[i][j] <= x) {
			cnt += i + 1;
			++j;
		} else {
			--i;
		}
	}
	return cnt;
}

### 二、答案

```cpp
if (countLE(matrix, mid) >= k) {
    hi = mid;
} else {
    lo = mid + 1;
}
```

1. **`<= mid` 的数 ≥ k 个**  
   → 答案**就在左边，包含 mid**  
   → 不能丢 mid，所以 `hi = mid`

2. **`<= mid` 的数 < k 个**  
   → 答案**一定在 mid 右边**  
   → 可以直接 `lo = mid + 1`

---

### 三、易错点：不能写 `hi = mid - 1`

因为 `mid` **可能就是最终答案**。
- 比如答案就是 5
- `countLE(5) = 10 ≥ k`
- 你写 `hi = mid -1` → 直接把 5 扔掉了，结果必错
