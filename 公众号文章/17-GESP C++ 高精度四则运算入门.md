# GESP C++ 高精度四则运算入门

**高精度运算的核心原理**：本质上是利用软件算法，模拟人类 **“列竖式计算”** 的思维过程。通过将超大整数拆解并存储在**数组或字符串**中，程序能够逐位执行加减乘除，并精准处理**进位与借位**，从而突破C++原生数据类型（如`int`、`long long`）的位数限制。

## 一、为什么我们需要高精度？

在计算机底层，数据类型的存储空间是有限的。当数字大到一定程度，硬件就无法直接处理了，需要在软件层面进行计算，突破硬件自身的限制。

### 1. 原生数据类型的“天花板”

| 数据类型 | 位数 | 最大值（约） | 位数限制 | 典型溢出后果 |
| :--- | :--- | :--- | :--- | :--- |
| `int` | 32位 | $2.1 \times 10^9$ | 10位 | 数据截断、变为负数 |
| `long long` | 64位 | $9.2 \times 10^{18}$ | 19位 | 精度丢失、计算错误 |
| **高精度算法** | **自定义** | **无限（受内存限制）** | **数千/数万位** | **精准无误** |

### 2. 核心应用场景
*   **密码学（RSA算法）**：依赖数百位大素数的生成与运算，是网络安全的基石。
*   **科学计算**：如计算圆周率 $\pi$ 的数亿位小数，或模拟流体动力学的纳维-斯托克斯方程（需极高精度以避免误差累积）。
*   **金融精算**：处理巨额资金流转或极小汇率差，不能容忍浮点数的精度丢失。
*   **算法竞赛与数学**：计算 $100!$（100的阶乘）等超大数值。

## 二、大数的存储策略

为了让计算机像人一样计算，我们需要改变数字的存储方式。在C++语言的编程环境下，一般有下面两个策略：
*   **输入**：由于数字太长，必须先用**字符串 (`string`)** 读入。
*   **存储**：将字符串转换为**数组 (`vector<int>`)**，并采用**逆序存储**。（注：除法不需要）

注：也可以使用字符串数组和普通数组

> **为什么要逆序？**
> 人类计算习惯从个位（最低位）算起，而字符串是正序的（高位在前）。将个位存在数组下标 `0` 的位置，方便直接进行进位操作（`push_back`），无需移动整个数组。


**存储示意图：**

假设数字为 `"12345"`

```text
字符串: "1" "2" "3" "4" "5"  (高位 -> 低位)
  ↓ 逆序转换
数组: (下标0 -> 下标4)
       ↑
     个位 (方便计算起点)
```

## 三、四则运算原理（模拟竖式）

### 1. 加法：逐位累加 + 进位

模拟竖式加法，核心公式如下：
*   **当前位和**：$Sum = A[i] + B[i] + Carry$ （当前位数字 + 进位）
*   **本位结果**：$Result[i] = Sum \pmod{10}$
*   **新进位**：$Carry = Sum \div 10$

注：编程时：一般用 t 表示进位和借位的值，即：上面公式里面的 Carry。
#### 流程演示：

假设我们要计算 **123 + 4567**。
在数组中，数字是**逆序存储**的（个位在下标0），计算也是从下标0（最左边）开始向右进行。

```text
      A=3  A=2  A=1      (数字 123，逆序存储: 下标0是3)
    + B=7  B=6  B=5  B=4 (数字 4567，逆序存储: 下标0是7)
    -------------------
    3+7=10  -> 写0进1 (进位 t=1)
    2+6+1=9 -> 写9 (进位 t=0)
    1+5+0=6 -> 写6
        4   -> 直接落下
    -------------------
    结果: 4690 (逆序数组: 0, 9, 6, 4)
```

1.  **对齐方式**：
    -   **同位对齐**：即 `A` 的第 `i` 位只和 `B` 的第 `i` 位相加，结果直接存入 `C` 的第 `i` 位。

2.  **进位处理 (`t`)**：
    -   **第1步**：`3 + 7 = 10`。因为 $10 \ge 10$，所以本位存 `0`，进位 `t` 变为 `1`。
    -   **第2步**：`2 + 6 + t(1) = 9`。进位被消耗，`t` 变为 `0`。
    -   **第3步**：`1 + 5 + t(0) = 6`。
    -   **第4步**：`A` 已经算完了，`B` 还剩一位 `4`，直接加上进位 `0` 落下。

3.  **代码对应逻辑**：
    这就对应了代码中的核心循环：
    ```cpp
    t += A[i];        // 加上A的当前位
    t += B[i];        // 加上B的当前位
    C.push_back(t % 10); // 本位存余数
    t /= 10;          // 算出新的进位
    ```

### 2. 减法：逐位相减 + 借位

减法比加法复杂，因为涉及小数减大数，产生负数的情况。
*   **预处理**：先比较两个数的大小。确保用 **大数 - 小数**。如果实际是小减大，先标记负号，计算绝对值。
*   **借位逻辑**：
    *   若 $A[i] < B[i]$，则向高位借1：$A[i] += 10$，且高位 $A[i+1]--$。
    *   结果：$Result[i] = A[i] - B[i]$。
*   **去零**：计算完成后，需去除结果高位的 `0`（如 `005` 变为 `5`）。

#### 流程演示：

假设我们要计算 **123 - 48**。
在数组中，数字是**逆序存储**的，计算从下标 0（最左边）开始向右进行。

```text
      A=3  A=2  A=1      (数字 123，逆序存储: 下标0是3)
    - B=8  B=4  B=0      (数字 048，逆序存储: 下标0是8，高位补0)
    -------------------
    3-8不够减 -> 向高位借1 (借位 t=1)
    (3+10)-8 = 5   -> 写5
    
    2-4-1(借位)不够减 -> 向高位借1 (借位 t=1)
    (2+10)-4-1 = 7 -> 写7
    
    1-0-1(借位) = 0 -> 写0
    -------------------
    结果: 075 (逆序数组: 5, 7, 0)
    去前导零后: 75
```


1.  **借位标记 (`t`)**：
    -   **第 1 步**：`3 - 8` 不够减。向高位（A=2）借 1。此时 `3` 变成 `13`。`13 - 8 = 5`。同时标记借位 `t = 1`，即告诉下一位“你被借走了 1”。
    -   **第 2 步**：`2 - 4`。因为上一位借走了 1，所以实际是 `2 - 1 - 4`，还是不够减。继续向高位（A=1）借 1。此时 `2` 变成 `12`（减去借位剩 11，再借位当 12 算）。`12 - 4 - 1 = 7`。标记借位 `t = 1`。
    -   **第 3 步**：`1 - 0`。因为上一位借走了 1，所以 `1 - 1 = 0`。
    - 注：这个例子中没有出现不借位的情况，如果有的话，需要把 t 设置成 0；

2.  **代码对应逻辑**：
    这就对应了代码中的核心循环：
    ```cpp
    t = A[i] - t;       // 先减去上一位的借位
    if (i < B.size()) t -= B[i]; // 再减去减数的对应位
    C.push_back((t + 10) % 10); // 处理负数情况 (相当于借位后的结果)
    if (t < 0) t = 1;   // 如果结果小于0，说明不够减，标记下一位需要借位
    else t = 0;         // 否则借位消除
    ```

### 3. 乘法：错位累加 + 统一进位

乘法是高精度运算中最精妙的部分，因为有个错位的情况，而且结果的长度会非常长，
*   **核心规律**：第 `i` 位数字与第 `j` 位数字相乘，其结果会影响结果数组的第 `i+j` 位和 `i+j+1` 位。
*   **算法步骤**：
    1.  **双重循环**：遍历 A 和 B 的每一位，执行 $C[i+j] += A[i] \times B[j]$。
    2.  **统一进位**：所有乘法做完后，再遍历一次结果数组处理进位（$C[k+1] += C[k]/10$）。

#### 流程演示：

假设我们要计算 **12 × 34**。
乘法的核心在于 **“错位相乘”**：第 `i` 位与第 `j` 位相乘，结果累加到第 `i+j` 位。

```text
      A=2  A=1      (数字 12，逆序存储: 下标0是2)
    x B=4  B=3      (数字 34，逆序存储: 下标0是4)
    -------------------
    第一轮：A[0] 乘 B (即 2 乘 34)
    2x4=8 -> 累加到 C[0]
    2x3=6 -> 累加到 C[1]
    
    第二轮：A[1] 乘 B (即 1 乘 34，需左移一位)
    1x4=4 -> 累加到 C[1] (与上一轮的6叠加)
    1x3=3 -> 累加到 C[2]
    -------------------
    累加后 (未进位): C[0]=8, C[1]=10, C[2]=3
    统一进位处理:
    C[0]=8 (不变)
    C[1]=10 -> 写0进1 (C[2]变为3+1=4)
    C[2]=4 (不变)
    -------------------
    结果: 408 (逆序数组: 8, 0, 4)
```


1.  **错位规律 (`i+j`)**：
    -   **个位乘个位** (`A[0]×B[0]`)：结果影响 `C[0]`。
    -   **交叉相乘** (`A[1]×B[0]` 和 `A[0]×B[1]`)：结果都影响 `C[1]`，这就是为什么中间位往往是多位数之和（如示例中的 `6+4=10`）。
    -   **高位乘高位** (`A[1]×B[1]`)：结果影响 `C[2]`。

2.  **统一进位**：
    -   与加减法不同，乘法通常**先累加所有乘积**，让数组中间出现大于 10 的数字（如示例中的 `10`），最后再统一遍历一次数组处理进位。这样效率更高，逻辑更清晰。

#### 流程演示：（有连续进位）

这是一个**连续进位**的极端例子。
计算 **99 × 99 = 9801**。
可以看到中间累加阶段会出现很大的数字（如81），必须依赖最后的统一进位来处理。

```text
      A=9  A=9      (数字 99，逆序存储: 下标0是9)
    x B=9  B=9      (数字 99，逆序存储: 下标0是9)
    -------------------
    第一轮：A[0] 乘 B (即 9 乘 99)
    9x9=81 -> 累加到 C[0]
    9x9=81 -> 累加到 C[1]
    
    第二轮：A[1] 乘 B (即 9 乘 99，需左移一位)
    9x9=81 -> 累加到 C[1] (与上一轮的81叠加)
    9x9=81 -> 累加到 C[2]
    -------------------
    累加后 (未进位): C[0]=81, C[1]=162, C[2]=81
    (注意：此时数组里存的都是几十上百的数)
    
    统一进位处理:
    1. C[0]=81 -> 写1进8 (C[1]变为162+8=170)
    2. C[1]=170 -> 写0进17 (C[2]变为81+17=98)
    3. C[2]=98 -> 写8进9 (C[3]变为0+9=9)
    4. C[3]=9 -> 写9
    -------------------
    结果: 9801 (逆序数组: 1, 0, 8, 9)
```

1.  **累加阶段的“爆炸”**：
    -   在乘法中，`C[i]` 的值可能会非常大。
    -   例如 `C[1]` 接收了两个 `81`，变成了 `162`。这在加法中是不可能出现的（加法最多是 `9+9+1=19`）。
    -   这就是为什么乘法**必须**使用 `long long` 或者在累加后立刻处理进位，否则 `int` 可能会溢出（如果是几百位的大数相乘，中间累加值会非常大）。

2.  **连续进位链**：
    -   第0位的进位（8）加到了第1位。
    -   导致第1位变得更大（170），从而产生了巨大的进位（17）给第2位。
    -   这种 **“进位传导”** 是乘法最后一步统一处理进位的核心原因。

3.  **代码对应逻辑**：
    ```cpp
    // 1. 累加 (此时 C 数组里可能存着 81, 162, 81)
    for (int i = 0; i < lenA; i++)
        for (int j = 0; j < lenB; j++)
            C[i + j] += A[i] * B[j]; 

    // 2. 统一进位 (把 81, 162, 81 变成 1, 0, 8, 9)
    for (int i = 0; i < C.size() || t; i++) {
        t += C[i];      // t 初始为0，加上当前位的巨大数值
        C[i] = t % 10;  // 只保留个位
        t /= 10;        // 剩下的全部作为进位传给下一位
    }
    ```

### 4. 除法（高精 ÷ 低精）：模拟试商

对于除以一个小整数（如 `int` 范围），不需要模拟复杂的竖式减法。
*   **从高位到低位**遍历大数数组。
*   **余数传递**：$Remainder = Remainder \times 10 + CurrentDigit$。
*   **计算商位**：$Quotient[i] = Remainder \div Divisor$。
*   **更新余数**：$Remainder = Remainder \pmod{Divisor}$。

#### 流程演示：

假设我们要计算 **1234 ÷ 7**。

**注意**：与加减乘不同，除法必须**从高位向低位**（从左向右）计算，模拟竖式除法的过程。

```text
    被除数: 1  2  3  4  (正常顺序读取)
    除数: 7
    -------------------
    第1步：取 1
    1 < 7，不够除 -> 商0 (最高位通常不写0)，余数 r=1
    
    第2步：余数 r 落下一位变成 12
    12 / 7 = 1 ... 5 -> 商1，余数 r=5
    
    第3步：余数 r 落下一位变成 53
    53 / 7 = 7 ... 4 -> 商7，余数 r=4
    
    第4步：余数 r 落下一位变成 44
    44 / 7 = 6 ... 2 -> 商6，余数 r=2
    -------------------
    最终结果:
    商: 176
    余数: 2
```


1.  **计算方向（反向）**：
    -   **加减乘**：都是从个位（数组下标0）开始算。
    -   **除法**：必须从最高位（数组下标 `len-1`）开始算。因为我们要先看高位够不够除，不够除才看前两位。

2.  **余数传递 (`r`)**：
    -   核心公式：`r = r * 10 + 当前位`。
    -   每一步的余数，对于下一位来说，相当于“进位”变成了“十倍”。例如第2步余数是5，到了第3步，它变成了50，再加上当前位的3，变成53。

3.  **代码对应逻辑**：
    这就对应了代码中的核心循环：
    ```cpp
    int r = 0;
    // 注意：i 从 A.size()-1 开始递减到 0
    for (int i = A.size() - 1; i >= 0; i--) {
        r = r * 10 + A[i];    // 余数左移一位 + 当前位
        C.push_back(r / b);   // 算出当前位的商
        r %= b;               // 算出新的余数
    }
    ```

4.  **结果反转**：
    由于我们是从高位算的，算出的商 `1, 7, 6` 是按顺序存入数组的（高位在前）。但为了保持高精度数“低位在前”的统一存储规则，最后必须将结果数组**反转**。


### 5. 除法（高精 ÷ 高精）


高精度除以高精度（例如 **12345 ÷ 123**）是四则运算中最复杂的部分。
因为无法像“除以低精”那样直接用 `int` 存储余数，我们需要**模拟竖式除法**，核心步骤是 **“试商”** （估算商是多少）和 **“做减法”**。

#### 流程演示：

假设我们要计算 **12345 ÷ 123**。
**核心逻辑**：从高位开始，不断从被除数中**减去** `除数 × 试商`，直到剩下的数小于除数。

```text
被除数 A: 1 2 3 4 5
除数 B:   1 2 3
-------------------
第1步：取被除数前3位 "123"
当前余数 R = 123
判断：R (123) >= B (123) ? 是。
试商：123 / 123 ≈ 1
操作：R = R - (B × 1) = 123 - 123 = 0
商的第一位：1

第2步：落下被除数下一位 "4"
当前余数 R = 4 (即 04)
判断：R (4) < B (123) ? 是，不够除。
试商：0
操作：无减法操作
商的第二位：0

第3步：落下被除数下一位 "5"
当前余数 R = 45
判断：R (45) < B (123) ? 是，不够除。
试商：0
操作：无减法操作
商的第三位：0

-------------------
最终结果:
商: 100
余数: 45
```

####  进阶试商演示 (1000 ÷ 3)

如果除数比较小（如3），被除数很大，逐次减3太慢了。我们需要**估算**商是多少。

```text
被除数 A: 1 0 0 0
除数 B:   3
-------------------
第1步：取最高位 "1"
R = 1 < 3，不够除，商0。

第2步：取前两位 "10"
R = 10
试商估算：10 / 3 ≈ 3
操作：R = 10 - (3 × 3) = 1
商的第二位：3

第3步：落下 "0"
R = 10
试商估算：10 / 3 ≈ 3
操作：R = 10 - (3 × 3) = 1
商的第三位：3

第4步：落下 "0"
R = 10
试商估算：10 / 3 ≈ 3
操作：R = 10 - (3 × 3) = 1
商的第四位：3

-------------------
最终结果:
商: 333
余数: 1
```

1.  **减法代替除法**：
    -   计算机底层做高精度除法时，本质上是在做**减法**。
    -   问“10里面有几个3？”，计算机的做法是：10减3得7（商1），7减3得4（商2），4减3得1（商3），1不够减了，所以商是3，余数是1。
    -   为了加速，通常使用**二分法**或**估算法**（如直接用 `R` 的首位除以 `B` 的首位）来确定试商，避免一次一次减。

2.  **处理流程**：
    -   **对齐**：先看被除数的前 `len(B)` 位。
    -   **比较**：如果这部分小于除数，就多取一位。
    -   **试商**：估算这部分能包含几个除数。
    -   **相减**：从被除数中减去 `除数 × 试商`。
    -   **落下**：把被除数的下一位移下来，拼接到余数后面，重复上述步骤。

3.  **代码对应逻辑**：
    这通常需要一个辅助的 **“大数减法”** 函数和 **“大数比较”** 函数。
    ```cpp
    vector<int> div_high(const vector<int>& A, const vector<int>& B, vector<int>& R) {
        vector<int> Q; // 商
        R = A; // 余数初始化为被除数
        
        // 从高位开始处理 (伪代码逻辑)
        for (int i = A.size() - B.size(); i >= 0; i--) {
            // 1. 构造临时除数 (B 左移 i 位)
            // 2. 试商：看 R 能减去多少个临时除数
            int s = 0;
            while (compare(R, temp_B_shifted) >= 0) {
                R = sub(R, temp_B_shifted); // 做减法
                s++; // 试商加1
            }
            Q.push_back(s); // 记录商
        }
        return Q;
    }
    ```
    *(注：实际代码中，为了效率，试商通常不会用 `while` 循环一次减1，而是通过计算首位估算出一个接近的值，然后微调。)*


## 四、代码、关键细节与优化技巧


**核心思想**：用 `vector<int>` 逆序存储大数（低位在前、高位在后），方便进位/借位；实现 **加、减、高精×高精、高精÷低精** 四类运算。

---

### 1. 辅助函数（字符串 ↔ 向量）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <utility>
using namespace std;

// 功能：将数字字符串 转换为 逆序存储的vector（低位在前，方便计算）
// 例如："123" → [3,2,1]
vector<int> str_to_vec(string s) {
    vector<int> res;
    for (int i = s.size() - 1; i >= 0; i--)
        res.push_back(s[i] - '0');  // 字符转数字
    return res;
}

// 功能：将逆序vector转回正常字符串（自动去掉前导零）
// 例如：[3,2,1] → "123"
string vec_to_str(vector<int> v) {
    // 去掉高位多余的0
    while (v.size() > 1 && v.back() == 0)
        v.pop_back();
    string s;
    // 逆序输出，恢复正常数字顺序
    for (int i = v.size() - 1; i >= 0; i--)
        s += (v[i] + '0');
    return s;
}

// 功能：比较两个大数 A 和 B 的大小
// 返回值：A > B 则返回 true，否则 false
bool cmp(vector<int> &A, vector<int> &B) {
    // 位数不同，位数多的更大
    if (A.size() != B.size())
        return A.size() > B.size();
    // 位数相同，从高位到低位逐位比较
    for (int i = A.size() - 1; i >= 0; i--)
        if (A[i] != B[i])
            return A[i] > B[i];
    return true;
}
```

### 2. 高精度加法（A + B）
**原理**：从低位逐位相加，处理进位。
```cpp
// 功能：A + B，模拟竖式加法，逐位相加 + 进位
vector<int> add(vector<int> &A, vector<int> &B) {
    vector<int> C;
    int carry = 0;  // 进位

    // 遍历所有位，直到A、B都遍历完且无进位
    for (int i = 0; i < A.size() || i < B.size() || carry; i++) {
        if (i < A.size()) carry += A[i];
        if (i < B.size()) carry += B[i];
        C.push_back(carry % 10);  // 当前位
        carry /= 10;              // 更新进位
    }
    return C;
}
```

### 3. 高精度减法（A − B，A ≥ B ≥ 0）
**原理**：先比较大小，不够减则借位；结果带符号。
```cpp
// 功能：A - B（前提：A >= B），模拟竖式减法 + 借位
vector<int> sub(vector<int> &A, vector<int> &B) {
    vector<int> C;
    int borrow = 0;  // 借位

    for (int i = 0; i < A.size(); i++) {
        int val = A[i] - borrow;  // 减去上一位的借位
        if (i < B.size()) val -= B[i];
        borrow = 0;

        // 不够减，向前借1
        if (val < 0) {
            val += 10;
            borrow = 1;
        }
        C.push_back(val);
    }

    // 去掉前导零
    while (C.size() > 1 && C.back() == 0)
        C.pop_back();
    return C;
}

// 功能：对外接口，支持带符号的减法
string big_sub(string a, string b) {
    vector<int> A = str_to_vec(a);
    vector<int> B = str_to_vec(b);

    // 如果 A < B，结果为负数
    if (!cmp(A, B)) {
        vector<int> C = sub(B, A);
        return "-" + vec_to_str(C);
    } else {
        vector<int> C = sub(A, B);
        return vec_to_str(C);
    }
}
```

### 4. 高精度乘法（高精 × 高精）
**原理**：`c[i+j] += a[i] * b[j]`，最后统一进位。
```cpp
// 功能：模拟竖式乘法，先累加再统一处理进位
vector<int> mul(vector<int> &A, vector<int> &B) {
    vector<int> C(A.size() + B.size(), 0);

    // 逐位相乘，结果存在 i+j 位置
    for (int i = 0; i < A.size(); i++)
        for (int j = 0; j < B.size(); j++)
            C[i + j] += A[i] * B[j];

    // 统一处理进位
    int carry = 0;
    for (int k = 0; k < C.size() || carry; k++) {
        if (k < C.size()) carry += C[k];
        if (k < C.size()) C[k] = carry % 10;
        else C.push_back(carry % 10);
        carry /= 10;
    }

    // 去前导零
    while (C.size() > 1 && C.back() == 0)
        C.pop_back();
    return C;
}
```

### 5. 高精度除法（高精 ÷ 低精，带余数）
**原理**：从高位到低位试商，`r = r*10 + A[i]`，求商与余数。
```cpp
// 功能：A ÷ b（b是普通整数），返回商，参数r返回余数
vector<int> div_low(vector<int> &A, int b, int &r) {
    vector<int> C;
    r = 0;  // 余数

    // 从高位往低位计算
    for (int i = A.size() - 1; i >= 0; i--) {
        r = r * 10 + A[i];
        C.push_back(r / b);   // 当前位商
        r %= b;               // 更新余数
    }

    // 反转并去前导零
    reverse(C.begin(), C.end());
    while (C.size() > 1 && C.back() == 0)
        C.pop_back();
    return C;
}
```

### 6. 高精度除法（高精 ÷ 高精，带余数）
```cpp

// 辅助函数：高精 × 单个数字（0~9），给除法内部使用
vector<int> mul_one(vector<int> &a, int k) {
    vector<int> res;
    long long carry = 0;
    for (int x : a) {
        carry += 1LL * x * k;
        res.push_back(carry % 10);
        carry /= 10;
    }
    while (carry) {
        res.push_back(carry % 10);
        carry /= 10;
    }
    return res;
}

// 功能：高精 ÷ 高精
// 返回值：pair<商, 余数>
pair<vector<int>, vector<int>> div_high(vector<int> A, vector<int> B) {
    vector<int> Q;  // 商
    vector<int> R;  // 余数

    // 如果被除数 < 除数，商为0，余数为被除数
    if (cmp(B, A)) {
        Q = str_to_vec("0");
        return {Q, A};
    }

    int n = A.size();
    // 从高位到低位，逐位试商
    for (int i = n - 1; i >= 0; --i) {
        // 将当前最高位加到余数前面
        R.insert(R.begin(), A[i]);

        // 去掉余数前导零
        while (R.size() > 1 && R.back() == 0)
            R.pop_back();

        // 试减：最多能减几次 B，当前位商就是几
        int k = 0;
        while (cmp(R, B)) {
            R = sub(R, B);
            k++;
        }
        Q.push_back(k);
    }

    // 反转商，去掉前导零
    reverse(Q.begin(), Q.end());
    while (Q.size() > 1 && Q.back() == 0)
        Q.pop_back();
    while (R.size() > 1 && R.back() == 0)
        R.pop_back();

    return {Q, R};
}
```

### 9. 进阶优化：压位存储
为了减少循环次数，提高运行速度，我们可以让数组的每个单元不只存 1 位数字，而是存 **4位** 或 **9位**（万进制或亿进制）。
*   **原理**：数组存 `0~9999`，进位阈值变为 `10000`。
*   **效果**：循环次数减少为原来的 1/4 或 1/9，显著提升大数运算效率。

## 五、总结

**高精度运算 = 数组逆序存大数 + 模拟竖式逐位算 + 严谨的进位/借位/去零处理**。它是用软件逻辑弥补硬件位宽不足的经典范例。

### 1. 高精度加法：逐位累加 + 进位传递

整体流程：对齐数位 → 逐位求和 → 取余留位 → 整除进位

1. 遍历两个大数数组，对应数位数值相加，叠加上一轮进位值；
2. 计算公式：`当前位数值 = 总和 % 10`，`新进位 = 总和 / 10`；
3. 所有数位计算完成后，若仍存在残留进位，单独补充至结果末尾。

### 2. 高精度减法：大小预判 + 逐位相减 + 向前借位

1. 前置判断：优先比较两个大数的位数与数值大小，强制遵循**大数减小数**，单独记录正负号；
2. 逐位运算：对应数位相减，若当前位数值不足减，则`当前位 + 10`，并向高一位借 1；
3. 结果处理：运算结束后统一剔除前导零，结合预判的符号输出最终结果。

### 3. 高精度乘法：数位错位累加 + 统一进位

采用竖式错位相乘逻辑，区别于加减法，优化进位处理时机提升效率：

1. 错位规则：第 `i` 位 × 第 `j` 位，结果固定存储在目标数组 `i+j` 下标位置；
2. 批量累加：先完成所有数位乘法运算，统一累加结果，不实时处理进位；
3. 后置进位：全部相乘结束后，从低位到高位统一遍历，批量处理进位，减少循环次数。

### 4. 高精度除法（高精 ÷ 低精）：高位试商 + 余数迭代

多用于大数除以普通整型的场景，逻辑贴合手写除法试商：

1. 顺序运算：区别于加减乘，除法**从高位向低位**逐位计算；
2. 迭代规则：`余数 = 余数 × 10 + 当前数位数值`；
3. 试商取值：`当前商 = 余数 / 除数`，`更新余数 = 余数 % 除数`；
4. 数据清洗：剔除商的前导零，最终保留商与剩余余数。
