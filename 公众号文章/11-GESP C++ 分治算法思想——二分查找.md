

# GESP C++ 分治算法思想——二分查找


## 一、分治算法思想

分治，全称“分而治之”（Divide and Conquer），是一种核心的算法设计思想。它的核心策略非常直观：**将一个复杂的大问题，分解成若干个规模更小、结构相同或相似的子问题，分别求解这些子问题，最后将子问题的解合并，从而得到原问题的解**。

这个思想可以概括为三个标准步骤：

1.  **分解 (Divide)**：将原问题递归地分解为一系列规模更小、相互独立且与原问题性质相同的子问题。
2.  **解决 (Conquer)**：当子问题足够小，可以直接求解时，就解决它。否则，继续递归地对子问题进行分解和解决。
3.  **合并 (Merge)**：将各个子问题的解合并，形成原问题的最终解。

分治思想通常与**递归**紧密结合，通过递归不断地“分”，直到问题小到可以直接“治”，再层层返回，将结果“合”起来。

### 经典应用实例

许多高效的算法都是基于分治思想设计的，你之前提到的二分算法就是其中之一。

#### 1. 二分查找 (Binary Search)

这是一个非常典型的分治应用。
*   **分解**：在一个有序数组中查找目标值时，将查找范围一分为二，通过比较中间元素与目标值，可以确定目标值只可能存在于其中一半。
*   **解决**：在确定的那一半范围内继续查找。
*   **合并**：此问题的“合并”步骤很简单，就是直接返回找到的位置。

这个过程不断将问题规模减半，体现了分治的精髓。

#### 2. 归并排序 (Merge Sort)

归并排序是另一个教科书级的例子，用于对数组进行排序。
*   **分解**：将待排序的数组从中间分成两个子数组。
*   **解决**：递归地对这两个子数组分别进行归并排序，直到子数组中只有一个元素（天然有序）。
*   **合并**：将两个已经排好序的子数组合并成一个完整的有序数组。

### 适用场景与特点

并非所有问题都适合用分治法解决，它通常适用于具备以下特征的问题：

*   **可分解性**：问题可以被分解为若干个规模较小的相同问题。
*   **子问题独立**：分解出的子问题之间是相互独立的，不相互影响。这是分治法高效的关键。
*   **解可合并**：能够将子问题的解有效地合并为原问题的解。
*   **存在基本情况**：当问题规模缩小到一定程度时，可以直接求解。

### 优势

*   **高效性**：分治算法常常能显著降低问题的时间复杂度。例如，归并排序和快速排序的时间复杂度为 O(n log n)，远优于简单的冒泡排序 O(n²)。
*   **并行化潜力**：由于子问题是相互独立的，它们非常适合在多处理器系统上进行并行计算，从而进一步提升效率。


## 二、二分查找


**二分查找（Binary Search）**，又称折半查找，是基于**分治策略**、针对**有序数组**的高效查找算法。
- **核心思想**：利用数组**有序性**，每次将查找**区间减半**，通过比较目标值与中间元素，排除不可能存在目标的半区，快速缩小范围。
- **本质**：每次比较排除一半错误答案，将O(n)暴力查找优化为O(log n)级别。

### 核心知识点

1.  **前提条件**：
    *   数组必须是**有序**的（通常是单调递增）。
    *   如果是无序数组，必须先使用 `std::sort` 进行排序。
2.  **时间复杂度**：
    *   $O(\log n)$。每次查找都将范围缩小一半，效率远高于 $O(n)$ 的遍历。
3.  **核心思想**：
    *   通过比较中间元素 `a[mid]` 与目标值 `target`，排除掉一半不可能存在的区间。


### 代码模板（必背）

在 GESP 考试中，二分查找，以及变种的 `lower_bound` 和 `upper_bound` 是常考的知识点，尤其是细节的考察，我看了历年的真题，考察频率极高。

#### 1. 基础二分查找（查找值是否存在）

判断一个数 `target` 是否在数组中，并返回其下标。

```cpp
#include <iostream>
#include <vector>
#include <algorithm> // 包含 sort 函数
using namespace std;

// 基础二分查找函数
// 在有序数组 a 中查找 target，如果找到返回下标，否则返回 -1
int binarySearch(vector<int>& a, int target) {
    int left = 0;
    int right = a.size() - 1; // 右边界是最后一个元素的下标
    
    while (left <= right) {   // 注意：是 <=，因为区间是 [left, right]
        int mid = left + (right - left) / 2; // 防止 (left+right) 溢出的标准写法
        
        if (a[mid] == target) {
            return mid;       // 找到了
        } else if (a[mid] < target) {
            left = mid + 1;   // 目标在右半边，收缩左边界
        } else {
            right = mid - 1;  // 目标在左半边，收缩右边界
        }
    }
    return -1; // 没找到
}

int main() {
    // 模拟输入
    int n = 5;
    vector<int> arr = {1, 3, 5, 7, 9};
    int target = 5;
    
    // 确保数组有序（如果是题目给定的无序数组，必须加这一行）
	 sort(arr.begin(), arr.end()); 
    
    int result = binarySearch(arr, target);
    
    if (result != -1) {
        cout << "找到了，下标为: " << result << endl;
    } else {
        cout << "没找到" << endl;
    }
    return 0;
}
```

#### 2. 进阶：查找第一个大于等于 target 的位置 (`lower_bound`)

找 target 的**左边界**（第一次出现的位置）

- **核心定义**：找到下标 `i`，使得 `a[i] >= target`（**大于或等于**），且 `i` 尽可能小。
- **含义**：它是“第一个不小于 `target` 的数”的位置。
- **返回值**：
    - 如果数组中有等于 `target` 的数，返回**第一个等于 `target` 的数的下标**。
    - 如果数组中没有等于 `target` 的数，返回**第一个大于 `target` 的数的下标**。
    - 如果数组中所有数都小于 `target`，返回数组长度 `n`。

```cpp
// 查找第一个 >= target 的位置
// 如果所有数都小于 target，返回 a.size()
int lowerBound(vector<int>& a, int target) {
    int left = 0;
    int right = a.size() - 1;
    int ans = a.size(); // 初始化答案为数组长度（表示没找到或超出范围）
    
    while (left <= right) {
        int mid = left + (right - left) / 2;
        
        if (a[mid] >= target) {
            ans = mid;      // 记录当前满足条件的位置
            right = mid - 1; // 关键点：继续向左找，看有没有更小的满足条件的下标
        } else {
            left = mid + 1; // 不满足条件，向右找
        }
    }
    return ans;
}
```


#### 3. 进阶：查找第一个大于 target 的元素的位置(`upper_bound`)

找 target 的**右边界**（最后一次出现位置的下一个位置）。

- **核心定义**：找到下标 `i`，使得 `a[i] > target`，且 `i` 尽可能小。
- **返回值**：
    - 如果找到了比 `target` 大的数，返回该数的下标。
    - 如果数组中所有数都小于等于 `target`，返回数组长度 `n`（即 `a.end()` 的位置）。

```cpp
// 查找第一个 > target 的位置
int upperBound(vector<int>& a, int target) {
    int left = 0;
    int right = a.size() - 1;
    int ans = a.size(); // 默认答案是数组长度（表示没找到比 target 大的数）
    
    while (left <= right) {
        int mid = left + (right - left) / 2;
        
        if (a[mid] > target) { // 注意与 lower_bound 的区别
            ans = mid;      // 记录当前位置，因为它满足“大于 target”
            right = mid - 1; // 关键点：向左收缩，试图找到更靠前的满足条件的数
        } else {
            left = mid + 1; // a[mid] <= target，说明目标在右边
        }
    }
    return ans;
}
```


### 3 代码细节说明
#### 1. 变量定义
- `left`：区间左边界（初始=0）
- `right`：区间右边界（初始=数组长度-1）
- `mid`：中间下标（**防溢出写法**）
  ```java
  mid = left + (right - left) / 2; // 推荐
  // 不推荐：mid = (left + right) / 2; （大数相加易溢出）
  ```

### 2. 两种区间写法

上面样例是闭区间的模式 `[left, right]`，最常用，适合找到确切的值。还有一种情况是查找边界的，适合用左开右闭的模式`[left, right)`，边界定义必须与循环条件、更新规则一致

| 写法                     | 初始right | 循环条件            | 右边界更新         | 适用场景      |
| :--------------------- | :------ | :-------------- | :------------ | :-------- |
| **闭区间 [left, right]**  | `n-1`   | `left <= right` | `right=mid-1` | 标准查找、找确切值 |
| **左闭右开 [left, right)** | `n`     | `left < right`  | `right=mid`   | 边界查找、插入位置 |

### 3. 复杂度分析
- **时间复杂度**：O(log n)
  - 长度n，最多折半`log₂n`次。
  - 例：n=10⁶ → 最多约20次比较。
- **空间复杂度**：
  - 迭代：O(1)（仅常数变量）
  - 递归：O(log n)（递归栈深度）


### 4. 考试易错点（避坑指南）

1.  **死循环问题**：
    *   如果使用 `while (left < right)`，更新边界时通常不需要 `+1` 或 `-1`（取决于具体逻辑）。考试的时候需要注意这个变种写法，也可以自己写写代码体会。
    *   如果使用 `while (left <= right)`（教材多推荐的方法），更新边界**必须**是 `mid + 1` 和 `mid - 1`，否则当 `left == right` 时会陷入死循环。
2.  **整数溢出**：
    *   虽然 GESP 考试的数据范围通常不会大到让 `left + right` 溢出，但养成写 `mid = left + (right - left) / 2;` 是一个不错的习惯。
3.  **忘记排序**：
    *   题目如果给的是乱序数组，第一步一定要先 `sort` （注意：上面的代码都是基于升序实现的），否则二分查找的结果是错误的。
