# GESP C++ 分治算法思想——快速排序

快速排序（Quick Sort）是分治算法（Divide and Conquer Algorithm）的经典应用，由东尼·霍尔于1960年提出，通过“先分区（Partition）后递归”的方式实现排序，因其高效性成为实际应用中最常用的排序算法之一。

**算法原理**：**选基准分区** + **递归排序**
- **分区**：从数组中选取一个元素作为“**基准值（Pivot）**”，将数组划分为三部分——小于基准值的元素、基准值本身、大于基准值的元素，最终基准值会落在其最终排序后的正确位置。
- **递归排序**：对基准值左右两侧的两个子数组，分别重复“选基准分区”的操作，直至每个子数组仅含1个元素（此时子数组天然有序），整个数组即完成排序。


快速排序跟前面学习的归并排序，有两个重要的不同，先简单的了解一下，文章末位有更详细的比对，在学习的过程中体会这个两个差异。

1. **分治逻辑不同**（最核心）
    - 归并排序：**先分解，后合并**，分解仅按数组中间位置二分，合并时需用临时数组整合有序子数组。
    - 快速排序：**先分区，后递归**，无需合并，通过选基准值将数组划分为 “小于 / 等于 / 大于基准” 三部分，基准值直接归位。

2. **排序过程不同**
    - 归并排序：自顶向下分解，触底后自下向上合并，全程依赖临时数组。
    - 快速排序：自顶向下分区，基准值归位后递归处理左右子数组，无需合并，仅通过元素交换实现排序。

## 二、代码实现



归并排序的分区方案较多，不同的AI工具给了不同的代码。从学习的角度，我发现Lomuto 分区 是最简单的，可以更好的理解算法逻辑。下面的代码由AI工具（千问）生成

```C++

#include <iostream>
#include <vector>
using namespace std;

// 分区函数：Lomuto 分区方案
// 选择最后一个元素作为基准
int partition(vector<int>& arr, int left, int right) {
    int pivot = arr[right]; // 基准值
    int i = left - 1;       // i 指向“小于等于区”的最后一个元素
    
    for (int j = left; j < right; j++) {
        // 如果当前元素小于等于基准，说明它属于左边
        if (arr[j] <= pivot) {
            i++;
            swap(arr[i], arr[j]); // 把它交换到“小于等于区”的末尾
        }
    }
    // 最后，把基准值放到“小于等于区”的后面，这样基准值就归位了
    swap(arr[i + 1], arr[right]);
    return i + 1; // 返回基准值的最终位置
}

// 快速排序主函数
void quickSort(vector<int>& arr, int left, int right) {
    if (left < right) {
        // 1. 分区，拿到基准值的位置
        int pivotIndex = partition(arr, left, right);
        
        // 2. 递归排序基准值左边的部分
        quickSort(arr, left, pivotIndex - 1);
        
        // 3. 递归排序基准值右边的部分
        quickSort(arr, pivotIndex + 1, right);
    }
}

int main() {
    vector<int> arr = {38, 27, 43, 3, 9, 82, 10};
    quickSort(arr, 0, arr.size() - 1);
    
    for (int x : arr) cout << x << " ";
    return 0;
}
```



同样的，让AI（豆包）写了一个东尼 · 霍尔（Hoare） 分区方案（Hoare Partition Scheme） 的一种变体，也常被称为 双指针交换法。是`std::sort` 等标准库的底层实现中经常能看到它的影子。是一个不错的代码阅读练习，注意双指针的移动，比较容易出错。

```C++

#include <iostream>
#include <vector>
using namespace std;

// 分区函数：选取基准值，将数组划分为小于、等于、大于基准的三部分
// 返回基准值最终的索引位置
int partition(vector<int>& arr, int left, int right) {
    int pivot = arr[left]; // 选取左端点作为基准值（GESP常用方式）
    int i = left + 1;      // 左指针：从基准值下一个位置开始
    int j = right;         // 右指针：从数组末尾开始

    while (i <= j) {
        // 左指针找大于基准值的元素
        while (i <= j && arr[i] <= pivot) {
            i++;
        }
        // 右指针找小于基准值的元素
        while (i <= j && arr[j] > pivot) {
            j--;
        }
        // 交换左右指针指向的元素（此时左>基准，右<基准）
        if (i < j) {
            swap(arr[i], arr[j]);
        }
    }
    // 交换基准值和j指针指向的元素（j是最后一个小于基准的元素位置）
    swap(arr[left], arr[j]);
    return j; // 返回基准值的最终索引
}

// 快速排序主函数
// 要结合上面的逐层展示的步骤来看：分区、递归排序左子数组、递归排序右子数组
void quickSort(vector<int>& arr, int left, int right) {
    if (left < right) {
        int pivotIndex = partition(arr, left, right); // 分区，获取基准值索引
        quickSort(arr, left, pivotIndex - 1);        // 递归排序左子数组（小于基准）
        quickSort(arr, pivotIndex + 1, right);       // 递归排序右子数组（大于基准）
    }
}

int main() {
    vector<int> arr = {38, 27, 43, 3, 9, 82, 10};
    quickSort(arr, 0, arr.size() - 1);
    for (int x : arr) cout << x << " ";
    return 0;
}

```

```C++

#include <iostream>
#include <vector>

// 打印数组
void printArr(vector<int>& arr, int left, int right) {
    for (int i = left; i <= right; i++) {
        cout << arr[i] << " ";
    }

// 分区函数
int partition(vector<int>& arr, int left, int right) {
    int pivot = arr[left];
    int i = left + 1;
    int j = right;

    cout << "→ 分区数组：[";
    printArr(arr, left, right);
    cout << "], 基准值：" << pivot << "\n";

    while (i <= j) {
        while (i <= j && arr[i] <= pivot) i++;
        while (i <= j && arr[j] > pivot) j--;
        if (i < j) {
            swap(arr[i], arr[j]);
            cout << "  交换元素：" << arr[j] << " 和 " << arr[i] << "，数组变为：[";
            printArr(arr, left, right);
            cout << "]\n";
        }

    cout << "  基准值归位：" << pivot << " 移至位置 " << j << "，分区后数组：[";

        cout << "]\n";

        int pivotIndex = partition(arr, left, right);
        quickSort(arr, left, pivotIndex - 1);  // 递归左子数组
        quickSort(arr, pivotIndex + 1, right); // 递归右子数组
```

## 三、性能分析

- **时间复杂度**：平均情况下，分区操作耗时O(n)，递归层数为log n，总时间复杂度为`O(n log n)`；最坏情况下（数组已有序或逆序，基准值选两端），递归层数为n，时间复杂度退化到`O(n²)`。

- **空间复杂度**：仅需递归栈空间，平均递归深度为log n，空间复杂度为`O(log n)`；最坏情况下递归深度为n，空间复杂度为`O(n)`。

- **稳定性**：`不稳定排序`，相等元素的相对位置在分区交换过程中可能改变。

### 时间复杂度

1. **分区过程**

    - 每次分区都会遍历当前子数组，耗时 `O(k)`（k为当前子数组长度）。

    - 整个排序过程中，所有分区操作的总耗时为 `O(n)`（每层分区的子数组总长度均为n）。

2. **递归过程**

    - 理想情况（基准值选中间，分区均匀）：递归层数为 `log₂n` 层。

    - 最坏情况（基准值选两端，分区极端不均）：递归层数为 `n` 层（如数组已有序，每次分区仅拆分出1个元素）。

3. **总时间复杂度**

    - 平均情况：`O(n log n)`（最常用，实际应用中概率最高）。

    - 最好情况：`O(n log n)`（基准值每次都选中间）。

    - 最坏情况：`O(n²)`（基准值选两端，数组有序/逆序）。

---

### 空间复杂度

快速排序无需额外的临时数组（仅交换元素），空间消耗主要来自递归调用的栈空间：

1. **递归栈空间**

    - 理想情况：递归深度为 `log₂n`，栈空间为 `O(log n)`。

    - 最坏情况：递归深度为 `n`，栈空间为 `O(n)`。

2. **总空间复杂度**

    - 平均情况：`O(log n)`。

    - 最坏情况：`O(n)`。

注：可通过“随机选基准”三数取中（左、中、右三个元素选中间值作为基准）”优化，避免最坏情况，使空间复杂度稳定在`O(log n)`。

---

### 不稳定性的原因分析

原因在于分区过程中的“交换操作”，会破坏相等元素的相对位置。

关键代码：

```cpp
if (i < j) {
    swap(arr[i], arr[j]);
}
swap(arr[left], arr[j]);
```

举个简单的例子：

- 原始：`[ 3, 2ₐ, 2ᵦ, 1 ]`，选取3作为基准值。

- 分区过程：右指针j找到小于3的元素1，左指针i找到大于3的元素（无），交换基准值3和j指向的1，得到 `[1, 2ₐ, 2ᵦ, 3]`。

- 继续递归左子数组 `[1, 2ₐ, 2ᵦ]`，选取1作为基准值，分区后得到 `[1, 2ₐ, 2ᵦ]`，看似有序。

- 再举一个反例：原始 `[2ᵦ, 1, 2ₐ, 3]`，选取2ᵦ作为基准值，分区时j找到1（小于2ᵦ），i找到2ₐ（大于2ᵦ），交换1和2ₐ，得到 `[2ᵦ, 2ₐ, 1, 3]`，此时2ₐ和2ᵦ的相对位置颠倒。

可见，快速排序中，相等元素的相对位置可能因交换操作改变，因此是不稳定排序。

## 四、快速排序与归并排序核心区别

快速排序与归并排序均为分治思想的典型应用，但核心逻辑、操作流程及性能特点差异显著，简单对比如下：

### 分治逻辑（最核心）

- 归并排序 (Merge Sort)
    
    - **分解 (Divide):** 它的分解过程非常简单且机械，就是**无条件地**从数组的中间位置将数组一分为二，然后递归地对左右两半继续分解，直到每个子数组只剩下一个元素。

    - **合并 (Conquer/Combine):** 这是归并排序的核心。它需要一个“合并”操作，将两个已经排好序的子数组合并成一个更大的有序数组。这个过程**必须**借助一个**临时数组**来辅助完成，通过比较两个子数组的元素，按顺序将较小的元素放入临时数组中。

- 快速排序 (Quick Sort)
    
    - 分区 (Divide/Partition): 这是快速排序的核心。它首先选择一个**基准值 (pivot)**，然后通过一次“分区”操作，将数组重新排列，使得所有小于基准值的元素都在其左边，所有大于基准值的元素都在其右边。这样一来，**基准值本身就到达了它最终排序后应该在的位置**。
    
    - 递归 (Conquer): 分区完成后，基准值已经“归位”，我们只需要递归地对左右两个子数组重复“分区”和“递归”的过程即可。整个过程**不需要**一个显式的“合并”步骤，因为排序是在分区和元素交换的过程中完成的。

### 排序过程差异

- 归并排序：自顶向下分解，自下向上合并
    
    - 自顶向下分解： 这个过程就像一棵树的生长，从根节点（整个数组）开始，不断向下分裂成子节点（子数组），直到叶子节点（单个元素）。

    - 自下向上合并： 排序发生在“回溯”阶段。从最小的有序单元（单个元素）开始，两两合并成更大的有序数组，层层向上，最终合并成一个完整的有序数组。这个过程全程依赖临时数组来暂存和整合数据。

- 快速排序：自顶向下分区，递归处理
    
    - 自顶向下分区： 从整个数组开始，通过一次分区操作，就确定了一个元素（基准值）的最终位置。

    - 递归处理子数组： 然后，算法分别对基准值左右两边的子数组重复上述过程。排序是通过在原数组上进行元素交换来实现的，这是一种“原地”操作，因此不需要像归并排序那样开辟一个等大的临时数组

### 关键性能对比

- 时间复杂度：归并排序（最好/最坏/平均均为O(n log n)）；快速排序（平均O(n log n)，最坏O(n²)，可通过基准优化避免）。

- 空间复杂度：归并排序需O(n)临时数组；快速排序仅需O(log n)~O(n)递归栈空间。

- 稳定性：`不稳定`（交换操作破坏相对位置）。


| 特性 | 归并排序 (Merge Sort) | 快速排序 (Quick Sort) |
| :--- | :--- | :--- |
| **时间复杂度** | **稳如泰山**最好/最坏/平均均为 $O(n \log n)$ | **看运气**平均 $O(n \log n)$，最坏 $O(n^2)$*(注：最坏情况通常发生在数组已有序且选首/尾为基准时)* |
| **空间复杂度** | **高**需要 $O(n)$ 额外空间 | **低**仅需 $O(\log n)$ 递归栈空间 |
| **稳定性** | **稳定**相同元素的相对顺序不变 | **不稳定**交换过程可能打乱相同元素顺序*(例：`[5a, 5b, 2]` 选 `2` 做基准交换后可能变 `[2, 5b, 5a]`)* |
