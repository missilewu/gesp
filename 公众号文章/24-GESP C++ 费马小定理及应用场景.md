# GESP C++ 费马小定理及应用场景

## 一、定理的核心定义

如果 `p` 是一个**质数**，且整数 `a` 不是 `p` 的倍数（即 `a` 与 `p` 互质），那么：

$$
a^{p-1} \equiv 1 \pmod{p}
$$

其中：
- `p` 必须是质数，这是前提条件；
- `a` 不能被 `p` 整除，否则 $a \equiv 0 \pmod{p}$，就不满足这个式子；
- $\equiv$ 是**同余符号**，表示两边的数除以 `p` 的余数相等。

简单来说：任何一个不能被质数 $p$ 整除的整数 $a$，它的 $p-1$ 次方除以 $p$ 的余数必然是 1。

## 二、定理的等价形式

如果 `a` 是任意整数， `p` 是质数，那么费马小定理也可以写成：

$$a^p \equiv a \pmod{p}$$
实际上是在费马小定理的基础之上，在同余式子的两边同时乘以整数`a`。 

$$
a^{p-1} \times a \equiv 1 \times a \pmod{p} \implies a^p \equiv a \pmod{p}

$$


这个形式更通用：
- 当  `a` 不是 `p` 的倍数时，两边同时除以 `a` ，就得到 $a^{p-1} \equiv 1 \pmod{p}$；
- 当 `a`  是 `p`  的倍数时，$a \equiv 0 \pmod{p}$，此时 $a^p \equiv 0 \equiv a \pmod{p}$，式子依然成立。

## 三、举例说明

下面分**两种情况**举例，结合计算直观验证等价形式 $a^p \equiv a \pmod{p}$，统一取质数 $p=5$。

---
#### 情况1：$\boldsymbol{a}$ 不是质数 $p$ 的倍数
取 $p=5$（质数），$a=2$。

$$
2^5 = 32,\quad 32 \bmod 5 = 2
$$

$$
a \bmod 5 \implies 2 \bmod 5 = 2
$$
可得：

$$
2^5 \equiv 2 \pmod{5}
$$

两边同除以 $a=2$（$2$ 与 $5$ 互质，可做模除法）：

$$
2^{4} \equiv 1 \pmod{5}
$$
还原为原始形式，和定理，以及定理的等价形式结论一致。

再换一组：$p=5,\ a=3$，效果一样。

$$
3^5 \equiv 3 \pmod{5},\quad 3^4 \equiv 1 \pmod{5}
$$

---
#### 情况2：$\boldsymbol{a}$ 是质数 $p$ 的倍数

依旧取 $p=5$，令 $a=10$（10 是 5 的倍数，或者说10可以被5整除）。

$$
a = 10 \implies 10 \equiv 0 \pmod{5}
$$

$$
a^p = 10^5
$$

$10^5$ 显然是 5 的倍数，因此：

$$
10^5 \equiv 0 \pmod{5}
$$

于是：

$$
10^5 \equiv 10 \pmod{5}
$$

---

从两个样例可以看出，等价形式 $a^p \equiv a \pmod{p}$ 对**任意整数 $a$**、**任意质数 $p$** 都通用。

1. 当 $a$ 不被质数 $p$ 整除：$a^p\equiv a\pmod{p}$，可推导出 $a^{p-1}\equiv 1\pmod{p}$；即费马小定理的核心定义；
2. 当 $a$ 被质数 $p$ 整除：$a^p$ 和 $a$ 模 $p$ 余数都为 0，等式依旧成立。


## 四、形象理解：余数的“摩天轮”

我们把前面的情况1的例子展开看，即令质数 $p = 5$。我们选一个不能被 5 整除的数，比如 $a = 2$。  
我们让 2 的幂次一个一个乘以 2，看看它们模 5 的余数：

- $2^1 = 2 \implies$ 模5，余数是 2
- $2^2 = 4 \implies$ 模5，余数是 4
- $2^3 = 8 \implies$ 模5，余数是 3
- $2^4 = 16 \implies$ 模5，余数是 1 （刚好到了第 $p-1=4$ 次方，余数变成了 1！）
- $2^5 = 32 \implies$ 模5，余数是 2 （开始新一轮循环...）
- $2^6 = 64 \implies$ 模5，余数是 4
- ......
- $2^8 = 256 \implies$ 模5，余数是 1 （新一轮循环结束，余数变成了 1！）

发现了吗？余数就像坐摩天轮，绕了一圈，在第 $4$ 次方（即 $p-1$ 次方）的时候，必然会回到 1，然后以4，（即 `p-1`）为步长形成余数最终为1的循环。这就是费马小定理保证的规律。

我们试一下另外一个不能被5整除的数 $a = 3$。

- $3^1 = 3 \implies$ 模5，余数是 3
- $3^2 = 9 \implies$ 模5，余数是 4
- $3^3 = 27 \implies$ 模5，余数是 2
- $3^4 = 81 \implies$ 模5，余数是 1 （刚好到了第 $p-1=4$ 次方，余数变成了 1！）
- $3^5 = 243 \implies$ 模5，余数是 3 （开始新一轮循环...）
- $3^6 = 729 \implies$ 模5，余数是 4
- ......
- $2^8 = 6561 \implies$ 模5，余数是 1 （新一轮循环结束，余数变成了 1！）

同样证明了，在第 $4$ 次方（即 $p-1$ 次方）的时候，必然会回到 1。

## 五、应用场景

结合数论、算法、竞赛、工程实战，分场景讲解费马小定理的典型用法，附示例，兼顾理解与实操。

#### 1. 快速化简高次模运算（最基础、最常用）

当遇到**超大指数求模**，直接计算不现实，利用等价形式 $a^p \equiv a \pmod p$ 或 $a^{p-1}\equiv 1\pmod p$ 降幂。
规则：$p$ 为质数，$\gcd(a,p)=1$ 时，即`a`和`p`互质，$a^{k} \equiv a^{k \bmod (p-1)} \pmod p$。

**示例**：计算 $2^{100} \bmod 7$

$p=7$ 是质数，$p-1=6$

$100 \bmod 6 = 4$
$2^{100} \equiv 2^4 \equiv 2 \pmod 7$

#### 2. 求模逆元（数论/算法核心应用）

在模质数 $p$ 意义下，**$a$ 的乘法逆元** 是满足 $a\cdot x \equiv 1 \pmod p$ 的整数 $x$。
由 $a^{p-1}\equiv 1 \pmod p$，变形得：
$$a \cdot a^{p-2} \equiv 1 \pmod p$$
结论：**质数模数下，$a$ 的逆元为 $a^{p-2} \bmod p$**。

**示例**：求 3 在模 7 下的逆元

逆元 $=3^{5} \bmod 7 = 5$
验证：$3 \times 5 \equiv 1 \pmod 7$，成立。

用途：模意义下做除法、组合数计算、分式取模。

#### 3. 组合数取模（算法竞赛高频）

竞赛中常求 $\mathrm{C}_n^k \bmod p$（$p$ 为大质数）。
组合数公式：
$$\mathrm{C}_n^k = \frac{n!}{k!\cdot (n-k)!}$$
模运算不能直接除法，改用**乘逆元**：
$$\mathrm{C}_n^k \equiv n! \cdot (k!)^{p-2} \cdot \big((n-k)!\big)^{p-2} \pmod p$$
费马小定理是该解法的理论根基。

#### 4. 素性测试（判断一个数是不是质数）

费马小定理反过来可做**概率性素数判定**，即**费马素性测试**：
1. 给定待测数 $n$，随机选取若干整数 $a$（$1<a<n$）；
2. 若 $a^{n-1} \not\equiv 1 \pmod n$，则 $n$ **一定是合数**；
3. 若多次测试都满足 $a^{n-1}\equiv 1\pmod n$，则 $n$ **大概率是质数**。

补充：存在“卡迈克尔数”（伪素数）会骗过测试，因此衍生出更强的 **Miller-Rabin 素性测试**，其底层依然基于费马小定理。
应用场景：大数质数判断、密码学前置步骤。

#### 5. 密码学（RSA 加密体系）

RSA 是目前广泛使用的非对称加密算法，核心数学基础之一就是费马小定理：
1. RSA 选取两个大质数 $p,q$，计算 $n=p\cdot q$；
2. 利用欧拉定理（费马小定理是欧拉定理特例）推导加密、解密公式；
3. 公钥、私钥的幂次设计，完全依赖模幂与逆元，而二者都由费马小定理实现。

日常场景：HTTPS 网页加密、文件加密、数字签名、网银/通讯安全。

#### 6. 同余方程求解

用于简化一元高次同余方程：
形如 $x^k \equiv b \pmod p$（$p$ 为质数），可借助费马小定理缩小指数范围，降低求解难度。

#### 7. 竞赛/数学拓展：循环节分析

对应之前学的「余数摩天轮」：
与质数 $p$ 互质的数 $a$，其幂次模 $p$ 的余数**周期一定整除 $p-1$**。
可用于分析数列周期、找循环规律、数论找规律题型。

## 六、代码实现

费马小定理在代码中的实现，核心就是配合**快速幂算法**来计算大数的次方取模。

在GESP和日常算法题中，费马小定理最经典的两个应用场景是：**求解大指数取模**和**求乘法逆元（处理模运算中的除法）**。

### 核心工具：快速幂算法 (Fast Power)

```cpp
#include <iostream>
using namespace std;
using ll=long long;

// 快速幂：计算 (a^b) % p
ll fast_pow(ll a, ll b, ll p) {
    ll res = 1;       // 初始化结果为 1
    a = a % p;        // 先对底数取模，防止 a 本身过大
    while (b > 0) {
        // 如果当前指数 b 是奇数，就把当前的底数 a 乘到结果里
        if (b & 1) {
            res = (res * a) % p;
        }
        // 底数 a 自乘，指数 b 除以 2（右移一位）
        a = (a * a) % p;
        b >>= 1;
    }
    return res;
}
```

---

### 场景一：求大指数的余数

```cpp
// 计算 a^n % p (p 为质数)
ll solve_big_power(ll a, ll n, ll p) {
    // 利用费马小定理，将巨大的指数 n 降维到 n % (p-1)
    ll new_n = n % (p - 1);
    return fast_pow(a, new_n, p);
}
```

---

### 场景二：求乘法逆元（解决模运算中的除法）

```cpp
// 求 b 在模 p 下的乘法逆元 (p 为质数)
ll mod_inverse(ll b, ll p) {
    // 根据费马小定理，b 的逆元就是 b^(p-2) % p
    return fast_pow(b, p - 2, p);
}

// 计算 (a / b) % p
ll solve_mod_division(ll a, ll b, ll p) {
    ll inv_b = mod_inverse(b, p); // 先求出 b 的逆元
    return (a * inv_b) % p;       // 把除法转化为乘法
}
```

### 全部可运行代码

```cpp
#include <iostream>
using namespace std;
using ll=long long;

const ll MOD = 1e9 + 7; // 竞赛中最常用的质数模数

// 快速幂模板
ll fast_pow(ll a, ll b, ll p) {
    ll res = 1;
    a %= p;
    while (b > 0) {
        if (b & 1) res = (res * a) % p;
        a = (a * a) % p;
        b >>= 1;
    }
    return res;
}

int main() {
    ll a = 3, b = 4; 
    
    // 示例1：求 (a / b) % MOD，即 (3 / 4) 对 1e9+7 取模
    ll inv_b = fast_pow(b, MOD - 2, MOD); // 求 4 的逆元
    ll result_div = (a * inv_b) % MOD;
    cout << "(3 / 4) % MOD = " << result_div << endl;

    // 示例2：求 3^(10^18) % MOD
    ll huge_exp = 1000000000000000000LL;
    ll reduced_exp = huge_exp % (MOD - 1); // 费马小定理降维指数
    ll result_pow = fast_pow(a, reduced_exp, MOD);
    cout << "3^(10^18) % MOD = " << result_pow << endl;

    return 0;
}
```

**⚠️注意：**  
使用这套代码的前提是模数必须是质数（比如 $10^9+7$、998244353 等）。如果模数是合数，费马小定理将失效，需要改用扩展欧几里得算法来求逆元。下一次重点介绍。
