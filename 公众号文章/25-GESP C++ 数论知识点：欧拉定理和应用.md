## 一、费马小定理回顾

### 1. 核心定义

如果 `p` 是一个质数，且整数 `a` 不是 `p` 的倍数（即 `a` 与 `p` 互质），那么：  

$$a^{p-1} \equiv 1 \pmod p$$

通俗来说，`a` 的 `p-1` 次方，除以质数 `p` 的余数永远是 1。同时，我们用”摩天轮“来形象的类比这个余数变成 `1` 的过程，以及产生的循环周期和对应的余数序列。注：数学上称为“完全剩余系”，这里不展开了。

### 2. 定理的等价形式

如果 `a` 是任意整数， `p` 是质数，那么费马小定理也可以写成：

$$a^p \equiv a \pmod{p}$$

这个形式更通用：
- 当  `a` 不是 `p` 的倍数时，两边同时除以 `a` ，就得到 $a^{p-1} \equiv 1 \pmod{p}$；
- 当 `a`  是 `p`  的倍数时，$a \equiv 0 \pmod{p}$，此时 $a^p \equiv 0 \equiv a \pmod{p}$，式子依然成立。

## 二、欧拉定理与扩展欧拉定理

费马小定理虽然强大，但它有两个死板的限制：**模数必须是质数**，且**底数不能是模数的倍数(等价形式除外）**。为了打破这些限制，数学家将其升级为了欧拉定理，并最终进化为“终极形态”——扩展欧拉定理。

### 1. 欧拉定理（过渡形态）

欧拉定理把费马小定理中的质数 `p` 推广到了任意正整数 `m`。  

如果 `a` 与 `m` 互质，那么：

$$
a^{φ(m)} ≡ 1 \pmod m
$$ 
这里的 `φ(m)` 是欧拉函数，代表小于 `m` 且与 `m` 互质的数的个数。

- 特例 `m=1`：$\varphi(1)=1$，唯一和 1 互质的是数字 1。
* 当 `m` 是质数时，`φ(m)` 正好等于 `m-1`，欧拉定理就**退化成了费马小定理**。

这里我们要注意欧拉函数（`φ`函数）的意义：是数的个数 —— 小于 `m` 且与 `m` 互质的数的个数。当 `m` 是一个质数`p`时，这个小于p，且与p互质的数的个数就是 `p-1`个，就跟费马小定理对上了。

举例：取质数 ${p=7}$，按照定义：小于 7、和 7 互质的正整数：`1,2,3,4,5,6`

一共 ${6 = 7-1}$个，即 ${\varphi(7)=7-1=6}$。

### 2. 扩展欧拉定理（终极形态）

扩展欧拉定理彻底打破了“互质”的限制。无论 `a` 和 `m` 是否互质，都可以用来对巨大的指数进行“降幂打击”。

对于任意正整数 `a`, `m` 和非负整数 `b`，计算 $a^{b} \pmod m$ 的规则如下：

- **情况一：当 `b < φ(m)` 时**  
    
    指数还不够大，还没进入循环周期，**老老实实直接算** $a^b \pmod m$。
    
- **情况二：当 `b ≥ φ(m)` 时**  
    
    指数足够大，可以安全降幂。公式为：  
$$
a^{b} \equiv a^{b \mod {φ(m)} + φ(m)} \pmod m
$$

**💡 为什么要多加一个 `φ(m)`？**  
这是一个“安全补丁”。当 `a` 和 `m` 不互质时，幂运算的余数序列可能不会从最开始就进入循环（前面可能有一小段“不循环的尾巴”）。$b \mod {φ(m)}$ 可能会得到一个很小的数，导致结果掉回那段“尾巴”里算错。加上 `φ(m)` 可以保证新的指数足够大，稳稳地落在循环周期内。

### 3. 实战演示

计算 $7^{85}\bmod 12$

$\gcd(7,12)=1$，两数互质，直接使用欧拉定理。
1. **求 $\varphi(m)$**：$\varphi(12)=4$（$1,5,7,11$ 这四个数与 $12$ 互质）。
2. **套用欧拉定理**：$7^{\varphi(12)}\equiv1\pmod{12}$，即 $7^4\equiv1\pmod{12}$。
3. **化简指数**：$85\div4$ 余数为 $1$，$7^{85}=7^{4\times21+1}=(7^4)^{21}\times7^1$。
4. **计算结果**：
$$
(1)^{21}\times7 \equiv7\pmod{12}
$$
最终 $7^{85}\bmod 12=7$。

---
再来一个**不互质、用扩展欧拉**的例题：

计算 $4^{91}\bmod 10$

$\gcd(4,10)=2$，不互质，使用扩展欧拉定理。
1. **求 $\varphi(m)$**：$\varphi(10)=4$（$1,3,7,9$ 四个数与 $10$ 互质）。
2. **比大小**：指数 $b=91$，$91\ge4$，满足扩展欧拉定理的 $\varphi(m)$ 条件。
3. **套公式降幂**：
新指数 $=91\bmod4+4=3+4=7$，原式变为 $4^7\bmod10$。
4. **计算结果**：
$4^1\bmod10=4,\ 4^2\bmod10=6$，奇偶次循环；$7$ 是奇数，$4^7\bmod10=4$。
$4^{91}\bmod10=4$。

### 4. 总结与对比

| 定理名称       | 核心公式 (求 a^b % m)             | 适用条件                        | 核心作用                                  |
| :--------- | :--------------------------- | :-------------------------- | :------------------------------------ |
| 费马小定理      | $a^{p-1} ≡ 1 \pmod p$        | `p` 是质数，`a` 与 `p` 互质        | 快速求逆元 $a^{-1} \equiv a^{p-2} \pmod m$ |
| 费马小定理的等价形式 | $a^p \equiv a \pmod{p}$      | `p` 是质数，`a` 为任意整数不用与 `p` 互质 | 化简幂运算，`a` 是 `p` 倍数时两边模 `p` 都为 `0`     |
| 欧拉定理       | $a^φ(m) ≡ 1 \pmod m$         | `a` 与 `m` 互质                | 费马小定理的推广，用于降幂                         |
| 扩展欧拉定理     | $a^b ≡ a^{b \mod φ(m)+φ(m)}$ | 无条件 (当 `b ≥ φ(m)`)          | 处理任意底数和模数的超大指数降幂                      |

掌握上述定理的递进关系，就可以掌握了数论中处理模幂运算的基础方法。


## 三、欧拉函数φ(m)的计算方法

计算欧拉函数 φ(m) 的方法主要分为两种场景：一种是**单次求某个特定数 m 的欧拉函数**，另一种是**批量求 1 到 n 范围内所有数的欧拉函数**。

这两种场景对应的最优解法完全不同，下面详细拆解：

### 1. 场景一：单次快速求解（基于试除法的质因数分解）

如果你只需要求某一个特定数字 m 的 φ(m)，最快的方法是直接套用欧拉函数的通项公式，配合试除法进行质因数分解。

**核心公式：**  

${\varphi(m)=m\cdot \prod_{p\mid m}\Big(1-\frac1p\Big)}$
（其中 p 是 m 的所有不同质因数）

- ${\varphi(1)=1}$（定义规定，1 和自身互质）
- m 是质数 p：$\varphi(p)=p-1$，公式：$p\times(1-\tfrac1p)=p-1$

式子看起来复杂，我们可以这样理解：
1. `m * 1/p` 表示是质数 p 的倍数的数有几个？这些数都包括 p 这个质因数，因此他们跟 36 是不互质的，要剔除掉；
2. 剩下的数就是 `m - m * 1/p` 即 `m * (1-1/p)` ;
3. 在剩下的数中继续用下一个质数 p 来筛掉不互质的数，以此类推；
### 举例：

${\varphi(36)}$

$36=2^2\times3^2$，不同质因子：\(2、3\)

$$
\varphi(36)=36\times(1-\tfrac12)\times(1-\tfrac13)=36\times\tfrac12\times\tfrac23=\boldsymbol{12}
$$
* `2` 可以筛掉：`2,4,6,8,10...,36` 这些偶数，一下子少了一半，即`1/2`，还剩`18`个数
* `3` 可以筛掉：`3,9,15,21,27,33` 这些数，筛掉了 `1/3`, 还剩 `12` 数
* 剩下的数跟`36`互质：`1,5,7,11,13,17,19,23,25,29,31,35` `（12 个）`。


在编程实现时，为了避免浮点数运算产生精度误差，我们通常把公式变形为：每找到一个质因数 `p`，就执行一次 `res = res / p * (p - 1)`。

**算法步骤：** 

1. 初始化结果 `res = m`。
2. 从 2 开始枚举到 `√m`，寻找`m` 的质因数。
3. 如果找到一个质因数 `i`，先更新结果 `res = res / i * (i - 1)`，然后把 `m` 中所有的 `i` 因子除干净（`while m % i == 0: m /= i`）。
4. 循环结束后，如果 `m` 仍然大于 `1`，说明剩下的这个 `m` 本身就是一个大质因数，同样需要更新结果。

**时间复杂度：** `O(√m)`

```cpp
#include <iostream>
using namespace std;
using ll=long long;

// 单次求解欧拉函数 φ(m)
ll euler_phi_single(ll m) {
    ll res = m;
    ll p = m;
    // 试除法分解质因数
    for (ll i = 2; i * i <= p; ++i) {
        if (p % i == 0) {
            res = res / i * (i - 1); // 先除后乘，防止溢出
            while (p % i == 0) {  // 除尽该质因数
                p /= i;
            }
        }
    }
    // 如果最后剩下的 temp > 1，说明它是一个大质因数
    if (p > 1) {
        res = res / p * (p - 1);
    }
    return res;
}

int main() {
    ll m;
    cout << "请输入一个数字: ";
    cin >> m;
    cout << "φ(" << m << ") = " << euler_phi_single(m) << endl;
    return 0;
}
```

### 2. 场景二：批量快速求解（基于线性筛法 / 欧拉筛）

如果需要求出 `1` 到 `n`（例如 `n` = $10^6$）范围内**每一个数**的欧拉函数，再对每个数单独用上面的方法就会非常慢（总复杂度会达到 `O(n√n)`）。此时，最优解法是使用**线性筛法**（也叫欧拉筛），它可以在`O(n)`的线性时间内一次性求出所有结果。

**核心原理：**  
线性筛在筛选质数的过程中，利用欧拉函数的积性性质同步计算出 `φ` 值。  
假设当前遍历到的数是 `i`，筛掉的质数是 `p`，我们要计算合数 `i * p` 的欧拉函数：

1. **当 `p` 是 `i` 的质因数时**（即 `i % p == 0`）：  
    说明 `i` 已经包含了质因数 `p`，`i * p` 与 `i` 的质因数种类完全相同。  
    根据公式推导，此时 `φ(i * p) = φ(i) × p`。
2. **当 `p` 不是 `i` 的质因数时**（即 `i % p != 0`）：  
    说明 `i` 与 `p` 互质。根据欧拉函数的积性，`φ(i * p) = φ(i) × φ(p)`。  
    因为 `p` 是质数，`φ(p) = p - 1`，所以 `φ(i * p) = φ(i) × (p - 1)`。

**时间复杂度：** `O(n)`

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int N = 1000010;   // 最大预处理范围
int phi[N];              // 存储每个数的欧拉函数值
int primes[N];           // 存储筛出来的所有质数
bool is_primes[N];       // 标记是否为质数：true=质数，false=合数
int cnt = 0;             // 质数的数量统计

// 线性筛（欧拉筛）批量求 1~n 所有数的欧拉函数
void euler_phi_batch(int n) {
    // 初始化：默认所有数都是质数
    fill(is_primes, is_primes + N, true);
    // 0 和 1 不是质数，手动标记
    is_primes[0] = is_primes[1] = false;

    // 定义：phi[1] = 1
    phi[1] = 1;

    // 从 2 开始遍历每个数
    for (int i = 2; i <= n; ++i) {
        // 如果当前数 i 是质数
        if (is_primes[i]) {
            // 把 i 加入质数数组
            primes[cnt++] = i;
            // 质数的欧拉函数：phi[p] = p-1
            phi[i] = i - 1;
        }

        // 用已经筛出的质数去标记合数
        for (int j = 0; j < cnt && i * primes[j] <= n; ++j) {
            // i * primes[j] 一定是合数，标记为非质数
            is_primes[i * primes[j]] = false;

            // 如果 i 能被 primes[j] 整除，说明 primes[j] 是 i 的最小质因子
            if (i % primes[j] == 0) {
                // 公式：phi(i * p) = phi(i) * p
                phi[i * primes[j]] = phi[i] * primes[j];
                // 找到最小质因子后停止，保证线性复杂度
                break;
            }
            // 如果 i 不能被 primes[j] 整除，说明 i 与 primes[j] 互质
            else {
                // 公式：phi(i * p) = phi(i) * phi(p) = phi(i) * (p-1)
                phi[i * primes[j]] = phi[i] * (primes[j] - 1);
            }
        }
    }
}

int main() {
    int n;
    cout << "请输入范围 n: ";
    cin >> n;

    // 预处理 1~n 的欧拉函数
    euler_phi_batch(n);

    // 输出结果
    for (int i = 1; i <= n; ++i) {
        cout << "φ(" << i << ") = " << phi[i] << endl;
    }
    return 0;
}
```

### 3. 总结与选择建议

| 求解场景            | 推荐方法      | 时间复杂度   | 适用情况                                  |
| :-------------- | :-------- | :------ | :------------------------------------ |
| 单次求 `φ(m)`      | 质因数分解法    | `O(√m)` | 题目只给一个数，或者数字非常大（如 `10^18`）            |
| 批量求 `1~n `的 `φ` | 线性筛法（欧拉筛） | `O(n)`  | 题目需要多次查询不同数字的 `φ` 值，或 `n` 在 `10^7` 以内 |
|                 |           |         |                                       |

在算法竞赛或实际工程中，如果题目涉及大量的模运算、逆元计算（比如预处理阶乘逆元），通常会先用线性筛法把 1 到 n 的欧拉函数全部预处理出来，后续直接 `O(1)` 调用即可。

## 四、费马小定理的证明（通俗解释）

补充上一篇文章没有说明的证明过程。

我们可以用“排队”的思路来理解：  
假设 `p = 5`，`a = 2`。我们有一个队伍：`{1, 2, 3, 4}`。  
现在让队伍里的每个人都乘以 `a`（即乘以 2），得到新队伍：`{2, 4, 6, 8}`。  
把这组新数字对 `p=5` 取模，就变成了：`{2, 4, 1, 3}`。  
你会发现，新队伍取模后，依然是 `{1, 2, 3, 4}`，只是顺序被打乱了！

既然两组数字取模后本质是一样的，那么把它们各自全部乘起来，结果也应该相等：  
`1×2×3×4 ≡ 2×4×6×8 (mod 5)`  
`1×2×3×4 ≡ (1×2)×(2×2)×(3×2)×(4×2) (mod 5)`  
`1×2×3×4 ≡ (1×2×3×4) × 2^4 (mod 5)`

等式两边都有 `1×2×3×4`，约掉之后，就剩下了 `1 ≡ 2^4 (mod 5)`。  
这就完美印证了费马小定理：`a^(p-1) ≡ 1 (mod p)`。
