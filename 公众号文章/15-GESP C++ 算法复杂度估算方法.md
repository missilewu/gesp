
# GESP C++ 算法复杂度估算方法

在算法的世界里，评价一个程序好坏的标准，从来不是看它在你的电脑上跑了几秒，而是看当数据规模 $n$ 变得非常大时，它的运行时间和占用空间是如何增长的。这就是**复杂度分析**。

对于 GESP 考试和后续的竞赛来说，掌握复杂度估算不仅是为了游刃有余的回答选择题和判断题，还能让你在写代码前预判算法是否会超时（TLE）。

## 一、 关键结论和答题技巧

先说干货，在 GESP 考试中，面对复杂度估算题，可以根据**循环结构**来估算。

- 单层循环 $\to O(n)$
- 双层嵌套循环 $\to O(n^2)$
- 循环变量每次 `x2` 或 `/2` $\to O(\log n)$
- 外层 $n$ 次，内层 `/2` $\to O(n \log n)$
- 还有就是要书籍所有典型算法的时间复杂度。$O(n \log n)$（快排、归并），$O(\log n)$（二分查找）等。

编程的时候，优先推荐使用标准库的 `std::sort`,  `std::lower_bound` 和 `std::upper_bound`等方法。遇到要自己实现的算法题目，需要**看数据规模（反推法）**，例如：

-  如果题目给出 $n \le 100$，通常 $O(n^3)$ 或 $O(2^n)$ 也能过。
-  如果 $n \le 10^5$，必须是 $O(n)$ 或 $O(n \log n)$。
-  如果 $n \le 10^9$，通常只能是 $O(\log n)$ 或 $O(1)$。

《算法竞赛入门经典（第2版）》（刘汝佳）的第8章 —— “高效算法设计”给出了一张表格，说明“运算量随着规模的变化”。假设机器速度是每秒 10e8 次基本运算（加减乘除），1秒内能够解决的问题的规模。

| 运算量         | 最大规模  | 速度扩大两倍后 |
| ----------- | ----- | ------- |
| n!          | 11    | 11      |
| $2^n$       | 26    | 27      |
| $n^3$       | 464   | 584     |
| $n^2$       | 10000 | 14142   |
| $n\log_2​n$ | 4.5e6 | 8.6e6   |
| n           | 1e8   | 2e8     |

这个表格里面的数据也侧面印证了上面干货给的建议。而且，绝对不要用 `n!` 和 $2^n$ 这两个非多项式的复杂度。

## 二、含多项式的算法复杂度

多项式复杂度是算法中最常见的一类（也是渐进时间复杂度的一种，这个可以自行AI检索一下，概念更为抽象），其运行时间可以表示为输入规模 $n$ 的多项式函数。通俗地说，就是公式里只有 $n$ 的整数次幂（如 $n, n^2, n^3$）。%%注意：阶乘`n!` 和 $2^n$ 类的指数不是多项式%%

**核心法则：大 O 表示法与“抓大头”**
在估算多项式复杂度时，我们遵循以下规则：
1.  **忽略常数项和低阶项**：当 $n$ 很大时，$n^2$ 的增长速度远快于 $n$ 和常数，所以只看最高次幂。
2.  **忽略最高次幂的系数**：$2n^2$ 和 $n^2$ 在增长趋势上属于同一量级，都记为 $O(n^2)$。

### 1. 线性阶：$O(n)$
*   **特征**：数据规模扩大 $k$ 倍，耗时也扩大 $k$ 倍。
*   **代码模式**：单层循环。
*   **示例**：遍历数组查找最大值、计算数组元素之和。
    ```cpp
    // 循环执行 n 次
    for (int i = 0; i < n; i++) {
        // 执行常数时间操作
        sum += arr[i];
    }
    ```

### 2. 平方阶：$O(n^2)$
*   **特征**：数据规模扩大 $k$ 倍，耗时扩大 $k^2$ 倍。通常出现在双重循环中。
*   **代码模式**：嵌套循环（两层）。
*   **示例**：冒泡排序、选择排序、插入排序。
    ```cpp
    // 外层 n 次，内层平均 n/2 次，总次数约 n^2/2
    // 根据“抓大头”法则，忽略系数 1/2，复杂度为 O(n^2)
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
             // 比较和交换
             if (arr[i] > arr[j]) swap(arr[i], arr[j]);
        }
    }
    ```

### 3. 线性对数阶：$O(n \log n)$
*   **特征**：介于 $O(n)$ 和 $O(n^2)$ 之间。通常出现在“分治”算法中，即每一层处理所有 $n$ 个元素，而层数是 $\log n$。
*   **示例**：快速排序（平均情况）、归并排序、堆排序。
*   **理解**：想象你把一副扑克牌排序。如果你先把牌分成两堆（$\log n$ 层），每堆再分，最后在每一层都要把所有牌整理一遍（$n$），这就是 $n \log n$。


在计算机科学中，如果一个问题的解法时间复杂度是多项式级别的（如 $O(n), O(n^2), O(n^{100})$），我们通常认为它是 “有效算法”或“好算法”。相比之下，阶乘和指数级算法（如 $O(2^n)$）在 $n$ 稍大时就无法计算了。

## 三、含对数的算法复杂度

对数复杂度是算法效率的“奇迹”。它代表了极快的收敛速度，通常与“折半”、“二分”、“树的高度”有关。

**$\log n$ 的核心概念？**

在算法中，默认底数通常是 2。$\log_2 n$ 的含义是：**将 $n$ 连续除以 2，直到结果变为 1，需要除多少次？**，%%即：指数运算的逆运算%%
*   例如：$1024 \to 512 \to \dots \to 1$。因为 $2^{10} = 1024$，所以 $\log_2 1024 = 10$。
*   **直观感受**：即使数据量翻一千倍（从 1000 到 100万），对数算法的操作次数可能只增加了不到一倍（从 10次 到 20次）。例如： $2^{20}$  是1,048,576（即100万）

### 1. 对数阶：$O(\log n)$
*   **特征**：每次操作都将问题规模缩小为原来的一半（或常数分之一）。
*   **代码模式**：循环变量每次乘 2 或除 2。
*   **示例**：二分查找、欧几里得算法（求最大公约数）。
    ```cpp
    // 二分查找：每次将搜索范围缩小一半
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) left = mid + 1; // 范围缩小一半
        else right = mid - 1; // 范围缩小一半
    }
    ```

### 2. 为什么底数不重要？

如果是三分查找（每次缩小为 1/3），复杂度是 $O(\log_3 n)$ ，但在大 O 表示法中，底数被忽略，统一写作 $O(\log n)$。这个跟前面的指数多项式的常系数被忽略的原理是一样的。
*   **数学原理**：根据换底公式，$\log_a n = \frac{\log_b n}{\log_b a}$。因为 $\frac{1}{\log_b a}$ 是一个常数，根据大 O 法则，常数系数被忽略。

### 3. 常见对数算法对比

| 算法            | 复杂度         | 原理                            |
| :------------ | :---------- | :---------------------------- |
| **二分查找**      | $O(\log n)$ | 每次排除一半元素                      |
| **快速幂**       | $O(\log n)$ | 指数每次减半 (如 $x^{16} = (x^8)^2$) |
| **线段树/平衡树操作** | $O(\log n)$ | 树的高度为 $\log n$，每次向下走一层        |

## 四、常见复杂度速查表

| 复杂度符号             | 名称    | 典型算法/场景             | GESP 考点关联   |
| :---------------- | :---- | :------------------ | :---------- |
| **$O(1)$**        | 常数阶   | 数组访问、哈希表查找、简单运算     | 基础操作耗时分析    |
| **$O(\log n)$**   | 对数阶   | 二分查找、欧几里得算法（辗转相除）   | 五级重点（高效算法）  |
| **$O(n)$**        | 线性阶   | 单层循环、线性查找、遍历数组      | 基础循环结构      |
| **$O(n \log n)$** | 线性对数阶 | 快速排序、归并排序、堆排序       | 四级/五级排序算法核心 |
| **$O(n^2)$**      | 平方阶   | 冒泡排序、选择排序、插入排序、双重循环 | 四级重点（基础排序）  |
| **$O(2^n)$**      | 指数阶   | 朴素递归斐波那契、部分回溯/深搜    | 识别低效递归      |
