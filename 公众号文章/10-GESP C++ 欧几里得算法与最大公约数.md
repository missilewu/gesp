
# GESP C++ 欧几里得算法与最大公约数

欧几里得算法，又称辗转相除法，是计算两个非负整数最大公约数（GCD）的一种高效方法。它在 GESP C++ 等级考试的数论部分是一个核心知识点。

## 一、核心原理

该算法基于一个核心定理：两个整数 `a` 和 `b` 的最大公约数，等于 `b` 和 `a` 除以 `b` 的余数（`a mod b`）的最大公约数。其计算公式可以表示为：

> **`gcd(a, b) = gcd(b, a mod b)`**
> 
> （`a mod b` 表示 `a` 除以 `b` 所得的余数）

这个过程会不断重复，直到余数为 0。当余数为 0 时，此时的除数就是最初那两个数的最大公约数。

### **举个例子：求 84 和 36 的最大公约数**

1.  `gcd(84, 36)` -> `84 mod 36 = 12`，问题变为求 `gcd(36, 12)`
2.  `gcd(36, 12)` -> `36 mod 12 = 0`，问题变为求 `gcd(12, 0)`
3.  当第二个数为 0 时，最大公约数就是第一个数，即 **12**。

### **原理证明**：

1. 设 `a = kb + r`（`k` 为整数商，`r` 为余数，`0 ≤ r ＜ b`，即 `r = a mod b`）。
2. 若 `d` 是 `a` 和 `b` 的公约数，则 `d` 能分别整除 `a` 和 `b`，必然`d`也能整除 `r = a - kb`，即：
	- `d∣a, d∣b ⟹ d∣kb`，故 `d∣(a−kb) ⟹ d∣r`
	- 因此，`(a, b)`的任一公约数 `d`, 必是`(b, r)`的公约数。
3. 反之，若 `d` 是 `b` 和 `r` 的公约数，则 `d` 能整除 `b` 和 `r`，必然`d`也能整除 `a = kb + r`，即：
	- `d∣b ⟹ d∣kb`，`d | r`, 故 `d∣(kb+r) ⟹ d∣a`
	- 因此，`(b, r)`的任一公约数 `d`, 必是`(a, b)`的公约数。
4. 因此，由前两步，`(a, b)` 与 `(b, r)` 的公约数完全相同，最大公约数也相等。
	- `gcd(a,b) = gcd(b, r) = gcd(b, amodb)`

### **质因数视角**

**辗转相除 = 自动消去非公共质因数，最后剩下公共质因数的乘积（GCD）**。

设 $d = \gcd(a,b)$，写成
$$
a = d\,a',\quad b = d\,b',\quad \gcd(a',b')=1
$$
- `d`：**a、b全部公共质因数**
- `a'`：**a独有的质因数**
- `b'`：**b独有的质因数**
- $\gcd(a',b')=1$：**a'、b'互质，无公共质因数**
- $a = d\,a'$ 含：公共质因数 `d` + 独有 `a'`
- $kb = k\,d\,b'$ 含：公共质因数 `d` + 独有 `b'`

做减法 $r=a−kb$：
$$
r = a - k\,b = d\,a' - k\,d\,b' = d\,(a' - k\,b')
$$
  * 推导出 d 是 r 的因数
  - 独有部分 `a'` 被“抵消/砍掉”（注：`a'`里的质因数，在`kb'`里一个都没有，所以`a'-kb'`不再包含任何`a'`的质因数，只留下公共质因数 `d`）

因此：

1. $a = kb + r$ （$k$ 为商，$r = a \bmod b$）
	- `a` 里包含：**`b`的全部质因数 + `a`独有的质因数**
	- `r = a-kb` 就是：**把a中所有的，b没有的质因数全部砍掉，只保留与b共享部分**
2. 若 `d` 是 `a,b` 的公约数，则 $d \mid a$，$d \mid b$ ⇒ $d \mid (a - kb) = r$
	* `d` 是公共质因数，**当然也能整除砍掉多余部分后的 r**
3. 反之，若 `d` 是 `b,r` 的公约数，则 $d \mid b$，$d \mid r$ ⇒ $d \mid (kb + r) = a$
	* `d` 是 `b` 和 `r` 的公共质因数，那它**一定也是 a 和 b 的公共质因数**
4. 结论：$(a,b)$ 与 $(b,r)$ 的**公约数集合完全相同**，那么最大公约数一定是相等的，即
	* $\gcd(a,b) = \gcd(b,r)$

### 用质因数视角看一遍辗转相除
例：求 $\gcd(84,36)$

1. 先分解质因数
$$
\begin{align*}
84 &= 2^2 \times 3^1 \times 7^1 \\
36 &= 2^2 \times 3^1 \times \color{red}{?}
\end{align*}
$$
	- 84 比 36 **多一个质因子 7**（多余部分）
	- 36 没有 7

2. 第一步：$a=84,\ b=36$
$$
84 = 2\times36 + 12 \quad \Rightarrow \ r=12
$$
- 质因数视角：**84 扔掉 2 倍 36（扔掉所有 7）** ⇒ 剩下 $12=2^2\times3^1$（**只剩公共质因数**）

2. 第二步：$\gcd(36,12)$
$$
36 = 3\times12 + 0
$$
	- 余数为 0，**除数 12 就是 GCD**
	- 质因数：12 就是两数全部**公共质因数的乘积**

```
a = kb + r
（a含：b的质因数 + 多余质因数）
        ↓（扔掉多余质因数）
gcd(a,b) = gcd(b, r)
        ↓（重复）
...
        ↓（r=0时）
除数 = 公共质因数的乘积 = GCD
```

## 二、 C++ 代码实现

欧几里得算法主要有两种实现方式：递归和迭代。

#### 递归实现

递归版本的代码非常简洁，逻辑直观，直接体现了算法的数学定义。

```cpp
// 递归版欧几里得算法
int gcd(int a, int b) {
    // 当 b 为 0 时，a 就是最大公约数
    return b == 0 ? a : gcd(b, a % b);
}
```

#### 迭代实现

迭代版本使用循环来替代递归调用，在处理非常大的数字时，可以有效避免栈溢出的风险，效率更高。

```cpp
// 迭代版欧几里得算法
int gcd(int a, int b) {
    while (b != 0) {
        int temp = b; // 保存当前的 b
        b = a % b;    // b 更新为 a 除以 b 的余数
        a = temp;     // a 更新为原来的 b
    }
    return a; // 循环结束时，a 即为最大公约数
}
```

## 三、扩展应用：求最小公倍数 (LCM)

在求出最大公约数后，可以非常方便地计算两个数的最小公倍数（LCM）。公式如下：

`lcm(a, b) = (a * b) / gcd(a, b)`

在编程实现时，为了防止 `a * b` 的结果过大导致整数溢出，通常采用“先除后乘”的写法：

```cpp
int lcm(int a, int b) {
    // 先除后乘，避免 a*b 可能导致的溢出
    return a / gcd(a, b) * b;
}
```


## 四、GCD 和 LCM的公式推导

**公式：**
$$\text{lcm}(a,b) = \frac{a \times b}{\gcd(a,b)}$$
这是数论中 **GCD 与 LCM 最核心的关系**。

###  质因数视角（最直观、最本质）
设
$$
\begin{align*}
a &= p_1^{x_1} p_2^{x_2} \dots p_n^{x_n} \\
b &= p_1^{y_1} p_2^{y_2} \dots p_n^{y_n}
\end{align*}
$$

- **gcd(a,b)**：每个质因子取 **最小指数**
  $$\gcd(a,b) = p_1^{\min(x_1,y_1)} p_2^{\min(x_2,y_2)} \dots$$
- **lcm(a,b)**：每个质因子取 **最大指数**
  $$\text{lcm}(a,b) = p_1^{\max(x_1,y_1)} p_2^{\max(x_2,y_2)} \dots$$

对每个质数：
$$\min(x,y) + \max(x,y) = x + y$$

所以：
$$
\gcd(a,b) \times \text{lcm}(a,b)
= \prod p_i^{\min+\max}
= \prod p_i^{x+y}
= a \times b
$$

**移项即得：**
$$\text{lcm}(a,b) = \frac{ab}{\gcd(a,b)}$$

### 实例验证
例：$a=84,\ b=36$

- 质因数：
  $84=2^2 \cdot 3^1 \cdot 7^1$
  $36=2^2 \cdot 3^1 \cdot 7^0$
- $\gcd=2^2 \cdot 3^1 = 12$
- $\text{lcm}=2^2 \cdot 3^1 \cdot 7^1 = 84$
- 公式：
  $$\text{lcm} = \frac{84 \times 36}{12} = \frac{3024}{12} = 252 \quad \text{正确}$$

### 代数证明（简洁版，可用AI工具去补充理解）
设 $g = \gcd(a,b)$，则一定存在整数`a', b'`可以把`a, b` 写成：
$$a = g \cdot a',\quad b = g \cdot b'$$
并且满足：$\quad \gcd(a',b')=1$，即`a', b'`互质。

- 乘积：$ab = g^2 a' b'$
- 最小公倍数：$\text{lcm}(a,b) = g a' b'$（因 $a',b'$ 互质）

于是：
$$
\frac{ab}{\gcd(a,b)} = \frac{g^2 a' b'}{g} = g a' b' = \text{lcm}(a,b)
$$
