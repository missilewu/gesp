# GESP C++ 素数的判断与筛法


前面我学习了因数、素（质）数和合数、质因数等基础概念，它们之间是层层递进的关系。简单来说，**因数**是构成数字的“组件”，**素数**是那些“不可再分”的特殊组件，而**质（素）因数**就是组合成数字的组件都是素数。把一个数字彻底拆解成最基础的“素数组件”的过程就是**分解质因数**。找到质因数是为了快速的计算最大公约数、最小公倍数、约分、通分和分数计算。在计算机领域，则是密码学、安全、算法、性能优化的核心基石。（果然是层层递进啊!!!)

AI工具给我一个用 **“化学元素”** 的类比，便于更好的理解
*   **因数**就像是组成物质的各种成分。
*   **素数**就像是化学元素周期表里的**元素**（如氢、氧、碳），它们是不可再分的基础。
*   **合数**（如12、30）就像是**化合物**（如水、二氧化碳），是由不同的元素组合而成的。
*   **分解质因数**就是分析这个化合物由哪些元素组成的过程。

因此，找到素数，判断一个数是否是素数是一个非常重要而且基础的工作。在 C++ 中处理素数判断的问题，主要有两大类方法：（也是GESP五级的知识点）
1. 针对单个数字的**素数判断**
2. 用于生成一定范围内所有素数的**筛法**。

## 🔎 试除法：判断单个数字是否为素数

当只需要判断一个或少数几个数字是否为素数时，可以使用**试除法（Trial Division）**。这个方法很简单，属于穷举法的算法模式，就是根据素数定义：**大于 1 的自然数，除了 1 和自身，不能被其他数整除**，试除法从 2 开始，依次尝试用每个整数去整除目标数 n，只要能整除，n就是合数。

### 1. 基础试除法（暴力法）
最直观的方法是检查从 2 到 `n-1` 的所有整数是否能整除 `n`。但这种方法效率较低。一个关键的优化是，如果一个数 `n` 是合数，那么它必然有一个不大于 `√n` 的因子。因此，我们只需检查到 `√n` 即可。

```cpp
#include <iostream>
using namespace std;

// 判断 n 是否为素数
bool isPrime(int n) {
    if (n <= 1) return false; // 1及以下的数不是素数
    for (int i = 2; i * i <= n; ++i) { // 只需检查到 sqrt(n)
        if (n % i == 0) return false; // 如果能被 i 整除，则不是素数
    }
    return true;
}

int main() {
    int num;
    cout << "请输入整数: ";
    cin >> num;

    if (isPrime(num))
        cout << num << " 是素数" << endl;
    else
        cout << num << " 不是素数" << endl;
    
    return 0;
}
```

### 2. 优化的试除法（只跳偶数）

这个是对朴素试除法最经典、最基础的优化，核心是**先排除所有偶数，只检查奇数因子**，属于**暴力枚举 + 数学剪枝**的算法模式。通过排除偶数来减少检查次数。**除了 2 以外，所有的素数都是奇数**（注：2 是唯一的偶素数）

```cpp

// 只跳偶数（仅检查奇数）的素数判断
bool isPrime(int n) {
    if (n <= 1) return false; // 1 及以下的数不是素数
    if (n == 2) return true; // 2 是唯一的偶素数    
    if (n % 2 == 0) return false; // 剩下的偶数（4,6,8...）一定不是素数
  
    // 核心优化：只检查 奇数 (3,5,7,9...)，步长为 2
    // 循环到 sqrt(n) 为止
    for (int i = 3; i * i <= n; i += 2) {
        if (n % i == 0)
            return false;
    }
    
    return true;
}
```

### 3. 优化的试除法 （6k±1）

该方法也叫 **“6k±1 素数判断”**，是**试除法**的高阶数学优化，核心是**只检查 6k±1 形式的因子**，比 “只跳偶数” 再快约 33%

```cpp

bool isPrime(int n) {
    if (n <= 1) return false; // 1 及以下的数不是素数
    if (n <= 3) return true; // 2 和 3 是素数
    if (n % 2 == 0 || n % 3 == 0) return false; // 2 和 3 的倍数不是素数

    // 检查形如 6k ± 1 的因子
    for (int i = 5; i * i <= n; i += 6) {
        if (n % i == 0 || n % (i + 2) == 0) return false;
    }
    return true;
}
```

为什么可以只查 6k±1呢？因为任何自然数**按模 6 分类**，只有 6 种形式：：
```text
6k, 6k+1, 6k+2, 6k+3, 6k+4, 6k+5
```

- **6k** → 被 6 整除（合数）
- **6k+1** → 可能素数
- **6k+2** → 偶数（合数，除 2）
- **6k+3** → 被 3 整除（合数，除 3）
- **6k+4** → 偶数（合数）
- **6k+5** = **6(k+1)−1** → 可能素数

所以结论是：

> **除 2、3 外，所有素数必形如 6k±1**
> 
> 但 6k±1 **不一定是素数**（如 25=6×4+1，但 25=5×5）


分析这三种算法的循环次数，
* 暴力（只到√n）
	* 检查：**2,3,4,5,6,7,...,√n**
	* 共：**√n - 1 次**
* 只跳过偶数（2,3,5,7,9...）
	* 检查：**3,5,7,9,11...√n**
	* 次数 ≈ **√n / 2**
* 6k±1 优化
	* 检查：**5,7,11,13,17,19...√n**，只保留6个数里面的 **6k±1** 两个数了，即1/3
	* 次数 ≈ **√n / 3**

因此可以得出结论：
- **6k±1 比 纯暴力（到√n）快：≈ 3 倍**
- **6k±1 比 只跳偶数 快：1.5 倍**

## 📜 筛法：生成范围内的所有素数

当需要找出某个范围内（例如 1 到 N）的所有素数时，筛法是更高效的选择。这个是GESP五级的考点 **“素数表的埃氏筛法和线性筛法”**。这个“筛”就是字面的“筛选”的意思，会通过构造一个”筛子“工具来批量的选择（标记）出素数。

### 1. 埃氏筛 (埃拉托斯特尼筛法，Sieve of Eratosthenes)

这是一种古老而高效的算法。是生成 **`[2, n]` 范围内所有素数** 的最高效、最经典算法之一。核心思想是：**标记合数，留下素数**。

#### **核心原理（直观理解）：**
1.  创建一个布尔数组 `is_prime[0...N]` (数组的下标就是对应的正整数)，并初始化为 `true`，表示默认都是素数
2.  从第一个素数 2 开始，将其所有倍数（除了它本身）标记为 `false`（即合数）。具体筛选过程如下：
	- 从第一个素数 `2` 开始。
	- 如果当前数 `i` 是素数（未被标记），则将 **`i` 的所有倍数**（`2i, 3i, 4i...`）全部标记为合数（`false`）。
	- 遍历到 `√n` 即可停止（大于 `√n` 的合数，其因子必已被更小的素因子筛掉了）。
3.  找到下一个未被标记的数，它一定是素数，然后重复步骤 2。
4.  **结果**：数组中仍为 `true` 的下标即为素数。

#### **图解（n=20）：**

- 初始：`[T, T, T, T, T, T, T, T, T, T, T, T, T, T, T, T, T, T, T, T, T]`
- 筛 2：`[F, F, T, T, F, T, F, T, F, T, F, T, F, T, F, T, F, T, F, T, F]`
- 筛 3：`[F, F, T, T, F, T, F, T, F, F, F, T, F, T, F, F, F, T, F, T, F]`
- ... 最终素数：`2, 3, 5, 7, 11, 13, 17, 19`

#### 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 埃氏筛：返回筛选出来的素数数组
vector<int> sieveOfEratosthenes(int n) {
    vector<bool> is_prime(n + 1, true); // 1. 初始化：默认全是素数
	is_prime[0] = is_prime[1] = false; // 0和1不是素数

	// 2. 核心筛除循环
    for (int p = 2; p * p <= n; ++p) {
        if (is_prime[p]) { // 如果p是素数，筛掉它的所有倍数
            // 从 p*p 开始标记，因为更小的倍数已被之前的素数标记过
            // 注意这里的步长是 p: i += p
            for (long long i = (long long)p * p; i <= n; i += p) {
                is_prime[i] = false;
            }
        }
    } 

    vector<int> primes;
    // 收集所有素数
    for (int i = 2; i <= n; ++i) {
        if (is_prime[i]) {
            primes.push_back(i);
        }
    }
    return primes;
}

int main() {
    int limit = 30;
    cout << "请输入上限（正整数）: ";
    cin >> limit;
    vector<int> primes = sieveOfEratosthenes(limit);
    cout << "小于等于 " << limit << " 的素数有: ";
    for (int p : primes) {
        cout << p << " ";
    }
    cout << endl;
    return 0;
}
```

#### **代码关键解析**

1. **从 `p*p` 开始标记**
    
    - 原因：`p` 的倍数 `2p, 3p...(p-1)p` 已被 `2, 3...(p-1)` 筛过。
    - 效果：**减少约一半重复标记**。
    
2. **数据类型防溢出**
    
    - 内层循环 `i` 必须用 `long long`。当 `p` 很大时（如 `p=46340`），`p*p` 会超出 `int` 范围。
    
3. **只筛奇数（进阶优化，见下面的跳偶数优化版本）**
    
    - 除 `2` 外，所有偶数都是合数。可只处理奇数，**内存与速度减半**。
   
#### **复杂度分析**

- **时间复杂度**：**O(n log log n)**
    
    - 极高效！`log log n` 增长极慢（`n=1e8` 时 `log log n ≈ 3`），**接近线性**。
    
- **空间复杂度**：**O(n)**
    
    - 需要一个大小为 `n+1` 的数组。
    

#### **时间复杂对比**

- **试除法**：O(n√n) —— `n=1e6` 极慢。
- **埃氏筛**：O(n log log n) —— `n=1e8` 仍可在 1 秒内完成。


#### **进阶优化：只筛奇数（跳偶数优化版）**

只筛奇数（跳偶数优化版） 是埃拉托色尼筛法最经典、最基础的优化。核心思路是：**除 2 以外，所有偶数都是合数 → 全程只处理奇数，跳过所有偶数**。其**数学依据**如下：
    
1.  素数中只有 **2** 是偶数，其余全是奇数
2. 偶数（>2）必被 2 整除 → 必为合数
    
优化效果的效果也非常明显：
1. **内存减半**：只需存奇数状态，数组长度减半
2.  **算减半**：外层、内层循环都只跑奇数，步长放大
3. 复杂度仍 **O(n log log n)**（常数变小）


下面这段代码是没有压缩内存，让时间减半的模式

```cpp
vector<int> sieveOddOnly(int n) {
    vector<bool> is_prime(n + 1, true);
    is_prime[0] = is_prime[1] = false;
    if (n >= 2) is_prime[2] = true; // 2是唯一偶素数
    // 所有偶数（除了2）直接设为非素数
    for (int i = 4; i <= n; i += 2) {
        is_prime[i] = false;
    }
    // 只遍历奇数 p=3,5,7...
    for (int p = 3; p * p <= n; p += 2) {
        if (is_prime[p]) {
            // i 从 p*p 开始，步长 2p（只标记奇数倍）
            // 注意步长的代码变化：i += 2 * p
            for (long long i = (long long)p * p; i <= n; i += 2 * p) {
                is_prime[i] = false;
            }
        }
    }
    
    vector<int> primes;
    // 收集所有素数
    primes.push_back(2);
	// 然后循环 i 从 3 开始，i += 2, 只遍历奇数位，这样能减少一半的判断次数。
    for (int i = 3; i <= n; i+=2) {
        if (is_prime[i]) {
            primes.push_back(i);
        }
    }
    return primes;
}

```

下面这段代码是**有压缩内存**，让内存减半的模式，可以针对性的对比一下差异。

```cpp
vector<int> sieveOddOnlyCompressed(int n) {
	if (n < 2) return {};

    // 1. 确定压缩数组的大小
    // 我们只存奇数。如果 n=10，奇数有 1,3,5,7,9 (共5个)
    // 公式：(n + 1) / 2 或者 n / 2 + (n%2)
    int size = n / 2 + 1; 
    vector<bool> is_prime(size, true);

    // 2. 处理特殊情况：数字 1
    // k=0 对应数字 1。1 不是素数，标记为 false。
    if (size > 0) is_prime[0] = false;

    // 3. 埃氏筛核心逻辑
    // 遍历下标 k，对应真实数字 p = 2*k + 1
    // 优化：只需遍历到 sqrt(n)。
    // 当 p*p > n 时停止，即 (2k+1)^2 > n
    for (int k = 1; k < size; ++k) {
        int p = 2 * k + 1; // 将下标还原为真实数字
        
        // 如果当前数字已经大于 sqrt(n)，后续不需要再筛了
        if ((long long)p * p > n) break;

        if (is_prime[k]) {
            // 4. 标记倍数
            // 从 p*p 开始标记。
            // 步长为 2*p，因为我们要跳过偶数倍数，只标记奇数倍数。
            // 注意：p*p 可能会溢出 int，所以转为 long long
            for (long long i = (long long)p * p; i <= n; i += 2 * p) {
                // 将真实数字 i 转换为压缩下标 idx
                // 公式：idx = (i - 1) / 2
                int idx = (i - 1) / 2;
                is_prime[idx] = false;
            }
        }
    }

    // 5. 收集结果
    vector<int> primes;
    if (n >= 2) primes.push_back(2); // 单独加入偶素数 2

    // 遍历压缩数组，收集剩下的奇素数
    for (int k = 1; k < size; ++k) {
        if (is_prime[k]) {
            int num = 2 * k + 1; // 还原真实数字
            if (num <= n) {
                primes.push_back(num);
            }
        }
    }
    return primes;
}
```


### 2. 欧拉筛法 (Euler Sieve)

咱们先复习一下这个概念

> **只要一个数能找到除了 1 和自己以外的因子，它就一定是合数；而最小质因子，就是这样的因子。** 所以：**找到了最小质因子 ⇒ 这个数一定是合数**。


欧拉筛法，也称线性筛法，是对埃氏筛的优化。**核心思想** 是确保每个**合数只被它的最小质因数筛掉一次**，从而避免了埃氏筛中可能出现的重复标记问题，从而将时间复杂度从埃氏筛的 **O(n log log n)** 降至严格的 **O(n)** 线性复杂度。

#### **核心原理（为什么比埃氏筛快？）**

1. 埃氏筛的缺陷：一个合数会被**多个质因数重复标记**。例：数字 `30` 会被素数 `2`、`3`、`5` 各标记一次。
2. 欧拉筛的解决思路是：**每个合数仅被其最小的质因数筛掉**。（注意：**最小**这个定语）
- 关键规则：
	- 遍历数字 `i`，并用 `i` 乘以已找到的素数 `p` 来标记合数 `i*p`。
	- **一旦发现 `i % p == 0`，立即停止内层循环**。
    - 原因：此时 `p` 是当前数字`i` 的最小质因数，也是数字 `i*p` 的最小质因数，已经可以明确`i*p`是合数不是素数了。若继续用更大的素数去标记，`i*p` 就会被非最小质因数标记，造成重复标记。

#### 代码

```cpp
vector<int> eulerSieve(int n) {
	if (n < 2) return {};
    vector<bool> is_prime(n + 1, true);
    vector<int> primes;
	is_prime[0] = is_prime[1] = false;

    for (int i = 2; i <= n; ++i) {
	    // 如果i是素数，加入列表
        if (is_prime[i]) {
            primes.push_back(i); // i 是素数，2会是第一个被放进来的素数
        }
        // 用当前已找到的素数去标记合数
        // 注意：这里的 primes[j] 就是前文中的 p
        for (size_t j = 0; j < primes.size() && i * primes[j] <= n; ++j) {
            // 加上 long long 防止乘法溢出
            // 提前判断乘积是否越界
            long long composite = (long long)i * primes[j];
            if (composite > n) break;
	        // 用 i * p 来标记合数
            is_prime[composite] = false;    
            // 关键一步：如果 primes[j] 是 i 的因子，则 i * primes[j] 已经被筛过
            // 或者更准确地说，i 的更大倍数将由 primes[j] 作为最小质因子来筛
            // 这个break是保证 O(n) 线性时间的关键
            if (i % primes[j] == 0) {
                break;
            }
        }
    }
    return primes;
}
```

#### **举例说明** 

让我们通过一个具体的例子来理解。假设我们要筛选 1 到 30 之间的素数。

当外层循环进行到 `i = 4` 时：
*   `prime` 数组中已包含 `2, 3`。
*   进入内层循环：
	- `j = 0`, `prime[j] = 2`。
	*   标记合数 `4 * 2 = 8`。8 的最小质因数是 2，在 `is_prime` 中筛掉，正确。
	*   检查 `if (4 % 2 == 0)`，条件成立，**立即 `break`**。
*   **为什么不继续筛 `4 * 3 = 12`？**
    *   如果我们不 `break`，下一步就会标记 `12`。
    *   但是，`12 = 2 * 2 * 3`，它的最小质因数是 `2`。
    *   根据规则，`12` 应该由最小质因数 `2` 来筛掉。这个任务会在外层循环 `i = 6` 时完成：当 `i = 6`，`prime[j] = 2` 时，会标记 `6 * 2 = 12`。
    *   如果在 `i = 4` 时就用 `3` 筛掉 `12`，就造成了重复操作。`break` 语句完美地避免了这一点。

#### 进阶优化：只筛奇数（跳偶数优化版）

同样的，欧拉筛也可以采用跳偶数的空间减半技术来压缩空间。（下面代码是用千问直接基于上面的版本优化而来，因此采用的是char，不是bool，千问说char的性能更好）

```cpp
#include <vector>
#include <iostream>

std::vector<int> eulerSieveOddOnlyCompressed(int n) {
    if (n < 2) return {};

    // 1. 初始化压缩数组
    int size = n / 2 + 1;
    std::vector<char> is_prime(size, 1); 
    std::vector<int> primes;

    // 2. 处理数字 1 (下标 0)
    is_prime = 0; 

    // 3. 主循环
    for (int i = 3; i <= n; i += 2) {
        int k = (i - 1) / 2;

        // --- 步骤 A: 判断 i 是否为素数 ---
        if (is_prime[k]) {
            primes.push_back(i);
        }

        // --- 步骤 B: 用已有的素数 p 去筛掉合数 i * p ---
        for (int p : primes) {
            long long composite = (long long)i * p;
            if (composite > n) break;

            // 先标记合数！(因为奇数*奇数必为奇数，无需再判断 composite % 2 == 1)
            int idx = (composite - 1) / 2;
            is_prime[idx] = 0;

            // 然后再判断是否需要跳出循环
            if (i % p == 0) {
                break; // 保证每个合数只被最小质因数筛一次
            }
        }
    }

    // 4. 别忘了把唯一的偶素数 2 加上
    if (n >= 2) {
        primes.insert(primes.begin(), 2);
    }
    
    return primes;
}
```



## 📊 不同方法对比与选择

| 方法           | 时间复杂度          | 适用场景                 |
| :----------- | :------------- | :------------------- |
| **试除法**      | O(√N)          | 判断单个或少量数字是否为素数。      |
| **埃拉托斯特尼筛法** | O(N log log N) | 生成一个中等大小范围内的所有素数。    |
| **欧拉筛法**     | O(N)           | 生成一个较大范围内的所有素数，效率最高。 |

**如何选择：**
*   如果只需要判断几个数是不是素数，用**优化的试除法**。
*   如果需要找出 1 到 N 之间的所有素数，优先选择**筛法**。在 N 较大时，**欧拉筛法**的性能优于**埃氏筛法**（埃拉托斯特尼筛法）。
