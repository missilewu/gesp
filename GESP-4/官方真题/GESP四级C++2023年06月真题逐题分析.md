### 第 1 题
1.  **考察的知识点**：基础常识（程序开发流程）
2.  **知识点详解**：C++ 程序从源代码到可执行文件的过程。通常包括：编辑（编写代码）、保存（存储文件）、编译（将源代码转换为目标代码）、链接（生成可执行文件）、调试（查找错误）。只有经过**编译**（及链接）才能生成机器可识别的二进制代码。
3.  **选项对错分析**：
    *   A. 编辑：只是编写文本，未生成代码。
    *   B. 保存：只是存储文件，未生成代码。
    *   C. 调试：是发现问题的手段，不是生成代码的必要转换步骤。
    *   D. 编译：是将高级语言转换为机器语言的关键步骤，正确。
4.  **答案**：D
5.  **易错点分析**：容易混淆“保存”和“编译”的概念，认为保存后就能运行。
6.  **相关的知识点**：IDE 的使用、编译器的作用、链接器的作用。

### 第 2 题
1.  **考察的知识点**：6. 排序算法 -> 2. 时间复杂度、空间复杂度、算法稳定性
2.  **知识点详解**：**排序稳定性**是指排序前后，相等元素的相对位置保持不变。
    *   **稳定排序**：冒泡排序、插入排序、归并排序。
    *   **不稳定排序**：选择排序、快速排序、堆排序。
3.  **选项对错分析**：
    *   A. 冒泡排序是稳定的，选项说不稳定，错误。
    *   B. 插入排序是稳定的，选项说不稳定，错误。
    *   C. 选择排序是不稳定的（因为交换可能跨越相等元素），选项说不稳定，正确。
    *   D. 既然 C 正确，D 错误。
4.  **答案**：C
5.  **易错点分析**：死记硬背排序算法名称，却忽略了其稳定性特性；容易误认为选择排序是稳定的。
6.  **相关的知识点**：常见排序算法的原理、时间复杂度对比。

### 第 3 题
1.  **考察的知识点**：1. 指针 -> 1. 指针类型、2. 指针类型定义变量
2.  **知识点详解**：指针变量存储的是内存地址。定义时必须指定指向的类型（如 `int*`）。指针可以指向基本类型，也可以指向另一个指针（二级指针）。指针指向的地址可能无效（如未初始化或已释放）。
3.  **选项对错分析**：
    *   A. 指针存储地址，正确。
    *   B. 定义需指定类型，正确。
    *   C. 指针可以指向指针（如 `int**`），选项说不能，**不正确**。
    *   D. 指针可能指向非法地址，正确。
    *   题目要求选“不正确”的。
4.  **答案**：C
5.  **易错点分析**：初学者常认为指针只能指向变量，不理解二级指针或多级指针的概念。
6.  **相关的知识点**：1. 指针 -> 3. 指针类型变量的赋值、4. 解引用。

### 第 4 题
1.  **考察的知识点**：2. 二维及多维数组 -> 1. C++ 二维及多维数组的定义、使用
2.  **知识点详解**：C++ 中定义的静态多维数组（如 `int a[3][4]`）在内存中是**连续存放**的。二维数组可以看作“元素为一维数组的一维数组”。
3.  **选项对错分析**：
    *   A. 一维数组内存连续，正确。
    *   B. 二维数组本质是数组的数组，正确。
    *   C. 内存连续，正确。
    *   D. 二维数组在内存中必须是连续的，选项说可以不是，**不正确**。
    *   题目要求选“不正确”的。
4.  **答案**：D
5.  **易错点分析**：容易将二维数组 `int a[3][4]` 与指针数组 `int* a[3]` 或二级指针 `int** a` 的内存布局混淆，后者可能不连续。
6.  **相关的知识点**：数组内存模型、行优先存储原则。

### 第 5 题

2.  **知识点详解**：函数通常需要有名字（除匿名函数外，但大纲排除匿名函数）。函数可以没有参数（`void` 或空括号）。函数可以没有返回值（`void` 类型）。函数定义可以在调用之后，但需要提前声明。

    *   B. 函数可以无参，错误。
    *   C. 函数可以是 void 无返回值，错误。

5.  **易错点分析**：误以为 `void` 函数没有返回值类型（其实返回类型是 void）；误以为定义必须在调用之前（忽略了声明的作用）。

### 第 6 题

2.  **知识点详解**：变量的作用域决定了其可见性。不同作用域内（如全局与局部，或两个不同的局部块）可以使用相同的变量名，互不干扰。同一作用域内变量名必须唯一。

### 第 7 题
1.  **考察的知识点**：2. 二维及多维数组 -> 1. C++ 二维及多维数组的定义、使用
2.  **知识点详解**：计算数组占用内存大小。`double` 类型通常占用 8 字节。数组 `array[3][10]` 共有 $3 \times 10 = 30$ 个元素。总大小 = $30 \times 8 = 240$ 字节。

5.  **易错点分析**：忘记 `double` 类型占用 8 字节，误以为是 4 字节（与 `int` 混淆）。
6.  **相关的知识点**：基本数据类型大小（`sizeof`）、内存对齐。

### 第 8 题
1.  **考察的知识点**：1. 指针 -> 2. 指针类型定义变量、3. 指针类型变量的赋值
2.  **知识点详解**：`int* p = nullptr;` 定义了一个指向 `int` 类型的指针 `p`，并将其初始化为空指针。指针变量的类型是 `int*`，指向的类型是 `int`。访问空指针会导致运行时错误，而非编译错误。
3.  **选项对错分析**：
    *   A. 指针变量类型是 `int*`，不是 `int`，错误。
    *   B. 指向的类型是 `int`，正确。
    *   C. 地址是固定的空地址（0），不是随机的，错误。
    *   D. 编译可以通过，运行时访问才会出错，错误。
4.  **答案**：B
5.  **易错点分析**：混淆“指针变量的类型”和“指针指向的类型”；混淆编译错误与运行时错误。
6.  **相关的知识点**：1. 指针 -> 4. 解引用、野指针与空指针。

### 第 9 题
1.  **考察的知识点**：2. 二维及多维数组 -> 1. C++ 二维及多维数组的定义、使用
2.  **知识点详解**：二维数组按行优先存储。`int array[5][3]`，每行 3 个元素，`int` 占 4 字节。
    *   `array[1][2]` 是第 1 行（从 0 开始）第 2 个，线性索引为 $1 \times 3 + 2 = 5$。
    *   `array[2][1]` 是第 2 行第 1 个，线性索引为 $2 \times 3 + 1 = 7$。
    *   相差 $7 - 5 = 2$ 个元素。
    *   字节差 = $2 \times 4 = 8$ 字节。
3.  **选项对错分析**：
    *   A. 2 字节，错误。
    *   B. 4 字节，错误。
    *   C. 8 字节，正确。
    *   D. 可以确定，错误。
4.  **答案**：C
5.  **易错点分析**：行列表索引计算错误；忘记乘以单个元素的大小（4 字节）。
6.  **相关的知识点**：数组下标从 0 开始、行优先存储原理。

### 第 1 题
1.  **考察的知识点**：计算机常识（域名结构）
    *   *注：此题属于计算机基础常识，不在提供的 C++ 技术大纲内，但为 GESP 考试常见题型。*
2.  **知识点详解**：域名（Domain Name）是由一串用点分隔的名字组成的，用于标识互联网上的计算机。**顶级域名（TLD）** 是域名中最后一部分，例如 `.cn`、`.com`、`.org`。在 `gesp.ccf.org.cn` 中，从右向左级别依次升高，`cn` 是顶级域名，`org` 是二级域名，`ccf` 是三级域名，`gesp` 是主机名或四级域名。
3.  **选项对错分析**：
    *   题目陈述：“其中顶级域名是 gesp”。
    *   分析：`gesp` 是最左侧的部分，属于主机名或子域名部分，最右侧的 `cn` 才是顶级域名。
    *   结论：陈述错误。
4.  **答案**：×
5.  **易错点分析**：容易混淆域名的阅读顺序（从左到右 vs 从右到左），误认为最左边的是顶级域名。
6.  **相关的知识点**：互联网基础、URL 结构、IP 地址与域名的关系。

### 第 2 题
1.  **考察的知识点**：5. 递推算法 -> 1. 递推算法基本思想
2.  **知识点详解**：**递推算法**是一种用若干步可重复的简运算（规律）来描述复杂问题的方法。斐波那契数列定义为 $F(n) = F(n-1) + F(n-2)$，已知前两项，通过循环依次计算后续项，正是典型的递推思想（从已知边界条件出发，利用递推关系式逐步推导）。
3.  **选项对错分析**：
    *   题目描述了斐波那契数列的定义及通过循环计算第 n 项的过程。
    *   分析：该方法利用前两项计算后一项，符合递推算法“由已知求未知”的基本思想。
    *   结论：陈述正确。
4.  **答案**：√
5.  **易错点分析**：容易混淆“递推”与“递归”。递归是函数调用自身，递推通常是循环迭代。本题描述的是循环迭代，属于递推。
6.  **相关的知识点**：5. 递推算法 -> 2. 递推关系式推导、递归算法。

### 第 3 题
1.  **考察的知识点**：4. 函数 -> 4. 值传递、引用传递
2.  **知识点详解**：在 C++ 中，函数的参数默认传递方式是**值传递（Pass by Value）**。这意味着实参的值被拷贝给形参，函数内部修改形参不会影响外部实参。若要实现引用传递，必须显式使用引用符号 `&` 或指针。
3.  **选项对错分析**：
    *   题目陈述：“函数的参数默认以引用传递方式进行传递”。
    *   分析：C++ 默认是值传递，而非引用传递。
    *   结论：陈述错误。

# 编程题1：幸运数

基于提供的知识库文件《GESP 四级 C++2023 年 06 月.pdf》，以下是对**编程题第一题“幸运数”**的详细分析。

### 1. 题目基本信息
*   **题目名称**：幸运数
*   **分值**：25 分
*   **输入限制**：待判断的正整数个数 $N \le 20$，每个正整数小于 $10^{12}$。
*   **输出要求**：对于每个数，是幸运数输出 'T'，否则输出 'F'。

### 2. 题目大意与规则
题目定义了一种“幸运数”的判定规则，核心步骤如下：
1.  **数位定义**：个位为第 1 位（奇数位），十位为第 2 位（偶数位），以此类推。
2.  **数字变换**：
    *   **偶数位**：数字保持不变。
    *   **奇数位**：数字 $t$ 需要变换。
        *   计算 $t \times 7$。
        *   若结果 $\le 9$，即为变换结果。
        *   若结果 $> 9$，则将结果的各位数字相加；若和仍 $> 9$，继续相加，直到结果 $\le 9$。
        *   （注：这实际上是在求 $t \times 7$ 的“数根”，且结果范围保持在 1-9 之间，0 除外）。
3.  **幸运判定**：将所有数位变换后的结果相加，若总和是 **8 的倍数**，则该数为幸运数。

### 3. 算法思路分析
1.  **数据类型选择**：
    *   题目约定输入的正整数小于 $10^{12}$。
    *   C++ 中 `int` 通常最大约为 $2 \times 10^9$，无法存储 $10^{12}$。
    *   必须使用 `long long` 类型来存储输入的数字。
2.  **数位提取与遍历**：
    *   可以通过 `% 10` 获取当前个位数字，通过 `/ 10` 去掉个位。
    *   需要一个计数器变量（如 `d`）来记录当前是第几位，初始为 1，每处理一位加 1。
3.  **变换函数优化**：
    *   题目描述的奇数位变换过程（乘 7 -> 各位相加 -> 直到小于等于 9）其实有一个数学规律。
    *   参考代码中使用了公式 `(t * 7 - 1) % 9 + 1` 来实现这一逻辑。这是利用模 9 同余的性质快速计算数根的技巧（将 0 映射为 9 的处理方式，但此处 0 单独处理）。
    *   对于 $t \in [0, 9]$，$t \times 7$ 最大为 63。手动模拟也可行，但公式法更简洁。
4.  **求和与判断**：
    *   累加所有处理后的数位值。
    *   最后判断 `sum % 8 == 0`。

### 4. 参考代码逻辑解析
根据文件中的【参考程序】，代码结构清晰，主要包含三个部分：

#### (1) 变换函数 `trans(int t)`
```cpp
int trans(int t){
    if(t == 0) return 0;
    return (t * 7 - 1) % 9 + 1;
}
```
*   **功能**：实现奇数位的变换规则。
*   **逻辑**：处理了 0 的特殊情况。对于非 0 数字，利用数学公式直接得到反复相加各位数字后的结果。例如 $t=2$，$2 \times 7 = 14 \rightarrow 1+4=5$。公式计算：$(14-1)\%9 + 1 = 13\%9 + 1 = 4+1=5$。结果一致。

#### (2) 判断函数 `judge(long long x)`
```cpp
bool judge(long long x){
    int sum = 0;
    // d 记录位数，从 1 开始（个位）
    for(int d = 1; x > 0; d++, x /= 10){
        int t = (int)(x % 10); // 取出当前位数字
        if(d % 2 == 0)         // 偶数位
            sum += t;
        else                   // 奇数位
            sum += trans(t);
    }
    return (sum % 8 == 0);
}
```
*   **功能**：遍历数字的每一位，根据奇偶性决定是否变换，并累加和。
*   **细节**：`x % 10` 最先取出的是个位，对应题目定义的“第 1 位”，因此循环初始 `d=1` 是正确的。

#### (3) 主函数 `main()`
```cpp
int main(){
    int N = 0;
    cin >> N;
    for(int n = 0; n < N; n++){
        long long x = 0;
        cin >> x;
        if(judge(x))
            cout << "T" << endl;
        else
            cout << "F" << endl;
    }
    return 0;
}
```
*   **功能**：控制输入输出流程。
*   **逻辑**：先读入测试用例数量 $N$，然后循环 $N$ 次，每次读入一个 `long long` 类型的数，调用 `judge` 并输出结果。

### 5. 关键点与易错点
1.  **变量类型**：必须使用 `long long`。如果使用 `int`，当输入数据超过 $2 \times 10^9$ 时会发生溢出，导致计算错误。
2.  **位数计数**：题目明确规定“个位为第 1 位”。在循环取模时，第一次取到的就是个位，所以计数器初始值应为 1。如果初始化为 0，会导致奇偶位判断颠倒。
3.  **变换逻辑**：虽然题目描述了“各位数相加...直到结果不大于 9"，但在编程时可以直接模拟这个过程（while 循环），也可以使用参考代码中的数学公式。模拟过程更直观，不易出错；公式法更高效。
    *   *模拟写法示例*：
        ```cpp
        int res = t * 7;
        while(res > 9){
            int sum = 0;
            while(res > 0){ sum += res % 10; res /= 10; }
            res = sum;
        }
        ```
4.  **输入输出格式**：题目提示“不需要等到所有输入结束在依次输出”，即处理一个输出一个。参考代码也是这么做的，符合交互习惯。
5.  **边界情况**：输入数字包含 0 的情况（如 102）。0 在奇数位时，$0 \times 7 = 0$，变换结果为 0。参考代码中 `trans` 函数专门处理了 `t==0` 返回 0，逻辑严谨。

### 6. 复杂度分析
*   **时间复杂度**：对于每个数字，需要遍历其每一位。数字小于 $10^{12}$，最多 12 位。每次变换操作是常数时间。总复杂度约为 $O(N \times \log_{10}(\text{Value}))$，对于 $N=20$，计算量极小，完全满足 90 分钟考试的时间要求。
*   **空间复杂度**：仅使用了几个变量存储中间状态，$O(1)$。

### 编程题第一题：幸运数 - 完整代码

```cpp
#include <iostream>

using namespace std;

/**
 * 函数功能：对奇数位上的数字进行变换
 * 变换规则：数字 t 乘以 7，如果结果大于 9，则将各位数字相加，
 *          重复此过程直到结果不大于 9。
 * 数学优化：这实际上是在求 (t * 7) 的数根。
 *          公式 (n - 1) % 9 + 1 可以快速计算一个正整数 n 的数根。
 * 
 * @param t 输入的数字 (0-9)
 * @return 变换后的结果 (0-9)
 */
int trans(int t) {
    if (t == 0) return 0; // 0 乘 7 还是 0，单独处理
    // 利用数根公式快速计算反复相加各位数字后的结果
    return (t * 7 - 1) % 9 + 1;
}

/**
 * 函数功能：判断一个数是否为幸运数
 * 幸运数规则：
 * 1. 个位为第 1 位（奇数位），十位为第 2 位（偶数位），以此类推。
 * 2. 偶数位数字不变，奇数位数字进行 trans 变换。
 * 3. 将所有处理后的数位相加，若和是 8 的倍数，则为幸运数。
 * 
 * @param x 待判断的正整数 (注意题目要求小于 10^12，需用 long long)
 * @return true 是幸运数，false 不是幸运数
 */
bool judge(long long x) {
    int sum = 0;      // 用于累加变换后的数位和
    int d = 1;        // 位数计数器，个位是第 1 位
    
    // 循环取出每一位数字，直到 x 变为 0
    for (; x > 0; d++, x /= 10) {
        int t = (int)(x % 10); // 取出当前最低位数字
        
        if (d % 2 == 0) {
            // 偶数位：数字保持不变，直接累加
            sum += t;
        } else {
            // 奇数位：数字需要变换后累加
            sum += trans(t);
        }
    }
    
    // 判断总和是否为 8 的倍数
    return (sum % 8 == 0);
}

int main() {
    // 优化 I/O 操作速度（虽然本题数据量小，但这是一个好习惯）
    ios::sync_with_stdio(false);
    cin.tie(0);

    int N = 0;
    // 输入待判断的正整数个数
    if (!(cin >> N)) return 0;

    // 循环处理每一个数
    for (int n = 0; n < N; n++) {
        long long x = 0;
        cin >> x; // 输入正整数，必须使用 long long 防止溢出 (题目约定 < 10^12)
        
        // 判断并输出结果
        if (judge(x)) {
            cout << "T" << endl;
        } else {
            cout << "F" << endl;
        }
    }

    return 0;
}
```

### 代码关键点解析

1.  **数据类型选择 (`long long`)**：
    *   题目约定输入的正整数小于 $10^{12}$。
    *   C++ 中 `int` 通常最大约为 $2 \times 10^9$，无法存储 $10^{12}$。
    *   必须使用 `long long` 类型来存储输入的数字 `x`，否则会发生溢出导致计算错误。

2.  **数位提取与奇偶判断**：
    *   使用 `x % 10` 获取当前个位数字，`x /= 10` 去掉个位。
    *   题目定义“个位为第 1 位”，因此计数器 `d` 初始值为 1。
    *   `d % 2 == 0` 表示偶数位（十位、千位...），`d % 2 != 0` 表示奇数位（个位、百位...）。

3.  **变换函数优化 (`trans`)**：
    *   题目描述的“各位数相加...直到结果不大于 9"实际上是求**数根**的过程。
    *   参考代码使用了数学公式 `(t * 7 - 1) % 9 + 1` 来替代循环相加，效率更高且代码更简洁。
    *   特别注意 `t=0` 的情况，公式可能涉及负数取模，因此代码中单独判断 `if (t == 0) return 0;`。

4.  **输入输出流程**：
    *   先读入测试用例数量 `N`。
    *   循环 `N` 次，每次读入一个数，判断后立即输出，符合题目“不需要等到所有输入结束再依次输出”的提示。



# 编程题2：图像压缩


基于提供的知识库文件《GESP 四级 C++2023 年 06 月.pdf》，以下是对**编程题第二题“图像压缩”**的详细分析。

### 1. 题目基本信息
*   **题目名称**：图像压缩
*   **分值**：25 分
*   **输入限制**：
    *   行数 $N$：$10 \le N \le 20$。
    *   每行像素数：最多 20 个像素。
    *   像素值：256 级灰阶（0-255），输入为十六进制字符串（每两个字符表示一个像素）。
    *   保证条件：输入图像中至少包含 16 种不同的灰阶。
*   **输出要求**：
    *   第一行：选定的 16 种灰阶的十六进制编码（共 32 个字符）。
    *   后续 $N$ 行：压缩后的图像，每个像素用 1 位十六进制数（0-F）表示。

### 2. 题目大意与规则
题目要求将 256 级灰度图像压缩为 16 级，核心流程如下：
1.  **统计频次**：统计输入图像中每种灰阶（0-255）出现的次数。
2.  **选取代表色**：
    *   选出出现次数最多的前 16 种灰阶。
    *   **平局规则 1**：若两种灰阶出现次数相同，优先选择**灰阶值较小**的。
    *   **编号**：选出的第 1 多编号为 0，第 2 多编号为 1，...，第 16 多编号为 15（对应十六进制 0-F）。
3.  **像素映射（压缩）**：
    *   对于图像中的每个像素，将其映射到选出的 16 种灰阶之一。
    *   **最近原则**：计算原像素值与 16 种代表色的绝对差值，差值最小者为最近。
    *   **平局规则 2**：若与多个代表色的绝对差值相等，选择**编号较小**（即优先级更高）的那个。
4.  **输出**：
    *   先输出选出的 16 种代表色的原始十六进制值。
    *   再输出压缩后的图像（使用新编号 0-F 的十六进制表示）。

### 3. 算法思路分析
1.  **十六进制处理**：
    *   输入是字符串，每两个字符代表一个字节（0-255）。需要编写函数将字符 '0'-'9', 'A'-'F' 转换为整数 0-15，再组合成 0-255 的整数。
    *   输出时需要将整数 0-15 转换回十六进制字符。
2.  **频次统计**：
    *   使用一个大小为 256 的数组 `his[256]`，下标对应灰阶值，值对应出现次数。
3.  **选取前 16 种灰阶**：
    *   循环 16 次，每次遍历 `his` 数组找到当前最大值。
    *   为了处理“次数相同选灰阶值小”的规则，遍历时应从 0 到 255，且使用严格大于号 `>` 更新最大值，这样第一次遇到的最大值（下标最小）会被保留。
    *   选中后，将该灰阶的计数标记为 -1 或其他无效值，防止重复选中。
    *   将选中的原始灰阶值存入数组 `color[16]`，下标 0-15 即为其新编号。
4.  **压缩映射**：
    *   遍历图像每个像素，调用压缩函数。
    *   压缩函数遍历 `color` 数组（0-15），计算绝对差。
    *   为了处理“差值相等选编号小”的规则，遍历顺序从 0 到 15，且仅在严格小于当前最小差值时更新，这样编号小的优先被保留。
5.  **输出格式**：
    *   注意第一行输出的是**原始灰阶**的十六进制（2 位），后续输出的是**新编号**的十六进制（1 位）。

### 4. 参考代码逻辑解析
根据文件中的【参考程序】，代码结构清晰，主要包含以下部分：

#### (1) 进制转换函数
```cpp

    if(a <= '9') return(a - '0');
    return(a - 'A' + 10);
}
// 一位十六进制数字转换为字符

}
```
*   **功能**：实现字符与整数之间的十六进制互转。
*   **注意**：输入样本中为大写字母，代码假设输入为大写。若输入包含小写，需额外处理（但题目样例均为大写）。

#### (2) 压缩映射函数 `compress`
```cpp
int compress(int c){
    int dis = 256, res = -1;
    for(int i = 0; i < 16; i++){
        int d = c - color[i];
        if(d < 0) d = -d;
        if(d < dis){
            dis = d;
            res = i; // 记录新编号
        }
    }
    return res;
}
```
*   **功能**：寻找离当前像素值 `c` 最近的代表色编号。
*   **逻辑**：`color[i]` 存储的是第 `i` 个代表色的**原始灰阶值**。循环 `i` 从 0 到 15，若发现更小的距离 `d` 则更新。若 `d == dis`，不更新，从而保证保留编号 `i` 较小的结果，符合题目“编号较小的灰阶更近”的要求。

#### (3) 主函数 `main` 核心逻辑
1.  **输入与统计**：

### 5. 关键点与易错点
1.  **十六进制解析**：
    *   输入是字符串流，需要每两个字符解析成一个整数。例如 "00" -> 0, "FF" -> 255, "1A" -> 26。
    *   公式：`HighChar * 16 + LowChar`。
2.  **双重平局规则**：
    *   **选色时**：频次相同，选**原始值小**的。代码通过 `0-255` 遍历 + `>` 实现。
    *   **映射时**：距离相同，选**新编号小**的。代码通过 `0-15` 遍历 + `<` 实现。
    *   这是本题最大的逻辑陷阱，容易搞反或忽略。
3.  **输出格式差异**：
    *   第一行输出的是**原始值**（范围 0-255，需输出 2 位十六进制，如 "00", "FF"）。
    *   图像输出的是**新编号**（范围 0-15，需输出 1 位十六进制，如 "0", "F"）。
    *   参考代码中 `itrans` 只转换 1 位，所以第一行输出时调用了两次 `itrans`（分别输出高 4 位和低 4 位）。
4.  **数组大小**：
    *   图像最大 20 行，每行最多 20 像素，`image[20][20]` 足够。
    *   灰阶统计数组 `his[256]` 必须覆盖 0-255。
5.  **字符串处理**：
    *   使用 `strlen` 需要包含 `<cstring>` 头文件。
    *   输入行可能包含换行符残留，但 `cin >> line` 会跳过 whitespace，通常没问题。

### 6. 复杂度分析
*   **时间复杂度**：
    *   统计频次：$O(N \times M)$，其中 $N \le 20, M \le 20$，计算量很小。
    *   选色：$16 \times 256$ 次循环，常数级。
    *   压缩映射：$N \times M \times 16$ 次循环，计算量很小。
    *   总复杂度极低，完全满足 90 分钟考试要求。
*   **空间复杂度**：
    *   主要消耗在图像存储数组和统计数组，$O(1)$（固定大小）。

### 编程题第二题：图像压缩 - 完整代码

```cpp
#include <iostream>
#include <cstring>  // 用于 strlen 函数
#include <cmath>    // 用于 abs 函数，虽然代码中手动实现了绝对值

using namespace std;

// 全局变量定义
// 存储原始图像像素值 (0-255)
int image[20][20]; 
// 存储压缩后的图像像素值 (0-15)
int cpimg[20][20]; 
// 统计每种灰阶 (0-255) 出现的次数
int his[256];      
// 存储选出的前 16 种代表灰阶的原始值
int color[16];     

/**
 * 函数功能：将一位十六进制字符转换为对应的整数 (0-15)
 * 支持 '0'-'9' 和 'A'-'F'
 * 
 * @param a 十六进制字符
 * @return 对应的整数值
 */
int trans(char a) {
    if (a <= '9') 
        return (a - '0');
    else 
        return (a - 'A' + 10);
}

/**
 * 函数功能：将一位整数 (0-15) 转换为对应的十六进制字符
 * 输出为大写 '0'-'9' 和 'A'-'F'
 * 
 * @param n 整数值 (0-15)
 * @return 对应的字符
 */
char itrans(int n) {
    if (n >= 10) 
        return (char)(n - 10 + 'A');
    else 
        return (char)(n + '0');
}

/**
 * 函数功能：寻找离当前灰阶值 c 最近的代表灰阶的编号 (0-15)
 * 规则：
 * 1. 绝对差值最小。
 * 2. 若差值相等，选择编号较小的（因为循环从 0 到 15，且使用严格小于号）。
 * 
 * @param c 原始灰阶值 (0-255)
 * @return 代表灰阶的编号 (0-15)
 */
int compress(int c) {
    int dis = 256; // 初始化最小距离为一个足够大的数
    int res = -1;  // 初始化结果编号
    
    // 遍历选出的 16 种代表灰阶
    for (int i = 0; i < 16; i++) {
        int d = c - color[i];
        if (d < 0) d = -d; // 计算绝对值
        
        // 如果找到更小的距离，更新结果
        // 注意：使用 < 而不是 <=，保证距离相等时保留编号较小的 i
        if (d < dis) {
            dis = d;
            res = i;
        }
    }
    return res;
}

int main() {
    // 优化 I/O 操作速度
    ios::sync_with_stdio(false);
    cin.tie(0);

    int N = 0; // 图像行数
    int M = 0; // 每行像素数
    
    cin >> N;

    // 初始化灰阶计数数组
    for (int i = 0; i < 256; i++) 
        his[i] = 0;

    // 1. 输入图像数据并统计灰阶频次
    for (int i = 0; i < N; i++) {
        char line[50]; 
        cin >> line; // 读入一行十六进制字符串
        
        // 每两个字符表示一个像素，计算每行像素个数
        M = strlen(line) / 2; 
        
        for (int j = 0; j < M; j++) {
            // 将两个十六进制字符转换为一个 0-255 的整数
            // 高 4 位 * 16 + 低 4 位
            int c = trans(line[j * 2]) * 16 + trans(line[j * 2 + 1]);
            
            image[i][j] = c; // 存储原始像素值
            his[c]++;        // 对应灰阶计数加 1
        }
    }

    // 2. 选取出现次数最多的 16 个灰阶作为代表色
    for (int c = 0; c < 16; c++) {
        int max = -1;      // 当前找到的最大频次
        int max_id = -1;   // 对应的灰阶值
        
        // 遍历所有可能的灰阶值 0-255
        for (int i = 0; i < 256; i++) {
            // 寻找频次最大的灰阶
            // 注意：使用 > 而不是 >=，保证频次相等时保留灰阶值较小的 i
            // 因为循环是从 0 到 255 递增的
            if (his[i] > max) {
                max = his[i];
                max_id = i;
            }
        }
        
        color[c] = max_id;   // 将选中的灰阶值存入代表色数组，下标 c 即为其新编号 (0-15)
        his[max_id] = -1;    // 将该灰阶频次标记为 -1，防止下次重复选中
    }

    // 3. 将原始图像压缩为新编号图像
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < M; j++) {
            cpimg[i][j] = compress(image[i][j]);
        }
    }

    // 4. 输出结果
    // 第一行：输出选定的 16 种灰阶的原始十六进制编码 (每种 2 位字符)
    for (int c = 0; c < 16; c++) {
        // 分别输出高 4 位和低 4 位对应的十六进制字符
        cout << itrans(color[c] / 16) << itrans(color[c] % 16);
    }
    cout << endl;

    // 后续 N 行：输出压缩后的图像 (每种 1 位字符)
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < M; j++) {
            cout << itrans(cpimg[i][j]);
        }
        cout << endl;
    }

    return 0;
}
```

1.  **十六进制处理**：
    *   **输入**：每两个字符代表一个字节（0-255）。例如 "00" -> 0, "FF" -> 255, "1A" -> 26。
    *   **转换公式**：`HighChar * 16 + LowChar`。
    *   **输出**：第一行输出的是**原始灰阶值**（需 2 位十六进制），后续输出的是**新编号**（需 1 位十六进制）。

    *   题目要求第一行输出 32 个字符（16 种颜色 * 2 字符），中间无空格。
    *   图像输出每行像素紧凑排列，中间无空格。
    *   代码中 `cout` 连续输出字符符合此要求。

5.  **数据类型**：
    *   像素值范围 0-255，`int` 足够。
    *   行数 $N \le 20$，`int` 足够。
    *   无需使用 `long long`，因为不涉及大整数运算。
