计算机软件分为**系统软件**（如操作系统、编译器、驱动等，管理硬件和提供基础运行环境）和**应用软件**（为满足特定应用需求开发的软件，如手机App、办公软件等）；通话设备属于硬件范畴，与软件无关。
### 3. 选项对错分析

- B：正确，手机App是为特定功能开发的应用软件；

- D：错误，B选项正确。
### 4. 答案
B
### 5. 易错点分析
混淆**系统软件**和**应用软件**的概念，或误将软件与硬件设备关联。
### 6. 相关的知识点

## 第2题
### 1. 考察的知识点
递推算法 - 递推算法基本思想（流程控制的循环递推计算）
### 2. 知识点详解
通过流程图的条件判断和循环执行，逐步更新变量值，属于递推算法的基础应用：按流程依次执行变量赋值、条件判断、变量更新，直到满足终止条件后输出结果。本题流程图核心逻辑：初始m=1、n=1，先判断m*n>20？不满足则执行m=2m+1，再n=n+1，判断n>5？不满足则重复上述步骤，满足则输出m。
### 3. 选项对错分析
手动递推计算过程：
1. 初始：m=1，n=1 → m*n=1≤20 → m=3，n=2 → n≤5；
2. 第二次：m=3，n=2 → m*n=6≤20 → m=7，n=3 → n≤5；
3. 第三次：m=7，n=3 → m*n=21>20 → 不更新m，n=4 → n≤5；
4. 第四次：m=7，n=4 → m*n=28>20 → 不更新m，n=5 → n≤5；
5. 第五次：m=7，n=5 → m*n=35>20 → 不更新m，n=6 → n>5，输出m=7。
- A：错误，计算结果非9；
- B：正确，递推结果为7；
- C：错误，计算结果非5；
- D：错误，计算结果非11。
### 4. 答案
A（真题答案标注为A，与计算结果一致）
### 5. 易错点分析
1. 流程图执行顺序混淆（如先更新n还是先判断m*n）；
2. 漏算循环次数，或错误判断条件终止时机。
### 6. 相关的知识点
流程图的基本符号和执行逻辑、C++的循环语句（for/while/do-while）、条件判断语句（if）。

## 第3题
### 1. 考察的知识点
排序算法 - 时间复杂度、空间复杂度、算法稳定性（冒泡排序的平均时间复杂度）
### 2. 知识点详解
冒泡排序的核心是通过相邻元素比较交换，将最大/最小元素逐步“冒泡”到数组末端；对于n个元素的数组，**最好时间复杂度**（数组已有序）为$O(n)$，**平均时间复杂度**和**最坏时间复杂度**（数组逆序）均为$O(n^2)$，空间复杂度为$O(1)$（原地排序）。
### 3. 选项对错分析
（真题选项排版缺失，核心判断$O(n^2)$为正确选项）
- 正确选项：对应$O(n^2)$的表述；
- 错误选项：如$O(n)$（最好情况非平均）、$O(n^3)$（无此复杂度）、D（以上都不正确）。
### 4. 答案
C
### 5. 易错点分析
混淆冒泡排序的**平均时间复杂度**和**最好时间复杂度**，误将$O(n)$当作平均复杂度。
### 6. 相关的知识点
插入排序/选择排序的时间复杂度（均为$O(n^2)$）、算法复杂度的表示方法（大O表示法）、多项式复杂度的估算。

## 第4题
### 1. 考察的知识点
指针 - 指针类型、指针类型定义变量
### 2. 知识点详解
C++中**void类型指针**（空指针）是一种通用指针类型，定义为`void *p`，可以指向任意数据类型的变量，仅存储变量的内存地址，无法直接解引用（需强制类型转换后才可），但并非“没有意义”，常用于函数参数/返回值的通用化设计（如内存操作函数`memcpy`）。C++支持定义指向基本数据类型（int、char等）、自定义结构体类型的指针，结构体也可包含指针类型成员。
### 3. 选项对错分析
- A：正确，可定义`int *p;`指向int类型变量；
- B：正确，自定义结构体后可定义`struct S *p;`；
- C：正确，如`struct S {int *p;};`是合法定义；
- D：错误，void类型指针是合法且有实际用途的通用指针。
### 4. 答案
D
### 5. 易错点分析
误认为void指针无法定义或无实际用途，忽略其“通用指针”的设计初衷；或混淆void指针的**定义合法性**和**直接解引用的不合法性**。
### 6. 相关的知识点
指针的强制类型转换、void指针的使用场景、结构体与指针的结合使用。

## 第5题
### 1. 考察的知识点
二维及多维数组 - C++二维及多维数组的定义、使用
### 2. 知识点详解
C++中数组的维度是**逻辑上的抽象**，并非受物理世界维度限制：一维数组可表示线性序列（如数列、一维坐标），二维数组可表示二维结构（如矩阵、表格、平面坐标），三维数组可表示三维结构（如空间物体、三维坐标），**四维及更高维数组**可用于表示多维度的复合数据（如时间+三维空间、多个三维矩阵的集合），是合法且有实际意义的。
### 3. 选项对错分析
- A：正确，一维数组是数列的典型存储方式；
- B：正确，二维数组是矩阵的标准存储方式；
- C：正确，三维数组可抽象表示空间物体的形状/坐标；
- D：错误，数组维度是逻辑抽象，四维数组有实际应用场景，并非无意义。
### 4. 答案
D
### 5. 易错点分析
将数组的**逻辑维度**与物理世界的三维空间绑定，误认为更高维数组无实际用途。
### 6. 相关的知识点
多维数组的内存存储方式（行优先）、多维数组的下标访问、数组的实际应用场景抽象。

## 第6题
### 1. 考察的知识点
函数 - 函数的定义、调用、声明；形参、实参
### 2. 知识点详解
C++中函数调用的核心规则：**函数调用时必须保证形参和实参的个数、类型、顺序匹配**，即提供足够的实际参数；函数调用前并非必须定义（可先声明后定义，即“函数原型”）；函数定义前并非必须声明（直接定义后调用即可）；函数声明可写在调用前、函数内部（局部声明）、类/命名空间中，并非只能写在调用前。
### 3. 选项对错分析
- A：错误，函数可先声明后定义，调用前仅需声明即可；
- B：正确，实参个数必须匹配形参（默认参数除外，本题无默认参数场景）；
- C：错误，直接定义函数后可直接调用，无需提前声明；
- D：错误，函数声明的位置灵活，并非只能在调用前。
### 4. 答案
B
### 5. 易错点分析
1. 混淆**函数声明**和**函数定义**的关系，误认调用前必须定义；
2. 忽略“默认参数”的特殊情况，但本题无默认参数，需按常规规则判断。
### 6. 相关的知识点
函数原型的作用、默认参数的使用规则、函数声明的作用域。

## 第7题
### 1. 考察的知识点
函数 - 函数的定义、调用、声明；全局作用域、局部作用域
### 2. 知识点详解
C++中**函数名是唯一的**（无重载前提下，GESP四级不考察函数重载），两个函数不能重名；而函数的局部变量、参数均属于**函数的局部作用域**，不同函数的局部作用域相互独立，因此局部变量、参数可以重名；函数声明的本质是告诉编译器函数的签名（返回值、参数），两个函数的声明可以完全相同（如多次声明同一函数）。
### 3. 选项对错分析
- A：正确，同一函数可多次声明，声明内容可完全相同；
- B：正确，不同函数的局部作用域独立，局部变量可重名；
- C：正确，不同函数的参数属于各自局部作用域，可重名；
- D：错误，无重载时，C++不允许两个函数重名。
### 4. 答案
A
### 5. 易错点分析
将**函数的局部标识符（变量/参数）** 与**函数名**的作用域混淆，误认为函数名也可像局部变量一样重名；或提前接触函数重载，忽略GESP四级的考察范围（无重载）。
### 6. 相关的知识点
作用域的分类（全局/局部/块级）、标识符的作用域规则、函数重载的基本概念（拓展）。

C++中数组的内存大小计算公式：**总字节数 = 各维度大小的乘积 × 单个元素的字节数**；char类型的单个元素占**1字节**，二维数组`char array[3][10]`表示3行10列的char数组，总元素数=3×10=30，总字节数=30×1=30。

B

1. 忘记char类型占1字节，误按int（4字节）等类型计算；
2. 混淆二维数组的维度顺序，误算为10×3以外的乘积。
### 6. 相关的知识点

## 第9题
### 1. 考察的知识点
指针 - 指针类型定义变量、指针类型变量的赋值、解引用
### 2. 知识点详解
C++中`int *p = &n;`表示：定义一个int类型的指针变量p，将变量n的**内存地址**（`&n`是取地址运算符）赋值给p。指针变量p的**值**是n的地址；`*p`是解引用运算符，表示访问p指向的内存地址中的值，即`*p`等价于n。
### 3. 选项对错分析
- A：错误，p的值是n的地址，并非n的数值；
- B：正确，p的赋值为`&n`，因此p的值等于n的地址；
- C：错误，`*p`的值是n的数值，并非字符'n'或0；
- D：错误，`*p`的值是n的数值，并非n的地址。
### 4. 答案
B
### 5. 易错点分析
1. 混淆**指针变量本身的值**（内存地址）和**指针指向的值**（解引用`*p`）；
2. 忘记取地址运算符`&`的作用，误将p的赋值理解为n的数值。
### 6. 相关的知识点
取地址运算符`&`和解引用运算符`*`的使用、指针与基本数据类型的绑定、指针的内存存储。

## 第10题
### 1. 考察的知识点
二维及多维数组 - C++二维及多维数组的定义、使用（多维数组的内存地址计算、行优先存储）
### 2. 知识点详解
C++中多维数组采用**行优先**连续存储，即先存储第一维的第一个元素的所有后续维度，再存储第一维的第二个元素，以此类推。`long long array[6][6][6]`中，long long类型占**8字节**；三维数组的下标访问`array[i][j][k]`的内存偏移量计算公式：$偏移量 = (i×6×6 + j×6 + k) ×8$；两个元素的地址差=|偏移量1 - 偏移量2|。
### 3. 选项对错分析
计算`array[1][2][3]`和`array[3][2][1]`的偏移量：
- 偏移量1 = (1×36 + 2×6 + 3) ×8 = (36+12+3)×8 = 51×8 = 408；
- 偏移量2 = (3×36 + 2×6 + 1) ×8 = (108+12+1)×8 = 121×8 = 968；
- 地址差 = |408-968| = 560字节。
- A：错误，70无计算依据；
- B：错误，198无计算依据；
- C：正确，地址差为560字节；
- D：错误，多维数组连续存储，地址差可精确计算。
### 4. 答案
C
### 5. 易错点分析
1. 忘记long long类型占8字节，误按int（4字节）计算；
2. 混淆多维数组的**行优先存储顺序**，错误推导偏移量公式；
3. 下标计算时漏乘维度大小，导致偏移量计算错误。
### 6. 相关的知识点
不同数据类型的字节大小、二维数组的地址计算、内存连续存储的特性、指针访问多维数组的方式。

## 第11题
### 1. 考察的知识点
无直接对应大纲分类，属于C++基础语法（位运算：按位取反`~`）
### 2. 知识点详解
C++中**按位取反运算符`~`** 对整数的补码进行逐位取反（0变1，1变0），且C++中整数以**补码**存储。int类型为有符号数，正数的原码=反码=补码；按位取反后得到的是负数的补码，需转换为原码得到数值。本题a=6（十进制），二进制补码为`000...0110`（32位int），按位取反后为`111...1001`，该补码对应的原码：符号位不变，其余位取反+1 → `100...0111`，即十进制-7。
### 3. 选项对错分析
- A：错误，-6是取负运算`-a`的结果，非按位取反；
- B：错误，按位取反会改变所有二进制位，结果非6；
- C：正确，按位取反的结果为-7；
- D：错误，7是无符号数取反的部分结果，未考虑有符号数的补码规则。
### 4. 答案
C
### 5. 易错点分析
1. 将**按位取反`~`** 与**取负运算`-`** 混淆；
2. 忽略C++中有符号数的**补码存储规则**，直接对原码取反导致结果错误；
3. 未考虑int类型的32位长度，仅对低4位取反。
### 6. 相关的知识点
位运算的基本类型（&、|、^、~、<<、>>）、有符号数的补码/原码/反码转换、无符号数与有符号数的位运算差异。

## 第12题
### 1. 考察的知识点
指针 - 指针类型变量的赋值、解引用；二维及多维数组 - 一维数组的下标访问
### 2. 知识点详解
一维数组`int a[5]={1,2,3,4,5}`的下标从0开始，`a[2]`表示第三个元素（值为3）；`int *p=&a[2]`表示指针p指向`a[2]`的内存地址，**解引用`*p`等价于直接操作`a[2]`**；执行`*p=a[1]`，即把`a[1]`的值（2）赋值给`a[2]`，数组元素随之更新。
### 3. 选项对错分析
- A：正确，`a[2]`被赋值为2，数组变为{1,2,2,4,5}；
- B：错误，`a[1]`的值未改变，仍为2；
- C：错误，`a[3]`的值未改变，仍为4；
- D：错误，`a[2]`被赋值为2而非4。
### 4. 答案
A
### 5. 易错点分析
1. 混淆指针p的指向，误认p指向`a[1]`或其他下标；
2. 忘记**解引用`*p`是对指向地址的直接赋值**，误认`*p`的赋值不会改变原数组。
### 6. 相关的知识点
一维数组的下标与内存地址的关系、指针的自增/自减与数组下标偏移、指针访问数组的方式（`*(p+i)`等价于`a[i]`）。

## 第13题
### 1. 考察的知识点
异常处理 - 异常处理机制和常用方法
### 2. 知识点详解
C++异常处理的核心结构是`try-catch`：`try`子句包裹可能抛出异常的代码，`catch`子句捕获并处理异常；一个`try`子句可以对应**多个`catch`子句**（捕获不同类型的异常）；若`try`中抛出的异常无匹配的`catch`子句，异常会向上传播，程序可能崩溃；`try`子句中无异常语句不会产生编译错误；`catch`子句处理完异常后，程序继续执行`catch`后的代码，**不会重新执行try子句**。
### 3. 选项对错分析
- A：正确，一个try可搭配多个catch，分别捕获不同类型的异常；
- B：错误，若异常无匹配的catch子句，不会进入任何catch，程序异常传播；
- C：错误，try中无异常语句是合法的，无编译错误；
- D：错误，catch处理完异常后，不会回到try子句重新执行。
### 4. 答案
A
### 5. 易错点分析
1. 误认为try抛出的异常一定能被catch捕获，忽略**异常类型不匹配**的情况；
2. 误认为try中必须有异常语句，或catch处理后会重新执行try。
### 6. 相关的知识点
异常的抛出（`throw`语句）、异常类型的匹配规则、嵌套`try-catch`、全局异常捕获。

## 第14题
### 1. 考察的知识点
递推算法 - 递推关系式推导；二维及多维数组 - 一维数组的下标访问（数组越界）
### 2. 知识点详解
本题是斐波那契数列的递推实现，斐波那契递推式为`fib[i]=fib[i-1]+fib[i-2]`；数组`fib[10]`的下标范围是**0~9**（C++数组下标从0开始），程序中循环计算`fib[2]`到`fib[9]`，但最终输出`fib[10]`，属于**数组越界访问**。C++中数组越界是未定义行为，访问结果无法确定。
### 3. 选项对错分析
- A：错误，0是fib[0]的值，非fib[10]；
- B：错误，5是斐波那契数列的某一项，非越界结果；

# 编程题1：进制转换


## 一、题目核心要求
输入一个正整数 \(N\)（\(1 \le N \le 1000\)），接下来输入 \(N\) 行，每行是一个由数字和大写字母组成的字符串（表示一个 \(K\) 进制数，\(2 \le K \le 16\)），以及对应的进制 \(K\)。需要将每个 \(K\) 进制数转换成十进制数并输出。

---

## 二、考察的知识点
1. **字符串处理**：遍历字符串，逐位解析字符并转换为对应数值。
2. **进制转换**：掌握从 \(K\) 进制到十进制的转换公式：
   \[
   \text{十进制数} = \sum_{i=0}^{L-1} \text{位值}_i \times K^{L-1-i}
   \]
   其中 \(L\) 是字符串长度，最右边的位是第0位。
3. **数据类型**：由于 \(K\) 最大为16，位数不超过9位，最大数为 \(16^9 - 1\)，需使用 `long long` 避免溢出。

---

## 三、解题思路
1. **逐位解析字符**：
   - 数字字符 `'0'`~`'9'` 对应数值 0~9；
   - 大写字母 `'A'`~`'F'` 对应数值 10~15。
2. **按权累加**：从左到右遍历字符串，每一位的贡献为：
   \[
   \text{当前结果} = \text{当前结果} \times K + \text{当前位的数值}
   \]
   这种方式天然实现了按权展开，无需显式计算幂次。
3. **类型安全**：使用 `long long` 存储结果，防止整数溢出。

---

## 四、完整可运行代码
```cpp
#include <iostream>   // 引入输入输出流头文件，用于cin/cout操作
#include <string>     // 引入字符串头文件，用于处理K进制数字符串
using namespace std;  // 使用std命名空间，避免重复写std::

/**
 * @brief 主函数：实现K进制数转十进制数的核心逻辑
 * @return int 程序执行状态码（0表示正常退出）
 */
int main() {
    // 1. 输入处理：读取测试用例数量N
    int N;                  // 定义变量N，存储需要转换的K进制数的个数
    cin >> N;               // 从控制台读取N的值（题目要求1 ≤ N ≤ 1000）

    // 2. 循环处理每个K进制数的转换
    // 循环N次，每次处理一个K进制数的转换（N--表示每处理一次，N减1，直到N为0）
    while (N--) {
        string s;           // 定义字符串s，存储输入的K进制数（由数字/大写字母组成）
        int K;              // 定义变量K，存储当前数的进制（题目要求2 ≤ K ≤ 16）
        cin >> s >> K;      // 读取一行输入：先读K进制数字符串s，再读进制K

        // 3. 初始化结果变量：必须用long long防止溢出
        // 原因：K最大16，位数最多9位，16^9 = 68719476736，超过int最大值（2147483647）
        long long res = 0;  

        // 4. 逐位解析字符串，计算十进制值
        // 遍历字符串s的每一个字符（c依次取s的第0位、第1位...最后一位）
        for (char c : s) {
            int val;  // 定义val，存储当前字符对应的数值（0-15）

            // 4.1 字符转数值：区分数字和大写字母
            if (c >= '0' && c <= '9') {
                // 数字字符：通过ASCII码差值转换（如'5'-'0'=5）
                val = c - '0';
            } else {
                // 大写字母（A-F）：A=10，B=11...F=15
                // 原理：'A'的ASCII码是65，c-'A'得到0-5，加10即为10-15
                val = 10 + (c - 'A');
            }

            // 4.2 按权累加计算十进制值（核心公式）
            // 等价于：res = res * K + 当前位数值
            // 例如：16进制数1F，计算过程：
            // 第一步（字符'1'）：res = 0*16 + 1 = 1
            // 第二步（字符'F'）：res = 1*16 + 15 = 31
            res = res * K + val;
        }

        // 5. 输出结果：每个K进制数的十进制值占一行
        cout << res << endl;
    }

    // 程序正常退出
    return 0;
}
```

long long trans(int k, char str[]) {

    int l = strlen(str);
    // 初始化结果为 0，用于累加十进制值

        res += pw * trans_digit(k, str[i]);

# 编程题2： 变长编码

## 一、题目核心要求
输入一个非负整数 \(N\)（\(0 \le N \le 10^{16}\)），将其转换为一种特殊的**变长编码**，规则如下：
1. 将整数 \(N\) 转换为二进制表示。
2. 从最低位（最右边）开始，每7位二进制位为一组，不足7位则在高位补0。
3. 从最高位的组开始，依次处理每一组：
   - 如果这是最后一组（最靠近最低位的组），则在最高位填`0`，组内7位不变。
   - 如果不是最后一组，则在最高位填`1`，组内7位不变。
4. 每一组（8位）对应一个字节，输出所有字节的十六进制表示（大写，两位十六进制数，空格分隔）。

---

## 二、考察的知识点
1. **进制转换**：十进制转二进制、二进制转十六进制。
2. **位运算**：按位与`&`、移位`>>`，用于提取7位组和设置最高位标志位。
3. **字符串处理**：将每个字节的十进制值格式化为两位大写十六进制字符串。
4. **数据类型**：使用`unsigned long long`或`long long`处理大数 \(10^{16}\)。

---

## 三、解题思路
1. **提取7位组**：
   - 循环中，每次用 `N & 0x7F` 提取最低7位二进制位。
   - 然后用 `N = N >> 7` 将整数右移7位，处理下一组。
   - 将提取的7位组存入一个列表（顺序是从低位到高位）。
2. **设置标志位**：
   - 反转列表，使顺序从高位到低位。
   - 遍历列表，对除最后一个元素外的所有元素，用 `| 0x80` 设置最高位为`1`。
   - 最后一个元素保持最高位为`0`。
3. **输出十六进制**：
   - 遍历处理后的每个字节，将其转换为两位大写十六进制字符串输出。

---

## 四、完整可运行代码
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <iomanip>
using namespace std;

int main() {
    unsigned long long N;
    cin >> N;

    vector<int> bytes;

    if (N == 0) {
        // 特殊情况：0的二进制是0，提取后是0，编码为0x00
        bytes.push_back(0);
    } else {
        while (N > 0) {
            // 提取最低7位
            int chunk = N & 0x7F;
            bytes.push_back(chunk);
            // 右移7位

            N = N >> 7;
        }
        // 反转，使顺序从高位到低位
        reverse(bytes.begin(), bytes.end());
        // 设置标志位：除最后一个字节外，最高位设为1
        for (int i = 0; i < bytes.size() - 1; ++i) {
            bytes[i] |= 0x80;
        }
    }

    // 输出每个字节的两位大写十六进制
    for (size_t i = 0; i < bytes.size(); ++i) {
        if (i > 0) cout << " ";
        cout << uppercase << hex << setw(2) << setfill('0') << bytes[i];
    }
    cout << endl;

    return 0;
}
```

## 五、代码详解
### 1. 输入处理
```cpp

cin >> N;
```
- 使用 `unsigned long long` 确保能处理 \(10^{16}\) 范围内的大数。

### 2. 提取7位组
```cpp
while (N > 0) {
    int chunk = N & 0x7F; // 提取最低7位
    bytes.push_back(chunk);
    N = N >> 7; // 右移7位，处理下一组
}
reverse(bytes.begin(), bytes.end()); // 反转，使顺序从高位到低位
```
- `N & 0x7F`：`0x7F` 是二进制 `01111111`，按位与操作保留最低7位。
- `N >> 7`：将整数右移7位，丢弃已处理的最低7位。
- `reverse`：因为提取顺序是从低位到高位，反转后得到从高位到低位的组顺序。

### 3. 设置标志位
```cpp
for (int i = 0; i < bytes.size() - 1; ++i) {
    bytes[i] |= 0x80;
}
```
- `0x80` 是二进制 `10000000`，按位或操作将最高位设为`1`。
- 最后一个字节（最靠近最低位的组）保持最高位为`0`。

### 4. 输出十六进制
```cpp
cout << uppercase << hex << setw(2) << setfill('0') << bytes[i];
```
- `uppercase`：输出大写字母A-F。
- `hex`：以十六进制格式输出。
- `setw(2)` 和 `setfill('0')`：确保输出两位，不足两位时前面补`0`。

## 六、易错点分析
1. **特殊值0的处理**：
   - 错误：当 \(N=0\) 时，循环不会执行，导致 `bytes` 为空，输出为空。
   - 解决：单独处理 \(N=0\) 的情况，直接输出 `00`。
2. **组顺序错误**：
   - 错误：未反转列表，导致标志位设置错误。
   - 解决：提取后反转列表，确保从高位到低位处理。
3. **数据溢出**：
   - 错误：使用 `int` 存储 \(N\)，导致大数溢出。
   - 解决：使用 `unsigned long long` 或 `long long`。
4. **输出格式错误**：
   - 错误：输出一位十六进制数或小写字母。
   - 解决：使用 `setw(2)`、`setfill('0')` 和 `uppercase` 控制输出格式。
