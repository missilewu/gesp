## 提出问题

我们写的程序，其中的变量、数组、计算结果都保存在哪里？关闭程序后，这些数据还在吗？如果想保存一个游戏进度、一份通讯录，该怎么办？

## 引导思考

## 答案与解析

程序运行时，变量、数组、计算结果等数据均存储在内存（RAM）中。内存的核心特点是“临时性”——一旦程序关闭、电脑断电，内存中的所有数据会立即丢失。而我们需要长期保存的数据（如游戏进度、通讯录、考试成绩），必须存储到磁盘（硬盘、U盘等）这类“持久性存储设备”中，这个过程就叫做**数据持久化**。

文件是程序与磁盘交互的核心桥梁，程序通过操作文件，实现数据在内存与磁盘之间的传输。在C++中，我们主要通过标准库`<fstream>`提供的类来完成文件操作，该库封装了文件交互的底层细节，让我们可以用类似控制台输入输出（cin、cout）的方式操作文件。

# 第二章：技巧进阶——从手动输入到文件重定向的高效转化

🎯**本章学习目标**：

1. 掌握freopen函数的用法（GESP四级编程题必考点，占3-5分）；

2. 学会命令行重定向的操作，区分两种重定向方式的适用场景；

3. 理解标准输入流（stdin）、标准输出流（stdout）的重定向原理。

**考点清单**：freopen函数原型与参数、两种重定向方式对比、跨平台流恢复。

🔗 **知识衔接（关联GESP三级）**：三级已掌握cin（对应stdin）、cout（对应stdout）的控制台输入输出，本章核心是“改变这两个流的默认指向”，用法与cin、cout完全兼容，仅需额外掌握重定向的实现方式。

## 设定场景

你正在调试一个排序程序，需要输入100个整数测试边界情况。每次运行程序，都要在控制台手动输入这100个数，不仅耗时还容易输错。有没有办法让程序自动从提前准备好的文本文件里读取输入数据，同时把排序结果自动保存到另一个文件中，省去手动输入输出的麻烦？

## 引导思考

我们平时用cin从控制台读入数据，用cout向控制台输出数据，cin和cout的默认“数据源”和“输出目标”都是控制台。那能不能改变它们的默认指向，让cin从文件读数据，让cout向文件写数据呢？

## 答案与解析

### 1. 核心概念

cin对应的是“标准输入流（stdin）”，默认来源是键盘；cout对应的是“标准输出流（stdout）”，默认去向是屏幕。**文件重定向**就是改变这两个标准流的来源或去向，让它们与文件关联，实现自动读写文件的效果，这也是GESP四级文件操作的核心考点之一。

### 2. 方法一：freopen函数（C风格，GESP四级常考）

freopen是C标准库`<cstdio>`中的函数，可将标准流重定向到指定文件，用法简洁且能嵌入代码逻辑，适合需要在程序中动态切换输入输出目标的场景。

函数原型：`FILE *freopen(const char *filename, const char *mode, FILE *stream);`

参数说明：

- filename：目标文件路径及名称（如“input.txt”）；

- mode：文件打开模式（“r”读、“w”写）；

- stream：要重定向的标准流（stdin、stdout）。

经典示例（读取input.txt，输出到output.txt）：

```cpp

#include <iostream>
#include <cstdio> // freopen所在头文件（考点：头文件依赖）
#include <algorithm>
using namespace std;

int main() {
    // 将stdin重定向到input.txt，从文件读入数据（考点：stdin重定向写法）
    freopen("input.txt", "r", stdin);
    // 将stdout重定向到output.txt，结果写入文件（考点：stdout重定向写法）
    freopen("output.txt", "w", stdout);

    int arr[100], n = 100;
    // 从文件读入100个整数，用法和cin完全一致（衔接三级cin用法）
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }
    // 排序（三级已学算法，此处仅作功能演示）
    sort(arr, arr + n);
    // 结果写入文件，用法和cout完全一致
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    // 恢复控制台输入输出（可选，跨平台处理考点）
    #ifdef _WIN32 // Windows系统（考点：跨平台适配）
        freopen("CON", "r", stdin);
        freopen("CON", "w", stdout);
    #else // Linux/Mac系统
        freopen("/dev/tty", "r", stdin);
        freopen("/dev/tty", "w", stdout);
    #endif

    return 0;
}
```

注意：C标准库并未提供恢复标准流的统一方法，上述代码通过系统特定文件名实现恢复，实际使用时需注意跨平台兼容性。

### 3. 方法二：命令行重定向（快速测试用）

这种方法无需修改代码，在运行程序时通过命令行参数指定重定向关系，适合快速测试已写好的程序。

语法格式（Windows命令提示符/ Linux终端）：

```Plain Text

程序名.exe < 输入文件名 > 输出文件名
```

示例：假设编译后的程序为sort.exe，输入文件为input.txt，输出文件为output.txt，运行命令为：

```Plain Text

sort.exe < input.txt > output.txt
```

特点：操作便捷，无需修改代码，但无法在程序运行中动态切换输入输出目标。

### 4. 两种方法对比

| **方法**    | **优点**         | **缺点**           | **适用场景**        |
| --------- | -------------- | ---------------- | --------------- |
| freopen函数 | 可嵌入代码逻辑，支持动态切换 | 需包含头文件，恢复流需跨平台处理 | 程序需根据条件切换输入输出目标 |
| 命令行重定向    | 无需修改代码，操作快速    | 无法动态切换，依赖命令行环境   | 快速测试程序，验证代码逻辑   |

## 提出问题

我们已经有了一个保存着学生姓名和成绩的“data.txt”文件，如何让C++程序精准打开这个文件，并把里面的内容读取到内存中进行处理呢？

## 引导思考

cin是面向控制台的输入工具，那有没有一个类似cin，但专门面向文件的“输入工具”？这个工具需要具备哪些功能（比如打开文件、读取数据、判断是否读完）？

## 答案与解析

### 1. 核心类：ifstream（输入文件流）

C++通过`<fstream>`库提供的ifstream类（Input File Stream）实现文件读操作，该类继承自istream（cin的父类），因此很多用法和cin保持一致，降低了学习成本。

### 2. 打开文件（必做：检查打开是否成功）

打开文件有两种方式，无论哪种方式，都必须检查文件是否打开成功——这是GESP四级考试的高频考点，也是实际编程中避免错误的关键。

#### 方式一：通过构造函数打开

```cpp

#include <iostream>
#include <fstream> // ifstream所在头文件（考点：头文件依赖）
#include <string>
using namespace std;

int main() {
    // 构造函数中指定文件名，默认以“读模式”打开（考点：默认模式）
    ifstream fin("data.txt");
    
    // 检查文件是否打开成功（两种写法均可，考点：打开检查）
    if (!fin) { // 写法1：流对象为空表示打开失败
        cerr << "文件打开失败！" << endl;
        return 1; // 非0返回值表示程序异常退出（编程规范考点）
    }
    // if (!fin.is_open()) { // 写法2：调用is_open()函数判断（备选写法）
    //     cerr << "文件打开失败！" << endl;
    //     return 1;
    // }

    // 后续读取操作...

    fin.close(); // 关闭文件（良好编程习惯，避免资源泄露）
    return 0;
}
```

#### 方式二：通过open()成员函数打开

```cpp

int main() {
    ifstream fin; // 先定义ifstream对象
    // 调用open()打开文件，参数为文件名（考点：open()用法）
    fin.open("data.txt");
    
    // 检查打开成功（必写步骤，否则可能导致后续操作崩溃）
    if (!fin) {
        cerr << "文件打开失败！" << endl;
        return 1;
    }

    // 后续读取操作...

    fin.close();
    return 0;
}
```

打开失败的常见原因：文件路径错误（如文件不在程序运行目录）、文件被占用、文件名拼写错误。

### 3. 三种读取数据的方式

#### 方式一：格式化读取（>>操作符）

与cin用法完全一致，按空格、换行符分割数据，适合读取结构化的文本数据（如整数、浮点数、不含空格的字符串）。

```cpp

// 假设data.txt内容：Alice 95 Bob 88 Charlie 92
string name;
int score;
// 循环读取，直到文件末尾（考点：循环读取写法）
while (fin >> name >> score) {
    cout << "姓名：" << name << "，成绩：" << score << endl;
}
```

#### 方式二：读取一行数据（getline()函数）

当数据中包含空格时（如“Zhang San 90”），>>操作符会截断数据，此时需用getline()函数读取整行内容。

```cpp

string line;
// getline(流对象, 字符串变量)：读取一行内容到line中，不包含换行符（考点：函数用法）
while (getline(fin, line)) {
    cout << "一行数据：" << line << endl;
}
```

注意：若先使用`>>`读取数据，再用getline()，需处理残留的换行符（可通过fin.ignore()清空缓冲区）。GESP四级常考此场景，需掌握ignore()的标准用法。

❌**错误代码对比（getline残留换行符）**：

❌ 错误代码（遗漏ignore()）：

```cpp

int age;
string name;
fin >> age; // 读取整数后，缓冲区残留换行符
getline(fin, name); // 错误：读取到残留换行符，返回空字符串
cout << "年龄：" << age << "，姓名：" << name << endl;
```

错误原因：>>读取整数后，换行符仍留在缓冲区，getline()会优先读取该换行符，直接返回空串；

✅ 修正代码（补全ignore()）：

```cpp

#include <iostream>
#include <fstream>
#include <string>
#include <limits> // numeric_limits所在头文件（考点：头文件依赖）
using namespace std;

int main() {
    ifstream fin("data.txt");
    if (!fin) {
        cerr << "文件打开失败！" << endl;
        return 1;
    }
    int age;
    string name;
    // 先用法>>读取整数，缓冲区残留换行符
    fin >> age;
    // 忽略缓冲区中剩余的所有字符（直到换行符），避免getline()读空行（考点：ignore()标准用法）
    fin.ignore(numeric_limits<streamsize>::max(), '\n');
    // 再用getline()读取完整姓名（含空格）
    getline(fin, name);
    cout << "年龄：" << age << "，姓名：" << name << endl;
    fin.close();
    return 0;
}
```

核心说明：

- `numeric_limits<streamsize>::max()` 表示忽略最大可能长度的字符，确保清空残留内容；

- 第二个参数 '\n' 表示忽略到换行符为止（包含换行符），精准清空一行残留；

- 若省略ignore()，getline()会读取到缓冲区残留的换行符，直接返回空字符串，这是GESP四级编程题常见易错点。

#### 方式三：读取单个字符（fin.get()函数）

逐字符读取文件内容，适合处理文本中的每个字符（如统计字符个数、替换特定字符）。

```cpp

char ch;
// 逐字符读取，直到文件末尾（考点：EOF的使用）
while ((ch = fin.get()) != EOF) {
    cout << ch; // 原样输出字符
}
```

### 4. 读取状态检查与流重置

在循环读取时，需判断读取状态（是否到文件末尾、是否读取错误），常用函数如下：

- fin.eof()：返回bool值，true表示已读到文件末尾；

- fin.fail()：返回bool值，true表示读取失败（如格式错误、文件损坏）；

- fin.good()：返回bool值，true表示读取状态正常。

示例：用状态函数控制循环（分步注释版）

```cpp

int num;
while (fin.good()) { // 步骤1：状态正常则继续读取（考点：good()用法）
    fin >> num; // 步骤2：尝试读取整数
    if (!fin.fail()) { // 步骤3：确保读取成功（考点：fail()用法）
        cout << num << " ";
    } else {
        // 读取失败（如格式错误），处理异常
        if (fin.eof()) break; // 步骤4：若为文件末尾，正常退出循环（考点：eof()用法）
        fin.clear(); // 步骤5：重置流状态标志，恢复可读写能力（GESP四级高频考点）
        // 步骤6：忽略当前行剩余字符，避免死循环（搭配ignore()）
        fin.ignore(numeric_limits<streamsize>::max(), '\n');
        cerr << "读取到非法数据，已跳过" << endl;
    }
}
```

#### 补充：流状态重置函数 clear()（GESP四级高频考点）

当读取失败（如用>>读整数时遇到字母、指针越界），流对象会设置错误标志（failbit被置1），此时流将无法继续读写，必须用`clear()`重置状态标志。

核心要点：

- `clear()` 仅重置流状态标志，不清空缓冲区内容，需搭配 `ignore()` 使用；

- `ignore(numeric_limits<streamsize>::max(), '\n')` 表示忽略到换行符前的所有字符（需包含头文件 `<limits>`）；

- GESP四级常考场景：处理用户输入错误、文件格式异常后的流恢复。

## 答案与解析

### 1. 核心类：ofstream（输出文件流）

ofstream类（Output File Stream）用于文件写操作，同样位于`<fstream>`库，继承自ostream（cout的父类），用法与cout高度兼容。

### 2. 打开文件与核心模式（关键考点）

写操作的核心是“打开模式”，不同模式决定了文件的写入行为，ofstream默认打开模式为ios::out（覆盖写入），常用模式如下（💡 核心必掌握）：

- ios::out：默认模式，以写方式打开文件，若文件已存在则清空原有内容；

- ios::app：追加模式，打开文件后将数据写入文件末尾，不覆盖原有内容，写指针始终固定在末尾；

- ios::trunc：清空模式，打开文件时立即清空原有内容（通常与ios::out组合使用，效果与默认模式一致）；

- ios::ate：打开文件后自动将读写指针定位到文件末尾，可读写任意位置（非强制追加，GESP四级考点，⚠️ 了解核心差异即可）。

#### 补充：ios::ate 与 ios::app 的核心区别（GESP四级辨析考点）

两者均会定位到文件末尾，但读写权限和指针行为差异显著，是考试选择题高频考点，对比如下：

| **模式**   | **指针初始位置** | **是否允许覆盖写入** | **写指针是否固定**    |
| -------- | ---------- | ------------ | -------------- |
| ios::app | 文件末尾       | 否，仅能追加       | 是，始终在末尾        |
| ios::ate | 文件末尾       | 是，可通过指针定位覆盖  | 否，可通过seekp()移动 |

// ios::ate模式示例（分步注释）

### 4. 缓冲区与flush()函数

与cout类似，ofstream写入数据时，不会立即写入磁盘，而是先存储在输出缓冲区中，当缓冲区填满、程序正常结束或调用flush()函数时，才会将数据刷新到磁盘。

显式调用flush()可确保数据及时写入磁盘，避免因程序异常退出导致数据丢失，适合写入重要数据（如日志、配置）。

```cpp

fout << "重要数据：" << 12345;
fout.flush(); // 立即刷新缓冲区，将数据写入磁盘（考点：flush()用法）
fout << "普通数据：" << 67890 << endl; // endl也会刷新缓冲区（对比考点）
```

## 答案与解析

### 1. 核心类：fstream（文件流）

fstream类是功能最全面的文件操作类，同时继承了ifstream和ofstream的功能，支持双向读写操作，需通过组合打开模式实现读写功能。

### 2. 打开模式组合（必记，💡 核心）

fstream需显式组合模式标志，才能实现预期的读写行为，常用组合如下：

- ios::in | ios::out：以读写模式打开文件，文件必须存在，不会清空原有内容；

- ios::in | ios::out | ios::trunc：以读写模式打开，若文件存在则清空内容；

- ios::in | ios::out | ios::binary：二进制读写模式（后续讲解）。

示例：读写模式打开文件（分步实现指南）

📝 **分步实现指南（先自主尝试，再对照完整代码）**：

1. 定义fstream对象，用ios::in | ios::out模式打开“config.txt”；

2. 检查文件是否打开成功，失败则输出提示并退出；

3. 尝试读取文件内容（用getline()），输出到控制台；

4. 移动写指针到指定位置，写入新内容；

5. 关闭文件。

```cpp

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {

    fstream file("config.txt", ios::in | ios::out);
    if (!file) {
        cerr << "文件打开失败！" << endl;
        return 1;
    }

    // 读取文件内容
    string line;
    cout << "原有配置：" << endl;
    while (getline(file, line)) {
        cout << line << endl;
    }

    // 移动写指针到文件开头，准备覆盖写入（考点：seekp()定位）

    file.close();
    return 0;
}
```

### 3. 文件指针操作（随机读写核心）

默认情况下，文件读写是“顺序”的，即从文件开头依次向后操作。若要修改文件中间的内容，需通过“文件指针”定位到指定位置，常用函数如下（💡 核心必掌握）：

- seekg(pos, base)：移动“读指针”到指定位置；

- seekp(pos, base)：移动“写指针”到指定位置；

- tellg()：返回当前读指针的位置（字节数，从文件开头计算）；

- tellp()：返回当前写指针的位置。

参数base的取值：ios::beg（文件开头，默认）、ios::cur（当前位置）、ios::end（文件末尾）。
