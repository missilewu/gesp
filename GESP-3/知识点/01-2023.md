## 一、数据编码：原码、反码、补码
### （一）核心知识点
1. 数据编码方式的多样性，并非仅原码、反码、补码三种；
2. 不同编码的适用场景（如格雷码用于通信、哈夫曼编码用于压缩）。

### （三）易错点
1. 误以为数据编码仅原码、反码、补码，忽略格雷码、哈夫曼编码等其他类型；
2. 混淆“数据编码”与“字符编码”（如ASCII码属于字符编码，并非原码/反码/补码范畴）。

### （四）相关知识点
1. 常见其他编码：格雷码（相邻数值二进制仅1位不同）、哈夫曼编码（前缀编码，用于数据压缩）；
2. 原码、反码、补码的核心作用：解决计算机中负数的存储与运算问题（补码可避免减法运算）。

## 二、进制转换：二进制、八进制、十进制、十六进制
### （一）核心知识点
1. 各进制的表示规则：
   - 二进制：仅含0、1；八进制：0-7；十进制：0-9；十六进制：0-9、A-F（大写）；
   - 进制字面量：0x开头为十六进制（如0xf）、0开头为八进制（如015）；
2. 相互转换方法：
   - 任意进制→十进制：整数部分按位加权求和（位×进制^位权），小数部分按位×进制^(-位权)；
   - 十进制→其他进制：整数部分除基取余（逆序排列），小数部分乘基取整（顺序排列）；
3. 快捷转换：二进制转八进制（3位一组）、二进制转十六进制（4位一组）；
4. 多进制判断：根据字符串中最大字符确定合法进制（如最大字符≤'1'为二进制）。

### （三）易错点
1. 二进制小数转十进制时，小数部分位权计算错误（如2⁻¹误算为0.1，实际为0.5）；
2. 混淆进制字面量：将0开头的数字误判为十进制（实际为八进制），0x开头误判为十进制；
3. 误以为“非2的整数次幂的十进制数无法转二进制”，忽略任意进制可相互转换的本质；
4. 八进制最大数字记错（误记为8，实际为7），十六进制忽略A-F的范围；
5. 多进制判断时，未遍历字符串找最大字符，而是逐个字符判断导致效率低或遗漏。

### （四）相关知识点
1. 进制位权公式：对于R进制数dₙdₙ₋₁…d₁d₀.d₋₁…d₋ₘ，十进制值=Σdᵢ×Rⁱ（i从-n到m）；
2. 常见进制对照表：十进制0-16对应二/八/十六进制值；
3. 字符与进制的关系：不同进制的字符串最大字符限制（二进制≤'1'、八进制≤'7'、十进制≤'9'、十六进制≤'F'）；
4. 进制转换工具：手动转换技巧（如二进制小数转十进制分步计算）、编程中进制处理逻辑（字符串遍历+位权计算）。

## 三、位运算：与(&)、或(|)、非(~)、异或(^)、左移(<<)、右移(>>)
### （一）核心知识点
1. 合法位运算符识别：C++中支持&（按位与）、|（按位或）、~（按位非）、^（异或）、<<（左移）、>>（右移），非法运算符如~~、**；
2. 核心性质：
   - 异或（^）：`a^a=0、a^0=a、a^b^b=a`（两次异或恢复原值）；
   - 按位与（&）：a&0=0、a&全1=a（可清零指定位）、a&1判断奇偶（1为奇数，0为偶数）；
   - 按位或（|）：a|0=a、a|全1=全1（可置1指定位）；
   - 左移（<<）：a<<n = a×2ⁿ（无溢出时），可能溢出；
   - 右移（>>）：a>>n = a÷2ⁿ（整数除法），负数补符号位，低位清零；
3. 应用场景：变量交换（无需临时变量）、相等判断（a^b==0）、指定位操作（清零、置1）、数值范围限制（如a&~3求最大4的倍数）；
4. 优先级：位运算优先级低于算术运算符，高于逻辑运算符（如a+b&c 等价于 (a+b)&c）。

### （三）易错点
1. 忽略位运算溢出：左移时未考虑int类型的取值范围（如32位int左移31位可能溢出），导致原值恢复失败；
2. 右移特性误解：认为右移后再左移能恢复原值，忽略右移会清零低位（如int a=5（101），右移1位为2（10），再左移1位为4（100）≠5）；
3. 异或交换逻辑不理解：未掌握“b=a^b → a=a^b → b=a^b”的三步推导，误选其他赋值顺序；
4. 相等判断用错运算符：用(a&b)==a代替(a^b)==0，忽略“a是b的子集”与“a==b”的区别；
5. 逻辑运算符与位运算符混淆：将&&（逻辑与）与&（按位与）、||（逻辑或）与|（按位或）混用，导致逻辑错误（如5&&2=1，5&2=0）；
6. 位运算优先级遗漏括号：如a+b&c误算为a+(b&c)，实际等价于(a+b)&c，需手动加括号改变优先级。

### （四）相关知识点
1. 位运算实用技巧：
   - 变量交换：a=a^b; b=a^b; a=a^b;（无需临时变量，仅适用于同类型变量）；
   - 求最大公约数：gcd(a,b) = gcd(b, a^b)（二进制优化，效率高于辗转相除法）；
   - 判断2的整数次幂：(a & (a-1)) == 0（a≠0）；
   - 清零指定位：a & ~mask（mask为指定位为1的数）；
   - 置1指定位：a | mask；
2. 32位int的位运算边界：取值范围-2³¹~2³¹-1，左移时注意符号位（负数左移可能变为正数）；
3. 逻辑运算符与位运算符的区别：
   - 逻辑运算符（&&、||）：短路特性（左侧确定结果时右侧不执行），结果为bool值（0或1）；
   - 位运算符（&、|）：无短路特性，按二进制位逐位运算，结果为整数；
4. 位运算在编程中的应用：状态压缩（如用一个整数存储多个布尔状态）、数据加密（简单异或加密）。

## 四、算法与描述
### （一）核心知识点
#### 1. 枚举法、模拟法
- 枚举法：逐个尝试所有可能的解，验证是否满足条件（适用于数据量小的场景）；
- 模拟法：将实际场景抽象为程序中的“标记-遍历-计算”逻辑，模拟真实过程（如统计、状态跟踪）；
- 适用场景：枚举法用于验证猜想（如哥德巴赫猜想）、查找可行解；模拟法用于统计次数、状态标记、合规检测。

#### 2. 算法描述方式
- 支持多种描述方式：自然语言（如中文描述步骤）、伪代码（类代码的简化描述）、流程图（图形化步骤）；
- 核心要求：描述清晰、逻辑严谨，无歧义。

### （三）易错点
1. 模拟法遗漏特殊情况：如春游问题中“所有同学都到达”需输出N，未单独处理导致输出为空；密码合规检测中遗漏“特殊字符仅!@#$”的限制；
2. 枚举法效率未考虑：虽然GESP三级题目数据量小（如N<10），但未优化枚举范围（如小猫分鱼从最后一只猫的最少拿鱼数逆向枚举），导致程序运行时间过长；
3. 算法描述认知错误：误以为“算法必须用程序语言或流程图描述”，忽略自然语言的合法性；
4. 模拟法逻辑建模不清晰：如储蓄罐问题中“第i天存i元”未对应到数组下标，导致累加错误。

### （四）相关知识点
1. 模拟法实施步骤：
   - 抽象场景：提取核心要素（如春游中的“同学编号”“报到状态”）；
   - 数据建模：用数组/变量存储状态（如bool数组标记到达、int数组存储金额）；
   - 流程实现：按真实顺序遍历/计算（如按天数遍历存钱、按字符遍历密码）；
   - 特殊处理：单独判断边界情况（如全部到达、密码长度超限）；
2. 枚举法优化思路：
   - 缩小枚举范围（如小猫分鱼从k=1开始，而非从1遍历到极大值）；
   - 提前剪枝（如验证某一步不满足条件时，直接跳过后续枚举）；
3. 算法描述示例：
   - 自然语言：“第一步初始化到达数组为false；第二步遍历报到编号，标记对应位置为true；第三步遍历数组，输出未标记的编号”；
   - 伪代码：用类代码语法描述，省略具体语言细节（如“for 每个报到编号 in 输入列表: arrive[编号] = true”）。

## 五、数据结构：C++一维数组（不包含变长数组）
### （一）核心知识点
1. 数组定义规则：
   - 合法定义：明确长度+初始化（int a[5]={1,2}）、省略长度+初始化（int a[]={1,2,3}）、字符作为下标（int a['3']，'3'的ASCII码为51，等价于int a[51]）；
   - 非法定义：[]内用小数（int a[3.0]）、省略长度且无初始化（int a[]）、类型写在[]后（int[3] a）；
2. 数组内存计算：总字节数=元素个数×单个元素字节数（如double数组每个元素8字节，3个元素共24字节）；
3. 数组特性：
   - 内存连续：所有元素在内存中按顺序连续存储；
   - 大小固定：定义时确定长度，运行时不可修改；
   - 下标范围：0~n-1（n为元素个数），越界访问为运行时错误（编译期不报错）；
   - 赋值规则：不能整体赋值（如a=b，a、b为数组），可逐个元素赋值；
4. 数组应用：存储批量数据、状态标记（如到达状态）、统计计数（如储蓄罐金额）。

### （三）易错点
1. 字符数组长度计算错误：忽略字符串结束符'\0'，如"Hello"的字符数组长度误算为5（实际为6）；
2. 数组内存计算记错数据类型字节数：将long long（8字节）误算为4字节、double（8字节）误算为4字节，导致总内存计算错误；
3. 下标范围混淆：认为长度为n的数组下标范围是0~n（含n），导致越界访问；
4. 数组定义合法性判断错误：
   - 误判“char作为下标”为非法（如int b['3']），忽略字符本质是ASCII码值（整数常量）；
   - 误选“省略长度且无初始化”（int a[]）为合法；
5. 数组名与元素混淆：将数组名（如list）当作首元素输出（实际数组名是内存地址），如cout<<list<<endl输出地址而非元素；
6. 数组初始化误解：认为“部分初始化数组的剩余元素未定义”（实际默认值为0），如int a[10]={1}，a[1]~a[9]均为0；
7. 越界访问认知错误：认为数组越界访问会产生编译错误（实际是运行时错误，编译期无法检测），导致忽略下标检查。

### （四）相关知识点
1. 常见数据类型字节数（32/64位系统通用）：
   - char：1字节；int：4字节；long long：8字节；double：8字节；
2. 数组初始化方式汇总：
   - 完全初始化：int a[3]={1,2,3}；
   - 部分初始化：int a[3]={1}（剩余元素为0）；
   - 省略长度初始化：int a[]={1,2,3}（长度为3）；
   - 字符数组初始化：char a[]="Hello"（含'\0'，长度6）、char a[]={'H','e','l','l','o','\0'}（等价于前一种）；
3. 数组内存布局：以int a[3]={1,2,3}为例，内存中按a[0]、a[1]、a[2]顺序连续存储，地址依次递增4字节；
4. 数组越界的危害：程序崩溃、数据污染（修改其他变量内存）、结果不确定（可能正常运行但输出错误）；
5. 数组与字符串的关系：字符数组是存储字符串的基础，字符串必须以'\0'结尾，否则无法被string相关函数（如strlen）正确识别；
6. 数组的替代方案：string类（自动管理长度，避免'\0'遗漏）、vector（动态数组，支持长度修改，GESP三级暂不重点考察）。

## 六、字符串及其函数：大小写转换、字符串搜索、分割、替换等
### （一）核心知识点
1. 字符串存储：
   - 字符数组存储：必须以'\0'作为结束标记，长度=实际字符数+1；
   - string类存储：自动管理长度，无需手动添加'\0'，支持动态操作；
2. 字符串核心操作：
   - 长度获取：字符数组用strlen（不含'\0'）、数组长度计算（含'\0'）；string用length()或size()；
   - 字符判断：大写字母（'A'<=c<='Z'）、小写字母（'a'<=c<='z'）、数字（'0'<=c<='9'）；
   - 字符串分割：按指定分隔符（如逗号、空格）拆分字符串，遍历+截取实现；
   - 字符串替换：string的replace(pos, len, str)方法（起始位置、替换长度、替换字符串）；
   - 字符统计：遍历字符串，计数目标字符出现次数；
3. 字符串合规检测：结合长度、字符类型、组合规则判断（如密码合规检测）。

### （三）易错点
1. 字符串长度混淆：strlen（字符数组，不含'\0'）与数组长度（含'\0'）混用，如char a[]="Hello"，strlen(a)=5，sizeof(a)=6；
2. 字符串分割遗漏最后一段：按逗号分割时，仅处理逗号前的子串，未处理最后一个逗号后的子串（如输入"a,b,c"，遗漏"c"）；
3. replace方法参数顺序记错：string的replace(pos, len, str)误写为replace(len, pos, str)，导致替换位置错误；
4. 字符与数值混淆：将字符'3'当作数值3处理（如计算时直接用'3'参与算术运算，实际ASCII码为51）；
5. 字符串越界访问：访问string的下标超过length()-1（如str="chen"，访问str[5]），导致输出未知值；
6. 字符判断逻辑错误：用连续比较'A'<=c<='Z'（C++中左结合，等价于('A'<=c)<='Z'，结果恒为true），正确写法为('A'<=c)&&(c<='Z')；
7. 字符串提取时忽略大小写：如提取数字时未区分字符'0'~'9'与其他字符（如字母O与数字0）。

### （四）相关知识点
1. 字符数组与string类的区别：

| 特性   | 字符数组（char[]）                     | string类                         |
| ---- | -------------------------------- | ------------------------------- |
| 结束标记 | 需手动添加'\0'                        | 自动管理，无需'\0'                     |
| 长度获取 | strlen()（不含'\0'）、sizeof()（含'\0'） | length()/size()（不含结束符）          |
| 赋值方式 | 不能整体赋值，需逐个元素或strcpy              | 支持直接赋值（=）、拼接（+）                 |
| 动态修改 | 长度固定，修改需重新定义或strcat              | 支持push_back、append、replace等动态操作 |
| 越界检测 | 无自动检测，需手动控制                      | 部分编译器支持越界检测（如Dev C++）           |
2. string类常用函数（GESP三级必备）：
   - 长度：str.length()、str.size()（功能等价）；
   - 拼接：str.append(s)、str += s；
   - 替换：str.replace(pos, len, s)（从pos开始，替换len个字符为s）；
   - 查找：str.find(s)（返回s首次出现的位置，未找到返回string::npos）；
   - 截取：str.substr(pos, len)（从pos开始截取len个字符，len省略则截取到末尾）；
3. 字符串分割方法（按分隔符split）：
   - 字符数组实现：遍历数组，遇到分隔符则记录子串起始位置，截取子串后重置起始位置；
   - string实现：用find找到分隔符位置，substr截取子串，循环直到find返回string::npos；
4. 字符类型转换：
   - 字符转数值：int num = c - '0'（适用于数字字符'0'~'9'）；
   - 数值转字符：char c = num + '0'（适用于数值0~9）；
   - 大写转小写：c = c + 32（'A'~'Z'）；
   - 小写转大写：c = c - 32（'a'~'z'）；
5. 字符串合规检测通用逻辑：
   - 第一步：判断长度是否在指定范围；
   - 第二步：遍历每个字符，判断是否属于合法字符集；
   - 第三步：按规则统计字符类型（如大写、小写、数字、特殊字符）；
   - 第四步：验证组合规则（如至少两种字符类型+特殊字符）。
