# GESP三级C++2024年6月考试逐题考点分析
## 一、单选题（共15题）
### 第1题
1. **考察的知识点**：GESP认证基础规则（语言选择）
2. **知识点详解**：GESP一级支持的认证语言为C++、Python两种，这是GESP认证的基础规则，考生需了解不同级别对应的可选语言范围。
3. **易错点**：误记为支持3种或4种语言，混淆GESP不同级别或其他编程认证的语言选项。
4. **相关的知识点**：GESP各等级认证的核心要求、不同级别对应的知识范围界定。

### 第2题
1. **考察的知识点**：算法与描述（流程图描述）、闰年判断逻辑
2. **知识点详解**：闰年的判定规则为“能被400整除，或能被4整除但不能被100整除”，流程图中菱形框需填入该逻辑的布尔表达式。流程图是算法的图形化描述，菱形框用于表示判断条件。
3. **易错点**：
   - 遗漏“能被4整除但不能被100整除”中的“不能被100整除”条件，误选A选项；
   - 混淆逻辑运算符“&&”和“||”的使用，导致条件逻辑错误。
4. **相关的知识点**：
   - 算法与描述：自然语言、流程图、伪代码的逻辑表达；
   - 条件判断语句（if-else）的逻辑实现。

### 第3题
1. **考察的知识点**：数据编码（整型变量的表示范围）
2. **知识点详解**：32位int型变量采用补码编码，最高位为符号位，取值范围为$-2^{31} \sim 2^{31}-1$（共$2^{32}$个不同值）。64位系统中int默认仍为32位，long long为64位（范围$-2^{63} \sim 2^{63}-1$）。
3. **易错点**：混淆32位int和64位long long的表示范围，误选D选项。
4. **相关的知识点**：
   - 数据编码：原码、反码、补码的编码规则；
   - 不同整型类型（short、int、long long）的位数与表示范围。

### 第4题
1. **考察的知识点**：进制转换（十进制转八进制）、数据结构（一维数组）
2. **知识点详解**：十进制转八进制的核心算法是“除8取余，逆序输出”。需通过数组存储每次取余的结果，数组索引需自增（i++），同时原数需整除8更新。
3. **易错点**：
   - 忘记数组索引自增（i++），导致后续逆序输出时数据覆盖或索引错误；
   - 混淆“取余（%）”和“整除（/）”的用法，误将取余和整除的逻辑颠倒。
4. **相关的知识点**：
   - 进制转换：二进制、八进制、十进制、十六进制的互转算法；
   - 数据结构：一维数组的存储与遍历操作；
   - 循环语句（while）的逻辑控制。

### 第5题
1. **考察的知识点**：进制转换（二进制转十进制）
2. **知识点详解**：二进制数的整数部分从右往左权重为$2^0,2^1,2^2,...$，小数部分从左往右权重为$2^{-1},2^{-2},...$。计算方式为“每一位数字×对应权重，求和”：$1×2^2 + 0×2^1 + 1×2^0 + 1×2^{-1} + 1×2^{-2} = 5.75$。
3. **易错点**：
   - 小数部分的权重计算错误（如将$2^{-1}$误算为2）；
   - 遗漏某一位数字的权重累加，导致结果偏差。
4. **相关的知识点**：
   - 进制转换：其他进制（八进制、十六进制）转十进制的权重计算法；
   - 小数的进制转换规则。

### 第6题
1. **考察的知识点**：算法与描述（流程图描述）、双重循环逻辑
2. **知识点详解**：流程图中包含双重循环，外层循环i从0到4（i<5），内层循环j从0到i-1（j<i），每次内层循环满足条件时sum加1。sum的最终值为内层循环执行次数之和：0+1+2+3+4=10。
3. **易错点**：
   - 误解双重循环的执行次数，误算sum的累加结果；
   - 混淆外层循环和内层循环的终止条件，导致循环次数统计错误。
4. **相关的知识点**：
   - 算法与描述：流程图中循环结构的表示；
   - 双重循环的嵌套逻辑与执行次数计算。

### 第7题
1. **考察的知识点**：位运算（右移>>）
2. **知识点详解**：右移运算（>>）表示将二进制数向右移动指定位数，高位补符号位（正数补0，负数补1），等价于“整除$2^k$”（k为移动位数）。12的二进制为1100，右移2位后为11（二进制），即十进制3。
3. **易错点**：将右移运算等同于“减法运算”或“整除运算的近似值”，误选B选项（12/2=6）。
4. **相关的知识点**：
   - 位运算：左移（<<）、与（&）、或（|）、异或（^）的运算规则；
   - 位运算与算术运算的对应关系（如左移<<等价于乘$2^k$）。

### 第8题
1. **考察的知识点**：位运算（异或^）、变量交换逻辑
2. **知识点详解**：异或运算的性质：$a^a=0$、$a^0=a$、$a^b=b^a$。通过三次异或可实现无临时变量的交换：
   - 第一步：b = a^b（b存储a和b的异或结果）；
   - 第二步：a = a^b（a = a^(a^b) = b，此时a为原b的值）；
   - 第三步：b = a^b（b = b^(a^b) = a，此时b为原a的值）。
3. **易错点**：不熟悉异或交换的逻辑，误判交换结果；混淆异或与其他位运算的性质。
4. **相关的知识点**：
   - 位运算：异或的交换律、结合律及特殊值运算；
   - 变量交换的三种方法（临时变量法、算术交换法、异或交换法）。

### 第9题
1. **考察的知识点**：字符串及其函数（字符串的存储结构）
2. **知识点详解**：C++中字符串常量“GESP”存储时，末尾会自动添加'\0'作为字符串结束标志。字符数组str的长度为实际字符数（4个）加结束标志（1个），共5个。
3. **易错点**：忽略字符串结束标志'\0'，误选B选项（仅统计可见字符数）。
4. **相关的知识点**：
   - 字符串及其函数：字符串的存储方式、strlen()函数的作用（统计'\0'前的字符数）；
   - 字符常量与字符串常量的区别（如'a'与"a"的存储差异）。

### 第10题
1. **考察的知识点**：数据结构（一维数组）、枚举法（找最大值）
2. **知识点详解**：找数组最大值的枚举算法逻辑为“初始化max为数组首个元素（或0，需确保数组元素为正），遍历数组时若当前元素大于max，则更新max”。题目中数组元素均为正，需填入“max < array[i]”作为判断条件。
3. **易错点**：
   - 混淆大小比较方向，误选A选项（max > array[i]）；
   - 误将赋值语句“max = array[i]”作为判断条件，导致逻辑错误。
4. **相关的知识点**：
   - 算法与描述：枚举法的应用（找最大/最小值、查找特定元素）；
   - 一维数组的遍历（for循环遍历索引）。

### 第11题
1. **考察的知识点**：数据结构（一维数组）、枚举法（筛选特定元素）
2. **知识点详解**：题目要求筛选1-35中能被7整除的数存入数组，需通过count变量记录有效元素个数，将符合条件的i存入arr[count]，同时count自增（count++）。
3. **易错点**：
   - 数组索引错误（如使用i作为数组索引，而非count）；

4. **相关的知识点**：
   - 一维数组的元素赋值与访问；
   - 枚举法结合条件判断筛选数据的逻辑。

### 第12题
1. **考察的知识点**：字符串及其函数（字符串长度、字符ASCII编码）
2. **知识点详解**：字符串中每个字符存储的是其ASCII编码值，'0'的ASCII值为48，因此“0629”中各字符的ASCII值分别为48、54、50、57，求和为48+54+50+57=209。
3. **易错点**：误将字符本身的数值（0、6、2、9）求和，而非ASCII编码值，误选A选项。
4. **相关的知识点**：
   - 数据编码：ASCII编码的基本规则（数字、字母的编码范围）；

### 第13题
1. **考察的知识点**：数据结构（一维数组）、枚举法（统计符合条件的元素）
2. **知识点详解**：需统计数组中大于135的元素个数，通过三元运算符“arr[i]>135?1:0”判断单个元素是否符合条件，再通过count累加（count += ）统计总数。
3. **易错点**：

### 第14题

### 第15题
1. **考察的知识点**：字符串及其函数（字符串分割、substr()函数）
2. **知识点详解**：字符串分割需通过find()函数查找分隔符“.”的位置，再通过substr()函数截取分隔符前的子串，之后需更新原字符串为分隔符后的部分（从found+1位置开始，截取剩余长度）。substr(pos, len)函数中，pos为起始位置，len为截取长度，若省略len则截取到字符串末尾。
3. **易错点**：
   - substr()函数的起始位置错误，未跳过分隔符（如从found位置开始截取，而非found+1）；
   - 截取长度计算错误，导致剩余字符串包含分隔符。
4. **相关的知识点**：
   - 字符串及其函数：string类的find()、substr()函数用法；
   - 字符串分割的常用算法（基于分隔符的循环分割）。

## 二、判断题（共10题）
### 第1题
1. **考察的知识点**：GESP认证基础规则（等级与编程语言的关系）
2. **知识点详解**：GESP同一级别认证的核心是编程能力（逻辑思维、算法实现、数据结构应用等），与具体编程语言无关，考生可选择擅长的语言（如C++、Python）参加考试。
3. **易错点**：误认为同一级别能力与编程语言强相关，导致判断错误。
4. **相关的知识点**：GESP认证的评价标准、不同编程语言在认证中的等价性。

### 第2题
1. **考察的知识点**：数据编码（补码、十进制转十六进制）
2. **知识点详解**：-6的16位原码为1000 0000 0000 0110，反码为1111 1111 1111 1001，补码为反码加1（1111 1111 1111 1010），十六进制表示为FFFA（4位二进制对应1位十六进制）。
3. **易错点**：混淆原码、反码、补码的转换规则，或十进制负数转十六进制的步骤错误。
4. **相关的知识点**：
   - 数据编码：原码、反码、补码的转换；
   - 进制转换：二进制转十六进制（4位分组）。

### 第3题
1. **考察的知识点**：数据编码（补码的优点）
2. **知识点详解**：补码的核心优点是将减法运算转化为加法运算（a - b = a + (-b)的补码），无需单独设计减法电路，简化了计算机硬件设计。
3. **易错点**：不了解补码的运算优势，误判其功能。
4. **相关的知识点**：补码的运算规则（加法运算、溢出判断）。

### 第4题
1. **考察的知识点**：字符串及其函数（字符串结束标志、字符常量）
2. **知识点详解**：'\0'是字符串结束标志，ASCII值为0；'0'是数字字符，ASCII值为48，二者本质不同（字符类型相同，但数值和含义不同）。
3. **易错点**：混淆二者的ASCII值或功能，误认为是相同的字符常量。
4. **相关的知识点**：ASCII编码表中控制字符与可打印字符的区别。

### 第5题
1. **考察的知识点**：数据结构（一维数组的内存存储）
2. **知识点详解**：数组的所有元素在内存中是连续存放的，元素地址按索引递增（如int arr[3]的地址为&arr[0]、&arr[0]+4、&arr[0]+8，因int占4字节）。
3. **易错点**：误认为数组元素可分散存储，忽略数组的内存连续性特征。
4. **相关的知识点**：一维数组的内存布局、数组元素的地址计算。

### 第6题
1. **考察的知识点**：数据结构（一维数组的赋值）
2. **知识点详解**：C++中可对数组整体初始化（如int arr[3] = {1,2,3}），也可对单个元素单独赋值（如arr[0] = 5）。
3. **易错点**：误认为数组只能整体赋值，不能单独修改元素，导致判断错误。
4. **相关的知识点**：一维数组的初始化方式（完全初始化、部分初始化、默认初始化）。

### 第7题
1. **考察的知识点**：位运算（或运算|）
2. **知识点详解**：或运算（|）的规则是“有1则1”，3的二进制为0011。若(a | 3) == 3，说明a的二进制低2位只能是00、01、10、11（即a的低2位与3或运算后仍为3），因此a的取值范围是0-3（低2位决定，高位不影响或运算结果）。
3. **易错点**：不理解或运算对低位的影响，误判a的取值范围。
4. **相关的知识点**：位运算的按位操作特性、不同位运算对二进制位的影响。

### 第8题
1. **考察的知识点**：进制转换（八进制、二进制）、位运算（与运算&）
2. **知识点详解**：C++中以0开头的数字为八进制，01100（八进制）转换为十进制为$1×8^3 + 1×8^2 + 0×8^1 + 0×8^0 = 576$，二进制为1001000000；以0b开头的数字为二进制，0b1010（二进制）转换为十进制为10。二者与运算（按位取1需双方为1）的结果为0，而非8。
3. **易错点**：
   - 误将八进制01100当作十进制1100计算；
   - 混淆与运算的规则，误算结果。
4. **相关的知识点**：
   - 进制转换：八进制、二进制与十进制的互转；
   - 位运算：与运算的按位计算规则。

### 第9题
1. **考察的知识点**：算法与描述（枚举法、随机数）、数据结构（一维数组）
2. **知识点详解**：代码中rand()%10生成0-9的随机数，s[i]的取值需满足“a%3 == (i+1)%3”（i从1到5），因此s[i]的可能值为0-9中符合上述模3条件的数。最终输出的是5个0-9的数字拼接结果，而89781是五位数且每位均为0-9，但代码中循环逻辑存在错误（cout语句位置错误，可能输出未初始化的元素），且随机数生成的是0-9的数，拼接后最大为99999，但代码逻辑导致输出结果不可能是89781（如i=1时，(i+1)%3=2，a需满足a%3=2，可能值为2、5、8等，但若后续位不满足则无法形成该数）。
3. **易错点**：未分析代码逻辑错误（如cout位置、数组初始化），或误判随机数的取值范围与模3条件的限制。
4. **相关的知识点**：
   - 随机数生成（srand()、rand()函数的用法）；
   - 枚举法结合条件判断筛选数据；
   - 数组元素的初始化与访问规则。

### 第10题
1. **考察的知识点**：算法与描述（枚举法）
2. **知识点详解**：“雷劈数”的定义是四位数剪开为前后两部分（各两位），两部分之和的平方等于原数。枚举法是遍历所有四位数（1000-9999），对每个数按规则剪开、计算、判断是否符合条件，因此枚举法可求解该问题。
3. **易错点**：认为枚举法效率低，误判其不可行，忽略四位数的范围（仅8999个，枚举效率足够）。
4. **相关的知识点**：
   - 枚举法的适用场景（范围小、逻辑简单的问题）；
   - 数字的拆分与拼接算法（如四位数abcd拆分为ab和cd：ab = x/100，cd = x%100）。

## 三、编程题（共2题）
### 第1题（移位）
1. **考察的知识点**：算法与描述（模拟法）、字符串及其函数、进制转换（字符与数值的映射）
2. **知识点详解**：
   - 模拟法：按题目要求模拟字母移位过程，将大写字母表视为环形（Z移位后为A）；
   - 字符与数值映射：'A'-'Z'的ASCII值连续（65-90），通过“(字符索引 + 偏移量) % 26”计算移位后的索引，再转换为字符。
3. **易错点**：
   - 偏移量超过26时未取模（如n=30，等价于n=4），导致索引超出范围；
   - 字符与数值的映射错误（如误将'A'的ASCII值记为97，混淆大小写）。
4. **相关的知识点**：
   - 字符串的遍历与字符修改；
   - 模运算在环形问题中的应用；
   - 字符ASCII值的运算（如ch = 'A' + j）。

### 第2题（寻找倍数）
1. **考察的知识点**：算法与描述（枚举法）、数据结构（一维数组）
2. **知识点详解**：
   - 核心逻辑：若存在某元素是所有元素的倍数，则该元素必为数组中的最大值（因为倍数不小于原数）；
   - 枚举法：先遍历数组找到最大值，再遍历数组判断最大值是否能整除所有元素，输出对应结果。
3. **易错点**：
   - 未意识到“最大值是唯一可能的候选者”，遍历所有元素判断是否为其他元素的倍数，导致时间复杂度超标（n=1e5时O(n²)超时）；
   - 忽略数组中存在1的情况（1是所有正整数的倍数）；
   - 数据范围处理错误（a_i可达1e9，但整除运算无溢出问题）。
4. **相关的知识点**：
   - 枚举法的优化策略（缩小候选范围）；
   - 一维数组的遍历与最值查找；
   - 整除运算的判断（a%b == 0表示a能被b整除）。
