
## 题目

描述

小杨共有N个储蓄罐，编号从0到N-1。从第 1 天开始，小杨每天都会往存钱罐里存钱。具体来说，第i天他会挑选一个存钱罐ai，并存入i元钱。过了D天后，他已经忘记每个储蓄罐里都存了多少钱了，你能帮帮他吗？

输入

输入 2 行，第一行两个整数N,D；第二行D个整数，其中第i个整数为ai（保证0≤ai≤N-1 ）。

每行的各个整数之间用单个空格分隔。

保证 1≤N≤1000，1≤D≤1000；

输出

输出 个用单个空格隔开的整数，其中第 个整数表示编号为i-1的存钱罐中有多少钱（i=1,...,N）。

输入样例 1 

2 3
0 1 0

输出样例 1

4 2

样例解释 1

小杨在第1天、第2天、第3天分别向0号、1号、0号存钱罐存了1元钱、2元钱、3元钱，因此0号存钱罐有1+3=4元钱，而1号存钱罐有2元钱。

样例输入2

3 5
0 0 0 2 0

样例输出2

11 0 4

## 分析

从GESP C++三级考生的视角，这道题的解题思路、步骤和注意事项可以这样分析：


### 一、解题思路
这道题的核心是**统计每个储蓄罐的总存款**，本质是“按编号累加数值”的简单模拟题，思路很直接：
1. 用一个数组存每个储蓄罐的金额（初始为0）；
2. 遍历每一天的存款操作：第`i`天往`a_i`号储蓄罐加`i`元；
3. 最后按顺序输出所有储蓄罐的总金额。


### 二、具体解题步骤（C++代码角度）
#### 步骤1：准备存储数组
因为储蓄罐编号是`0~N-1`，且`N≤1000`，所以定义一个足够大的数组（比如`int jar[1005]`），**初始化为0**（避免随机垃圾值影响结果）。

#### 步骤2：读取输入并处理存款
- 先读第一行的`N`（储蓄罐数量）和`D`（天数）；
- 再读第二行的`D`个数字（每天选择的储蓄罐编号），同时完成累加：
  第`i`天（从1开始），往当前读入的`a_i`号储蓄罐中加入`i`元。


#### 步骤3：输出结果
按`0~N-1`的顺序输出数组中的每个元素，用空格分隔（注意不要有多余空格）。


### 三、代码示例（考生可直接参考）
```cpp
#include <iostream>
using namespace std;

int main() {
    int jar[1005] = {0};  // 初始化所有储蓄罐金额为0，大小足够容纳最大N=1000
    int N, D;
    cin >> N >> D;  // 读储蓄罐数量和天数
    
    for (int i = 1; i <= D; ++i) {  // i是第i天，存i元
        int a;
        cin >> a;  // 读第i天选择的储蓄罐编号
        jar[a] += i;  // 往该储蓄罐加i元
    }
    
    // 输出结果：按0~N-1顺序，空格分隔
    for (int i = 0; i < N; ++i) {
        if (i > 0) {  // 第一个元素前不加空格，后面的元素先加空格
            cout << " ";
        }
        cout << jar[i];
    }
    return 0;
}
```


### 四、注意事项（考生易踩坑点）
1. **数组初始化**：
   局部数组默认是随机值，必须显式初始化为0（比如`int jar[1005] = {0};`）；如果用全局数组，会自动初始化为0。

2. **天数与存款的对应**：
   第`i`天要存`i`元，所以循环必须从`1`到`D`（不能从`0`开始，否则会存`0、1、2...`，导致金额错误）。

3. **输入输出格式**：
   - 不要加任何提示信息（比如“请输入N和D”），直接用`cin/cout`读写；
   - 输出时要严格按`0~N-1`的顺序，且用空格分隔，避免多余空格（可通过“先输出第一个元素，后续元素先输空格再输内容”实现）。

4. **数组大小**：
   数组大小要≥1000（因为`N≤1000`），避免编号越界（比如`jar[1005]`足够安全）。





## 样例代码


``` cpp
#include <iostream>
using namespace std;

int main() {
    int jar[1000];
	int n = 0; 
	int d = 0;
	cin >> n >> d;

    for (int i = 0; i < n; i++) {
        jar[i] = 0;
	}

    for (int i = 1; i <= d; i++) {
        int a = 0;
        cin >> a;
        jar[a] += i;
    }

    cout << jar[0];
    for (int i = 1; i < n; i++) {
        cout << " " << jar[i];
    }
    cout << endl;
	return 0;
}
```
