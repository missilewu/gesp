
## 题目

描述

进制数指的是逢N进一的计数制。例如，人们日常生活中大多使用十进制计数，而计算机底层则一般使用二进制。除此之外，八进制和十六进制在一些场合也是常用的计数制（十六进制中，一般使用字母 A 至 F 表示十至十五）。

现在有N个数，请你分别判断他们是否可能是二进制、八进制、十进制、十六进制。例如， 15A6F 就只可能是十六进制，而 1011 则是四种进制皆有可能。


输入

输入的第一行为一个十进制表示的整数N。接下来N行，每行一个字符串，表示需要判断的数。保证所有字符串均由数字和大写字母组成，且不以 0 开头。保证不会出现空行。

保证1≤N≤1000，保证所有字符串长度不超过10。


输出

输出N行，每行4个数，用空格隔开，分别表示给定的字符串是否可能表示一个二进制数、八进制数、十进制数、十六进制数。使用 1 表示可能，使用 0 表示不可能。

例如，对于只可能是十六进制数的 15A6F ，就需要输出 0 0 0 1 ；而对于四者皆有可能的 1011 ，则需要输出 1 1 1 1 。


输入样例 1 

2
15A6F
1011
输出样例 1

0 0 0 1
1 1 1 1


## 分析

作为考生，我会从**题目分析、解题思路、代码实现、注意事项**这几个角度来拆解这道题：


### 一、题目分析
这道题的核心是**判断一个字符串能否作为二进制、八进制、十进制、十六进制的合法数**，需要明确每种进制的合法字符范围：
- 二进制：只能包含 `0、1`
- 八进制：只能包含 `0~7`
- 十进制：只能包含 `0~9`
- 十六进制：可以包含 `0~9、A~F`（题目中是大写字母）


### 二、解题思路
对每个输入的字符串，依次检查它是否符合四种进制的规则，最终输出4个0/1的结果。

具体步骤：
1. 读入数字个数 `N`，然后循环读入 `N` 个字符串。
2. 对每个字符串，分别判断：
   - **二进制合法性**：所有字符是否只有 `0` 或 `1`。
   - **八进制合法性**：所有字符是否在 `0~7` 范围内（即字符对应的数值 ≤7）。
   - **十进制合法性**：所有字符是否在 `0~9` 范围内。
   - **十六进制合法性**：所有字符是否在 `0~9` 或 `A~F` 范围内。
3. 把每个判断的结果（1表示合法，0表示不合法）按“二进制、八进制、十进制、十六进制”的顺序输出，用空格分隔。


### 三、代码实现（C++）
可以用**字符遍历+条件判断**的方式实现，代码结构如下：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int N;
    cin >> N;
    while (N--) {
        string s;
        cin >> s;
        // 初始化四个进制的结果为1（默认合法，后续检查不合法则置0）
        int bin = 1, oct = 1, dec = 1, hex = 1;
        for (char c : s) { // 遍历每个字符
            // 检查二进制：只能是0或1
            if (c != '0' && c != '1') {
                bin = 0;
            }
            // 检查八进制：只能是0-7
            if (c > '7') {
                oct = 0;
            }
            // 检查十进制：只能是0-9
            if (c < '0' || c > '9') {
                dec = 0;
            }
            // 检查十六进制：0-9或A-F
            if (!((c >= '0' && c <= '9') || (c >= 'A' && c <= 'F'))) {
                hex = 0;
            }
        }
        // 按顺序输出结果
        cout << bin << " " << oct << " " << dec << " " << hex << endl;
    }
    return 0;
}
```


### 四、注意事项
1. **字符的范围判断**：
   - 字符是按ASCII码存储的，所以可以直接用 `c > '7'` 这类比较（比如 `'8'` 的ASCII码比 `'7'` 大）。
   - 十六进制要同时覆盖“数字”和“A-F”两种情况，注意逻辑运算符的优先级（用括号明确范围）。

2. **初始化的技巧**：
   - 先把四个结果初始化为 `1`（默认合法），遍历字符时只要发现不合法的情况，就把对应进制的结果置为 `0`（这样不需要“全合法才置1”，更高效）。

3. **输入的处理**：
   - 题目中说字符串“不以0开头”，但这对进制判断无影响（比如“01”在题目中不会出现，不用额外处理）。
   - 字符串长度不超过10，但C++的`string`可以直接处理，无需担心长度问题。

4. **输出格式**：
   - 每个结果之间用**空格**分隔，每行输出4个数字（比如样例中的“0 0 0 1”）。


这样写代码既简洁又能覆盖所有情况，符合GESP三级的考点（字符串遍历、条件判断、多分支逻辑）。

## 普通代码


``` cpp
#include <iostream>
using namespace std;

int main() {
    // 定义足够大的char数组（题目说明字符串长度≤10，定义20留余量）
    char s[20];
    int N;
    cin >> N;
    
    // 循环处理N个输入字符串
    while (N--) {
        // 读入字符串到char数组（cin会自动在末尾加'\0'结束符）
        cin >> s;
        
        // 初始化四个进制的结果：1表示合法，0表示不合法
        int bin = 1, oct = 1, dec = 1, hex = 1;
        
        // 遍历char数组，直到遇到字符串结束符'\0'
        for (int i = 0; s[i] != '\0'; i++) {
            char c = s[i]; // 取出当前字符
            
            // 1. 判断二进制：仅允许'0'或'1'
            if (c != '0' && c != '1') {
                bin = 0;
            }
            
            // 2. 判断八进制：仅允许'0'~'7'
            if (c > '7') {
                oct = 0;
            }
            
            // 3. 判断十进制：仅允许'0'~'9'
            if (c < '0' || c > '9') {
                dec = 0;
            }
            
            // 4. 判断十六进制：允许'0'~'9'或'A'~'F'
            if (!((c >= '0' && c <= '9') || (c >= 'A' && c <= 'F'))) {
                hex = 0;
            }
        }
        
        // 按要求输出结果（二进制 八进制 十进制 十六进制）
        cout << bin << " " << oct << " " << dec << " " << hex << endl;
    }
    
    return 0;
}
```
