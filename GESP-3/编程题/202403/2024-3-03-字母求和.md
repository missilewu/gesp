
## 题目

小杨同学发明了一种新型密码，对于每一个小写英文字母，该小写字母代表了一个正整数，即该字母在字母顺序中的位置,例如字母a代表了正整数1，字母b代表了正整数2；对于每一个大写英文字母，该大写字母代表了一个负整数，即该字母的ASCII码的相反数,例如字母A代表了正整数-65。小杨同学利用这种方式对一个整数进行了加密，并得到了一个由大写字母和小写字母组成的字符串，该字符串中每个字母所代表数字的总和即为加密前的整数,例如`aAc`对应的加密前的整数为`1+(-65)+3=-61`。

对于给定的字符串,请你计算出它对应的加密前的整数是多少,。

### 输入格式
第一行一个正整数n，表示字符串中字母的个数。
第二行一个由大写字母和小写字母的字符串T，代表加密后得到到的字符串。

### 输出格式
输出一行一个整数，代表加密前的整数。

### 样例1

```
3
aAc
```

```
-61
```



## 一、题目分析
### 1. 题目核心要求
给定一个由大小写英文字母组成的字符串，每个字符对应特定数值：
- 小写字母：对应其字母顺序的正整数（如`a`=1，`b`=2，…，`z`=26）；
- 大写字母：对应其ASCII码的相反数（如`A`=-65，`B`=-66，…，`Z`=-90）。
需要计算字符串中所有字符对应数值的总和，输出该总和。

### 2. 输入输出规则
- 输入：第一行是正整数`n`（字符串长度），第二行是仅含大小写字母的字符串`T`；
- 输出：一行整数，表示所有字符对应数值的总和。

### 3. 样例验证
样例输入`3`和`aAc`：
- `a`→1，`A`→-65，`c`→3；
- 总和：1 + (-65) + 3 = -61，与样例输出一致，验证理解无误。

## 二、解题思路
1. **初始化总和变量**：定义整型变量`sum`，初始值为0，用于存储所有字符的数值总和；
2. **读取输入**：先读取字符串长度`n`，再读取目标字符串`T`；
3. **遍历字符串计算**：逐个遍历字符串中的每个字符，根据字符大小写计算对应数值并累加到`sum`：
   - 小写字母：数值 = 字符 - 'a' + 1（如`c` - 'a' + 1 = 3）；
   - 大写字母：数值 = - (int)字符（如`A`的ASCII码是65，数值为-65）；
4. **输出结果**：遍历完成后，输出`sum`的值。

## 三、涉及的知识点
1. **字符与ASCII码的转换**：字符本质是ASCII码值，可直接与整数运算（如`'a'`的ASCII码是97，`'A'`是65）；
2. **C++输入输出**：`cin`读取整数/字符串，`cout`输出整数；
3. **字符串遍历**：可使用基于范围的`for`循环（简洁）或索引`for`循环；
4. **条件判断**：区分字符的大小写（通过ASCII码范围或`isupper()`/`islower()`函数）；
5. **变量定义与累加运算**：整型变量存储总和，通过`+=`完成累加。

## 四、重难点分析
### 1. 重点
- 小写字母的数值转换公式：**必须加1**（`c - 'a' + 1`），若遗漏`+1`会导致`a`对应0（不符合“正整数”要求）；
- 大写字母的数值转换：正确取ASCII码的相反数（`- (int)c`），注意负号的位置。

### 2. 难点
- 字符类型与整型的隐式转换：`char`类型在运算时会自动转为ASCII码对应的整数，需理解这一特性避免计算错误；
- 输入的稳定性：确保读取`n`后正确读取字符串（`cin`读取字符串会自动跳过空格，符合题目输入规则）。

## 五、注意事项
1. **头文件包含**：必须包含`<iostream>`（输入输出）和`<string>`（字符串类型）；若使用`isupper()`/`islower()`需额外包含`<cctype>`；
2. **变量类型**：`sum`用`int`即可（GESP三级数据规模小，`int`范围足够）；
3. **输入合法性**：题目保证输入的字符串长度为`n`且仅含大小写字母，无需额外校验；
4. **循环边界**：索引循环需注意`i`从0到`n-1`，避免越界；基于范围的循环更简洁，无需关注索引。

## 六、完整代码实现
```cpp
#include <iostream>
#include <string>  // 必须包含，否则无法使用string类型
using namespace std;  // 简化cin/cout的使用

int main() {
    // 步骤1：读取输入的字符串长度和字符串
    int n;
    cin >> n;
    string s;
    cin >> s;

    // 步骤2：初始化总和变量
    int sum = 0;

    // 步骤3：遍历每个字符，计算对应数值并累加
    for (char c : s) {  // 基于范围的for循环，遍历字符串中每个字符
        if (c >= 'a' && c <= 'z') {  // 判断是否为小写字母（无需<cctype>）
            sum += (c - 'a' + 1);    // 小写字母：字母顺序值
        } else if (c >= 'A' && c <= 'Z') {  // 判断是否为大写字母
            sum += - (int)c;                // 大写字母：ASCII码的相反数
        }
    }

    // 步骤4：输出最终总和
    cout << sum << endl;

    return 0;
}
```

## 七、代码测试（样例）
### 输入
```
3
aAc
```
### 执行过程
1. `n=3`，`s="aAc"`；
2. 遍历字符`'a'`：`'a'-'a'+1=1` → `sum=1`；
3. 遍历字符`'A'`：`-65` → `sum=1-65=-64`；
4. 遍历字符`'c'`：`'c'-'a'+1=3` → `sum=-64+3=-61`；
5. 输出`-61`，与样例一致。

## 总结
1. 核心公式：小写字母数值=`c-'a'+1`，大写字母数值=`-(int)c`，这是计算正确的关键；
2. 遍历方式：优先使用基于范围的`for`循环（`for (char c : s)`），代码更简洁且不易出错；
3. 头文件：必须包含`<iostream>`和`<string>`，避免因缺少头文件导致编译错误。




## 样例代码


``` cpp
#include <iostream>
#include <assert.h>
#include <cstdlib>
#include <cstdio>
#include <cstring>
using namespace std;
const int N = 100005;
char str[N];
int main() {
    int n;
    cin >> n;
    cin >> str;
    assert(n == strlen(str));
    int ans = 0;
    for (int i = 0; i < n; i ++) {
        if (str[i] >= 'a' && str[i] <= 'z')
            ans += str[i] - 'a' + 1;
        else if (str[i] >= 'A' && str[i] <= 'Z')
            ans -= str[i];
        else
            assert(false);
    }
    cout << ans << endl;
    return 0;
}

```
