在GESP（CCF编程能力等级认证）、NOI（全国青少年信息学奥林匹克竞赛）以及IOI（国际信息学奥林匹克竞赛）中，虽然C++ STL中的 `std::list` 可以直接使用，但在考察数据结构底层原理、内存管理或特定算法优化时，**手动实现链表**（尤其是C风格的结构体指针操作）是核心考点。

以下是标准的 **双向链表（Doubly Linked List）** 的C风格定义及核心操作代码。代码采用纯C风格（使用 `struct` 和原始指针），符合竞赛中对底层内存操作的要求。

### 1. 节点与链表定义

双链表的每个节点包含三个部分：数据域、指向前驱节点的指针、指向后继节点的指针。

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

// 定义节点结构体
typedef struct DNode {
    int data;               // 数据域
    struct DNode* prev;     // 前驱指针
    struct DNode* next;     // 后继指针
} DNode;

// 定义链表结构体（可选，也可以直接用头节点指针代表链表）
typedef struct DLinkedList {
    DNode* head;
    DNode* tail;
    int size;
} DLinkedList;

// 初始化链表
void initList(DLinkedList* list) {
    list->head = NULL;
    list->tail = NULL;
    list->size = 0;
}

// 创建新节点
DNode* createNode(int value) {
    DNode* newNode = (DNode*)malloc(sizeof(DNode));
    if (!newNode) {
        fprintf(stderr, "Memory allocation failed\n");
        exit(1);
    }
    newNode->data = value;
    newNode->prev = NULL;
    newNode->next = NULL;
    return newNode;
}
```

### 2. 遍历操作 (Traversal)

从头到尾打印链表内容。

```c
// 正向遍历
void traverseForward(DLinkedList* list) {
    DNode* curr = list->head;
    printf("List (Forward): ");
    while (curr != NULL) {
        printf("%d ", curr->data);
        curr = curr->next;
    }
    printf("\n");
}

// 反向遍历 (双链表特有优势)
void traverseBackward(DLinkedList* list) {
    DNode* curr = list->tail;
    printf("List (Backward): ");
    while (curr != NULL) {
        printf("%d ", curr->data);
        curr = curr->prev;
    }
    printf("\n");
}
```

### 3. 搜索操作 (Search)

查找特定值的节点，返回节点指针，若未找到返回 `NULL`。

```c
DNode* search(DLinkedList* list, int value) {
    DNode* curr = list->head;
    while (curr != NULL) {
        if (curr->data == value) {
            return curr;
        }
        curr = curr->next;
    }
    return NULL; // 未找到
}
```

### 4. 插入操作 (Insertion)

这是竞赛中最常考的细节，需要处理头插、尾插和中间插入，并正确维护 `prev` 和 `next` 指针。

#### A. 头部插入

```c
void insertAtHead(DLinkedList* list, int value) {
    DNode* newNode = createNode(value);
    
    if (list->head == NULL) {
        // 空链表
        list->head = newNode;
        list->tail = newNode;
    } else {
        newNode->next = list->head;
        list->head->prev = newNode;
        list->head = newNode;
    }
    list->size++;
}
```

#### B. 尾部插入

```c
void insertAtTail(DLinkedList* list, int value) {
    DNode* newNode = createNode(value);
    
    if (list->tail == NULL) {
        // 空链表
        list->head = newNode;
        list->tail = newNode;
    } else {
        newNode->prev = list->tail;
        list->tail->next = newNode;
        list->tail = newNode;
    }
    list->size++;
}
```

#### C. 在指定节点后插入 (通用插入)

_注意：在竞赛中，通常是在找到某个节点 `pos` 后，在其后面插入新节点。_

```c
// 在节点 pos 之后插入 value
// 如果 pos 为 NULL，则视为无效操作或可根据需求改为头插
void insertAfter(DLinkedList* list, DNode* pos, int value) {
    if (pos == NULL) return; 
    
    DNode* newNode = createNode(value);
    
    newNode->next = pos->next;
    newNode->prev = pos;
    
    if (pos->next != NULL) {
        pos->next->prev = newNode;
    } else {
        // 如果插在最后一个节点后面，更新 tail
        list->tail = newNode;
    }
    
    pos->next = newNode;
    list->size++;
}
```

### 5. 删除操作 (Deletion)

删除节点时需要特别注意断开前后指针的连接，并释放内存。

#### A. 删除指定值的第一个匹配节点

```c
bool deleteNode(DLinkedList* list, int value) {
    DNode* curr = search(list, value);
    if (curr == NULL) return false; // 未找到
    
    // 调整前驱指针
    if (curr->prev != NULL) {
        curr->prev->next = curr->next;
    } else {
        // 删除的是头节点
        list->head = curr->next;
    }
    
    // 调整后继指针
    if (curr->next != NULL) {
        curr->next->prev = curr->prev;
    } else {
        // 删除的是尾节点
        list->tail = curr->prev;
    }
    
    free(curr);
    list->size--;
    return true;
}
```

#### B. 销毁整个链表

```c
void clearList(DLinkedList* list) {
    DNode* curr = list->head;
    while (curr != NULL) {
        DNode* next = curr->next;
        free(curr);
        curr = next;
    }
    list->head = NULL;
    list->tail = NULL;
    list->size = 0;
}
```

### 6. 链表反转 (Reverse)

双链表的反转可以通过交换每个节点的 `prev` 和 `next` 指针来实现，最后交换头尾指针。时间复杂度 $O(N)$，空间复杂度 $O(1)$。

```c
void reverseList(DLinkedList* list) {
    if (list->head == NULL) return;
    
    DNode* curr = list->head;
    DNode* temp = NULL;
    
    // 交换头尾指针记录
    temp = list->head;
    list->head = list->tail;
    list->tail = temp;
    
    // 遍历交换每个节点的指针
    while (curr != NULL) {
        // 交换 prev 和 next
        temp = curr->prev;
        curr->prev = curr->next;
        curr->next = temp;
        
        // 移动到下一个节点 (注意：因为指针交换了，next 变成了原来的 prev)
        curr = curr->prev; 
    }
}
```

### 7. 完整测试示例 (Main Function)

```c
int main() {
    DLinkedList myList;
    initList(&myList);
    
    // 测试插入
    insertAtTail(&myList, 10);
    insertAtTail(&myList, 20);
    insertAtHead(&myList, 5);
    // 当前: 5 <-> 10 <-> 20
    
    printf("Initial List:\n");
    traverseForward(&myList);
    
    // 测试搜索
    DNode* found = search(&myList, 10);
    if (found) {
        printf("Found 10, inserting 15 after it.\n");
        insertAfter(&myList, found, 15);
    }
    // 当前: 5 <-> 10 <-> 15 <-> 20
    
    traverseForward(&myList);
    
    // 测试删除
    printf("Deleting 5...\n");
    deleteNode(&myList, 5);
    traverseForward(&myList);
    
    // 测试反转
    printf("Reversing list...\n");
    reverseList(&myList);
    traverseForward(&myList);   // 应输出: 20 15 10
    traverseBackward(&myList);  // 应输出: 10 15 20
    
    // 清理内存
    clearList(&myList);
    
    return 0;
}
```

### 竞赛考点提示 (GESP/NOI/IOI)

1. **指针边界检查**：在插入和删除时，必须判断 `prev` 或 `next` 是否为 `NULL`（即是否操作了头节点或尾节点），否则会导致段错误（Segmentation Fault）。
2. **内存泄漏**：在C/C++竞赛中，虽然程序结束后操作系统会回收内存，但在长时间运行或多组测试数据的题目中，忘记 `free` 删除的节点可能导致内存超限（MLE）。
3. **哨兵节点（Dummy Head）**：在某些复杂操作中，为了简化对头节点的特殊判断，高级选手有时会创建一个不存数据的“哨兵节点”，让 `head->next` 指向第一个真实节点，这样可以统一插入删除逻辑。
4. **STL vs 手写**：
    - 如果是考察算法逻辑（如动态规划、图论），优先使用 `std::list` 以节省时间。
    - 如果是考察数据结构实现、内存池优化（避免频繁 `malloc/free`）或特定约束（如禁止使用STL），则必须掌握上述手写代码。  
### GESP五级 C风格实现的关键点总结

1. **指针传递**：
    
    - 在C风格中，如果要修改头指针 `head` 本身（例如在头部插入或删除头节点），通常有两种做法：
        - 方法A（本例采用）：使用**全局变量** `head` 和 `tail`。这在算法竞赛和GESP考试中非常常见，因为代码简洁，不需要传递双重指针。
        - 方法B：函数参数使用**二级指针**（`Node** headRef`）或**引用指针**（`Node*& headRef`）。如果在函数签名中必须体现参数传递，请使用 `void pushFront(Node*& head, Node*& tail, int val)`。
2. **空指针检查**：
    
    - 每次访问 `curr->next` 或 `curr->prev` 之前，务必确保 `curr` 不为 `nullptr`。
    - 在删除节点时，判断 `curr->prev` 是否为空（是否是头节点）以及 `curr->next` 是否为空（是否是尾节点）是必考逻辑。
3. **内存管理**：
    
    - C风格没有析构函数，必须手动编写 `clearList` 或在 `remove` 函数中 `delete` 节点。忘记 `delete` 会导致内存泄漏，虽然在短期运行的考试程序中可能不会崩溃，但在评分标准中属于逻辑缺陷。
4. **双向链接的维护**：
    
    - 单链表只需要维护 `next`，双链表必须同时维护 `prev` 和 `next`。在插入和删除时，如果漏掉任何一条线的连接（例如忘了让后继节点的 `prev` 指回新节点），链表就会断裂，导致遍历时丢失数据或死循环。

这种C风格的实现方式更加贴近底层，能够充分展示考生对指针运算和内存布局的理解，完全符合GESP五级的考核要求。
