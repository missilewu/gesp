## 一、什么是栈？（概念与原理）

### 1. 定义
栈（Stack）是一种**线性数据结构**，其核心特征是**后进先出**（Last In, First Out，简称 **LIFO**）。
想象一下你往一个羽毛球筒里放球：最后放进去的球，必须最先拿出来；最底下的球，要等到上面的球都拿走了才能取出。这就是栈。

### 2. 核心操作
栈只允许在**一端**进行插入和删除操作，这一端称为**栈顶（Top）**，另一端称为**栈底（Bottom）**。

| 操作名称 | 英文术语 | 描述 | 时间复杂度 |
| :--- | :--- | :--- | :--- |
| **入栈** | Push | 将元素放入栈顶 | $O(1)$ |
| **出栈** | Pop | 移除并返回栈顶元素 | $O(1)$ |
| **查看栈顶** | Top / Peek | 返回栈顶元素但不移除 | $O(1)$ |
| **判空** | Empty | 判断栈是否为空 | $O(1)$ |
| **大小** | Size | 返回栈中元素个数 | $O(1)$ |

### 3. 底层实现原理
在竞赛编程（C++）中，栈通常有两种实现方式：
1.  **数组模拟（推荐）**：使用一个数组 `st[]` 和一个指针 `top`。
    *   `top` 指向当前栈顶元素的下标。
    *   入栈：`st[++top] = x;`
    *   出栈：`top--;`
    *   **优势**：速度极快，无动态内存分配开销，不易出错，是NOI/IOI选手的首选。
2.  **STL `std::stack`**：C++标准库提供的容器。
    *   用法：`stack<int> s; s.push(x); s.pop();`
    *   **劣势**：底层通常基于 `deque` 或 `list`，常数较大，且在极端卡常数的题目中可能不如数组模拟快。

## 二、为什么需要栈？（应用场景）

栈的应用非常广泛，主要体现在**“需要回溯”**或**“处理嵌套结构”**的场景中。

### 1. 函数调用与递归系统（系统底层）
这是栈最本质的应用。当你编写递归函数时，编译器在底层就是利用**系统栈**来保存每一层函数的局部变量、参数和返回地址。
*   **场景**：深度优先搜索（DFS）、分治算法。
*   **注意**：如果递归层数过深（如 $10^5$ 层），会导致**栈溢出（Stack Overflow）**。在NOI/Linux环境下，有时需要手动扩栈或将其改写为**非递归（显式栈）**形式。

### 2. 括号匹配与表达式求值
*   **括号匹配**：检查 `( [ ] )` 是否合法。遇到左括号入栈，遇到右括号则检查栈顶是否匹配，匹配则出栈。
*   **表达式求值**：将中缀表达式（如 `3 + 4 * 5`）转换为后缀表达式（逆波兰表达式），或直接计算。这是编译原理的基础。
    *   *经典例题*：洛谷 P1981 [表达式求值]

### 3. 单调栈（Monotonic Stack）—— **竞赛高频考点**
这是栈在算法优化中的神级应用。维护一个栈内元素单调递增或递减的栈。
*   **典型问题**：**“寻找左边/右边第一个比当前元素大/小的数”**。
*   **复杂度优化**：将暴力 $O(N^2)$ 的算法优化为 $O(N)$。
*   **应用场景**：
    *   柱状图中最大的矩形（LeetCode 84 / 洛谷相关题目）。
    *   接雨水问题。
    *   视野范围问题（如：奶牛看风景，能看到几头牛）。

### 4. 撤销操作（Undo）
编辑器中的 `Ctrl+Z` 功能。每一步操作压入栈，撤销时弹出栈顶操作并执行反向操作。

### 5. 图的遍历（DFS的非递归实现）
当递归爆栈时，我们需要手动用一个 `stack` 来模拟递归过程，显式地管理访问状态。

## 三、代码实战（C++）

作为教练，我要求大家必须掌握**数组模拟栈**的写法，这是基本功。

### 1. 数组模拟栈模板

```cpp
#include <iostream>
using namespace std;

const int MAXN = 1000005; // 根据题目数据范围调整
int st[MAXN];             // 栈数组
int top_idx = 0;          // 栈顶指针，指向当前栈顶元素

// 入栈
void push(int x) {
    st[++top_idx] = x;
}

// 出栈
void pop() {
    if (top_idx > 0) top_idx--;
}

// 获取栈顶
int top() {
    return st[top_idx];
}

// 判空
bool empty() {
    return top_idx == 0;
}

int main() {
    // 示例：简单的入栈出栈
    push(10);
    push(20);
    push(30);
    
    cout << "栈顶元素: " << top() << endl; // 输出 30
    
    pop(); // 移除 30
    cout << "出栈后栈顶: " << top() << endl; // 输出 20
    
    return 0;
}
```

### 2. 经典案例：单调栈（寻找左边第一个比它小的数）

**题目描述**：给定一个序列 $A$，对于每个元素 $A_i$，找到它左边第一个比它小的元素的下标。如果没有，输出 0。
**数据范围**：$N \le 10^6$，必须 $O(N)$ 解决。

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int MAXN = 1000005;
int a[MAXN];      // 原数组
int st[MAXN];     // 单调栈，存储下标
int top_idx = 0;  // 栈顶指针
int ans[MAXN];    // 答案数组

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    for (int i = 1; i <= n; i++) {
        // 维护单调递增栈：如果栈顶元素对应的值 >= 当前值，则弹出
        // 因为我们要找“比它小”的，所以比它大的或者相等的都没用，且会被当前元素“遮挡”
        while (top_idx > 0 && a[st[top_idx]] >= a[i]) {
            top_idx--;
        }

        // 此时栈顶就是左边第一个比 a[i] 小的元素
        if (top_idx == 0) {
            ans[i] = 0; // 没找到
        } else {
            ans[i] = st[top_idx];
        }

        // 当前元素入栈
        st[++top_idx] = i;
    }

    for (int i = 1; i <= n; i++) {
        cout << ans[i] << " ";
    }
    cout << endl;

    return 0;
}
```

## 四、教练的备考建议（GESP/NOI/IOI）

1.  **GESP 考级**：
    *   重点考察栈的基本概念（LIFO）、基本操作以及简单的括号匹配、进制转换。
    *   可能会考察手写栈或使用 `std::stack` 解决简单模拟问题。

2.  **NOIP / CSP-J/S**：
    *   **必考**：表达式求值、括号匹配。
    *   **高频**：单调栈。一定要熟练掌握“寻找左右边界”的模型，这是解决许多 $O(N^2)$ 超时问题的钥匙。
    *   **陷阱**：注意栈空时不要执行 `top()` 或 `pop()`，否则会运行时错误（RE）。

3.  **NOI / IOI**：
    *   栈往往作为复杂算法的一部分出现，例如在**双连通分量（Tarjan算法）**、**后缀自动机构建**、**笛卡尔树构建**中，栈是核心组件。
    *   需要能够灵活地将递归转化为非递归栈模拟，以应对极限数据下的栈空间限制。

## 五、总结

*   **核心思想**：后进先出（LIFO）。
*   **关键技能**：数组模拟栈、单调栈模型。
*   **解题直觉**：看到“最近的一个”、“嵌套结构”、“回溯”、“取消操作”，第一时间想到栈。

# 经典题目

作为你的竞赛教练，我为你精选了一份**“栈专项训练清单”**。这些题目按照难度和考察侧重点分级，涵盖了从基础语法到高级算法优化的全过程。

在NOI/IOI体系中，做题不在于多，而在于**“模型识别”**。做完这些题，你应该能形成条件反射：看到什么特征，就立刻想到用栈来解决。

---

### 第一阶段：基础入门与模拟（GESP / CSP-J 级别）
**目标**：熟练掌握栈的`push/pop`操作，理解LIFO特性，学会处理括号和简单表达式。

#### 1. 括号匹配 (Bracket Matching)
*   **题目来源**：洛谷 P1739 / 信息学奥赛一本通 1354
*   **核心考点**：最经典的栈应用。
*   **解题思路**：
    *   遇到左括号 `(`, `[`, `{` $\rightarrow$ **入栈**。
    *   遇到右括号 $\rightarrow$ 检查栈是否为空？栈顶是否是对应的左括号？
        *   是 $\rightarrow$ **出栈**（匹配成功）。
        *   否 $\rightarrow$ 匹配失败。
    *   最后检查栈是否为空（防止有多余的左括号）。
*   **教练点评**：这是所有栈题目的基石。注意处理字符串结束后的栈状态，以及空栈取顶的边界情况。

#### 2. 表达式求值 (Expression Evaluation)
*   **题目来源**：洛谷 P1981 [NOIP 2013 普及组] 表达式求值
*   **核心考点**：双栈法（一个存数字，一个存运算符）或 中缀转后缀（逆波兰表达式）。
*   **解题思路**：
    *   利用运算符优先级（`*` `/` > `+` `-`）。
    *   当当前运算符优先级 $\le$ 栈顶运算符时，弹出栈顶运算符并计算，直到满足条件再入栈。
*   **教练点评**：这是编译原理的雏形。在CSP-J/S中常考，务必掌握“遇低优先级则计算”的逻辑。

#### 3. 进制转换
*   **题目来源**：洛谷 P1017 (部分涉及) / 各类基础题库
*   **核心考点**：利用栈实现“倒序输出”。
*   **解题思路**：不断 `n % base` 得到余数并入栈，最后依次出栈即为高位到低位的顺序。
*   **教练点评**：理解栈如何自然地将“递归/逆序”过程转化为“线性输出”。

---

### 第二阶段：单调栈专项（CSP-S / NOIP 核心考点）
**目标**：掌握 $O(N)$ 解决“寻找最近的大/小值”问题。这是区分普通选手和高手的关键。

#### 4. 单调栈模板：左边第一个比它小的数
*   **题目来源**：洛谷 P5788【模板】单调栈
*   **核心考点**：维护一个**单调递增**的栈。
*   **解题思路**：
    *   遍历数组，若当前元素 $x$ 小于等于栈顶元素，则栈顶元素不可能成为后续元素的“左边第一个小值”（被 $x$ 挡住了），直接弹出。
    *   弹出后，新的栈顶即为答案。
*   **教练点评**：**背诵此代码模板**。理解为什么每个元素最多进栈一次、出栈一次，从而证明复杂度是 $O(N)$。

#### 5. 柱状图中最大的矩形 (Largest Rectangle in Histogram)
*   **题目来源**：洛谷 P4147 / LeetCode 84
*   **核心考点**：单调栈求左右边界。
*   **解题思路**：
    *   对于每个高度 $h[i]$，我们需要找到它向左能延伸到的最远位置（左边第一个比它小的下标 $L$）和向右的最远位置（右边第一个比它小的下标 $R$）。
    *   面积 = $h[i] \times (R - L - 1)$。
    *   使用两次单调栈（或一次栈处理两端）求出 $L$ 和 $R$ 数组。
*   **教练点评**：这是单调栈最著名的几何应用。很多二维矩阵问题（如“最大全1子矩阵”）都可以转化为多次调用此题的一维解法。

#### 6. 接雨水 (Trapping Rain Water)
*   **题目来源**：洛谷 对应变种 / LeetCode 42
*   **核心考点**：单调递减栈。
*   **解题思路**：
    *   维护一个高度递减的栈。当遇到一个比栈顶高的柱子时，说明形成了一个“凹槽”。
    *   弹出栈顶作为底部，新的栈顶作为左边界，当前元素作为右边界，计算积水量。
*   **教练点评**：相比上一题，这题更侧重逻辑推导。理解“凹槽”形成的条件是栈应用的精髓。

### 第三阶段：高级应用与综合技巧（NOI / IOI 级别）
**目标**：将栈融入复杂算法，处理递归模拟、图论及特殊数据结构。

#### 7. 火车进站/出站次序 (Train Sorting)
*   **题目来源**：洛谷 P1044 [NOIP 2003 普及组] 栈 / AcWing 129
*   **核心考点**：栈的合法序列判定 / 卡特兰数背景。
*   **解题思路**：
    *   给定入栈顺序 $1, 2, ..., n$，判断某个出栈顺序是否合法。
    *   模拟过程：按顺序入栈，若栈顶等于目标出栈序列的当前值，则出栈。最后看栈是否为空。
*   **教练点评**：这道题常结合搜索或动态规划考察。理解栈操作对序列排列的限制。

#### 8. 后缀表达式构建与计算 (逆波兰)
*   **题目来源**：洛谷 P1449
*   **核心考点**：表达式树与栈的结合。
*   **解题思路**：
    *   中缀转后缀：利用栈处理优先级和括号。
    *   后缀计算：利用栈存储操作数，遇运算符弹两数计算后压回。
*   **教练点评**：在涉及自定义运算符优先级的复杂题目中，手动构建后缀表达式往往比直接解析中缀更稳健。

#### 9. 直方图/矩阵问题的变种（悬线法辅助）
*   **题目来源**：洛谷 P4147 (玉蟾宫)
*   **核心考点**：二维转一维 + 单调栈。
*   **解题思路**：
    *   预处理出每个点向上连续的‘F’（或1）的高度。
    *   对每一行，将其视为一个直方图，调用“柱状图最大矩形”的单调栈解法。
*   **教练点评**：这是NOIP/省选常见套路：**降维打击**。将二维问题拆解为多次一维单调栈问题。

#### 10. 递归转非递归 (DFS 模拟)
*   **题目来源**：任何深搜题的“爆栈”版本（如某些树的遍历、迷宫最深层数）
*   **核心考点**：手动管理栈帧。
*   **解题思路**：
    *   定义结构体 `struct Frame { int u, int next_edge_idx, ...; }`。
    *   用 `stack<Frame>` 模拟系统递归调用过程。
*   **教练点评**：在IOI级比赛中，当数据规模导致系统栈溢出（Segmentation Fault）时，这是唯一的救命稻草。
