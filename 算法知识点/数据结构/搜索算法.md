## 一、深度优先搜索 (Depth-First Search, DFS)

### 1. 核心思想
**“不撞南墙不回头”**。
DFS 的策略是沿着一条路径一直走到底，直到无法继续前进（遇到死胡同或已访问节点），然后**回溯**到上一个节点，尝试另一条未走过的路径。

*   **数据结构**：通常使用 **递归 (Recursion)** 实现（系统栈），或者显式使用 **栈 (Stack)**。
*   **适用场景**：
    *   寻找所有可行解（如：全排列、组合、迷宫的所有路径）。
    *   判断连通性（如：图中两点是否可达）。
    *   拓扑排序、强连通分量（Tarjan算法）。
    *   需要配合“剪枝”优化的问题。

### 2. 算法原理与模板
DFS 的本质是递归。我们需要维护一个 `visited` 数组来记录哪些节点已经访问过，防止死循环。

**通用伪代码模板：**
```cpp
bool visited[MAX_N]; // 记录访问状态

void dfs(int u) {
    visited[u] = true; // 标记当前节点已访问
    // 在这里处理当前节点的逻辑
    
    for (int v : adj[u]) { // 遍历 u 的所有邻接点
        if (!visited[v]) {
            dfs(v); // 递归深入
        }
    }
    // 回溯阶段（如果需要恢复状态，例如在求路径或数独中）
    // visited[u] = false; 
}
```

### 3. 竞赛中的关键点：回溯与剪枝
在 NOIP/NOI 级别的问题中，单纯的 DFS 往往会超时（TLE），因为解空间通常是指数级的 ($O(2^N)$ 或 $O(N!)$)。因此必须掌握：

*   **回溯 (Backtracking)**：在递归返回时，撤销之前的选择（如恢复 `visited` 状态、还原棋盘状态），以便尝试其他分支。
*   **剪枝 (Pruning)**：
    *   **可行性剪枝**：如果当前状态已经不可能得到解，直接返回。
    *   **最优性剪枝**：如果当前代价已经超过已知的最优解，直接返回（常用于求最小值/最大值问题）。
    *   **记忆化搜索**：如果子问题重复出现，用数组记录结果，避免重复计算（这是搜索通向动态规划的桥梁）。

**经典例题**：
*   GESP/CSP-J: 全排列生成、迷宫问题。
*   NOI/IOI: 骑士游历、数独求解、复杂的组合优化问题（配合强力剪枝）。

## 二、宽度优先搜索 (Breadth-First Search, BFS)

### 1. 核心思想
**“层层推进，由近及远”**。
BFS 从起点开始，先访问所有距离为 1 的节点，再访问所有距离为 2 的节点，以此类推。它像水波一样向外扩散。

*   **数据结构**：必须使用 **队列 (Queue)**。
*   **适用场景**：
    *   **无权图的最短路径**：这是 BFS 最重要的性质！在边权为 1 的图中，BFS 第一次到达某个节点时的路径长度一定是最短的。
    *   最小步数问题（如：最少按几次按钮能打开锁）。
    *   层次遍历。

### 2. 算法原理与模板
BFS 利用队列的“先进先出” (FIFO) 特性，保证先入队的节点（距离近的）先被处理。

**通用伪代码模板：**
```cpp
queue<int> q;
bool visited[MAX_N];
int dist[MAX_N]; // 记录起点到各点的距离

void bfs(int start) {
    q.push(start);
    visited[start] = true;
    dist[start] = 0;
    
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        
        // 如果找到目标节点，可以直接返回（因为是最短路）
        // if (u == target) return dist[u];

        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true;
                dist[v] = dist[u] + 1; // 距离 +1
                q.push(v);
            }
        }
    }
}
```

### 3. 竞赛中的关键点
*   **最短路保证**：只要图中边的权重都是 1（或相等），BFS 求出的就是最短路。如果边有权重且不相等，需要使用 Dijkstra 算法。
*   **状态压缩 BFS**：在状态空间很大但每个状态可以用二进制表示时（如：开关灯问题、拼图游戏），常将状态存入队列进行 BFS。
*   **双向 BFS**：当知道起点和终点，且搜索树呈指数增长时，可以从起点和终点同时开始搜索，相遇时停止。这能将时间复杂度从 $O(b^d)$ 降低到 $O(b^{d/2})$，其中 $b$ 是分支因子，$d$ 是深度。

**经典例题**：
*   CSP-J/S: 走迷宫求最短步数、细胞分裂。
*   NOI/IOI: 八数码问题、多维空间的最短路径、0-1 BFS（边权只有0和1的特殊最短路）。

## 三、二叉树的搜索算法

二叉树是一种特殊的图结构（无环、有根、每个节点最多两个子节点）。在树上进行搜索，通常不需要 `visited` 数组（因为不会往回走，除非特意要求），只需防止从子节点回到父节点即可。

### 1. 树的深度优先遍历 (Tree DFS)
对应三种经典序：
*   **前序遍历 (Pre-order)**: 根 -> 左 -> 右。用于复制树、序列化。
*   **中序遍历 (In-order)**: 左 -> 根 -> 右。**二叉搜索树 (BST)** 的中序遍历是有序序列。
*   **后序遍历 (Post-order)**: 左 -> 右 -> 根。用于计算子树大小、树形 DP、释放内存。

**代码示例 (递归):**
```cpp
struct TreeNode {
    int val;
    TreeNode *left, *right;
};

void dfs_tree(TreeNode* root) {
    if (!root) return;
    
    // 前序操作
    // process(root->val); 
    
    dfs_tree(root->left);
    
    // 中序操作
    // process(root->val);
    
    dfs_tree(root->right);
    
    // 后序操作
    // process(root->val);
}
```

### 2. 树的宽度优先遍历 (Tree BFS / 层序遍历)
按层级从上到下，从左到右访问节点。
*   **应用**：求树的深度、打印树的每一层、寻找离根节点最近的满足条件的节点。
*   **实现**：同样使用队列。每次处理队列中当前层的所有节点。

**代码技巧 (分层处理):**
```cpp
void bfs_tree(TreeNode* root) {
    if (!root) return;
    queue<TreeNode*> q;
    q.push(root);
    
    while (!q.empty()) {
        int size = q.size(); // 当前层的节点数
        for (int i = 0; i < size; ++i) {
            TreeNode* node = q.front();
            q.pop();
            // 处理当前节点
            
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        // 这里可以处理完一整层后的逻辑
    }
}
```

### 3. 进阶：树形 DP 与 最近公共祖先 (LCA)
在 NOI/IOI 阶段，单纯的遍历不够用，常结合以下技术：
*   **树形 DP**：在后序遍历的过程中，利用子节点的信息更新父节点的状态（例如：求树的最大独立集、树的重心）。
*   **倍增法求 LCA**：利用 DFS 预处理每个节点的 $2^k$ 级祖先，从而在 $O(\log N)$ 时间内查询任意两点的最近公共祖先。

## 四、教练总结与对比

| 特性 | 深度优先搜索 (DFS) | 宽度优先搜索 (BFS) | 二叉树搜索 |
| :--- | :--- | :--- | :--- |
| **核心数据结构** | 栈 (递归) | 队列 | 递归 (隐式栈) 或 队列 |
| **空间复杂度** | $O(H)$ (H为最大深度)，较省空间 | $O(W)$ (W为最大宽度)，可能爆内存 | 同左 |
| **主要用途** | 找所有解、连通性、拓扑、配合剪枝 | **无权图最短路**、最小步数 | 树的遍历、树形DP、LCA |
| **解的性质** | 不一定是最近/最优的 | **第一次遇到即为最优** (无权图) | 取决于遍历顺序 |
| **竞赛策略** | 必须掌握**剪枝**和**回溯** | 注意**状态去重**，防止队列爆炸 | 掌握**递归思维**和**父子关系** |

### 给同学的建议：
1.  **手写模板**：不要只看不练，必须在白板或纸上熟练写出 DFS 和 BFS 的标准模板，做到肌肉记忆。
2.  **画图模拟**：遇到复杂的搜索题，先在草稿纸上画出搜索树或网格，模拟算法的执行过程，这能帮你发现剪枝的机会。
3.  **理解本质**：
    *   问自己：“我要找的是**任意**一个解，还是**所有**解？” $\rightarrow$ 选 DFS。
    *   问自己：“我要找的是**步数最少**的解吗？” $\rightarrow$ 选 BFS。
    *   问自己：“数据结构是树吗？需要自底向上汇总信息吗？” $\rightarrow$ 选树形 DFS (后序)。

搜索算法是通往算法殿堂的钥匙。在 GESP 考级中，它是必考点；在 NOI/IOI 赛场上，它是解决难题的最后一道防线（暴力分）或是正解的核心。希望大家勤加练习，融会贯通！
