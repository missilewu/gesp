
# 递归算法核心知识点

## 一、递归算法的相关概念

| 概念 | 说明 |
|------|------|
| **定义** | 函数直接或间接调用自身来解决问题的算法 |
| **两个必要条件** | ① **基准情况**(Base Case)：递归终止条件 ② **递归情况**(Recursive Case)：向基准情况推进 |
| **执行过程** | 入栈→递归调用→到达基准→出栈返回 |
| **典型应用** | 阶乘、斐波那契、汉诺塔、树的遍历、分治算法 |

**代码模板：**
```cpp
int func(int n) {
    if (n <= 1) return 1;      // 基准情况
    return n * func(n - 1);    // 递归情况
}
```

---

## 二、时间复杂度和空间复杂度

| 算法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 阶乘 | O(n) | O(n) | 递归深度n |
| 斐波那契(朴素) | O(2ⁿ) | O(n) | 大量重复计算 |
| 斐波那契(记忆化) | O(n) | O(n) | 避免重复计算 |
| 二分查找 | O(log n) | O(log n) | 每次规模减半 |
| 归并排序 | O(n log n) | O(n + log n) | 分治典型 |
| 快速排序(平均) | O(n log n) | O(log n) | 最坏O(n²) |

**关键公式：**
- 空间复杂度 ≈ **递归深度 × 每层空间**
- 时间复杂度用**递归树**或**主定理**分析

---

## 三、递归的优化策略

| 优化方法 | 核心思想 | 适用场景 |
|---------|---------|---------|
| **记忆化搜索** | 缓存已计算结果，避免重复 | 斐波那契、DP问题 |
| **尾递归优化** | 递归调用在函数末尾，编译器可优化为循环 | 阶乘、累加 |
| **剪枝** | 提前终止无效分支 | 回溯、搜索问题 |
| **迭代转换** | 手动维护栈，改为循环 | 深度过大防栈溢出 |
| **减少递归深度** | 改变问题分解方式 | 平衡递归树 |

**记忆化示例：**
```cpp
int memo[1000];
int fib(int n) {
    if (n <= 1) return n;
    if (memo[n]) return memo[n];  // 已计算直接返回
    return memo[n] = fib(n-1) + fib(n-2);
}
```

---

## ⚠️ 竞赛注意事项

1. **栈溢出风险**：递归深度一般不超过10⁴~10⁵（视系统而定）
2. **NOI/IOI**：深度大时优先用迭代或手动栈
3. **GESP考级**：重点掌握递归书写规范和复杂度分析
4. **调试技巧**：加深度计数器，打印递归轨迹

**DFS模板：**
```cpp
void dfs(int x, int y) {
    if (越界 || 已访问) return;  // 终止条件
    visited[x][y] = true;
    // 处理当前节点
    for (每个方向) dfs(nx, ny);   // 递归扩展
}
```

## 四、树与图论应用

| 应用 | 说明 | 典型题 |
|------|------|--------|
| **树的遍历** | 前序/中序/后序 | 树的直径、LCA |
| **树的DP** | 递归计算子树信息 | 最大独立集、树的重心 |
| **图的DFS** | 连通性、环检测 | 拓扑排序、强连通分量 |
| **最近公共祖先** | 递归向上查找 | LCA模板题 |

**树形DP示例：**
```cpp
int dfs(int u, int fa) {
    int size = 1;
    for (int v : G[u]) {
        if (v != fa) size += dfs(v, u);
    }
    return size;  // 返回子树大小
}
```

## 五、动态规划的记忆化搜索

| 类型 | 优化前 | 优化后 | 适用场景 |
|------|--------|--------|---------|
| 斐波那契 | O(2ⁿ) | O(n) | 线性DP |
| 背包问题 | 指数级 | O(nV) | 0/1背包 |
| 区间DP | O(2ⁿ) | O(n³) | 石子合并 |
| 数位DP | 指数级 | O(位数×状态) | 数字计数 |

**记忆化模板：**
```cpp
int memo[100][100];
int dp(int i, int j) {
    if (i > j) return 0;
    if (memo[i][j]) return memo[i][j];
    // 状态转移
    return memo[i][j] = calc(i, j);
}
```

# 递归算法在OI中的具体优势

## 一、代码实现优势

| 优势 | 说明 | 竞赛价值 |
|------|------|---------|
| **代码简洁** | 几行代码解决复杂问题 | 节省比赛时间，减少bug |
| **逻辑清晰** | 直接映射问题定义 | 易于理解和调试 |
| **易于书写** | 模板化程度高 | 考场快速实现 |

**对比示例（树的遍历）：**
```cpp
// 递归版（10行）
void dfs(int u) {
    visit(u);
    for (int v : G[u]) dfs(v);
}

// 迭代版（30+行，需手动维护栈）
void dfs_iter(int root) {
    stack<int> st;
    st.push(root);
    while (!st.empty()) {
        // 复杂的状态管理...
    }
}
```

## 三、算法转化优势

| 转化方向 | 说明 | 竞赛意义 |
|---------|------|---------|
| **递归→DP** | 记忆化搜索直接转递推DP | 动态规划入门捷径 |
| **递归→分治** | 自然分解子问题 | 归并、快速幂、CDQ分治 |
| **递归→剪枝** | 方便添加剪枝条件 | 搜索题拿分关键 |

**记忆化转DP流程：**
```
递归搜索 → 添加memo数组 → 记忆化搜索 → 改写为递推DP
```
