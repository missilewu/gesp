
# 逆序对 算法知识点详细解析
逆序对是算法竞赛中**排序、分治**领域的核心基础概念，也是GESP、NOIP等考试的高频考点，常与“相邻交换排序的最小次数”“序列有序性度量”等问题结合。本文从**定义、核心结论、统计方法、适用场景、拓展延伸**五个维度，全面讲解逆序对的知识点，兼顾基础理解与竞赛实操。

## 一、逆序对的基本定义
### 1. 正式定义
对于一个**线性序列** $a[0...n-1]$，若存在两个下标 $i$ 和 $j$，满足**$i < j$ 且 $a[i] > a[j]$**，则称有序对 $(i,j)$ 为该序列的一个**逆序对**。
简单来说：**位置靠前的数，比位置靠后的数大，这两个数就构成一个逆序对**。

### 2. 通俗举例
序列 $a = [3, 1, 2, 4]$ 的逆序对分析：
- $i=0,j=1$：$3>1$ → 逆序对
- $i=0,j=2$：$3>2$ → 逆序对
- 其余下标对均满足 $a[i] < a[j]$
**总逆序对数量：2个**。

### 3. 特殊序列的逆序对
- **升序序列**（如$[1,2,3,4]$）：逆序对数量为**0**（完全有序）；
- **降序序列**（如$[4,3,2,1]$）：逆序对数量为 $n(n-1)/2$（完全无序，是n个元素序列的最大逆序对数量）；
  例：n=4时，最大逆序对数量=4×3/2=6。

## 二、逆序对的核心核心结论（竞赛高频考点）
逆序对的核心价值在于**量化序列的无序程度**，且与**相邻交换排序**存在强关联，这也是GESP四级编程题2的解题关键，**该结论必须牢记**：
> **仅通过「相邻两个元素交换」的方式将一个序列排序为升序，所需的**最小交换次数**，等于该序列的**逆序对总数量**。

### 结论原理
相邻交换的本质是**每次交换只能消除「一个」逆序对**：
- 交换相邻的逆序对 $(i,i+1)$（$a[i]>a[i+1]$），交换后该逆序对消失，且不会新增其他逆序对；
- 要将序列转为完全有序（逆序对数量为0），最少需要执行「逆序对数量」次这样的交换。

### 结论拓展
若要求将序列排序为**降序**，则最小相邻交换次数 = 序列的**正序对数量**（正序对定义：$i<j$ 且 $a[i]<a[j]$）。

## 三、逆序对的三种统计方法
逆序对的统计是核心考点，不同方法的**时间复杂度**不同，适配的**数据范围**也不同，竞赛中需根据题目给出的n的大小选择对应方法。
以下按**从易到难、从暴力到优化**的顺序讲解，均以**统计升序的逆序对**为例，代码为C++实现。

### 方法一：暴力双层循环（$O(n^2)$）
#### 适用场景
**n ≤ 5000**（如GESP四级的n≤3000），时间复杂度为平方级，操作数在$10^7$以内时可在1s内完成。
#### 核心思路
遍历所有满足 $i < j$ 的下标对，逐一判断是否满足 $a[i] > a[j]$，满足则计数器加1。
#### 代码实现（通用版）
```cpp
#include <iostream>
#include <vector>
using namespace std;

// 统计逆序对数量，暴力O(n²)
long long countReversePair(vector<int>& a) {
    int n = a.size();
    long long ans = 0; // 用long long防止溢出（n大时逆序对数量会超int）
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (a[i] > a[j]) {
                ans++;
            }
        }
    }
    return ans;
}

int main() {
    vector<int> a = {3,1,2,4};
    cout << countReversePair(a) << endl; // 输出2
    return 0;
}
```
#### 关键注意点
用**long long**存储逆序对数量：当n=1e5时，最大逆序对数量约为5e9，远超int的存储范围（int最大约2e9），即使是暴力法，也建议养成用long long的习惯。

### 方法二：归并排序优化（$O(nlogn)$）
#### 适用场景
**1e5 ≤ n ≤ 1e6**（如NOIP普及组/提高组的常规数据范围），时间复杂度为对数级，是竞赛中**最常用**的逆序对统计方法。
#### 核心思路
利用**归并排序的分治思想**，在“合并两个有序子序列”的过程中，**顺带统计逆序对数量**，无需额外遍历，实现时间复杂度的优化。
归并排序将序列分为左半部分$left$和右半部分$right$，逆序对分为三类：
1. 完全在$left$内部的逆序对；
2. 完全在$right$内部的逆序对；
3. 一个在$left$、一个在$right$的跨区间逆序对（**合并阶段统计的核心**）。

#### 核心原理（合并阶段统计）
当合并两个有序子序列$left[L...mid]$和$right[mid+1...R]$时：
- 用两个指针$i$（遍历left）、$j$（遍历right）；
- 若$left[i] > right[j]$，则**left中从i到mid的所有元素**都大于$right[j]$，共产生**$mid - i + 1$个**跨区间逆序对；
- 若$left[i] ≤ right[j]$，则无逆序对，直接将$left[i]$加入临时数组。

#### 代码实现（归并排序版）
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

long long merge(vector<int>& a, vector<int>& temp, int L, int mid, int R) {
    long long cnt = 0; // 统计本层的逆序对数量
    int i = L, j = mid + 1, k = L;
    // 合并两个有序子序列，顺带统计逆序对
    while (i <= mid && j <= R) {
        if (a[i] > a[j]) {
            temp[k++] = a[j++];
            cnt += mid - i + 1; // 核心：left[i...mid]都大于a[j]
        } else {
            temp[k++] = a[i++];
        }
    }
    // 处理剩余元素
    while (i <= mid) temp[k++] = a[i++];
    while (j <= R) temp[k++] = a[j++];
    // 将临时数组的内容拷贝回原数组
    copy(temp.begin() + L, temp.begin() + R + 1, a.begin() + L);
    return cnt;
}

// 归并排序的分治函数
long long mergeSort(vector<int>& a, vector<int>& temp, int L, int R) {
    long long cnt = 0;
    if (L < R) {
        int mid = (L + R) / 2;
        // 分治：统计左、右子序列的逆序对
        cnt += mergeSort(a, temp, L, mid);
        cnt += mergeSort(a, temp, mid + 1, R);
        // 合并：统计跨区间的逆序对
        cnt += merge(a, temp, L, mid, R);
    }
    return cnt;
}

// 统计逆序对的入口函数
long long countReversePair(vector<int>& a) {
    int n = a.size();
    vector<int> temp(n); // 临时数组，用于归并
    return mergeSort(a, temp, 0, n - 1);
}

int main() {
    vector<int> a = {3,1,2,4};
    cout << countReversePair(a) << endl; // 输出2
    return 0;
}
```
#### 关键注意点
1. 归并排序会**修改原序列**（将其排序为升序），若题目要求保留原序列，需先拷贝一份再处理；
2. 临时数组`temp`只需定义一次，避免递归中反复创建，提升效率。

### 方法三：树状数组/线段树优化（$O(nlogM)$）
#### 适用场景
**n ≤ 1e6 且序列元素可离散化**（如NOIP提高组、IOI入门题），时间复杂度为$O(nlogM)$（M为元素的离散化后范围），是**最优**的逆序对统计方法，支持**动态序列的逆序对查询**。
#### 核心思路
利用**树状数组（Fenwick Tree）**的**单点更新、区间查询**功能，**从后往前**遍历序列，统计每个元素左侧**比它大的元素数量**，累加即为总逆序对数量。
#### 前置步骤：离散化
若序列元素的范围很大（如$10^9$），但n较小，需先对元素**离散化**（将大数值映射为连续的小整数，如$[10^9, 5, 1e5]$映射为$[3,1,2]$），否则树状数组的空间会超出限制。
#### 核心原理
1. 从后往前遍历序列$a$，对于当前元素$x$；
2. 查询树状数组中**1 ~ x-1**的元素个数（即已经遍历过的、比x小的元素数量，这些元素在原序列中位置靠后）；
3. 已遍历的元素总数 - 上述查询结果 = **当前x对应的逆序对数量**（位置靠前的x，比位置靠后的、比x大的元素数量）；
4. 将x插入树状数组（单点更新），继续遍历下一个元素。

#### 代码实现（树状数组+离散化版）
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 树状数组模板
class FenwickTree {
private:
    vector<int> tree;
public:
    FenwickTree(int size) : tree(size + 1, 0) {}
    // 单点更新：位置x加1
    void update(int x, int val) {
        while (x < tree.size()) {
            tree[x] += val;
            x += x & -x;
        }
    }
    // 区间查询：1~x的和
    int query(int x) {
        int res = 0;
        while (x > 0) {
            res += tree[x];
            x -= x & -x;
        }
        return res;
    }
};

// 离散化：将a映射为1~m的连续整数
vector<int> discretize(vector<int>& a) {
    vector<int> b = a;
    sort(b.begin(), b.end());
    b.erase(unique(b.begin(), b.end()), b.end());
    for (int& x : a) {
        x = lower_bound(b.begin(), b.end(), x) - b.begin() + 1; // 映射为1开始
    }
    return b;
}

// 树状数组统计逆序对：O(nlogM)
long long countReversePair(vector<int>& a) {
    discretize(a); // 离散化
    int maxVal = *max_element(a.begin(), a.end());
    FenwickTree ft(maxVal);
    long long cnt = 0;
    int n = a.size();
    // 从后往前遍历
    for (int i = n - 1; i >= 0; i--) {
        // 查询比a[i]小的元素数量，总数量-该值=当前逆序对数量
        cnt += i - ft.query(a[i] - 1);
        ft.update(a[i], 1); // 插入a[i]
    }
    return cnt;
}

int main() {
    vector<int> a = {3,1,2,4};
    cout << countReversePair(a) << endl; // 输出2
    return 0;
}
```
#### 关键注意点
1. 离散化时**从1开始映射**，避免树状数组查询0的情况（树状数组下标从1开始）；
2. 该方法**不修改原序列**，且支持动态添加元素并查询逆序对，灵活性远高于归并排序法。

## 四、三种统计方法的对比与选型建议
竞赛中最核心的是**根据n的大小选择合适的方法**，以下是清晰的对比表，方便快速选型：

| 统计方法       | 时间复杂度 | 空间复杂度 | 适用n范围   | 优点                     | 缺点                     |
|----------------|------------|------------|-------------|--------------------------|--------------------------|
| 暴力双层循环   | $O(n^2)$   | $O(1)$     | n ≤ 5000    | 代码极简、易理解、无修改 | 效率低，n大时超时        |
| 归并排序优化   | $O(nlogn)$ | $O(n)$     | 1e5 ≤n≤1e6  | 效率高、代码易实现       | 修改原序列、需额外临时数组 |
| 树状数组优化   | $O(nlogM)$ | $O(n+M)$   | n ≤1e6      | 效率最优、不修改原序列、支持动态查询 | 需离散化、代码稍复杂 |

### 竞赛选型原则
1. **GESP考试**：n通常≤5000，优先用**暴力法**，代码简洁不易出错；
2. **NOIP普及组**：n通常≤1e5，优先用**归并排序法**，无需离散化，代码比树状数组简单；
3. **NOIP提高组/IOI**：n≤1e6或需要动态查询，用**树状数组/线段树法**，兼顾效率和灵活性。

## 五、逆序对的拓展考点（竞赛延伸）
逆序对的考察并非仅局限于“统计数量”，竞赛中常结合**自定义排序规则、多维逆序对、带权逆序对**等拓展考点，其中**自定义排序规则的逆序对**是GESP到NOIP的过渡考点（如本次GESP四级编程题2）。

### 拓展1：自定义排序规则的逆序对
#### 核心问题
题目要求按**自定义规则**排序（如身高降序、体重降序），求最小相邻交换次数。
#### 解题思路
将**自定义规则的有序**转化为**普通升序**，再统计逆序对：
1. 按自定义规则对原序列的元素**赋值/映射**，使自定义降序/升序对应映射后序列的普通升序；
   例：GESP四级题中，将(h,w)映射为(-h,-w)，则“h降序、w降序”对应映射后序列的“普通升序”；
2. 对映射后的序列统计**普通逆序对**，数量即为最小相邻交换次数。
#### 本质
逆序对的定义是**基于“有序规则”的**，普通逆序对是“升序规则”，自定义逆序对只需将元素按规则重新映射即可。

### 拓展2：多维逆序对（如二维逆序对）
#### 定义
对于二维序列$(a_i, b_i)$，若$i<j$且$a_i>a_j$且$b_i>b_j$，则称$(i,j)$为二维逆序对。
#### 解法
先按第一维排序，再用树状数组统计第二维的逆序对，时间复杂度$O(nlogn)$。

### 拓展3：带权逆序对
#### 定义
每个逆序对$(i,j)$带有一个权值（如$a[i]+a[j]$），求所有逆序对的权值和。
#### 解法
在归并排序/树状数组的统计过程中，不仅统计数量，还统计权值的和（如树状数组存储元素值和元素个数，同时查询）。

## 六、逆序对的常见考试题型总结
逆序对在编程考试中主要以**两种题型**出现，均为高频考点：
### 题型1：直接统计逆序对数量
题目直接给出一个序列，要求输出其逆序对的数量，考察对统计方法的代码实现能力。
### 题型2：最小相邻交换次数
题目要求按指定规则排序，且仅允许相邻交换，求最小交换次数，考察**“逆序对数量=最小相邻交换次数”**的核心结论，以及自定义规则的映射能力（如GESP四级编程题2）。

## 七、学习与备考建议
### 1. 基础阶段（GESP）

## 总结
逆序对是**排序算法**的延伸，核心是“量化序列的无序程度”，而“最小相邻交换次数=逆序对数量”是竞赛中最核心的结论。
从GESP的暴力统计，到NOIP的归并排序优化，再到IOI的树状数组优化，逆序对的考察难度逐步提升，但**定义和核心结论**始终不变。
掌握逆序对的关键是：**先理解概念，再熟记结论，最后根据数据范围选择合适的统计方法**。

# 如何计算一个序列的逆序对数量？


计算序列的逆序对数量是算法中的基础问题，核心思路是**根据数据规模选择不同复杂度的方法**——小规模用暴力法（易实现）、中大规模用归并排序优化（高效）、超大规/动态场景用树状数组（最优）。下面从「核心定义」「三种实现方法」「选型建议」三个维度，给出清晰、可落地的计算方案。

### 一、先明确：逆序对的定义
对于序列 $a[0...n-1]$，若存在下标 $i < j$ 且 $a[i] > a[j]$，则 $(i,j)$ 是一个逆序对。我们的目标是统计这样的有序对总数。

### 二、三种计算方法（附完整代码+解析）
#### 方法1：暴力双层循环（O(n²)）
##### 适用场景
序列长度 $n ≤ 5000$（如GESP考试、小规模数据），代码极简，新手优先掌握。
##### 核心思路
遍历所有 $i < j$ 的下标对，逐一判断 $a[i] > a[j]$，满足则计数+1。
##### 完整代码（C++）
```cpp
#include <iostream>
#include <vector>
using namespace std;

// 统计逆序对数量（暴力法）
long long countReversePairs(vector<int>& a) {
    int n = a.size();
    long long cnt = 0; // 必须用long long，避免n大时溢出
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (a[i] > a[j]) { // 满足i<j且a[i]>a[j]，逆序对+1
                cnt++;
            }
        }
    }
    return cnt;
}

int main() {
    // 测试用例：序列[3,1,2,4]，逆序对数量为2
    vector<int> a = {3, 1, 2, 4};
    cout << "逆序对数量：" << countReversePairs(a) << endl;
    return 0;
}
```
##### 关键说明
- 用 `long long` 存储结果：当 $n=10^5$ 时，最大逆序对数量约 $5×10^9$，远超 `int` 范围（int最大约 $2×10^9$）；
- 优点：代码无任何冗余，直接体现逆序对定义，新手易理解；
- 缺点：效率低，$n=10^4$ 时操作数达 $5×10^7$，会超时。

#### 方法2：归并排序优化（O(n log n)）
##### 适用场景
序列长度 $10^4 < n ≤ 10^6$（如NOIP普及组），是竞赛中最常用的高效方法。
##### 核心思路
利用归并排序的「分治思想」，在“合并两个有序子序列”时**顺带统计逆序对**，无需额外遍历：
1. 分：将序列拆分为左、右两个子序列，递归统计子序列内部的逆序对；
2. 治：合并两个有序子序列时，统计「跨左右子序列」的逆序对。
##### 完整代码（C++）
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 合并两个有序子序列，返回本层的逆序对数量
long long merge(vector<int>& a, vector<int>& temp, int L, int mid, int R) {
    long long cnt = 0;
    int i = L, j = mid + 1, k = L;
    // 合并过程中统计逆序对
    while (i <= mid && j <= R) {
        if (a[i] > a[j]) {
            temp[k++] = a[j++];
            // 核心：左子序列i~mid的所有元素都大于a[j]，共mid-i+1个逆序对
            cnt += mid - i + 1;
        } else {
            temp[k++] = a[i++];
        }
    }
    // 处理剩余元素
    while (i <= mid) temp[k++] = a[i++];
    while (j <= R) temp[k++] = a[j++];
    // 拷贝回原数组
    copy(temp.begin() + L, temp.begin() + R + 1, a.begin() + L);
    return cnt;
}

// 归并排序递归函数，返回[L,R]区间的逆序对数量
long long mergeSort(vector<int>& a, vector<int>& temp, int L, int R) {
    long long cnt = 0;
    if (L < R) {
        int mid = (L + R) / 2;
        // 分：统计左、右子序列的逆序对
        cnt += mergeSort(a, temp, L, mid);
        cnt += mergeSort(a, temp, mid + 1, R);
        // 治：统计跨区间的逆序对
        cnt += merge(a, temp, L, mid, R);
    }
    return cnt;
}

// 统计逆序对入口函数
long long countReversePairs(vector<int>& a) {
    int n = a.size();
    vector<int> temp(n); // 临时数组，避免递归中反复创建
    return mergeSort(a, temp, 0, n - 1);
}

int main() {
    vector<int> a = {3, 1, 2, 4};
    cout << "逆序对数量：" << countReversePairs(a) << endl; // 输出2
    return 0;
}
```
##### 关键说明
- 合并阶段的核心逻辑：若 `a[i] > a[j]`，则左子序列中 `i` 到 `mid` 的所有元素都大于 `a[j]`，直接累加 `mid - i + 1` 个逆序对；
- 注意：归并排序会**修改原序列**（将其排序为升序），若需保留原序列，需先拷贝一份再处理；
- 效率：$n=10^5$ 时，操作数约 $10^5 × 20 = 2×10^6$，1s内可完成。

#### 方法3：树状数组+离散化（O(n log M)）
##### 适用场景
序列长度 $n ≤ 10^6$ 且元素值范围大（如 $10^9$），或需要「动态统计逆序对」（如NOIP提高组）。
##### 核心思路
1. 离散化：将大数值映射为连续小整数（如 $[10^9, 5, 10^5]$ → $[3,1,2]$），降低树状数组空间开销；
2. 从后往前遍历序列，用树状数组统计「当前元素右侧比它小的元素数量」，间接计算逆序对。
##### 完整代码（C++）
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 树状数组模板
class FenwickTree {
private:
    vector<int> tree;
public:
    FenwickTree(int size) : tree(size + 1, 0) {}
    // 单点更新：位置x加1
    void update(int x, int val) {
        while (x < tree.size()) {
            tree[x] += val;
            x += x & -x; // 加上最低位的1，找父节点
        }
    }
    // 区间查询：1~x的元素个数
    int query(int x) {
        int res = 0;
        while (x > 0) {
            res += tree[x];
            x -= x & -x; // 减去最低位的1，找子节点
        }
        return res;
    }
};

// 离散化：将数组映射为1~m的连续整数
void discretize(vector<int>& a) {
    vector<int> b = a;
    sort(b.begin(), b.end());
    b.erase(unique(b.begin(), b.end()), b.end()); // 去重
    for (int& x : a) {
        // 映射为1开始（树状数组下标从1开始）
        x = lower_bound(b.begin(), b.end(), x) - b.begin() + 1;
    }
}

// 树状数组统计逆序对
long long countReversePairs(vector<int>& a) {
    discretize(a); // 先离散化
    int maxVal = *max_element(a.begin(), a.end());
    FenwickTree ft(maxVal);
    long long cnt = 0;
    int n = a.size();
    // 从后往前遍历
    for (int i = n - 1; i >= 0; i--) {
        // 已遍历的元素中，比a[i]小的数量 = query(a[i]-1)
        // 逆序对数量 = 已遍历总数 - 比a[i]小的数量
        cnt += i - ft.query(a[i] - 1);
        ft.update(a[i], 1); // 将a[i]加入树状数组
    }
    return cnt;
}

int main() {
    vector<int> a = {3, 1, 2, 4};
    cout << "逆序对数量：" << countReversePairs(a) << endl; // 输出2
    return 0;
}
```
##### 关键说明
- 离散化是核心前置步骤：若元素值范围是 $10^9$，直接用树状数组会超出内存，离散化后仅需 $n$ 大小的空间；
- 从后往前遍历的逻辑：`i - ft.query(a[i]-1)` 表示“当前元素左侧比它大的元素数量”（即逆序对数量）；
- 优点：不修改原序列，支持动态添加元素并查询逆序对，效率最优。

### 三、方法选型建议（按场景匹配）
| 方法                | 时间复杂度 | 适用n范围   | 核心优势                     | 适用场景                  |
|---------------------|------------|-------------|------------------------------|---------------------------|
| 暴力双层循环        | O(n²)      | n ≤ 5000    | 代码极简、易理解             | GESP考试、小规模数据      |
| 归并排序优化        | O(n log n) | 10⁴ < n ≤ 10⁶ | 效率高、无需离散化           | NOIP普及组、中等规模数据  |
| 树状数组+离散化     | O(n log M) | n ≤ 10⁶     | 效率最优、支持动态查询       | NOIP提高组、超大数范围数据|

### 四、易错点提醒
1. **数据类型溢出**：无论用哪种方法，都必须用 `long long` 存储逆序对数量，避免int溢出；
2. **归并排序的数组拷贝**：合并后需将临时数组的内容拷贝回原数组，否则排序结果错误；
3. **树状数组的离散化**：映射后必须从1开始，否则查询 `a[i]-1=0` 时会出错；
4. **自定义排序规则的逆序对**：若题目要求按“降序”或“多关键字”排序，需先将元素映射为“升序等价序列”，再统计逆序对（如GESP四级题中对(h,w)取负）。

### 总结
计算逆序对数量的核心是：
1. **小规模（n≤5000）**：优先暴力法，代码简单不易错；
2. **中规模（10⁴<n≤10⁶）**：用归并排序法，平衡效率与代码复杂度；
3. **大规模/动态场景**：用树状数组+离散化，效率最优；
4. 所有方法都需牢记「逆序对数量=仅相邻交换的最小排序次数」这一核心结论，这是竞赛高频考点。
