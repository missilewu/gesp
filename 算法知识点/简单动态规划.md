很多初学者听到 DP 就头疼，觉得它玄之又玄。其实，动态规划的本质非常朴素：**“记住过去，为了未来”**。它通过记录子问题的解，避免重复计算，从而将指数级的时间复杂度降低到多项式级。

今天我们将重点讲解两个最基础也最重要的模型：**一维动态规划**和**简单背包问题**。

## 第一部分：动态规划的核心思想

在深入具体模型前，必须掌握两个核心概念，这是判断一个问题能否用 DP 解决的依据：

1.  **最优子结构 (Optimal Substructure)**：
    *   大问题的最优解，可以由小问题的最优解推导出来。
    *   *例子*：如果你想知道从家到学校的最短路径，而中间必须经过公园，那么“家->公园”这段路也必须是最短的。

2.  **无后效性 (No Aftereffect)**：
    *   一旦某个状态被确定，它之后的演变只与这个状态本身有关，而与它是如何到达这个状态的过程无关。
    *   *通俗理解*：英雄不问出处。不管你是怎么走到第 $i$ 步的，只要你现在站在第 $i$ 步，接下来的选择只取决于你在 $i$ 的位置，而不取决于你之前走了什么弯路。

**解题四步走（DP 通用模板）：**
1.  **定义状态**：$dp[i]$ 代表什么含义？
2.  **状态转移方程**：如何从已知状态推导出未知状态？（核心！）
3.  **初始化**：边界条件是什么？（$dp[0]$ 是多少？）
4.  **计算顺序**：从小到大还是从大到小？

## 第二部分：一维动态规划

一维 DP 通常用于解决线性序列上的问题，比如爬楼梯、斐波那契数列变种、最长上升子序列（简化版）等。

### 经典案例：爬楼梯 (Climbing Stairs)

**题目描述**：
假设你正在爬楼梯。需要 $n$ 阶你才能到达楼顶。每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

#### 1. 定义状态
设 $dp[i]$ 表示**爬到第 $i$ 阶楼梯的方法总数**。

#### 2. 寻找状态转移方程
要想跳到第 $i$ 阶，只有两种可能：
*   从第 $i-1$ 阶跳 1 步上来。
*   从第 $i-2$ 阶跳 2 步上来。

既然要求总方法数，根据加法原理：
$$dp[i] = dp[i-1] + dp[i-2]$$

这就是著名的斐波那契数列规律在 DP 中的体现。

#### 3. 初始化
*   $dp[0] = 1$ (在地面算一种方法，或者理解为基准)
*   $dp[1] = 1$ (只有一种方法：跳1步)
*   $dp[2] = 2$ (1+1 或 2)

#### 4. 代码实现 (C++)

```cpp
#include <iostream>
#include <vector>
using namespace std;

int climbStairs(int n) {
    if (n <= 1) return 1;
    
    // 定义 dp 数组
    vector<int> dp(n + 1);
    
    // 初始化
    dp[0] = 1; 
    dp[1] = 1;
    
    // 从小到大的顺序计算
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2]; // 状态转移
    }
    
    return dp[n];
}

int main() {
    int n;
    cin >> n;
    cout << climbStairs(n) << endl;
    return 0;
}
```

**教练提示**：
在一维 DP 中，你会发现很多时候 $dp[i]$ 只依赖于前两项。为了节省空间（空间优化），我们可以只用两个变量 `a` 和 `b` 来滚动更新，将空间复杂度从 $O(n)$ 降到 $O(1)$。这在 NOIP/NOI 高级组比赛中非常重要。

## 第三部分：简单背包问题 (0/1 Knapsack)

背包问题是动态规划的“亲儿子”，也是各类考试中出现频率最高的模型。**0/1 背包**的意思是：每件物品要么拿（1），要么不拿（0），不能切分，也不能拿多次。

### 题目描述
有一个容量为 $W$ 的背包，和 $N$ 件物品。
第 $i$ 件物品的重量是 $w[i]$，价值是 $v[i]$。
问：在不超过背包容量的前提下，能装入的最大总价值是多少？

### 1. 定义状态
我们需要两个维度来描述一个状态：当前考虑到了哪件物品，以及当前背包剩多少容量（或已用多少容量）。
设 $dp[i][j]$ 表示：**从前 $i$ 件物品中选择，且背包容量不超过 $j$ 时，能获得的最大价值。**

### 2. 状态转移方程
对于第 $i$ 件物品，我们有两种选择：

*   **情况 A：不选第 $i$ 件物品**。
    此时最大价值等于“从前 $i-1$ 件物品中选，容量为 $j$”的价值。
    $$value_A = dp[i-1][j]$$

*   **情况 B：选第 $i$ 件物品** (前提是 $j \ge w[i]$)。
    此时最大价值等于“从前 $i-1$ 件物品中选，容量为 $j - w[i]$”的价值，加上当前物品的价值 $v[i]$。
    $$value_B = dp[i-1][j - w[i]] + v[i]$$

**最终决策**：取两者的最大值。
$$dp[i][j] = \max(dp[i-1][j], \quad dp[i-1][j - w[i]] + v[i])$$
*(注：如果 $j < w[i]$，则只能选情况 A)*

### 3. 初始化
*   $dp[0][j] = 0$：没有物品可选时，价值为 0。
*   $dp[i][0] = 0$：背包容量为 0 时，价值为 0。

### 4. 二维代码实现 (便于理解逻辑)

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int N, W; // N: 物品数量，W: 背包容量
    cin >> N >> W;
    
    vector<int> w(N + 1), v(N + 1);
    for (int i = 1; i <= N; i++) cin >> w[i] >> v[i];
    
    // dp[i][j] 表示前 i 个物品，容量为 j 时的最大价值
    vector<vector<int>> dp(N + 1, vector<int>(W + 1, 0));
    
    for (int i = 1; i <= N; i++) { // 枚举物品
        for (int j = 1; j <= W; j++) { // 枚举容量
            // 默认不选
            dp[i][j] = dp[i-1][j];
            
            // 如果能装下，尝试选它
            if (j >= w[i]) {
                dp[i][j] = max(dp[i][j], dp[i-1][j - w[i]] + v[i]);
            }
        }
    }
    
    cout << dp[N][W] << endl;
    return 0;
}
```

### 5. 进阶：空间优化（滚动数组 / 一维化）

在 NOI/IOI 级别，我们通常直接使用**一维数组**来解决 0/1 背包，以节省内存并提高缓存命中率。

**优化原理**：
观察方程 $dp[i][j] = \max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])$。
我们会发现，$dp[i][...]$ 这一层的数据只依赖于 $dp[i-1][...]$ 这一层。
如果我们把第一维去掉，变成 $dp[j]$，那么在计算 $dp[j]$ 时，我们需要用到的 $dp[j-w[i]]$ 必须是**上一层（即未更新过）**的值。

**关键技巧**：**内层循环（容量）必须从大到小遍历！**
如果从小到大遍历，$dp[j-w[i]]$ 可能已经被本轮（第 $i$ 个物品）更新过了，这就变成了“完全背包”（物品可以选多次），违背了 0/1 背包的规则。

#### 一维优化代码 (背诵级模板)

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int N, W;
    cin >> N >> W;
    
    vector<int> w(N + 1), v(N + 1);
    for (int i = 1; i <= N; i++) cin >> w[i] >> v[i];
    
    // 一维 dp 数组，dp[j] 表示容量为 j 时的最大价值
    vector<int> dp(W + 1, 0);
    
    for (int i = 1; i <= N; i++) {
        // 【重点】必须倒序遍历！防止重复选取同一物品
        for (int j = W; j >= w[i]; j--) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    
    cout << dp[W] << endl;
    return 0;
}
```

## 教练总结与避坑指南

作为你们的教练，我总结了同学们在初学这两个知识点时最容易犯的错误：

1.  **一维 DP 的边界问题**：
    *   一定要想清楚 $dp[0]$ 的含义。是 0 还是 1？这取决于题目是求“方案数”（通常 $dp[0]=1$）还是“最大价值/最小代价”（通常 $dp[0]=0$ 或无穷大）。

2.  **背包问题的循环顺序**：
    *   **0/1 背包**：内层循环**倒序** ($W \to w[i]$)。
    *   **完全背包**（物品无限个）：内层循环**正序** ($w[i] \to W$)。
    *   口诀：**“01 倒着做，完全顺着做”**。搞反了必错！

3.  **数组越界**：
    *   定义数组时，大小通常是 $N+1$ 或 $W+1$，因为我们的下标通常从 1 开始计数，或者需要用到 0 作为边界。

4.  **数据类型**：
    *   如果价值总和很大，记得使用 `long long`，防止整数溢出（这在 GESP 高阶和 NOI 中是常见陷阱）。
