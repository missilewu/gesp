## 一、分治算法核心思想

### 📌 什么是分治法？

**分治法（Divide and Conquer）** 的核心思想可以用三个词概括：

```
分解（Divide）→ 解决（Conquer）→ 合并（Combine）
```

### 📌 分治法的三个步骤

|步骤|说明|示例|
|---|---|---|
|**分解**|将原问题分解为若干个规模较小的子问题|把大数组分成小数组|
|**解决**|递归地解决这些子问题|对小数组排序|
|**合并**|将子问题的解合并为原问题的解|合并已排序的小数组|

### 📌 分治法适用条件

1. **问题可分解**：原问题可以分解为若干个规模较小的相同问题
2. **子问题独立**：各子问题之间相互独立，不重叠
3. **可合并**：子问题的解可以合并为原问题的解
4. **基本情况**：问题规模足够小时可以直接求解

## 二、归并排序（Merge Sort）

### 📌 算法原理

归并排序是**分治法的典型应用**，由冯·诺依曼于1945年提出。

**核心思想**：

```
将数组不断二分，直到每个子数组只有一个元素（天然有序）
然后两两合并有序数组，最终得到完整有序数组
```

### 📌 算法步骤图解

```
原始数组: [38, 27, 43, 3, 9, 82, 10]

第一层分解:
[38, 27, 43, 3]           [9, 82, 10]

第二层分解:
[38, 27]    [43, 3]       [9, 82]    [10]

第三层分解:
[38] [27]   [43] [3]       [9] [82]   [10]

开始合并:
[27, 38]    [3, 43]       [9, 82]    [10]

继续合并:
[3, 27, 38, 43]           [9, 10, 82]

最终合并:
[3, 9, 10, 27, 38, 43, 82]
```

### 📌 核心代码实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 合并两个有序数组
void merge(vector<int>& arr, int left, int mid, int right) {
    int n1 = mid - left + 1;  // 左半部分长度
    int n2 = right - mid;     // 右半部分长度
    
    // 创建临时数组
    vector<int> L(n1), R(n2);
    
    // 复制数据到临时数组
    for (int i = 0; i < n1; i++)
        L[i] = arr[left + i];
    for (int j = 0; j < n2; j++)
        R[j] = arr[mid + 1 + j];
    
    // 合并临时数组回原数组
    int i = 0, j = 0, k = left;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) {
            arr[k++] = L[i++];
        } else {
            arr[k++] = R[j++];
        }
    }
    
    // 复制剩余元素
    while (i < n1) arr[k++] = L[i++];
    while (j < n2) arr[k++] = R[j++];
}

// 归并排序主函数
void mergeSort(vector<int>& arr, int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;  // 防止溢出
        
        mergeSort(arr, left, mid);      // 排序左半部分
        mergeSort(arr, mid + 1, right); // 排序右半部分
        
        merge(arr, left, mid, right);   // 合并
    }
}

int main() {
    vector<int> arr = {38, 27, 43, 3, 9, 82, 10};
    mergeSort(arr, 0, arr.size() - 1);
    
    for (int x : arr) cout << x << " ";
    return 0;
}
```

### 📌 时间复杂度分析

|情况|时间复杂度|说明|
|---|---|---|
|最好情况|O(n log n)|无论输入如何，分解层数固定|
|平均情况|O(n log n)|稳定的时间复杂度|
|最坏情况|O(n log n)|归并排序的优势所在|

**推导过程**：

```
T(n) = 2T(n/2) + O(n)
     = 2[2T(n/4) + O(n/2)] + O(n)
     = 4T(n/4) + 2O(n)
     = ...
     = nT(1) + log n × O(n)
     = O(n log n)
```

### 📌 空间复杂度

- **空间复杂度**：O(n)
- 需要额外的临时数组存储合并结果

### 📌 算法特性

|特性|说明|
|---|---|
|**稳定性**|✅ 稳定排序（相等元素相对位置不变）|
|**原地排序**|❌ 需要额外O(n)空间|
|**适应性**|对任何输入数据表现一致|

## 三、快速排序（Quick Sort）

### 📌 算法原理

快速排序由**托尼·霍尔（Tony Hoare）** 于1960年提出，是实际应用中**最常用的排序算法**。

**核心思想**：

```
1. 选择一个基准值（pivot）
2. 将数组分为两部分：小于基准的在左边，大于基准的在右边
3. 递归地对两部分继续排序
```

### 📌 算法步骤图解

```
原始数组: [38, 27, 43, 3, 9, 82, 10]
选择基准: 38（以第一个元素为例）

分区过程:
[27, 3, 9, 10]  [38]  [43, 82]
   小于38        基准    大于38

递归排序左边:
[3, 9, 10]  [27]  []

递归排序右边:
[]  [43]  [82]

最终结果:
[3, 9, 10, 27, 38, 43, 82]
```

### 📌 核心代码实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 分区函数（Lomuto分区方案）
int partition(vector<int>& arr, int low, int high) {
    int pivot = arr[high];  // 选择最后一个元素作为基准
    int i = low - 1;        // i指向小于pivot区域的最后一个元素
    
    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[high]);
    return i + 1;  // 返回基准的最终位置
}

// 快速排序主函数
void quickSort(vector<int>& arr, int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);  // 获取基准位置
        
        quickSort(arr, low, pi - 1);   // 排序左半部分
        quickSort(arr, pi + 1, high);  // 排序右半部分
    }
}

int main() {
    vector<int> arr = {38, 27, 43, 3, 9, 82, 10};
    quickSort(arr, 0, arr.size() - 1);
    
    for (int x : arr) cout << x << " ";
    return 0;
}
```

### 📌 优化版本（竞赛常用）

```cpp
// 三数取中法选择基准（避免最坏情况）
int medianOfThree(vector<int>& arr, int low, int high) {
    int mid = low + (high - low) / 2;
    if (arr[low] > arr[mid]) swap(arr[low], arr[mid]);
    if (arr[low] > arr[high]) swap(arr[low], arr[high]);
    if (arr[mid] > arr[high]) swap(arr[mid], arr[high]);
    swap(arr[mid], arr[high - 1]);  // 将中值放到high-1位置
    return arr[high - 1];
}

// 小数组使用插入排序优化
const int INSERTION_SORT_THRESHOLD = 10;
void quickSortOptimized(vector<int>& arr, int low, int high) {
    if (high - low < INSERTION_SORT_THRESHOLD) {
        // 插入排序
        for (int i = low + 1; i <= high; i++) {
            int key = arr[i], j = i - 1;
            while (j >= low && arr[j] > key)
                arr[j + 1] = arr[j--];
            arr[j + 1] = key;
        }
        return;
    }
    
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSortOptimized(arr, low, pi - 1);
        quickSortOptimized(arr, pi + 1, high);
    }
}
```

### 📌 时间复杂度分析

|情况|时间复杂度|说明|
|---|---|---|
|最好情况|O(n log n)|每次分区都均匀分割|
|平均情况|O(n log n)|随机输入下表现优秀|
|最坏情况|O(n²)|已排序数组+固定选基准|

**最坏情况示例**：

```
数组: [1, 2, 3, 4, 5, 6, 7]
基准总是选第一个元素

分区结果:
[] [1] [2,3,4,5,6,7]
   [] [2] [3,4,5,6,7]
      [] [3] [4,5,6,7]
...
退化为O(n²)
```

### 📌 空间复杂度

- **空间复杂度**：O(log n)（递归栈）
- 最坏情况：O(n)

### 📌 算法特性

|特性|说明|
|---|---|
|**稳定性**|❌ 不稳定排序|
|**原地排序**|✅ 只需要O(log n)额外空间|
|**适应性**|对输入数据敏感，需要优化|

### 📊 核心对比表

|对比项|归并排序|快速排序|

## 五、经典竞赛应用

### 🏆 应用1：逆序对计数（归并排序经典应用）

```cpp
// 统计数组中逆序对的数量
long long mergeAndCount(vector<int>& arr, int left, int mid, int right) {
    vector<int> temp;
    int i = left, j = mid + 1;
    long long count = 0;
    
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp.push_back(arr[i++]);
        } else {
            temp.push_back(arr[j++]);
            count += (mid - i + 1);  // 关键：统计逆序对
        }
    }
    
    while (i <= mid) temp.push_back(arr[i++]);
    while (j <= right) temp.push_back(arr[j++]);
    
    for (int k = 0; k < temp.size(); k++)
        arr[left + k] = temp[k];
    
    return count;
}

long long countInversions(vector<int>& arr, int left, int right) {
    if (left >= right) return 0;
    int mid = left + (right - left) / 2;
    
    long long count = 0;
    count += countInversions(arr, left, mid);
    count += countInversions(arr, mid + 1, right);
    count += mergeAndCount(arr, left, mid, right);
    
    return count;
}
```

### 🏆 应用2：第K大元素（快速排序思想）

```cpp
// 快速选择算法 - 找第k大元素
int quickSelect(vector<int>& arr, int low, int high, int k) {
    if (low == high) return arr[low];
    
    int pi = partition(arr, low, high);
    int rank = high - pi + 1;  // pi位置元素的排名
    
    if (rank == k) return arr[pi];
    else if (rank > k) return quickSelect(arr, pi + 1, high, k);
    else return quickSelect(arr, low, pi - 1, k - rank);
}
```

### ⚠️ 常见错误

|错误类型|说明|避免方法|
|---|---|---|
|边界错误|mid计算、递归终止条件|画图验证边界|
|溢出问题|mid = (left+right)/2可能溢出|使用 left+(right-left)/2|
|死递归|分区后子问题规模未减小|确保基准元素不参与下次递归|
|稳定性误解|快排不稳定但有时需要稳定|需要稳定时用归并|
