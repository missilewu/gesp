
同学们好，我是你们的GESP/NOI/IOI竞赛老师。二分算法是信息学竞赛中**性价比最高**的算法之一，核心思想是**“通过排除一半的可能性来快速缩小范围”**。

它的本质是将线性复杂度 $O(N)$ 优化为对数复杂度 $O(\log N)$。下面我简明扼要地讲解两个核心考点：

---

### 1. 二分查找 (Binary Search)
**适用场景**：在**有序**序列（单调递增或递减）中查找特定值，或查找满足某种性质的边界位置。

*   **核心逻辑**：
    维护一个区间 $[L, R]$，每次取中点 $mid = L + (R - L) / 2$。
    *   若 $a[mid]$ 等于目标值，直接返回。
    *   若 $a[mid]$ 小于目标值（升序），说明目标在右半区，令 $L = mid + 1$。
    *   若 $a[mid]$ 大于目标值（升序），说明目标在左半区，令 $R = mid - 1$。
*   **竞赛高频变种**：**查找边界**（Lower Bound / Upper Bound）。
    *   例如：查找第一个 $\ge x$ 的位置，或最后一个 $\le x$ 的位置。
    *   **关键点**：当 $a[mid]$ 满足条件时，不能直接返回，而要记录答案并继续向更优方向收缩（如 $R = mid$ 或 $L = mid$），直到 $L=R$。
*   **时间复杂度**：$O(\log N)$。
*   **易错点**：
    *   死循环：更新区间时必须是 `L = mid + 1` 或 `R = mid - 1`，或者在使用 `L = mid` 时配合向上取整的中点公式。
    *   溢出：计算中点请用 `L + (R - L) / 2` 而非 `(L + R) / 2`（虽然现代编译器通常能优化，但这是好习惯）。

---

### 2. 二分答案 (Binary Search on Answer)
**适用场景**：题目所求的答案具有**单调性**。即：如果答案 $x$ 可行，那么所有比 $x$ 更小（或更大）的值也都可行/不可行。常用于解决“最大化最小值”或“最小化最大值”问题。

*   **核心逻辑**：
    1.  **确定范围**：找到答案可能的最小值 $L$ 和最大值 $R$。
    2.  **构造检查函数 `check(mid)`**：这是灵魂所在。编写一个函数，判断当答案为 $mid$ 时，是否满足题目要求（通常用贪心或模拟实现）。
    3.  **二分过程**：
        *   若 `check(mid)` 为真：记录 $mid$ 为潜在答案，并根据单调性尝试更优解（如求最小值则 $R = mid - 1$，求最大值则 $L = mid + 1$）。
        *   若 `check(mid)` 为假：调整区间排除 $mid$。
*   **典型例题**：
    *   “使最大距离最小化”（如：在数轴上放 $M$ 个点，使任意两点间最小距离最大）。
    *   “完成工作的最少天数”。
*   **时间复杂度**：$O(\text{check函数复杂度} \times \log(\text{答案范围}))$。
*   **关键技巧**：
    *   **整数二分**：注意死循环问题（当 $L=mid$ 时，$mid$ 需向上取整）。
    *   **实数二分**：当答案可以是小数时，通常设定一个精度 $\epsilon$（如 $1e-6$），当 $R - L > \epsilon$ 时循环，不需要考虑 $+1/-1$，直接 $L=mid, R=mid$ 即可。

---

### 老师总结 (Takeaway)
1.  **看到“有序”、“单调”、“最大值最小化”**，第一时间联想二分。
2.  **二分查找**是对**数组下标**进行二分；**二分答案**是对**最终结果数值**进行二分，必须配合 `check` 函数。
3.  **模板要熟**：竞赛中建议背诵一套自己最熟悉的整数二分模板（区分找左边界和右边界），避免现场推导导致死循环。

在NOI（全国青少年信息学奥林匹克竞赛）和IOI（国际信息学奥林匹克竞赛）中，二分算法不仅仅是用来“查找数字”的，它更是一种**解决最优化问题的核心思维工具**。

根据历年真题统计，二分算法的应用主要集中在以下四大类场景：

### 1. “最大值最小化”与“最小值最大化” (二分答案)
这是二分算法在竞赛中**最高频、最重要**的应用场景。题目通常不直接让你求最优解，而是问“在满足某些条件下，最大的最小值是多少？”或“最小的最大值是多少？”。

*   **核心特征**：答案具有单调性。如果答案 $X$ 可行，那么比 $X$ 更“宽松”的值一定也可行。
*   **经典题型**：
    *   **跳石头 (NOIP 2015 / 洛谷 P2678)**：移除 $M$ 块石头，使得剩余石头间的最小距离最大。
        *   *思路*：二分“最小距离” $d$，用贪心法检查是否能移除不超过 $M$ 块石头使得所有间距 $\ge d$。
    *   **数列分段 (洛谷 P1182)**：将数列分成 $M$ 段，使每段和的最大值最小。
        *   *思路*：二分“最大段和” $S$，贪心检查能否在每段和不超过 $S$ 的情况下分成 $\le M$ 段。
    *   **愤怒的牛 (类似题目)**：安排牛棚位置，使最近的两头牛距离最大。
    *   **网线主管 (POJ 1064 / IOI 相关训练)**：切割 $K$ 条等长网线，求最大长度（实数二分）。

### 2. 复杂数据结构中的边界查找 (二分查找进阶)
在涉及高级数据结构（如线段树、平衡树、树状数组）或复杂字符串处理时，二分常作为子过程出现，用于快速定位。

*   **核心特征**：数据有序或具有前缀性质，需要 $O(\log N)$ 定位。
*   **经典题型**：
    *   **第 $K$ 大/小值问题**：在权值线段树上二分，或者在归并树（Merge Sort Tree）上二分查找区间内第 $K$ 小的数。
    *   **最长公共子串 (LCP)**：结合后缀数组 (SA) 或哈希 (Hash)。
        *   *思路*：二分答案“长度 $L$”，检查是否存在长度为 $L$ 的公共子串（通过哈希表或后缀数组的 $height$ 数组分组检查）。
    *   **动态规划优化**：某些 $DP$ 转移方程具有单调性，可以用二分查找优化状态转移（例如寻找第一个满足 $dp[j] + cost > val$ 的位置），将 $O(N^2)$ 优化为 $O(N \log N)$。

### 3. 实数域上的精度问题 (实数二分)
当答案不是整数，且要求保留若干位小数时，使用实数二分。这类题目通常涉及几何、物理模拟或比例分配。

*   **核心特征**：答案范围连续，通过设定精度 $\epsilon$ (如 $10^{-6}$) 终止循环。
*   **经典题型**：
    *   **最佳牛围栏 (POJ 2018 / 洛谷 P2985)**：求平均值最大的连续子段（长度 $\ge F$）。
        *   *思路*：二分“平均值的最大值” $avg$，将数组每个数减去 $avg$，转化为判断是否存在和 $\ge 0$ 的子段（前缀和 + 最小前缀维护）。
    *   **几何切割问题**：如切蛋糕、分披萨，要求面积比例或长度比例满足条件。
    *   **迭代求解**：某些方程无法直接解出，但函数单调，可通过二分逼近根。

### 4. 结合其他算法的“嵌套二分”
在IOI级别的难题中，二分往往不是单独出现的，而是作为外层框架，内部嵌套贪心、图论、动态规划或并查集。

*   **经典题型**：
    *   **最小生成树 (MST) 的变种**：给定边权限制，求满足连通性的最小瓶颈值。
        *   *思路*：二分边权上限 $W$，只保留权值 $\le W$ 的边，用并查集检查是否连通。
    *   **网络流/匹配问题**：
        *   *思路*：二分时间 $T$ 或容量 $C$，构建对应的图模型（如拆点、限制边容量），跑最大流判断是否满流。例如“在 $T$ 时间内能否运送完所有货物”。
    *   **树上路径问题**：
        *   *思路*：二分路径长度限制，结合树上差分或点分治来验证可行性。

### 老师给同学的备考建议

1.  **识别“单调性”是第一步**：
    看到题目问“至少”、“至多”、“最大中的最小”、“最小中的最大”，或者让你求一个**阈值**，立刻思考：**如果我猜一个答案，能不能在 $O(N)$ 或 $O(N \log N)$ 的时间内验证它是否正确？** 如果能，就是二分答案。

2.  **掌握 `check` 函数的构造**：
    二分答案的难点不在二分本身，而在 `check` 函数。
    *   如果是**区间问题**，通常用**贪心**。
    *   如果是**平均值问题**，通常用**前缀和变换**（减去二分值）。
    *   如果是**图论问题**，通常用**并查集**或**最短路/最大流**。

3.  **注意整数与实数的区别**：
    *   **整数二分**：死磕边界，`L = mid + 1`, `R = mid - 1` 还是 `L = mid`, `R = mid`？一定要想清楚，防止死循环。
    *   **实数二分**：不用纠结 $+1/-1$，直接 `L = mid`, `R = mid`，循环条件设为 `R - L > eps`。

4.  **熟悉 STL**：
    C++ 选手必须熟练掌握 `std::lower_bound` 和 `std::upper_bound`，它们能帮你快速解决基础的二分查找问题，把精力留给复杂的 `check` 函数逻辑。

**总结**：在NOI/IOI中，二分算法是**“化繁为简”**的利器。它将一个难求的最优化问题，转化为了一个容易验证的判定性问题。掌握它，你就掌握了通往金牌的一半钥匙！
