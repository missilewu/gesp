
# 贪心算法详解

你好！我是你的算法竞赛老师。今天我们来系统学习**贪心算法**，这是GESP、NOI、IOI等竞赛中的核心算法之一。

---

## 一、贪心算法的相关概念

### 1.1 什么是贪心算法？

**贪心算法（Greedy Algorithm）** 是一种在每一步选择中都采取**当前状态下最优选择**的算法策略。它希望通过局部最优选择，最终达到全局最优解。

```
核心思想：每一步都选"看起来最好"的选项，期望最终结果也是最好的
```

### 1.2 贪心算法的基本特征

|特征|说明|
|---|---|
|**贪心选择性质**|可以通过局部最优选择来构造全局最优解|
|**无后效性**|一旦做出选择，就不会再改变之前的决策|
|**自顶向下**|从初始状态开始，逐步做出选择，直到问题解决|

### 1.3 贪心算法的适用条件

贪心算法**不是万能**的，只有满足以下条件才能使用：

```
✅ 问题具有贪心选择性质
✅ 问题具有最优子结构
✅ 局部最优能推导出全局最优
```

### 1.4 经典贪心问题示例

|问题|贪心策略|
|---|---|
|活动选择问题|每次选择结束时间最早的活动|
|霍夫曼编码|每次合并频率最小的两个节点|
|最小生成树(Prim/Kruskal)|每次选择权重最小的边|
|背包问题(分数背包)|每次选择单位价值最高的物品|
|区间覆盖问题|每次选择能覆盖最远距离的区间|

### 1.5 贪心算法的模板框架

```cpp
// 贪心算法通用框架
GreedyAlgorithm(问题) {
    解 = 空集;
    
    while(问题未解决) {
        选择 = 当前最优选择();  // 贪心选择
        
        if(选择可行) {
            解 = 解 + 选择;
            问题 = 剩余子问题;
        }
    }
    
    return 解;
}
```

### 1.6 贪心算法的优缺点

**优点：**

- ✅ 时间复杂度通常较低
- ✅ 实现简单，代码量少
- ✅ 空间复杂度低

**缺点：**

- ❌ 不是所有问题都适用
- ❌ 需要证明贪心策略的正确性
- ❌ 容易陷入局部最优，得不到全局最优

## 二、最优子结构

### 2.1 什么是最优子结构？

**最优子结构（Optimal Substructure）** 是指：**一个问题的最优解包含其子问题的最优解**。

```
核心定义：如果问题的最优解可以通过子问题的最优解构造出来，
         则该问题具有最优子结构性质
```

### 2.2 最优子结构的数学表达

```
设问题P的最优解为S
如果S可以分解为 S = {选择a} ∪ S'
其中S'是子问题P'的最优解
则问题P具有最优子结构
```

### 2.3 最优子结构与贪心算法的关系

```
┌─────────────────────────────────────────┐
│         贪心算法成立的两个条件           │
├─────────────────────────────────────────┤
│  1️⃣ 贪心选择性质                         │
│     (局部最优选择能导致全局最优)          │
│                                         │
│  2️⃣ 最优子结构性质                       │
│     (原问题最优解包含子问题最优解)        │
└─────────────────────────────────────────┘
```

### 2.4 经典案例分析

#### 案例1：活动选择问题（具有最优子结构）

**问题描述：** 给定n个活动，每个活动有开始时间si和结束时间fi，选择最多的互不冲突的活动。

**贪心策略：** 每次选择结束时间最早的活动

**最优子结构证明：**

```
假设A是原问题的最优解，包含活动a1（结束最早）
剩余活动集合为 S' = {活动 | 开始时间 ≥ a1的结束时间}
如果A'是S'的最优解，则 A = {a1} ∪ A' 也是原问题最优解
```

#### 案例2：0-1背包问题（不具有贪心选择性质）

**问题描述：** n个物品，重量wi，价值vi，背包容量W，每个物品只能选或不选。

```
❌ 贪心策略失败示例：
物品1: 重量10, 价值60, 单位价值6
物品2: 重量20, 价值100, 单位价值5
物品3: 重量30, 价值120, 单位价值4
背包容量: 50

按单位价值贪心：选物品1(10) + 物品2(20) = 重量30, 价值160
最优解：选物品2(20) + 物品3(30) = 重量50, 价值220

结论：0-1背包问题不具有贪心选择性质，需用动态规划
```

### 2.5 如何证明最优子结构？

**证明步骤：**

```
步骤1：假设原问题有一个最优解S
步骤2：证明S中包含的第一个贪心选择a是安全的
步骤3：证明剩余子问题的最优解S'与a组合后仍是原问题最优解
步骤4：用数学归纳法或反证法完成证明
```

**证明模板：**

```
定理：贪心算法能得到问题P的最优解

证明：
1. 设O是问题P的任意最优解
2. 设G是贪心算法得到的解
3. 证明|G| ≥ |O|（或相应优化目标）
4. 由于O是最优解，故|O| ≥ |G|
5. 因此|G| = |O|，G也是最优解 □
```

### 2.6 最优子结构 vs 动态规划

|特性|贪心算法|动态规划|
|---|---|---|
|最优子结构|✅ 必需|✅ 必需|
|贪心选择性质|✅ 必需|❌ 不需要|
|子问题重叠|❌ 不需要|✅ 必需|
|决策方式|当前最优|枚举所有可能|
|时间复杂度|通常较低|通常较高|

## 三、实战建议

### 3.1 竞赛中的贪心题识别

```
🔍 看到以下特征可考虑贪心：
• 求最大值/最小值
• 每一步有明确的"最优"选择标准
• 选择后问题规模减小
• 数据范围较大（暗示需要O(n)或O(nlogn)解法）
```

### 3.2 验证贪心正确性的方法

1. **数学证明**：严谨但难度大
2. **对拍验证**：与暴力解法对比小数据
3. **反例构造**：尝试找反例，找不到则可能正确
4. **归纳法**：证明n=k成立时n=k+1也成立

```
GESP 3-4级 → 基础贪心（区间、排序类）

NOIP      → 贪心+其他算法综合
NOI/IOI   → 复杂贪心证明与构造
```

# 贪心算法正确性证明详解

你好！这是算法竞赛中最核心也最具挑战性的内容。证明贪心算法能得到最优解，是区分普通选手和顶尖选手的关键能力。

---

## 一、证明的核心框架

### 1.1 为什么需要证明？

```
⚠️ 贪心算法的致命陷阱：
局部最优 ≠ 全局最优

反例：0-1背包问题
物品1: 重量10, 价值60, 单位价值6
物品2: 重量20, 价值100, 单位价值5  
物品3: 重量30, 价值120, 单位价值4
背包容量: 50

贪心策略（按单位价值）: 选物品1+物品2 = 价值160
实际最优解: 选物品2+物品3 = 价值220

结论：没有证明的贪心=错误答案
```

### 1.2 证明的两大支柱

```
┌────────────────────────────────────────────────────┐
│          贪心算法正确性证明的必要条件               │
├────────────────────────────────────────────────────┤
│                                                    │
│  ① 贪心选择性质 (Greedy Choice Property)           │
│     存在一个最优解包含当前的贪心选择                │
│                                                    │
│  ② 最优子结构性质 (Optimal Substructure)          │
│     做出贪心选择后，剩余子问题的最优解 + 贪心选择   │
│     = 原问题的最优解                               │
│                                                    │
└────────────────────────────────────────────────────┘
```

---

## 二、三大证明方法

### 2.1 数学归纳法 (Mathematical Induction)

**适用场景：** 问题具有明显的"规模递减"特征

**证明步骤：**

```
步骤1：陈述命题 P(n)
       "贪心算法对规模为n的问题能得到最优解"

步骤2：归纳基础 (Base Case)
       证明 P(1) 成立（最小规模问题）

步骤3：归纳假设 (Inductive Hypothesis)
       假设 P(k) 对所有 k < n 成立

步骤4：归纳步骤 (Inductive Step)
       证明 P(n) 成立：
       - 贪心选择第一个元素 g
       - 证明存在最优解包含 g
       - 剩余子问题规模为 n-1，由归纳假设得最优解
       - 组合后得到原问题最优解
```

**经典案例：活动选择问题**

```cpp
// 问题：选择最多的互不冲突活动
// 贪心策略：每次选结束时间最早的活动

【完整证明】

定理：贪心算法能得到活动选择问题的最优解

证明（数学归纳法）：

1️⃣ 归纳基础：n=1时
   只有一个活动，贪心选择它，显然最优 ✓

2️⃣ 归纳假设：
   假设对任意 k < n 个活动，贪心算法能得到最优解

3️⃣ 归纳步骤：考虑 n 个活动
   设活动按结束时间排序：f₁ ≤ f₂ ≤ ... ≤ fₙ
   
   贪心选择：活动1（结束最早）
   
   关键引理：存在一个最优解包含活动1
   
   证明引理：
   设 O 是任意最优解
   - 若 O 包含活动1，引理成立 ✓
   - 若 O 不包含活动1，设 O 中第一个活动是活动k
     由于 f₁ ≤ fₖ，活动1结束得更早
     用活动1替换活动k，仍与O中其他活动兼容
     得到新解 O'，|O'| = |O|，也是最优解 ✓
   
   剩余子问题：
   选择与活动1兼容的剩余活动（开始时间 ≥ f₁）
   子问题规模 < n，由归纳假设，贪心得到最优解
   
   因此：{活动1} ∪ 子问题最优解 = 原问题最优解 ✓

证毕 □
```

---

### 2.2 交换论证法 (Exchange Argument)

**适用场景：** 需要比较贪心解与任意最优解的关系

**这是竞赛中最常用、最强大的证明方法！**

**证明步骤：**

```
步骤1：设 G 是贪心算法得到的解
       设 O 是任意一个最优解

步骤2：假设 G ≠ O（反证法思想）
       找到第一个不同的位置 i，使得 gᵢ ≠ oᵢ

步骤3：构造新解 O'
       将 O 中的 oᵢ 替换为 gᵢ
       调整后续选择以保持可行性

步骤4：证明 O' 仍是最优解
       - 可行性：O' 满足所有约束
       - 最优性：|O'| ≥ |O|（目标值不下降）

步骤5：重复交换，最终 O 变成 G
       因此 G 也是最优解
```

**经典案例：霍夫曼编码**

```
【问题】构造最优前缀码，使编码总长度最小

【贪心策略】每次合并频率最小的两个节点

【交换论证证明】

1️⃣ 设贪心解为 G，最优解为 O

2️⃣ 考虑频率最小的两个字符 a 和 b
   贪心算法：a 和 b 在树的最深层，且为兄弟
    
3️⃣ 若 O 中 a 和 b 不是最深层的兄弟
   设最深层兄弟是 x 和 y，频率 f(x) ≥ f(a), f(y) ≥ f(b)
    
4️⃣ 交换论证：
   在 O 中交换 (a,b) 与 (x,y) 的位置
    
   交换前成本：f(a)·d(a) + f(b)·d(b) + f(x)·d(x) + f(y)·d(y)
   交换后成本：f(a)·d(x) + f(b)·d(y) + f(x)·d(a) + f(y)·d(b)
    
   成本变化：
   Δ = [f(a)·d(x) + f(b)·d(y) + f(x)·d(a) + f(y)·d(b)]
     - [f(a)·d(a) + f(b)·d(b) + f(x)·d(x) + f(y)·d(y)]
    
   由于 d(x) = d(y) = D（最深层）, d(a) ≤ D, d(b) ≤ D
   且 f(x) ≥ f(a), f(y) ≥ f(b)
   
   可证 Δ ≤ 0，交换后成本不增加 ✓

5️⃣ 因此存在最优解使 a 和 b 为最深层兄弟
   合并 a 和 b 后，问题规模减小
   递归应用，贪心解 = 最优解 ✓

证毕 □
```

---

### 2.3 反证法 (Proof by Contradiction)

**适用场景：** 直接证明困难时，假设结论不成立推出矛盾

**证明步骤：**

```
步骤1：假设贪心解 G 不是最优解

步骤2：设 O 是最优解，且 cost(O) < cost(G)（或 |O| > |G|）

步骤3：分析 G 和 O 的差异
       找到导致矛盾的关键点

步骤4：推出矛盾
       说明假设不成立

步骤5：因此 G 是最优解
```

**经典案例：区间覆盖问题**

```
【问题】用最少的区间覆盖 [0, M]

【贪心策略】每次选择能覆盖当前起点且右端点最远的区间

【反证法证明】

1️⃣ 假设贪心解 G 不是最优解
   设最优解 O 使用的区间数更少：|O| < |G|

2️⃣ 设 G = {g₁, g₂, ..., gₖ}，O = {o₁, o₂, ..., oₘ}
   其中 k > m

3️⃣ 比较两个解的选择：
   - g₁ 是覆盖0且右端点最远的区间
   - o₁ 是 O 中覆盖0的某个区间
   - 因此 right(g₁) ≥ right(o₁)

4️⃣ 归纳地，对第 i 个区间：
   right(gᵢ) ≥ right(oᵢ)（贪心每次选最远的）

5️⃣ 矛盾推导：
   - O 用 m 个区间覆盖了 [0, M]
   - G 的前 m 个区间覆盖范围 ≥ O 的 m 个区间
   - 因此 G 的前 m 个区间也应覆盖 [0, M]
   - 但 G 用了 k > m 个区间，矛盾！

6️⃣ 因此假设不成立，G 是最优解 ✓

证毕 □
```

## 四、竞赛实战技巧

### 4.1 证明的"套路"模板

```cpp
// 交换论证法模板
证明贪心解G最优：

1. 设O为任意最优解
2. 若 G == O，得证 ✓
3. 否则，找到第一个不同位置 i
4. 构造 O'：将 O 的 oᵢ 替换为 gᵢ
5. 证明 O' 可行且最优
6. 重复直到 O 变成 G
7. 因此 G 最优 ✓
```

### 4.2 常见证明陷阱

```
❌ 陷阱1：只证明"交换后不更差"，没证明"最终能变成贪心解"
   正确：需要证明有限步内 O 能转化为 G

❌ 陷阱2：忽略可行性保持
   正确：必须证明交换后仍满足所有约束

❌ 陷阱3：归纳基础不完整
   正确：验证最小规模情况（n=0,1,2）

❌ 陷阱4：混淆"存在最优解包含贪心选择"与"所有最优解包含"
   正确：只需证明存在一个即可
```

### 4.3 考场上的证明策略

```
📝 时间分配建议：
• 简单贪心（排序类）：2-3分钟验证
• 中等贪心（区间类）：5-8分钟证明
• 困难贪心（构造类）：10+分钟或先写暴力对拍

📝 验证方法（当无法严格证明时）：
1. 小数据暴力对拍
2. 尝试构造反例
3. 分析边界情况
4. 参考类似问题的证明思路
```
