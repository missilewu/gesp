
同学们好，我是你们的GESP/NOI/IOI教练。在C++中，`long long` 最大只能存到 $10^{18}$ 左右，而竞赛中常出现几百甚至上千位的整数运算，这时必须使用**高精度算法**。

核心思想：**用数组模拟竖式运算**。
*   **存储方式**：通常将大整数的**低位存在数组下标小**的位置（倒序存储），方便进位和处理长度。
*   **数据结构**：`vector<int>` 或 `int a[N]`。

以下是四则运算的核心逻辑与代码模板：

---

### 1. 高精度加法 (High Precision Addition)
**逻辑**：从低位到高位逐位相加，处理进位 `t`。若最后 `t` 不为0，需额外补一位。
**适用**：$A + B$ ($A, B \ge 0$)

```cpp
vector<int> add(vector<int> &A, vector<int> &B) {
    if (A.size() < B.size()) return add(B, A); // 保证A更长，可选优化
    vector<int> C;
    int t = 0; // 进位
    for (int i = 0; i < A.size() || i < B.size() || t; i++) {
        if (i < A.size()) t += A[i];
        if (i < B.size()) t += B[i];
        C.push_back(t % 10); // 当前位
        t /= 10;             // 新的进位
    }
    return C;
}
```

---

### 2. 高精度减法 (High Precision Subtraction)
**逻辑**：先比较大小。若 $A < B$，输出负号并计算 $B-A$。逐位相减，处理借位 `t`（若结果为负，借位为1，当前位加10）。
**适用**：$A - B$ ($A, B \ge 0$)

```cpp
// 比较 A >= B ?
bool cmp(vector<int> &A, vector<int> &B) {
    if (A.size() != B.size()) return A.size() > B.size();
    for (int i = A.size() - 1; i >= 0; i--)
        if (A[i] != B[i]) return A[i] > B[i];
    return true;
}

vector<int> sub(vector<int> &A, vector<int> &B) {
    vector<int> C;
    int t = 0; // 借位标记
    for (int i = 0; i < A.size(); i++) {
        t = A[i] - t;
        if (i < B.size()) t -= B[i];
        C.push_back((t + 10) % 10); // 处理负数情况
        if (t < 0) t = 1; else t = 0;
    }
    // 去除前导零 (注意结果至少保留一位0)
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```

---

### 3. 高精度乘法 (High Precision Multiplication)
#### 情况A：高精度 × 低精度 (Big Int × int)
**逻辑**：逐位乘，处理进位。
```cpp
vector<int> mul(vector<int> &A, int b) {
    vector<int> C;
    int t = 0;
    for (int i = 0; i < A.size() || t; i++) {
        if (i < A.size()) t += A[i] * b;
        C.push_back(t % 10);
        t /= 10;
    }
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```

#### 情况B：高精度 × 高精度 (Big Int × Big Int) - **NOI/IOI重点**
**逻辑**：双重循环模拟竖式。$A[i] \times B[j]$ 的结果累加到 $C[i+j]$ 位置。
**注意**：结果长度最大为 $len(A) + len(B)$。
```cpp
vector<int> mul(vector<int> &A, vector<int> &B) {
    vector<int> C(A.size() + B.size(), 0);
    for (int i = 0; i < A.size(); i++)
        for (int j = 0; j < B.size(); j++)
            C[i + j] += A[i] * B[j];
    
    int t = 0;
    for (int i = 0; i < C.size(); i++) {
        t += C[i];
        C[i] = t % 10;
        t /= 10;
    }
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```

---

### 4. 高精度除法 (High Precision Division)
**逻辑**：从**高位到低位**模拟竖式（与加减乘相反）。余数 `r` 初始为0，每一步 `r = r * 10 + A[i]`，当前商为 `r / b`，新余数为 `r % b`。最后需反转结果数组（因为是从高位算的，存入是顺序，但输出习惯低位在前或需统一格式）。
**适用**：$A / b$ (商和余数)

```cpp
// A / b, 返回商，r引用返回余数
vector<int> div(vector<int> &A, int b, int &r) {
    vector<int> C;
    r = 0;
    for (int i = A.size() - 1; i >= 0; i--) { // 从高位开始
        r = r * 10 + A[i];
        C.push_back(r / b);
        r %= b;
    }
    reverse(C.begin(), C.end()); // 转回低位在前的存储格式
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```
*(注：高精度除以高精度较复杂，通常涉及二分答案或估商，基础阶段先掌握高精除低精)*

### 💡 教练的备考Tips：
1.  **输入输出模板**：记得写一个字符串转 `vector` (倒序) 和 `vector` 转字符串输出的辅助函数，避免主逻辑混乱。
2.  **前导零**：减法和乘法后务必检查并去除前导零，否则判题系统会判错（PE或WA）。
3.  **压位优化**：在IOI或极高难度题目中，可将数组每位存 $10^9$ (即 `int` 范围)，利用 `long long` 暂存中间结果，可将运算速度提升约9倍，减少常数时间。
4.  **调试技巧**：打印数组时，务必**从后往前**打印（因为我们是倒序存的）。

掌握这四个模板，GESP高阶及NOIP普及组的高精度题目即可拿下。加油！



作为你们的竞赛教练，我要明确告诉大家：**在IOI（国际信息学奥林匹克）及NOI（全国青少年信息学奥林匹克）的高级别赛事中，直接使用“数组模拟竖式”的高精度算法（即 $O(N^2)$ 复杂度的朴素高精度）通常是不够的，甚至会导致超时（TLE）。**

IOI级别的题目数据范围极大（往往达到 $10^{1000}$ 甚至更高），且对时间复杂度要求极高。高精度运算在IOI中的应用主要体现在以下几个**高阶场景**和**优化策略**中：

### 1. 核心应用场景

#### A. 组合数学与大数计数 (Combinatorics & Counting)
*   **场景**：计算路径数、方案数、排列组合（如 $C_n^m$）、卡特兰数等。
*   **挑战**：结果往往远超 `unsigned long long` 范围。
*   **IOI级解法**：
    *   **质因数分解法**：不直接进行大数乘除，而是将分子分母分解质因数，统计每个质因子的指数（加减法），最后用高精度乘法一次性算出结果。这能将复杂度从 $O(N^2)$ 降下来。
    *   **应用实例**：NOI/IOI 中常见的网格路径问题、树的结构计数问题。

#### B. 动态规划中的大数状态 (DP with Big Integers)
*   **场景**：DP的状态值表示方案数或极大权值，转移方程涉及加法或乘法。
*   **挑战**：如果DP层数多且每层都进行 $O(N^2)$ 的高精度加法，总复杂度会爆炸。
*   **IOI级解法**：
    *   通常结合**矩阵快速幂**。此时需要实现“高精度矩阵乘法”，必须使用**FFT/NTT优化**的大数乘法，否则无法通过。
    *   或者利用**取模性质**：如果题目只要求输出后几位或对某数取模，则完全不需要高精度，直接用 `long long` 取模即可（这是最常见的陷阱，很多同学没看清题就写高精度）。

#### C. 数论与密码学基础 (Number Theory)
*   **场景**：大整数分解、GCD、模逆元、RSA算法模拟等。
*   **IOI级解法**：
    *   需要实现高效的**高精度取模**、**高精度快速幂**。
    *   对于超大整数的GCD，可能涉及到更高级的算法（如Lehmer GCD算法），而不仅仅是模拟竖式除法。

#### D. 几何与计算 (Computational Geometry)
*   **场景**：坐标值极大，计算面积、叉积时避免浮点数误差。
*   **IOI级解法**：使用高精度整数代替 `double` 进行精确计算，确保判断点在线段哪一侧等操作绝对准确。

### 2. IOI级别的“生存法则”：必须掌握的优化

如果在IOI赛场上你只写了朴素的 $O(N^2)$ 高精度乘法，遇到 $N=10^5$ 位的大数相乘，你的程序会运行几小时甚至几天。因此，以下优化是必须的：

#### ① 压位优化 (Base Compression) - **基础必会**
*   **原理**：不用 `int` 存 1 位（0-9），而是存 4 位（0-9999）甚至 9 位（0-999999999，配合 `long long` 运算）。
*   **效果**：数组长度缩小为原来的 $1/4$ 或 $1/9$，运算次数减少为原来的 $1/16$ 或 $1/81$。
*   **代码示意**：
    ```cpp
    // 压9位，基数为 1e9
    const int BASE = 1e9; 
    // 输入时每次读9个字符转为一个int
    // 输出时注意补前导零 (printf("%09d", x))
    ```

#### ② FFT / NTT 优化乘法 - **进阶核心**
*   **原理**：利用**快速傅里叶变换 (FFT)** 或 **数论变换 (NTT)**，将多项式乘法（即大数乘法）的复杂度从 $O(N^2)$ 降低到 **$O(N \log N)$**。
*   **地位**：这是IOI金牌选手处理万位以上大数乘法的标配技能。
*   **应用**：当位数 $N > 2000$ 时，朴素算法必挂，必须上FFT/NTT。
*   **注意**：FFT涉及浮点数误差，需小心处理；NTT基于模数运算，无误差但需找原根。

#### ③ 牛顿迭代法求倒数/开方
*   **场景**：高精度除法（大数除以大数）或高精度开方。
*   **原理**：利用牛顿迭代公式 $x_{n+1} = x_n(2 - Ax_n)$ 快速逼近倒数，再转化为乘法。
*   **复杂度**：配合FFT乘法，可将除法复杂度也优化至 $O(N \log N)$。

### 3. 教练的特别叮嘱 (Exam Strategy)

1.  **先看是否需要高精度**：
    *   很多题目看似是大数，实则要求输出 **$\pmod M$**。如果是这样，全程取模即可，**千万不要写高精度**，写了反而慢且容易错。
    *   有些题目只要求比较大小，不需要算出具体值，可能只需比较位数或最高位。

2.  **Python/C++ BigInt 库的使用限制**：
    *   **IOI/NOI规则**：通常允许使用C++，但不允许使用非标准库的大数类（如GMP）。C++标准库没有内置高精度，**必须手写**。
    *   **Python选手注意**：虽然Python自带高精度，但在IOI中，Python的运行速度较慢。如果涉及 $10^5$ 位的大数运算，Python自带的算法（通常是Karatsuba或更优）虽然比朴素C++快，但仍可能因为解释器开销或特定测试点被卡常。**在极端数据下，C++ + NTT 依然是王道。**

3.  **调试心态**：
    *   高精度代码量大，极易出错（特别是边界、进位、前导零）。在考场上，如果必须写高精度，建议先写好一个**对拍程序**（生成随机大数，对比自己的高精度程序和Python/Java自带大数的结果），确保模板无误后再代入解题逻辑。

### 总结
在IOI中，高精度不仅仅是一个“工具”，它往往考察的是你对**算法复杂度**的理解。
*   **普及组/提高组**：掌握压位优化的朴素四则运算即可。
*   **省选/NOI/IOI**：必须掌握 **FFT/NTT优化乘法** 以及 **质因数分解优化组合数** 的技巧。
