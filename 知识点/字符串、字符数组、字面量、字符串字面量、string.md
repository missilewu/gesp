
# 字符串、字符数组、字面量、字符串字面量、string

最近在带Missile做GESP C++ 三级的真题过程中，发现他在字符串数组和字符串上的一些细节知识点上掌握的不扎实，容易踩到坑。因此，我和他一起系统的整理一下 GESP C++ 中**字符串、字符数组、字面量、字符串字面量、string** 这五个核心概念，厘清它们的定义、用法和区别。这是 C++ 字符串处理的基础，也是 GESP 考试以及NOI/IOI 入门的高频考点。

## 核心概念的理解
### 1. 字符串（广义抽象概念）

#### **定义**：

“字符串”是**一串字符的有序序列**，是一个抽象的逻辑概念，不是具体的语法元素。在 C++ 中，任何表示“一组字符”的形式（如：字符数组、string 对象、字符串字面量）都可以称为广义的“字符串”。

我们需要注意这个“串”字，在C++中，是通过**空字符**（常用**八进制转义字符**'\0'来表示，对应的ASCII码值是0）来表示“串”的结束。因此，我们有时候也把 '\0' 叫做**字符串结束符**。C/C++的标准库函数`strlen`、 `printf` 等就是根据这个'\0'来判断字符串的结束。

注意上面这段话里面的细节术语描述，都与高频的考点相关。

#### **考试视角**：

在考试题目中出现“处理字符串”等描述时，通常指处理**字符数组**或 **string** 类创建的对象，而非单纯的抽象概念。同时会结合**字符串字面量**和数组定义本身的特点出一些细节的考题。下面通过一个示例展示出常见的广义字符串。

#### **示例**：  （C++ 11及以上版本编译环境）

```cpp
#include <iostream>
using namespace std;

int main() {
    // 以下三种形式，都可以称为“字符串”（抽象概念）
    char arr[] = "hello"; // 字符数组形式的字符串
    string s = "world";   // string类形式的字符串
    cout << "GESP";       // 字符串字面量形式的字符串
    // 还有两种字符数组形式的字符串，通过逐个初始化元素实现“串”
    // 采用最后一个元素是'\0'的字符数组表示的“字符串”
    // 也会在考题中出现，注意'\0'的细节表示
    char str1[] = {'h', 'e', 'l', 'l', 'o', '\0'}; // 6个字符类型的元素，显示初始化'\0'
    char str2[6] = {'h', 'e', 'l', 'l', 'o'}; // 6个字符类型的元素，隐式初始化0，即'\0'
    return 0;
}
```

### 2. 字符数组（C风格字符串的具体实现）

#### **定义**：  

字符数组是存储 `char` 类型数据的数组，是 C 语言遗留的字符串实现方式，也是 C++ 兼容的底层形式。  
- **本质**：连续的字符存储空间，需以 `'\0'`（空字符，ASCII码的编码是 0）作为结束标志；  
- **特点**：长度固定（定义时、初始化时确定），可修改，需手动管理内存和结束符；  
- **考试场景**：在题目强制要求、处理底层字符操作（如逐字节读入）时使用，或者是为了极致的优化程序的运行效率时使用。

#### **示例**：

```cpp
#include <iostream>
#include <cstring> // 字符数组操作函数头文件
using namespace std;

int main() {
    // 正确初始化：自动补'\0'，长度=6（5个字符+1个'\0'）
    char str1[] = "GESP2026"; 
    // 手动初始化：
    // 开启 C++ 11 及以上标准的编译器可以不用加'\0'
    // 不支持 C++ 11的编译器，必须加'\0'，否则输出乱码
    char str2[6] = {'N','O','I','\0'}; 
    
    // 常用操作（需手动调用函数）
    cout << "str1长度：" << strlen(str1) << endl; // 输出：7（strlen忽略'\0'）
    cout << "str1内存长度：" << sizeof(str1) << endl; // 输出：8（包含'\0'）
    
    // 修改字符（合法，字符数组可写）
    str1[4] = '3'; 
    cout << str1 << endl; // 输出：GESP3026
    
    // 字符串拼接（需用strcat，且确保数组长度足够）
    strcat(str1, " NOIP"); 
    cout << str1 << endl; // 输出：GESP3026 NOIP
    
    return 0;
}
```

### 3. 字面量（常量值，程序中直接写死的“字面”值）

#### **定义**：  

**字面量**（Literal）是程序中直接书写的、无需变量存储的常量值，是“值本身”而非“存储值的容器”。  
按数据类型分类，可分为三类（高频考点）：

| 类型     | 示例                  | 说明                |
| ------ | ------------------- | ----------------- |
| 数值字面量  | `123`、`3.14`、`0x1A` | 整数、浮点数、十六进制数      |
| 字符字面量  | `'a'`、`'5'`、`'\n'`  | 单引号包裹，仅一个字符       |
| 字符串字面量 | `"hello"`、`"123\n"` | 双引号包裹，末尾自动加`'\0'` |

#### **关键点**：

字面量存储在内存的**只读区域**，不能修改（尤其是字符串字面量），否则会触发运行时错误。

#### **示例**：
```cpp
#include <iostream>
using namespace std;

int main() {
    // 1. 数值字面量：直接参与计算
    int a = 100 + 200; // 100、200是整型字面量
    double b = 3.14 * 2; // 3.14是浮点字面量
    
    // 2. 字符字面量：赋值给char变量
    char c = 'A'; // 'A'是字符字面量
    cout << c << endl; // 输出：A
    
    // 3. 字符串字面量：直接使用或赋值给const char*
    const char* s = "NOI2026"; // "NOI2026"是字符串字面量
    // s[0] = 'n'; // 错误！修改只读字面量会崩溃
    
    return 0;
}
```

### 4. 字符串字面量（字面量的子集，双引号包裹的字符序列）

#### **定义**：  

**字符串字面量**是字面量的一种，指用**双引号**包裹的字符序列（如 `"abc"`），是 C++ 中“只读的 C 风格字符串”。  
- **本质**：是`const char[]` 类型，编译器自动在末尾添加 `'\0'`；const表明其值是无法修改的；  
- **存储**：位于内存只读区，不可修改；  
- **考试场景**：常用于直接输出，初始化**字符数组**或**string 对象**；禁止直接修改。

**竞赛易错示例**：
```cpp
#include <iostream>
using namespace std;

int main() {
    // 正确用法1：直接输出
    cout << "GESP C++ 考试" << endl; // 输出：GESP C++ 考试
    
    // 正确用法2：初始化字符数组（拷贝到可写区）
    char arr[20] = "hello"; // 字面量内容拷贝到数组，数组可修改
    arr[0] = 'H';
    cout << arr << endl; // 输出：Hello
    
    // 正确用法3：初始化string对象（推荐）
    string s = "world"; // string自动拷贝字面量内容，可修改
    s += "!";
    cout << s << endl; // 输出：world!
    
    // 错误用法：直接修改字符串字面量
    char* p = "test"; // 编译器隐式转为const char*，仅兼容C语言
    // p[0] = 'T'; // 运行时崩溃（修改只读区）
    
    return 0;
}
```

### 5. string（C++标准字符串类）

#### **定义**：  

`string` 是 C++ 标准库（`<string>` 头文件）提供的**字符串类**，是对**字符数组**的封装，是考试和竞赛中**首选**的字符串处理方式。  
- **本质**：一个类创建的对象，封装了常用的字符串操作；
- **特性**：无需手动管理 `'\0'`，长度自动扩容，支持运算符重载（`+`/`=`/`==`），提供丰富的成员函数；  
- **考试场景**：相比字符数组(char []), string 对象更简洁、高效、少出错，substr、find、replace 等封装了常用的字符串操作，简单易用，编码效率高，而且不容易出错。

#### **示例**：

```cpp
#include <iostream>
#include <string> // 必须包含头文件
using namespace std;

int main() {
    // 初始化
    string s1 = "GESP";
    string s2("NOI");
    string s3; // 空字符串
    
    // 基础操作（运算符重载，竞赛高频）
    s3 = s1 + " " + s2; // 拼接：GESP NOI
    cout << s3 << endl;
    
    // 比较（直接用==/>/<）
    if (s1 == "GESP") cout << "相等" << endl; // 输出：相等
    
    // 成员函数（竞赛核心）
    cout << "长度：" << s3.size() << endl; // 输出：7（不含'\0'）
    cout << "第5个字符：" << s3[4] << endl; // 输出：N（下标从0开始）
    
    // 查找子串
    size_t pos = s3.find("NOI");
    if (pos != string::npos) cout << "NOI位置：" << pos << endl; // 输出：5
    
    // 截取子串（从pos开始，取len个字符）
    string sub = s3.substr(0, 4);
    cout << "子串：" << sub << endl; // 输出：GESP
    
    return 0;
}
```

##  小结

### 1. 核心概念的区别与关联

 * **核心定义**：**字符串**是抽象的字符序列，**字符数组**是字符串的C风格实现（需`'\0'`表明串的结束），**字面量**是直接写死的常量，**字符串字面量**是双引号包裹的只读字符序列（即字符串），string是C++封装的字符串类，可以创建string对象处理常用的字符串截取、合并、插入和查找替换等操作；
*  **关键区别**：字符数组需手动管理`'\0'`，string自动处理，字符串字面量只读，字面量是所有直接常量的统称；

| 概念     | 本质               | 存储属性      | 结束符`'\0'`   | 可修改性 | 操作便捷性       | 头文件        |
| ------ | ---------------- | --------- | ----------- | ---- | ----------- | ---------- |
| 字符串    | 抽象概念（字符序列）       | 无         | 无           | 无    | 无           | 无          |
| 字符数组   | char类型数组         | 栈/全局区（可写） | 需手动加        | 可修改  | 低（需调用C函数）   | 无需         |
| 字面量    | 直接写死的常量值         | 只读区       | 无（仅字符串字面量有） | 不可修改 | 仅能直接使用      | 无需         |
| 字符串字面量 | 只读的char数组（字面量子集） | 只读区       | 自动加         | 不可修改 | 仅能直接使用/拷贝   | 无需         |
| string | C++类（封装字符数组）     | 堆区（自动管理）  | 无需手动加       | 可修改  | 高（运算符+成员函数） | `<string>` |

### 2. 概念关联：  

   - 字符串（抽象）← 字符数组（C实现）/ string（C++实现）/ 字符串字面量（常量形式）；  
   - 字符串字面量（子集）← 字面量（父集）；  
   - string 底层基于字符数组实现，但封装了所有底层细节，对外暴露易用的操作函数。

### 3. 考试避坑点：  

   - 不要修改字符串字面量（如 `char* p = "abc"; p[0] = 'A';`），会崩溃；  
   - 字符数组作为字符串使用时，必须显示或隐式的补 `'\0'`，否则输出乱码；  
   - 优先用 string 而非字符数组，避免字符数组的底层陷阱，除非题目强制要求（如 GESP 基础题）；  
   - string 的 `size()`/`length()` 不包含 `'\0'`，字符数组的 `strlen()` 也不包含，但 `sizeof()` 包含。


这些概念是 GESP C++ 字符串考点的核心，厘清它们的区别后，能轻松应对选择题、编程题中的字符串的基本考点。中高级的考点，需要我们去熟练的掌握 string 类的用法，如： `insert()`、`erase()`、`replace()`、`delete()`、`find()`、`substr()`、`copy()`等成员函数，以及C风格的 `strcpy`, `strcmp`, `strcat`, `strlen`,`strlwr`, `strupr`, `strchr`等标准库函数。
